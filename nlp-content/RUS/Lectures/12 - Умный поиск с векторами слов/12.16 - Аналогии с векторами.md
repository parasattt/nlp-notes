### Арифметика с векторами слов

Разности векторов могут отражать отношения. В примере переход от `man` к `woman` примерно похож на переход от `king` к `queen`:

$$v_{\text{king}} - v_{\text{man}} + v_{\text{woman}} \approx v_{\text{queen}}$$

Здесь $v_{\text{word}}$ означает вектор данного слова. Начните с `king`, вычтите вектор `man`, прибавьте вектор `woman` и найдите близкое слово словаря. Это **словесная аналогия**.

Вызов gensim `most_similar(positive=[...], negative=[...])` выполняет сложение и вычитание. Функция ниже спрашивает: «a относится к b так же, как c к чему?», выполняя поиск около $b-a+c$.



Для каждой аналогии `positive=[b, c]` складывает два вектора, а `negative=[a]` вычитает один. `topn=1` возвращает один ближайший ответ.

```python
def analogy(a, b, c, kv=glove):
    # a is to b as c is to ?   ->   b - a + c
    return kv.most_similar(positive=[b, c], negative=[a], topn=1)[0][0]

print("man : king    = woman :", analogy("man", "king", "woman"))
print("walk : walked = swim  :", analogy("walk", "walked", "swim"))
print("france : paris = kazakhstan :", analogy("france", "paris", "kazakhstan"))
print("man : doctor  = woman :", analogy("man", "doctor", "woman"))
```


**Сохранённый вывод:**

```text
man : king    = woman : queen
walk : walked = swim  : swam
france : paris = kazakhstan : almaty
man : doctor  = woman : nurse
```



Первые два сохранённых ответа — `queen` и `swam` — соответствуют отношениям, о которых спрашивает пример.
