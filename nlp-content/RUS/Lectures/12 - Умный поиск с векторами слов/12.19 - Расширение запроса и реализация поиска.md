### Расширяем запрос перед поиском товаров

**Расширение запроса** добавляет близкие слова перед поиском. В примере сосед принимается только при косинусном сходстве не ниже **0.65**. Эта граница называется **порогом**.

Многоразовый класс `SynonymSearch` явно задаёт несколько решений:

- Загрузить модель один раз и передать в класс, не загружать для каждого запроса.
- Если слово неизвестно, искать его без расширения.
- Использовать **список исключений**, чтобы нежелательные соседи не добавлялись даже при прохождении порога.
- Использовать **кэш** для запоминания расширений. `most_similar` сравнивает с 400,000 векторов, поэтому повторное слово должно использовать прежний ответ.
- Разделить названия товаров на слова один раз при создании класса.

Дальше приведены полная реализация и сохранённые результаты поиска.



`expand` сначала проверяет кэш, сохраняет исходное слово, затем добавляет допустимых соседей из `topn=20` кандидатов. `search` объединяет расширения и проверяет пересечение с множествами слов товаров, подготовленными в конструкторе.

```python
class SynonymSearch:
    def __init__(self, vectors, catalogue, threshold=0.65, topn=20, block=()):
        self.vectors = vectors
        self.catalogue = catalogue
        self.threshold = threshold
        self.topn = topn
        self.block = set(block)
        self.product_words = [set(words_of(p)) for p in catalogue]   # cut each product name once
        self.cache = {}

    def expand(self, word):
        if word in self.cache:                       # answered before: reuse
            return self.cache[word]
        terms = [word]
        if word in self.vectors:                     # unknown word: no expansion
            terms += [w for w, s in self.vectors.most_similar(word, topn=self.topn)
                      if s >= self.threshold and w not in self.block]
        self.cache[word] = terms
        return terms

    def search(self, query):
        terms = {t for w in words_of(query) for t in self.expand(w)}
        return [p for p, words in zip(self.catalogue, self.product_words) if words & terms]

search = SynonymSearch(glove, catalogue)
print("terms for 'sofa':", search.expand("sofa"))
print()
for query in ["sofa", "desk", "sofaaa"]:
    print(f"{query!r:9} -> {search.search(query)}")
print()
print("nearest to 'desk':", [(w, round(s, 2)) for w, s in glove.most_similar("desk", topn=3)])
```
