### Проверяем модель по ясным ожиданиям

Перед выбором модели выпишите отношения, которые должны выполняться для вашей задачи. Следующий код проверяет ожидаемо близкие пары, далёкие пары и ответы аналогий. Для каждой проверки выводится успех, провал или пропуск, если слово неизвестно.



У близких пар сходство должно быть выше 0.5, у далёких — ниже 0.3. Проверки аналогий сравнивают предсказанную столицу с ожидаемым словом. Неизвестное слово отмечается как пропуск, чтобы отсутствие в словаре не приняли за успешную проверку.

```python
# kind "close":   similarity must be above 0.5
# kind "far":     similarity must be below 0.3
# kind "analogy": france : paris = a : expected
CHECKS = [
    ("close",   "sofa",       "couch",     None),
    ("close",   "waiter",     "server",    None),
    ("far",     "sofa",       "banana",    None),
    ("far",     "cheap",      "expensive", None),
    ("far",     "good",       "bad",       None),
    ("analogy", "kazakhstan", None,        "astana"),
    ("analogy", "japan",      None,        "tokyo"),
]

def run_checks(kv, name):
    print(name)
    for kind, a, b, expected in CHECKS:
        if a not in kv or (b and b not in kv):
            print(f"  SKIP  {a} / {b}: unknown word")
            continue
        if kind == "analogy":
            got = analogy("france", "paris", a, kv)
            ok, detail = got == expected, f"capital of {a}: got {got}, expected {expected}"
        else:
            s = kv.similarity(a, b)
            ok = s > 0.5 if kind == "close" else s < 0.3
            detail = f"{a} / {b} should be {kind}: {s:.2f}"
        print(f"  {'PASS' if ok else 'FAIL'}  {detail}")

run_checks(glove, "GloVe")
run_checks(yelp_vectors, "Yelp Word2Vec")
```


**Сохранённый вывод:**

```text
GloVe
  PASS  sofa / couch should be close: 0.68
  FAIL  waiter / server should be close: 0.07
  PASS  sofa / banana should be far: 0.22
  FAIL  cheap / expensive should be far: 0.77
  FAIL  good / bad should be far: 0.77
  FAIL  capital of kazakhstan: got almaty, expected astana
  PASS  capital of japan: got tokyo, expected tokyo
Yelp Word2Vec
  PASS  sofa / couch should be close: 0.83
  PASS  waiter / server should be close: 0.94
  PASS  sofa / banana should be far: 0.27
  FAIL  cheap / expensive should be far: 0.68
  FAIL  good / bad should be far: 0.69
  SKIP  kazakhstan / None: unknown word
  FAIL  capital of japan: got carlo, expected tokyo
```



#### Разбираем проверки

- **Обе модели сближают противоположности.** Провалы `cheap`/`expensive` и `good`/`bad` повторяют ограничение общих контекстов из маленького примера.
- **GloVe даёт `waiter`/`server` оценку 0.07.** В его новостях и Wikipedia `server` часто относится к компьютеру. Один вектор смешивает эти значения. Аналогия столицы Казахстана также не даёт ожидаемого правильного ответа.
- **Yelp Word2Vec проходит проверки синонимов**, но отвечает на столицу Японии `carlo`, связанное с Monte Carlo. Отзывы о ресторанах — плохой материал для обучения аналогиям столиц.

Знания модели зависят от прочитанного текста. Для мебельного магазина дальше нужно проверить, знает ли она вообще слова покупательских запросов.



```python
furniture_queries = ["sofa", "couch", "armchair", "recliner", "bookshelf", "wardrobe",
                     "dresser", "nightstand", "ottoman", "mattress", "headboard", "loveseat"]

for name, kv in [("GloVe", glove), ("Yelp Word2Vec", yelp_vectors)]:
    missing = [w for w in furniture_queries if w not in kv]
    print(f"{name:14} knows {len(furniture_queries) - len(missing):2} of {len(furniture_queries)}   missing: {missing}")
```


**Сохранённый вывод:**

```text
GloVe          knows 12 of 12   missing: []
Yelp Word2Vec  knows  8 of 12   missing: ['armchair', 'recliner', 'bookshelf', 'headboard']
```



GloVe содержит все двенадцать проверяемых мебельных слов. В Yelp отсутствуют четыре: `armchair`, `recliner`, `bookshelf` и `headboard`. В отзывах о ресторанах редко обсуждают мебель, а векторная модель не умеет расширять слово вне своего словаря.

Для этого каталога пример выбирает GloVe, помня, что связанные слова и противоположности могут давать плохие расширения.

Лекция утверждает, что в этой GloVe нет казахских слов. Для упражнения на казахском она предлагает обучить векторы на казахском тексте тем же способом.
