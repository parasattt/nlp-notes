### Простой поиск по ключевым словам

Начнём с маленького каталога. Разделим название товара на слова и вернём товар, если его множество слов пересекается со множеством слов запроса. Код ниже содержит весь пример каталога и функцию поиска.



`words_of` переводит текст в нижний регистр и извлекает последовательности букв ASCII. `keyword_search` превращает слова запроса и товара в множества, затем через `&` проверяет пересечение. Проверяются общие слова, а не общий смысл.

```python
catalogue = [
    "Grey three-seat couch with cushions",
    "Corner couch, beige fabric",
    "Oak dining table for six",
    "Leather recliner armchair",
    "Kitchen chair, set of 4",
    "Queen size mattress, memory foam",
    "Bookshelf with five shelves",
    "Glass coffee table",
]

def words_of(text):
    return re.findall(r"[a-z]+", text.lower())      # "Corner couch, beige" -> ["corner", "couch", "beige"]

def keyword_search(query, catalogue):
    q = set(words_of(query))
    return [p for p in catalogue if q & set(words_of(p))]    # & = words they have in common

for query in ["couch", "sofa", "table", "desk"]:
    print(f"{query!r:8} -> {keyword_search(query, catalogue)}")
```


**Сохранённый вывод:**

```text
'couch'  -> ['Grey three-seat couch with cushions', 'Corner couch, beige fabric']
'sofa'   -> []
'table'  -> ['Oak dining table for six', 'Glass coffee table']
'desk'   -> []
```



Сохранённый поиск находит оба товара с диванами по `couch`, но ничего по `sofa`. По `desk` он тоже ничего не возвращает.

Список синонимов, составленный вручную, исправил бы отдельные случаи, но не охватил бы все запросы. Следующая цель — по тексту выучить связь `sofa` и `couch`.
