Со списком исключений остаются только два товара с диванами. Следующий эксперимент очищает кэш, измеряет первый поиск `table`, затем усредняет время 1,000 повторных поисков.



```python
search.cache.clear()
start = time.perf_counter()
search.search("table")
first = time.perf_counter() - start

start = time.perf_counter()
for _ in range(1000):
    search.search("table")
cached = (time.perf_counter() - start) / 1000

print(f"first time : {first * 1000:.1f} ms")
print(f"from cache : {cached * 1000:.3f} ms")
```


**Сохранённый вывод:**

```text
first time : 3.3 ms
from cache : 0.001 ms
```



Сохранённый первый поиск занимает несколько миллисекунд; поиск из кэша — около тысячной доли миллисекунды. Повторяющиеся запросы покупателей делают кэш полезным.

#### Перед использованием поиска на настоящем сайте

- Выбирайте порог по настоящим запросам покупателей, а не по одному слову-примеру.
- Пополняйте список исключений после изучения поисков, которые не привели к кликам.
- При смене модели снова выполняйте проверки.
- Для применений, влияющих на людей, например работы, кредитов или жилья, проверяйте предвзятость модели.

Этот пример расширяет отдельные слова. Источник анонсирует блокнот 14: в нём усредняются векторы слов отзыва, чтобы получить один вектор отзыва, а затем обучается классификатор. Этого блокнота среди предоставленных источников нет.
