### Обучаем один раз, затем загружаем для поиска

Обучение занимает время, но поисковому запросу нужен быстрый ответ. Сохраняйте обученные объекты в файлы и загружайте при запуске сервиса, а не обучайте заново для каждого запроса.

`w2v.wv` содержит только векторы слов — центральные векторы $v$ маленькой модели. Для этого примера поиска их достаточно.



Первое сохранение оставляет полную модель с возможностью продолжить обучение. Второе сохраняет только векторы слов. `size_mb` считает все файлы с общим префиксом, потому что gensim может записывать большие массивы в дополнительные файлы.

```python
w2v.save("yelp_w2v.model")                  # everything, so training can continue later
w2v.wv.save("yelp_vectors.kv")              # only the word vectors

def size_mb(prefix):
    # gensim may write big arrays to extra files with the same name prefix
    return sum(os.path.getsize(f) for f in os.listdir(".") if f.startswith(prefix)) / 1e6

print(f"full model  : {size_mb('yelp_w2v.model'):.1f} MB")
print(f"vectors only: {size_mb('yelp_vectors.kv'):.1f} MB")

from gensim.models import KeyedVectors
yelp_vectors = KeyedVectors.load("yelp_vectors.kv")
print(f"loaded {len(yelp_vectors):,} word vectors")
```


**Сохранённый вывод:**

```text
full model  : 16.8 MB
vectors only: 8.7 MB
loaded 20,184 word vectors
```



Сохранённые файлы только с векторами примерно вдвое меньше полной модели. Полная модель также содержит векторы соседей $u$, необходимые для продолжения обучения, но не для этого поиска.
