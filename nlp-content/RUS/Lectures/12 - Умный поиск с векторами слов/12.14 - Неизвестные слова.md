### Слово вне словаря

Обученная модель оставила только слова, встреченные хотя бы пять раз, согласно `min_count`. Опечатки вроде `sofaaa` может не оказаться в словаре. Поиск вектора неизвестного слова вызывает ошибку, показанную в сохранённом примере ниже.



```python
query = "sofaaa"
try:
    yelp_vectors.most_similar(query)
except KeyError as e:
    print("KeyError:", e)

print(query in yelp_vectors, "pizza" in yelp_vectors)     # check first, then ask
```


**Сохранённый вывод:**

```text
KeyError: "Key 'sofaaa' not present in vocabulary"
False True
```

Проблема словаря связана с темой [[RUS/Lectures/4 - Токенизация/4.9 - Неизвестные слова и подсловная токенизация|неизвестные слова и subword tokenization]], где используется другой способ представления незнакомых целых слов.



Проверяйте `word in vectors` перед поиском соседей. Для неизвестного слова поиск может использовать исходное слово без расширения.
