### Используем готовую обученную модель

Наша модель читала только отзывы о ресторанах. Обучение на миллиардах слов требует больше вычислительных ресурсов. **Предобученная модель** — модель, которую другая группа уже обучила и опубликовала.

Источник использует **GloVe** (Stanford, 2014): шесть миллиардов слов из Wikipedia и новостей, словарь из 400,000 слов, по 100 значений на вектор. GloVe обучается иначе, чем Word2Vec, но векторы используются теми же функциями поиска и сходства.

Источник описывает модель размером 128 MB и загрузку примерно за 30 секунд. Следующий код загружает опубликованные файлы и изучает несколько слов.



```python
base = "https://huggingface.co/fse/glove-wiki-gigaword-100/resolve/main/"
for name in ["glove-wiki-gigaword-100.model", "glove-wiki-gigaword-100.model.vectors.npy"]:
    if not os.path.exists(name):
        urllib.request.urlretrieve(base + name, name)

glove = KeyedVectors.load("glove-wiki-gigaword-100.model")
print(f"{len(glove):,} words, {glove.vector_size} numbers each")

for word in ["sofa", "almaty", "apple", "python"]:
    print(f"{word:7} -> {', '.join(w for w, _ in glove.most_similar(word, topn=8))}")
```


**Сохранённый вывод:**

```text
400,000 words, 100 numbers each
sofa    -> couches, sofas, recliner, cushions, upholstered, couch, mattress, pillows
almaty  -> ashgabat, ulan, bator, ashkhabad, kazakhstan, dushanbe, kazakstan, kazakh
apple   -> microsoft, ibm, intel, software, dell, pc, macintosh, iphone
python  -> monty, php, perl, cleese, flipper, ruby, spamalot, javascript
```



Среди соседей GloVe для `sofa` есть `couches`, `sofas` и `couch` — это полезно для поиска.

Примеры `apple` и `python` показывают ограничение. `apple` близко к компьютерным компаниям, а не фруктам. `python` близко к языкам программирования и Monty Python. У каждого слова **один вектор**, поэтому разные употребления смешаны, а более частые влияют сильнее.
