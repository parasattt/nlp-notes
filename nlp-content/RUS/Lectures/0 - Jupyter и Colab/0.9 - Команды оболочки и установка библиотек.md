### Команды оболочки и установка библиотек

Строка, начинающаяся с `!`, передаётся **командной оболочке** машины, а не обрабатывается как Python. В блокноте обычная машина Colab описывается как машина с Linux.

Первый пример запрашивает версию Python. Второй показывает установку библиотеки. В блокноте сказано, что Colab уже содержит нужные для курса библиотеки, поэтому установка может сообщить, что требование уже выполнено.



```python
!python --version
```



```python
# Colab already has the libraries we need for this course, so this will just say
# "already satisfied". This is how you would install something new.
!pip install pandas --quiet
print("done")
```

`!python --version` запрашивает версию Python в среде. `!pip install pandas --quiet` показывает установку пакета, причём `--quiet` сокращает обычные служебные сообщения. Последняя строка Python вывела бы `done`. В исходнике ни у одной из этих ячеек нет сохранённого вывода, поэтому здесь не добавлен новый результат.
