### Файлы в Colab

**Машина Colab временная**. После периода бездействия сеанс может быть удалён, а файлы на этой машине — исчезнуть. Файл блокнота в Google Drive сохранится, но файлы, созданные кодом, нужно отдельно сохранить или скачать.

Пишите блокнот так, чтобы он мог заново создать нужные данные с нуля. Следующие ячейки показывают запись небольшого текстового файла и последующее чтение.



```python
# Write a small text file to the temporary machine.
with open("example.txt", "w", encoding="utf-8") as f:
    f.write("First line of the file.\n")
    f.write("Second line of the file.\n")

print("File written.")
```


**Сохранённый вывод:**

```text
File written.
```



```python
# Read it back.
with open("example.txt", "r", encoding="utf-8") as f:
    content = f.read()

print(content)
```


**Сохранённый вывод:**

```text
First line of the file.
Second line of the file.

```

В ячейке записи `"w"` открывает файл для записи, а каждый `\n` завершает строку. В ячейке чтения `"r"` открывает файл для чтения, а `read()` возвращает всё содержимое одной строкой. В обоих случаях указан UTF-8, а `with` закрывает файл после завершения блока. Другие примеры есть в теме [[RUS/Lectures/1 - Основы Python для работы с текстом/1.19 - Чтение и запись текстовых файлов|чтение и запись текстовых файлов]].



```python
# List the files on the machine. You should see example.txt in there.
!ls -la
```

`!ls -la` подробно перечисляет файлы, включая скрытые. В исходнике сохранён очень большой список из личной локальной папки, а не чистый пример Colab. Не относящиеся к уроку имена файлов здесь намеренно опущены. Главная задача — просмотреть файлы сеанса и найти созданный выше `example.txt`; временные файлы сеанса нужно заново создавать или сохранять в другом месте.



**Значок папки** в левой боковой панели Colab открывает панель файлов. Перетащите туда файлы для загрузки либо нажмите на файл правой кнопкой мыши, чтобы скачать его.
