#### Где возникают проблемы: выполнение не по порядку

Состояние блокнота зависит от **порядка, в котором вы запускали ячейки**, а не только от их расположения на экране. Python позволяет запустить ячейку 10, затем 3, затем 7.

Поэтому блокнот может работать у автора, но давать сбой у человека, который открыл его и запустил сверху вниз. В сеансе автора могут оставаться значения от прежних запусков, которых нет в новом сеансе.

Следующая демонстрация специально показывает эту проблему: сначала присвойте `total` ноль, затем несколько раз запустите ячейку, увеличивающую значение.



```python
# Run this cell FIRST.
total = 0
```



```python
# Then run this one a few times in a row. Watch the number change each time.
total = total + 1
print("total is now:", total)
```


**Сохранённый вывод:**

```text
total is now: 1
```

Каждый запуск прибавляет единицу к текущему значению `total`. Сохранённый вывод отражает один запуск после сброса и показывает `1`; он не означает, что весь блокнот был заново выполнен с начала.



Если после сброса трижды запустить ячейку с увеличением, `total` станет равна 3. Человек, который один раз запустит блокнот в новом сеансе, получит 1. По одной видимой ячейке нельзя узнать, сколько раз её запускали.

Выработайте привычку: закончив работу, выберите **Runtime → Restart session and run all**. Проверьте, что блокнот работает с чистого состояния и в порядке расположения ячеек. Результат **воспроизводим**, если новый запуск с чистого состояния позволяет получить его снова. Если блокноту нужна скрытая история сеанса, результат пока нельзя считать воспроизводимым.
