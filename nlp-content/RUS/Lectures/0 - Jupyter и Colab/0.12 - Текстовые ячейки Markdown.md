### Несколько слов о Markdown: текстовые ячейки

Дважды нажмите на текстовую ячейку, чтобы увидеть исходный Markdown. Нажмите **Shift + Enter**, чтобы снова показать оформленный текст.

В блокноте используются следующие основные формы:

```markdown
# Big heading
## Smaller heading

**bold**   *italic*   `code`

- bullet
- another bullet

1. numbered
2. list
```

В текстовых ячейках объясняйте ход решения домашней работы: это объяснение влияет на оценку. Блокнот, содержащий только код, трудно читать, а анализ без пояснений легко понять неправильно.
