### Добавление и перемещение ячеек

- Наведите указатель между ячейками, чтобы появились кнопки **+ Code** и **+ Text**, затем выберите тип новой ячейки.
- Чтобы удалить ячейку, выберите её и нажмите **значок корзины** на панели инструментов.

Перед использованием этих сочетаний нажмите **Esc**, чтобы выйти из редактирования текста и перейти в командный режим:

| Клавиши | Действие |
|---|---|
| `Esc`, затем `a` | вставить ячейку **выше** |
| `Esc`, затем `b` | вставить ячейку **ниже** |
| `Esc`, затем `d d` | **удалить** ячейку; нажмите `d` дважды |
| `Esc`, затем `z` | отменить удаление ячейки |
| `Ctrl + M M` | преобразовать ячейку в текстовую (Markdown) |
| `Shift + Enter` | запустить ячейку и перейти к следующей |
| `Ctrl + Enter` | запустить ячейку и остаться в ней |

Потренируйтесь: вставьте ниже новую ячейку и выведите в ней своё имя.
