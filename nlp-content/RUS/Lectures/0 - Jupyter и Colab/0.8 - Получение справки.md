### Получение справки прямо в блокноте

Следующие ячейки показывают три полезных инструмента: документацию через `?` или `help()`, доступные методы через `dir()` и тип значения через `type()`.



```python
# 1. A question mark shows the documentation for anything.
#    In Colab this opens a help panel at the bottom of the screen.
#    Run it and look down there - the output area here stays empty.
str.upper?
```



```python
# help() does the same thing but prints inline, so it works everywhere.
help(str.upper)
```


**Сохранённый вывод:**

```text
Help on method_descriptor:

upper(self, /) unbound builtins.str method
    Return a copy of the string converted to uppercase.

```

`str.upper?` — специальный синтаксис справки для блокнотов. `help(str.upper)` печатает документацию прямо в выводе. В сохранённом описании сказано, что `.upper()` возвращает копию строки в верхнем регистре.



```python
# 2. dir() lists everything you can do with an object.
#    Ignore the names starting with underscores for now.
text = "hello"
[name for name in dir(text) if not name.startswith("_")]
```

`dir(text)` перечисляет доступные атрибуты и методы строки. Генератор списка исключает имена, начинающиеся с `_`, и оставляет методы для обычного использования. Сохранён полный список, поэтому можно посмотреть, например, `lower`, `split`, `strip` и `upper`.



```python
# 3. type() tells you what something is. When confused, always ask this first.
print(type("hello"))
print(type(5))
print(type([1, 2, 3]))
```


**Сохранённый вывод:**

```text
<class 'str'>
<class 'int'>
<class 'list'>
```

Три значения имеют типы `str` (текст), `int` (целое число) и `list` (упорядоченная коллекция). Проверка типов — полезный первый шаг при отладке. Эти типы объясняются в теме [[RUS/Lectures/1 - Основы Python для работы с текстом/1.1 - Переменные и типы|переменные и типы]].



Colab также поддерживает **автодополнение по Tab**. Введите `text.` и нажмите **Tab**, чтобы увидеть доступные методы. Пользуйтесь этим регулярно: запоминать названия всех методов не нужно.
