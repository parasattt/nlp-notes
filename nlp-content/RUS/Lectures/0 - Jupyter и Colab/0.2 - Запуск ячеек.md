### Запуск первой ячейки

Нажмите на ячейку кода один раз, чтобы выбрать её. Затем воспользуйтесь любым из способов:

- **Shift + Enter** запускает ячейку и переходит к следующей.
- **Ctrl + Enter** запускает ячейку и оставляет её выбранной.
- **Кнопка запуска** слева запускает ячейку.

В блокноте предлагается попробовать это на следующей ячейке.



```python
print("Hello. The notebook is working.")
test = 10
```


**Сохранённый вывод:**

```text
Hello. The notebook is working.
```

`print()` выводит приветствие. `test = 10` также создаёт переменную, доступную последующим ячейкам, хотя само присваивание не выводит результат.



Первый запуск ячейки в Colab может занять несколько секунд: Colab запускает для вашего сеанса машину в центре обработки данных Google. Следующие ячейки обычно начинают выполняться быстрее.

Вращающийся кружок рядом с ячейкой означает, что она ещё выполняется. Число вроде `[1]` означает, что выполнение завершено. Это **номер выполнения** ячейки: он показывает порядок запусков, который может отличаться от порядка ячеек на странице.
