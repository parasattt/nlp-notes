### Сохранение работы

Colab автоматически сохраняет блокноты в Google Drive. Но привычка нажимать **Ctrl + S** всё равно полезна.

- **File → Save a copy in Drive** создаёт собственную редактируемую копию. Делайте это, когда преподаватель делится блокнотом, чтобы ваши правки оставались в копии, которую можно сохранить.
- **File → Download → .ipynb** сохраняет файл блокнота на компьютере. Именно этот файл нужно сдавать.
