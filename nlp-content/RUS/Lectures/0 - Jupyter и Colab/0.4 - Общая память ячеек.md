### Ячейки используют общую память

Все ячейки выполняются в одном сеансе Python. Переменную, созданную в одной ячейке, можно использовать в другой. Это удобно, но означает, что порядок выполнения имеет значение.

В блокноте предлагается запустить следующие две ячейки по порядку. Первая создаёт `sentence`, а вторая читает ту же переменную.



```python
sentence = "Natural language processing is mostly text cleaning."
```



```python
# This cell knows about `sentence` even though we never defined it here.
print(sentence)
test = 20
print("Number of characters:", len(sentence))
```


**Сохранённый вывод:**

```text
Natural language processing is mostly text cleaning.
Number of characters: 52
```

Вторая ячейка читает `sentence` из общей памяти сеанса и показывает длину строки с учётом пробелов и знаков препинания: **52 символа**. Она также меняет `test` на 20. Если снова запустить более раннюю ячейку, это изменение может повлиять на её результат.
