### Ваша очередь

Добавьте новые ячейки и выполните небольшое упражнение:

1. Создайте переменную `my_name` со своим именем.
2. Выведите предложение, использующее её, например `My name is Aisha and it has 5 letters.` Для числа букв используйте `len(my_name)`.
3. Добавьте под кодом **текстовую ячейку** с одним предложением о том, что вы сделали.
4. Выберите **Runtime → Restart session and run all** и проверьте, что блокнот работает в чистом сеансе.

Шаг 4 — главное упражнение: он проверяет воспроизводимость. Предыдущие шаги создают небольшой пример для этой проверки.
