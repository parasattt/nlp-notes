### Последняя строка выводится автоматически

В обычном скрипте Python для вывода значения обычно вызывают `print()`. В блокноте значение выражения на **последней строке** ячейки показывается автоматически.

Это автоматическое отображение относится только к последнему выражению. Если нужно показать несколько результатов, используйте `print()`.



```python
2 + 2 + test
```


**Сохранённый вывод:**

```text
14
```

Сохранённый результат равен `14`: выражение использует `test`, которой в предыдущей ячейке присвоено значение 10. Если изменить эту переменную до запуска данной ячейки, результат тоже может измениться.



```python
# But only the LAST line. This cell shows just 20, not 10 and 20.
5 + 5
10 + 10
```


**Сохранённый вывод:**

```text
20
```

Вычисляются оба выражения, но автоматически выводится только значение последнего — `20`.



```python
# If you want to see both, print them explicitly.
print(5 + 5)
print(10 + 10)
```


**Сохранённый вывод:**

```text
10
20
```

Здесь два явных вызова `print()`, поэтому видны оба результата: сначала `10`, затем `20`.
