### Градиенттік түсу

Градиент — әр параметр бойынша туындылар жиыны. Жаңарту: w ← w − η∂L/∂w, b ← b − η∂L/∂b; η — learning rate. Бастапқыда loss тез төмендеуі мүмкін, ал минимумға жақындағанда градиент кішірейеді. Контур диаграммасы w мен b бойынша жолды көрсетеді.

```python
def gradient_descent(lr, steps, w=0.0, b=0.0):
    path = [(w, b)]
    for _ in range(steps):
        sw, sb = slopes(w, b)
        w, b = w - lr * sw, b - lr * sb
        path.append((w, b))
    return np.array(path)

path = gradient_descent(lr=0.02, steps=1000)
for step in [0, 1, 2, 5, 20, 100, 1000]:
    w, b = path[step]
    print(f"step {step:4}:  w = {w:6.2f}   b = {b:5.2f}   MSE = {mse(predict(x, w, b), y):8.2f}")
```
