### Қалдық MSE және MAE

Қалдық = болжам − нақты мән. MAE — абсолют қалдықтардың орташа мәні, бастапқы өлшем бірлігінде; MSE — квадрат қалдықтардың орташа мәні және үлкен қателерді күштірек жазалайды. w=12, b=0 және w=10, b=2 нұсқаларын салыстырып, loss неге қажет екенін көріңіз.

```python
def predict(x, w, b):
    return w * x + b

def mse(y_pred, y_true):
    return np.mean((y_pred - y_true) ** 2)

def mae(y_pred, y_true):
    return np.mean(np.abs(y_pred - y_true))

for w, b in [(12, 0), (10, 0), (10, 2)]:
    y_hat = predict(x, w, b)
    print(f"w = {w:2}, b = {b}:  predictions {y_hat}   MAE {mae(y_hat, y):.2f}   MSE {mse(y_hat, y):.2f}")
```
