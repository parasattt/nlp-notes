### Yelp деректері және baseline

Yelp пікірлерінен 15 000 жазба алынып, бөлек train және test жиындары жасалады. Тестке қарамас бұрын қарапайым baseline құрыңыз: әр пікірге train бағаларының орташа мәнін болжау. Ноутбуктегі test MAE шамамен 1.17 жұлдыз; күрделі модель осы көрсеткішпен салыстырылады.

```python
url = ("https://huggingface.co/datasets/Yelp/yelp_review_full/resolve/main/"
       "yelp_review_full/test-00000-of-00001.parquet")

yelp = pd.read_parquet(url).sample(15000, random_state=0).reset_index(drop=True)
yelp["stars"] = yelp["label"] + 1                  # the file stores 0-4; we want 1-5 stars
y_train_df, y_test_df = yelp.iloc[:12000], yelp.iloc[12000:]

print("train:", len(y_train_df), " test:", len(y_test_df))
print(yelp["stars"].value_counts().sort_index().to_dict())
```

**Сохранённый результат:**

```text
train: 12000  test: 3000
{1: 2947, 2: 2988, 3: 3000, 4: 3059, 5: 3006}
```

```python
for stars in [1, 3, 5]:
    text = y_test_df[y_test_df["stars"] == stars]["text"].iloc[0]
    text = text.replace("\\n", " ")              # the file stores line breaks as the two characters \n
    print(f"{stars} stars: {text[:220]}...\n")
```

**Сохранённый результат:**

```text

```

```python
avg = y_train_df["stars"].mean()
baseline_pred = np.full(len(y_test_df), avg)
print(f"average training rating: {avg:.2f}")
print(f"baseline MAE on test   : {mae(baseline_pred, y_test_df['stars']):.3f} stars")
```

**Сохранённый результат:**

```text
average training rating: 3.01
baseline MAE on test   : 1.173 stars
```
