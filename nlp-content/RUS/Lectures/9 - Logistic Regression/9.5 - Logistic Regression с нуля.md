## Обучаем веса всего словаря и смещение

Теперь тот же метод использует все признаки TF-IDF: по одному весу на слово словаря и отдельное смещение. Положительные метки становятся 1, отрицательные — 0.

Разбиение оставляет для теста 25% из 120 отзывов: 90 обучающих и 30 тестовых. `stratify=y` сохраняет баланс классов, а `random_state=0` делает разбиение воспроизводимым. Векторизатор обучается только на обучающих текстах, затем преобразует тестовые тексты с уже полученным словарём.

В `w` каждому признаку сначала соответствует нулевой вес, `b` начинается с 0, а `step_size=1.0` задаёт размер обновления. На каждой итерации код:

1. Вычисляет `X_tr @ w + b` и применяет sigmoid для текущих вероятностей положительного класса.
2. Вычитает истинные метки и получает `error`.
3. Обновляет каждый вес по средней ошибке, умноженной на соответствующий признак.
4. Обновляет смещение по средней ошибке, поскольку смещение влияет на каждый отзыв.
5. Записывает потерю, accuracy на обучении и на тесте, чтобы сравнить их поведение.

Код сохранён без изменений. В частности, `p` вычисляется до обновления текущей итерации и используется для записи обучающей потери и accuracy; тестовая accuracy считается по обновлённым весам. При преобразовании ни одна ячейка не запускалась.



```python
y = np.array([1 if l == "positive" else 0 for l in review_labels])

tr_txt, te_txt, y_tr, y_te = train_test_split(
    reviews, y, test_size=0.25, random_state=0, stratify=y
)

tfidf = TfidfVectorizer()
X_tr = tfidf.fit_transform(tr_txt).toarray()
X_te = tfidf.transform(te_txt).toarray()

w = np.zeros(X_tr.shape[1])   # one weight per word, all starting at zero
b = 0.0
step_size = 1.0
history = []

for step in range(1, 2001):
    p = sigmoid(X_tr @ w + b)                  # current predictions
    error = p - y_tr                           # how wrong, and in which direction
    w -= step_size * X_tr.T @ error / len(y_tr)
    b -= step_size * error.mean()

    loss = -np.mean(y_tr * np.log(p) + (1 - y_tr) * np.log(1 - p))
    train_acc = ((p > 0.5) == y_tr).mean()
    test_acc = ((sigmoid(X_te @ w + b) > 0.5) == y_te).mean()
    history.append((step, loss, train_acc, test_acc))
    if step in (1, 10, 100, 500, 1000, 2000):
        print(f"step {step:4}  loss {loss:.4f}  train acc {train_acc:.2f}  test acc {test_acc:.2f}")

print()
print("vocabulary:", X_tr.shape[1], "words   test set:", len(y_te), "reviews")
```
