## Поможет ли больше обучающих данных

Notebook ссылается на Ng и Jordan (2002): Naive Bayes может достичь хорошего качества на меньшем количестве данных, а Logistic Regression способна улучшаться дальше, если данных достаточно. Здесь это утверждение источника, которое проверяется кривыми обучения.

**Кривая обучения** показывает тестовое качество при разных размерах обучающего набора. Следующий код использует 16, 32, 48, 64, 80 и 96 обучающих отзывов. При каждом размере он усредняет результаты пяти фолдов, затем пяти перемешиваний. Сравнение кривых показывает, продолжает ли добавление данных помогать.



```python
from sklearn.model_selection import learning_curve

sizes = [16, 32, 48, 64, 80, 96]
plt.figure(figsize=(6, 3.2))
for name in ["NB  + counts", "LR  + tf-idf"]:
    curves = []
    for s in range(5):
        _, _, test_scores = learning_curve(
            setups[name], reviews, review_labels, train_sizes=sizes,
            cv=StratifiedKFold(5, shuffle=True, random_state=s),
            shuffle=True, random_state=s,
        )
        curves.append(test_scores.mean(axis=1))
    mean_curve = np.mean(curves, axis=0)
    print(f"{name:14}", "  ".join(f"{n}:{v:.3f}" for n, v in zip(sizes, mean_curve)))
    plt.plot(sizes, mean_curve, "o-", label=name.replace("  ", " "))
plt.xlabel("training reviews"); plt.ylabel("cross-validated accuracy")
plt.title("Learning curve on our 120 reviews")
plt.legend()
plt.tight_layout()
plt.show()
```


**Сохранённый вывод:**

```text
NB  + counts   16:0.532  32:0.585  48:0.617  64:0.648  80:0.660  96:0.658
LR  + tf-idf   16:0.522  32:0.555  48:0.598  64:0.618  80:0.628  96:0.648
```

Сохранённая кривая LR всё ещё растёт при 96 обучающих отзывах: с 0.522 для 16 отзывов до 0.648 для 96. Naive Bayes растёт с 0.532 до 0.658 и становится пологой около 80 отзывов.

Увеличение обучающего набора с 16 до 96 добавляет примерно двенадцать процентных пунктов обеим моделям. Смена модели меняет оценку всего примерно на один-два пункта. По этим результатам количество обучающих данных гораздо важнее выбора между этими классификаторами.

Для реального проекта в такой ситуации источник рекомендует собрать больше отзывов. Позднее пример Amazon проверяет такое изменение в гораздо большем масштабе.
