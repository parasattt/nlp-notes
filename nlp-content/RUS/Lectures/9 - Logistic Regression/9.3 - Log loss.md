## Измеряем ошибки вероятностей с помощью log loss

Чтобы обучать веса, модели нужно число, показывающее, насколько ошибочны её текущие вероятности. Источник использует **log loss**:

$$\text{loss} = -\log(\text{probability the model gave to the correct answer})$$

Сначала берём вероятность истинного класса, затем её натуральный логарифм, затем меняем знак. Чем выше вероятность правильного ответа, тем меньше потеря. Очень маленькая вероятность правильного ответа означает большую потерю.

Представьте прогноз «99% солнце», после которого пошёл дождь. Это хуже, чем прогноз «50/50» перед тем же дождём. Оба могут дать неверную метку, но только первый уверенно ошибается. Log loss учитывает эту разницу. Следующая сохранённая таблица показывает точный штраф для разных вероятностей правильного класса.



```python
for p_correct in [0.99, 0.9, 0.6, 0.5, 0.1, 0.01, 0.001, 0.0001, 0.00001, 0.000001, 0.0000001]:
    print(f"gave the correct class {p_correct:4} -> loss {-np.log(p_correct):.3f}")
```


**Сохранённый вывод:**

```text
gave the correct class 0.99 -> loss 0.010
gave the correct class  0.9 -> loss 0.105
gave the correct class  0.6 -> loss 0.511
gave the correct class  0.5 -> loss 0.693
gave the correct class  0.1 -> loss 2.303
gave the correct class 0.01 -> loss 4.605
gave the correct class 0.001 -> loss 6.908
gave the correct class 0.0001 -> loss 9.210
gave the correct class 1e-05 -> loss 11.513
gave the correct class 1e-06 -> loss 13.816
gave the correct class 1e-07 -> loss 16.118
```



Вероятность правильного класса 0.99 даёт потерю всего 0.010. При 0.5 потеря равна 0.693. При 0.01 она достигает 4.605: это уверенно ошибочный прогноз «99% солнце» во время дождя. Сохранённая таблица продолжается до `1e-07`, где потеря равна 16.118.

Таким образом, log loss оценивает и уверенность, и правильность победившего класса. При обучении веса будут меняться так, чтобы уменьшить **среднюю** потерю на обучающих примерах.
