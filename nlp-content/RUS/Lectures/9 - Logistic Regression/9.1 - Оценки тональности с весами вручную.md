## Начнём с весов, выбранных вручную

Зададим словам тональности положительные или отрицательные веса. Для каждого отзыва сложим веса его слов и посмотрим на знак результата. Это первая простая версия взвешенной суммы, которую Logistic Regression позже научится вычислять с весами из данных.



`hand_score` переводит отзыв в нижний регистр, выделяет части, похожие на слова, с помощью показанного regex и складывает веса из словаря. Слова вне словаря добавляют ноль. Напечатанные оценки показывают ошибки правил.

```python
WEIGHTS = {
    "great": 2, "excellent": 2, "perfect": 2, "love": 2, "happy": 1.5,
    "good": 1, "recommend": 1,
    "broke": -2, "terrible": -2, "waste": -2, "disappointed": -2,
    "poor": -1.5, "cheap": -1, "not": -1,
}

def hand_score(text):
    return sum(WEIGHTS.get(w, 0) for w in re.findall(r"\w+", text.lower()))

for t in [
    "excellent product works perfectly very happy with this purchase",
    "terrible quality broke after two days waste of money",
    "Not good. The screen flickers constantly.",
    "Not bad at all for the price, I'm pleasantly surprised :)",
    "Returned it the next day.",
]:
    print(f"{hand_score(t):5}  {t}")
```


**Сохранённый вывод:**

```text
  3.5  excellent product works perfectly very happy with this purchase
   -6  terrible quality broke after two days waste of money
    0  Not good. The screen flickers constantly.
   -1  Not bad at all for the price, I'm pleasantly surprised :)
    0  Returned it the next day.
```



Первые две сохранённые оценки подходят отзывам: `3.5` для явной похвалы и `-6` для явной жалобы. Следующие три показывают разные проблемы:

- `Not good. The screen flickers constantly.` получает 0: `not` добавляет -1, а `good` добавляет +1, и они взаимно уничтожаются.
- `Not bad at all ...` — положительный отзыв, но получает -1. `bad` отсутствует в словаре весов, а `not` добавляет отрицательный вес.
- В `Returned it the next day.` нет выбранного слова, поэтому оценка тоже равна 0.

Следующая ячейка проверяет, у скольких отзывов ручная оценка равна нулю.



```python
scores = [hand_score(r) for r in reviews]

print("reviews containing no weighted word:", sum(s == 0 for s in scores), "of", len(reviews))
```


**Сохранённый вывод:**

```text
reviews containing no weighted word: 66 of 120
```



Сохранённый результат — 66 нулевых оценок из 120, то есть больше половины. В подписи вывода эти отзывы названы «не содержащими ни одного слова с весом», но код проверяет `s == 0`. Как показывает `not good`, выбранные слова также могут взаимно сократить сумму до нуля.

Выбирать веса вручную трудно при росте задачи. Слов слишком много, а полезный вес для чего-то вроде `returned` или `after` непросто угадать.

Но основная форма модели полезна: умножить признаки на веса и сложить. Logistic Regression сохраняет эту форму и добавляет две вещи: функцию перевода оценки в вероятность и способ обучения весов на размеченных примерах.
