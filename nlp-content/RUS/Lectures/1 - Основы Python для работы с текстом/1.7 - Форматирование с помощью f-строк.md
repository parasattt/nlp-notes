#### f-строки: вставка значений в текст

Поставьте `f` перед открывающей кавычкой строки. Внутри `{variable}` вставляет значение; в фигурных скобках также можно писать выражения, например `name.upper()` или `len(name)`.

Формат `:.1f` показывает число с одним знаком после десятичной точки.



```python
name = "Aisha"
score = 87.6531

print(f"{name} scored {score} points.")
print(f"{name} scored {score:.1f} points.")   # .1f = one decimal place
print(f"{name.upper()} — {len(name)} letters")# any expression works inside braces
```


**Сохранённый вывод:**

```text
Aisha scored 87.6531 points.
Aisha scored 87.7 points.
AISHA — 5 letters
```
