### Чтение текста из файла

В этом курсе данные будут поступать из файлов, а не только из строк, введённых в ячейки. Следующие ячейки сначала создают пример файла, чтобы блокнот работал на чистой машине, затем показывают чтение всего файла и отдельных строк.



```python
# First create a file to read, so this notebook works from a clean machine.
sample_text = """Product arrived on time and works perfectly.
Terrible quality, broke after two days.
Good value for the price, would buy again.
The packaging was damaged but the item was fine.
Absolutely useless, do not waste your money.
"""

with open("reviews.txt", "w", encoding="utf-8") as f:
    f.write(sample_text)

print("File created.")
```


**Сохранённый вывод:**

```text
File created.
```



```python
# Read the whole file as one string
with open("reviews.txt", "r", encoding="utf-8") as f:
    content = f.read()

print(content)
```


**Сохранённый вывод:**

```text
Product arrived on time and works perfectly.
Terrible quality, broke after two days.
Good value for the price, would buy again.
The packaging was damaged but the item was fine.
Absolutely useless, do not waste your money.
```



```python
# Read it as a list of lines - usually what you want
with open("reviews.txt", "r", encoding="utf-8") as f:
    lines = f.read().splitlines()

for i, line in enumerate(lines, start=1):
    print(f"{i}. ({len(line.split())} words) {line}")
```


**Сохранённый вывод:**

```text
1. (7 words) Product arrived on time and works perfectly.
2. (6 words) Terrible quality, broke after two days.
3. (8 words) Good value for the price, would buy again.
4. (9 words) The packaging was damaged but the item was fine.
5. (7 words) Absolutely useless, do not waste your money.
```

`read()` загружает одну строку со всем файлом. `read().splitlines()` создаёт список строк отзывов. `enumerate(lines, start=1)` нумерует их с 1 для вывода, а `len(line.split())` считает слова, разделённые пробельными символами, в каждой строке. Сохранённые длины — 7, 6, 8, 9 и 7 слов.



Для работы с файлом используйте `with open(...) as f:`. Python закрывает файл после окончания блока, в том числе если внутри произошла ошибка.

Для разделения строк используйте `splitlines()`, не предполагая, что в каждом файле используется только `"\n"`. В Windows окончания строк имеют вид `"\r\n"`; `splitlines()` обрабатывает их, не оставляя лишний `"\r"` в конце каждой строки. Явное указание UTF-8 объясняется в теме [[RUS/Lectures/0 - Jupyter и Colab/0.11 - UTF-8 и кодировка текста|файлы и кодировка UTF-8]].
