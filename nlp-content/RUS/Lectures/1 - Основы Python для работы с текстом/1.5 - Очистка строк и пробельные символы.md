#### Методы строк, которые действительно пригодятся

В Python много строковых методов. Следующие примеры знакомят с теми, которые регулярно используются для очистки и проверки текста.



```python
messy = "   The Movie Was GREAT!!!   "

print(repr(messy.strip()))          # remove whitespace at both ends
print(messy.strip().lower())        # chain them together
print(messy.replace("GREAT", "good"))
print(messy.strip().split("Was"))        # split on whitespace into a list
```


**Сохранённый вывод:**

```text
'The Movie Was GREAT!!!'
the movie was great!!!
   The Movie Was good!!!   
['The Movie ', ' GREAT!!!']
```

`strip()` убирает пробельные символы по краям, `lower()` меняет регистр, а `replace("GREAT", "good")` заменяет указанную подстроку в точности. Цепочка `.strip().lower()` применяет операции последовательно.

**Деталь исходника:** в конце кода используется `.split("Was")`, поэтому разбиение происходит по буквальному слову `Was` и даёт `['The Movie ', ' GREAT!!!']`. В исходном комментарии сказано «разбить по пробельным символам»; это описание подошло бы к `.split()` без аргумента, но не к сохранённому здесь коду. Исходные код и комментарий сохранены.



`repr()` показывает строку с видимыми кавычками и escape-последовательностями. Это особенно полезно для проверки пробельных символов: лишний пробел в конце трудно заметить в обычном выводе, но он всё равно меняет результат сравнения.



```python
a = "cat "
b = "cat"
print(a == b)          # False - and you cannot see why from the printout
print(repr(a), repr(b))# now you can
print(a.strip() == b)  # True
```


**Сохранённый вывод:**

```text
False
'cat ' 'cat'
True
```
