### Словари

**Словарь** сопоставляет **ключи** со **значениями**. Частое применение в обработке текста — подсчёт слов: ключом служит слово, а значением — число его появлений.



```python
counts = {"the": 12, "cat": 3, "sat": 1}

print(counts["the"])
print(len(counts))

counts["mat"] = 5          # add a new key
counts["the"] = 13         # change an existing one
print(counts)
```


**Сохранённый вывод:**

```text
12
3
{'the': 13, 'cat': 3, 'sat': 1, 'mat': 5}
```

`counts["the"]` находит значение по ключу. `len(counts)` считает ключи, а не суммирует их значения. Присваивание по новому ключу добавляет его, а по существующему — заменяет прежнее значение.



```python
# Asking for a missing key is an error.
print(counts["dog"])
```


**Сохранённая ошибка блокнота:**

```text
---------------------------------------------------------------------------
NameError                                 Traceback (most recent call last)
/tmp/ipykernel_4071/2830354060.py in <cell line: 0>()
      1 # Asking for a missing key is an error.
----> 2 print(counts["dog"])

NameError: name 'counts' is not defined
```

**Расхождение в сохранённом выводе:** урок должен показать ошибку отсутствующего ключа. Если `counts` уже существует, как определено выше, запрос `counts["dog"]` вызвал бы `KeyError`. Но сохранённый traceback сообщает `NameError: name 'counts' is not defined`: значит, `counts` не существовал в сеансе, где возникла сохранённая ошибка. Сохранены и исходный код, и фактическая ошибка.



```python
# .get() is the safe version: returns a default instead of crashing.
print(counts.get("dog"))         # None
print(counts.get("dog", 0))      # 0  <- this is the useful one for counting
print("dog" in counts)           # False
```


**Сохранённый вывод:**

```text
None
0
False
```



```python
# Looping over a dictionary
for word, n in counts.items():
    print(f"{word:>5} : {n}")
```


**Сохранённый вывод:**

```text
  the : 13
  cat : 3
  sat : 1
  mat : 5
```

`.get("dog")` возвращает `None` при отсутствии ключа, а `.get("dog", 0)` задаёт ноль как значение по умолчанию. `"dog" in counts` проверяет ключи. `.items()` выдаёт для цикла пары `(key, value)`, а `:>5` выравнивает слово вправо в поле шириной пять символов.
