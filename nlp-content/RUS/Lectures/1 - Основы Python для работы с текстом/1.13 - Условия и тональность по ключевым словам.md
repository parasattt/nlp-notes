### Условия

Для выбора действия используйте `if`, `elif` и `else`. Строка условия заканчивается двоеточием, а отступы обозначают тело. Python проверяет ветви по порядку и выполняет первую подходящую; `else` обрабатывает оставшийся случай.



```python
review = "The film was boring and far too long"
list_of_good_review_words = ["good", "amaing"]
list_of_bad_review_words = ["trash", "bad"]

if "excellent" in review or "great" in review:
    sentiment = "positive"
elif "boring" in review or "bad" in review:
    sentiment = "negative"
else:
    sentiment = "unclear"

print(sentiment)
```


**Сохранённый вывод:**

```text
negative
```

Пример выбирает `negative`, потому что в отзыве встречается `"boring"`. Два списка над условием сохранены из исходника, включая написание `"amaing"`; код не использует ни один из этих списков при принятии решения.



Это **классификатор тональности по ключевым словам**: выбранные слова помогают присвоить тексту положительную, отрицательную или неясную тональность. Ранние системы анализа тональности использовали такой общий подход.

Правило легко обмануть. `"The film was not boring"` всё ещё содержит `"boring"`, поэтому код назвал бы предложение отрицательным. Он не понимает отрицание. Помните об этом ограничении при переходе к [[RUS/Lectures/2 - Pandas для текстовых данных/2.17 - Оценки тональности и проверка базового метода|более крупному базовому методу анализа тональности]] и затем к обучаемым классификаторам.



```python
# Comparison operators
print(5 > 3)
print(5 == 5)      # == compares, = assigns. Mixing these up is a classic error.
print(5 != 3)
print("a" < "b")   # strings compare alphabetically (by character code)

# Combining conditions
n = 7
print(n > 5 and n < 10)
print(n < 5 or n > 6)
print(not (n == 7))
```


**Сохранённый вывод:**

```text
True
True
True
True
True
True
False
```

`==` сравнивает значения, а `=` присваивает значение. `!=` означает «не равно». `and`, `or` и `not` объединяют или обращают отдельные логические условия. Сравнение строк использует порядок кодов символов.
