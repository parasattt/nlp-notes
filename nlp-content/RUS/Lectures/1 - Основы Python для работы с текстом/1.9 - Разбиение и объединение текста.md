#### Разбиение и объединение: две постоянные операции

`split()` превращает строку в список частей. Без аргумента-разделителя он разбивает по пробельным символам. `join()` объединяет строки из списка в одну строку, используя разделитель перед `.join()`.

Частый порядок обработки текста: разбить его, обработать части, затем снова объединить. Об ограничениях этого первого подхода см. [[RUS/Lectures/3 - Разбор текста и регулярные выражения/3.2 - Токенизация строковыми методами|токенизация строковыми методами]].



```python
sentence = "natural language processing is useful"

tokens = sentence.split()
print(tokens)

back_together = " ".join(tokens)
print(back_together)

with_dashes = "-".join(tokens)
print(with_dashes)
```


**Сохранённый вывод:**

```text
['natural', 'language', 'processing', 'is', 'useful']
natural language processing is useful
natural-language-processing-is-useful
```



```python
# split() takes an argument if you do not want to split on spaces.
csv_line = "Aisha,Almaty,87"
print(csv_line.split(","))

path = "data/raw/reviews.txt"
print(path.split("/"))
```


**Сохранённый вывод:**

```text
['Aisha', 'Almaty', '87']
['data', 'raw', 'reviews.txt']
```

Без аргумента `split()` разделяет слова по пробельным символам. С `","` он разделяет поля по запятым, а с `"/"` — части пути. Строка перед `.join()` задаёт разделитель, поэтому `" ".join(tokens)` восстанавливает пробелы, а `"-".join(tokens)` вставляет дефисы.
