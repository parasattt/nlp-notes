### Переменные

**Переменная** — это имя, которое ссылается на значение. Чтобы присвоить имени значение, используйте `=`.



```python
course = "Natural Language Processing"
year = 2026
passing_grade = 50.0
is_fun = True

print(course)
print(year)
```


**Сохранённый вывод:**

```text
Natural Language Processing
2026
```

Присваивания сохраняют строку, целое число, дробное число и логическое значение. Ячейка выводит только `course` и `year`; остальные значения остаются доступны в общем сеансе блокнота.



Python автоматически определяет **тип** каждого значения: при создании этих переменных вы не объявляете тип. Но он всё равно важен. Если операция ведёт себя странно, проверьте тип с помощью `type()`.



```python
print(type(course))       # str   - text
print(type(year))         # int   - whole number
print(type(passing_grade))# float - number with a decimal point
print(type(is_fun))       # bool  - True or False
```


**Сохранённый вывод:**

```text
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```



Придерживайтесь таких правил и привычек при выборе имён:

- Имена могут содержать буквы, цифры и `_`, но не могут начинаться с цифры.
- Предпочитайте строчные слова с подчёркиваниями, например `word_count`, вместо `WordCount` или неясного сокращения вроде `wc`.
- Регистр важен: `Text` и `text` — разные переменные.
- Понятное имя может объяснить больше, чем комментарий.

Следующие примеры показывают, почему тип значения имеет значение.
