```python
# Python has a built-in counter that does all of the above in one line.
from collections import Counter

counter = Counter(cleaned)
print(counter.most_common(5))
```


**Сохранённый вывод:**

```text
[('the', 6), ('cat', 3), ('mat', 3), ('warm', 2), ('sat', 1)]
```

`Counter(cleaned)` создаёт счётчики слов из очищенных токенов. `.most_common(5)` возвращает пять самых частых пар `(word, count)`. Сохранённый результат начинается с `('the', 6)`, затем идут `cat` и `mat` с тремя появлениями каждое.



Python мог выполнить подсчёт через `Counter` с самого начала. Но ручное построение счётчика показывает, что делает этот короткий способ, и помогает впоследствии понимать неожиданные результаты.
