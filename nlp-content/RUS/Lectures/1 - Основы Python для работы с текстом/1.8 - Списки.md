### Списки

**Список** — это упорядоченная коллекция. Списки слов постоянно используются при обработке текста. Как и строки, списки поддерживают позиции с нуля, отрицательные позиции с конца и срезы.



```python
words = ["the", "quick", "brown", "fox"]

print(words)
print(len(words))
print(words[0])
print(words[-1])
print(words[1:3])
```


**Сохранённый вывод:**

```text
['the', 'quick', 'brown', 'fox']
4
the
fox
['quick', 'brown']
```



```python
words.append("jumps")       # add to the end
print(words)

words.insert(0, "and")      # add at a position
print(words)

words.remove("and")         # remove by value
print(words)

last = words.pop()          # remove and return the last item
print(last, "|", words)
```


**Сохранённый вывод:**

```text
['the', 'quick', 'brown', 'fox', 'jumps']
```


**Сохранённая ошибка блокнота:**

```text
---------------------------------------------------------------------------
TypeError                                 Traceback (most recent call last)
/tmp/ipykernel_4071/1455985292.py in <cell line: 0>()
      2 print(words)
      3 
----> 4 words.insert("and")      # add at a position
      5 print(words)
      6 

TypeError: insert expected 2 arguments, got 1
```

Эти операции меняют сам список: `append()` добавляет элемент в конец, `insert(index, value)` вставляет на указанную позицию, `remove(value)` удаляет совпадающее значение, а `pop()` по умолчанию удаляет и возвращает последний элемент.

**Расхождение в сохранённом выводе:** текущий исходник содержит `words.insert(0, "and")`, но в сохранённом traceback показан более ранний вызов `words.insert("and")`. В нём не было обязательного аргумента позиции, что вызвало `TypeError: insert expected 2 arguments, got 1`. Сохранены только первый выведенный список и эта ошибка. Успешные результаты последующих инструкций не выдумываются.
