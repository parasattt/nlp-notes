### Циклы

Цикл `for` выполняет своё тело один раз для каждого элемента коллекции. Следующие примеры выводят сведения о словах, строят отфильтрованный список и используют `enumerate()` для получения позиции элемента вместе с его значением.



```python
words = ["cat", "elephant", "dog", "hippopotamus"]

for word in words:
    print(word, "has", len(word), "letters")
```


**Сохранённый вывод:**

```text
cat has 3 letters
elephant has 8 letters
dog has 3 letters
hippopotamus has 12 letters
```



```python
# Building a new list as you go
long_words = []

for word in words:
    if len(word) > 3:
        long_words.append(word)

print(long_words)
```


**Сохранённый вывод:**

```text
['elephant', 'hippopotamus']
```



```python
# enumerate() gives you the position as well as the item
for i, word in enumerate(words):
    print(i, word)
```


**Сохранённый вывод:**

```text
0 cat
1 elephant
2 dog
3 hippopotamus
```

Обычный цикл проходит слова по порядку. Второй пример начинает с пустого списка и добавляет слова длиннее трёх символов. `enumerate(words)` даёт позиции с нуля вместе со словами.



#### Отступы — часть синтаксиса

Python использует **отступы**, чтобы показать, какие инструкции находятся внутри цикла или другого блока. Обычно используют четыре пробела. Закрывающей фигурной скобки или ключевого слова `end` нет.

В следующей ячейке `print()` с отступом выполняется для каждого слова. Последний `print()` без отступа выполняется только один раз после цикла.



```python
for word in ["a", "b", "c"]:
    print("inside the loop:", word)
print("outside the loop, runs once")
```


**Сохранённый вывод:**

```text
inside the loop: a
inside the loop: b
inside the loop: c
outside the loop, runs once
```
