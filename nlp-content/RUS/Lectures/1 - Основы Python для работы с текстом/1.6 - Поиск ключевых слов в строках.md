```python
review = "The service was slow but the food was excellent"

print(review.startswith("The"))
print(review.endswith("."))
print("food" in review)            # substring test - very common
print(review.count("was"))
print(review.find("food"))         # position, or -1 if not found
```


**Сохранённый вывод:**

```text
True
False
True
2
29
```

`startswith()` и `endswith()` проверяют начало и конец строки. `in` ищет подстроку в любом месте. `count("was")` находит два вхождения, а `find("food")` даёт позицию её первого символа, `29`, либо вернул бы `-1`, если бы подстроки не было.



Оператор `in` проверяет, встречается ли одна строка внутри другой. Так получается простой **поиск по ключевым словам**. Он полезен, но не определяет границы целого слова и не обрабатывает все текстовые шаблоны. [[RUS/Lectures/2 - Pandas для текстовых данных/2.7 - Фильтрация текста и категорий|Фильтрация текстовых столбцов]] применяет поиск ко многим строкам таблицы, а [[RUS/Lectures/3 - Разбор текста и регулярные выражения/3.3 - Токенизация с помощью regex|регулярные выражения]] дают больше контроля над текстовыми шаблонами.
