### Собираем всё вместе: счётчик частоты слов

Теперь объединим прежние навыки для настоящей текстовой задачи: подсчитаем, как часто каждое слово встречается в **корпусе**, то есть в наборе текстов.

Частота слов — одно из первых свойств, которые часто вычисляют для нового корпуса. Она также лежит в основе [[RUS/Lectures/6 - Преобразование текста в признаки/6.2 - Словарь и мешок слов|признаков мешка слов]] и [[RUS/Lectures/8 - TF-IDF и поиск текста/8.5 - TF-IDF вручную|TF-IDF]]. Следующие шаги приводят регистр к одному виду, разбивают текст, убирают пунктуацию, считают слова и упорядочивают результаты по частоте.



```python
text = """
The cat sat on the mat. The mat was warm.
The cat liked the warm mat, and the cat slept.
"""

# Step 1: normalise the case so "The" and "the" count as the same word
text_lower = text.lower()

# Step 2: split into words
words = text_lower.split()
print(words)
```


**Сохранённый вывод:**

```text
['the', 'cat', 'sat', 'on', 'the', 'mat.', 'the', 'mat', 'was', 'warm.', 'the', 'cat', 'liked', 'the', 'warm', 'mat,', 'and', 'the', 'cat', 'slept.']
```



Внимательно посмотрите на сохранённые токены. `'mat.'`, `'mat,'` и `'mat'` — разные строки, потому что к ним всё ещё прикреплена пунктуация. При раздельном подсчёте частота одного с точки зрения читателя слова разделилась бы между ними.

Следующая ячейка использует простое временное решение: убирает выбранные знаки препинания с краёв токена и пропускает пустые токены. Позднее [[RUS/Lectures/3 - Разбор текста и регулярные выражения/3.3 - Токенизация с помощью regex|токенизация с помощью regex]] даст более осознанное правило того, как должно выглядеть слово.



```python
cleaned = []
for w in words:
    w = w.strip(".,!?;:\"'")     # remove these characters from both ends
    if w:                        # skip anything that became empty
        cleaned.append(w)

print(cleaned)
```


**Сохранённый вывод:**

```text
['the', 'cat', 'sat', 'on', 'the', 'mat', 'the', 'mat', 'was', 'warm', 'the', 'cat', 'liked', 'the', 'warm', 'mat', 'and', 'the', 'cat', 'slept']
```

`.strip(".,!?;:\"'")` удаляет любые из перечисленных символов с **краёв** токена. Внутреннюю пунктуацию он не удаляет. `if w` пропускает пустую строку, поэтому часть, состоявшая только из удаляемых знаков, не считается словом.
