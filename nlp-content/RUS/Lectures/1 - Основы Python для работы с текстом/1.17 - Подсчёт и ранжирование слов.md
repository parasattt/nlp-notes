```python
# Step 3: count
counts = {}
for w in cleaned:
    counts[w] = counts.get(w, 0) + 1

print(counts)
```


**Сохранённый вывод:**

```text
{'the': 6, 'cat': 3, 'sat': 1, 'on': 1, 'mat': 3, 'was': 1, 'warm': 2, 'liked': 1, 'and': 1, 'slept': 1}
```



Важный шаблон подсчёта — `counts.get(w, 0) + 1`. Для каждого слова `w` возьмите текущий счётчик; если слово ещё не встречалось, используйте ноль; затем прибавьте единицу и сохраните результат.



```python
# Step 4: sort by count, most frequent first
ranked = sorted(counts.items(), key=lambda pair: pair[1], reverse=True)

for word, n in ranked:
    print(f"{word:>6} : {n}")
```


**Сохранённый вывод:**

```text
   the : 6
   cat : 3
   mat : 3
  warm : 2
   sat : 1
    on : 1
   was : 1
 liked : 1
   and : 1
 slept : 1
```



`lambda pair: pair[1]` — небольшая безымянная функция. Каждый элемент словаря — пара `(word, count)`, и `pair[1]` выбирает её счётчик. Сортировка по этому значению с `reverse=True` ставит самые частые слова первыми.

Самые частые слова — *the*, *cat* и *mat*. Здесь *cat* и *mat* помогают понять содержание текста, а *the* почти ничего не говорит о его теме. Частые слова вроде *the*, *a*, *is* и *and* называют **стоп-словами**. Решение об их сохранении постоянно возникает в NLP; см.
