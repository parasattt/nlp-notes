### Функции

**Функция** даёт имя многократно используемому фрагменту кода. Её можно вызывать с разными входными данными вместо копирования одних и тех же инструкций.



```python
def clean_text(text):
    """Lowercase the text and strip surrounding whitespace."""
    # Hello
    return text.strip().lower()



print(clean_text("   HELLO World   "))
print(clean_text("  Another EXAMPLE "))
```


**Сохранённый вывод:**

```text
hello world
another example
```



Читайте определение функции так:

- `def` начинает определение функции.
- `clean_text` — её имя.
- `text` — **параметр**, то есть входное значение, переданное вызывающим кодом.
- Инструкции с отступом образуют **тело**.
- `return` возвращает результат вызывающему коду. Функция без возвращённого значения возвращает `None`.
- Строка в тройных кавычках — это **docstring**, строка документации. Команда справки блокнота `clean_text?` может её показать.

Если вы снова и снова копируете несколько одинаковых строк, подумайте о том, чтобы оформить их как функцию.



```python
def count_words(text):
    return len(text.split())

def average_word_length(text):
    words = text.split()
    if len(words) == 0:          # guard against dividing by zero
        return 0
    total = sum(len(w) for w in words)
    return total / len(words)


sample = "Natural language processing is mostly data cleaning"
print(count_words(sample))
print(round(average_word_length(sample), 1))
```


**Сохранённый вывод:**

```text
7
6.4
```

`count_words()` считает части, разделённые пробельными символами. `average_word_length()` разбивает текст, возвращает `0` для пустого списка, чтобы избежать деления на ноль, суммирует длины в символах и делит на число слов. В сохранённом примере **7 слов**, а средняя длина после округления — **6.4**.



```python
# Default values for parameters
def preview(text, n=30, p = 10):
    if len(text) <= n or not len(text) > n+p:
        return text
    return text[:n+p] + "..."


long_text = "Python is a programming language that is widely used in data science and NLP"
print(preview(long_text))
print(preview(long_text, 50, 50))
print(preview(long_text, n=10, p=5))
```


**Сохранённый вывод:**

```text
Python is a programming language that is...
Python is a programming language that is widely used in data science and NLP
Python is a pro...
```

`n=30` и `p=10` — значения параметров по умолчанию. Именно эта функция использует **`n + p` как длину обрезки**, а не только `n`. Если текст укладывается в этот порог, функция оставляет его целиком; иначе берёт `text[:n+p]` и добавляет `"..."`.

Первый вызов использует порог 40 символов. Второй передаёт `50, 50`, получая порог 100, поэтому сохранённый результат содержит весь текст. Вызов с именованными аргументами использует `10 + 5 = 15` и даёт сохранённый фрагмент `Python is a pro...`.
