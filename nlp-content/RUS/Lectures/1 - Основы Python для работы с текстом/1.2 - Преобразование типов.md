```python
# This works and probably not the way you expect.
print("5" + "5")
```


**Сохранённый вывод:**

```text
55
```



```python
# This one fails. Read the error, then move on to the next cell.
print("5" + 5)
```


**Сохранённая ошибка блокнота:**

```text
---------------------------------------------------------------------------
TypeError                                 Traceback (most recent call last)
Cell In[4], line 2
      1 # This one fails. Read the error, then move on to the next cell.
----> 2 print("5" + 5)

TypeError: can only concatenate str (not "int") to str
```



```python
# Convert explicitly when you need to mix them.
print(int("5") + 5)
print("5" + str(5))
```


**Сохранённый вывод:**

```text
10
55
```

`"5" + "5"` объединяет две строки и даёт `"55"`. В сохранённой ошибке `TypeError` Python отклоняет сложение строки с целым числом. Преобразование через `int("5")` позволяет выполнить числовое сложение и получить `10`; преобразование через `str(5)` позволяет объединить строки и получить `"55"`. О чтении таких ошибок см. [[RUS/Lectures/0 - Jupyter и Colab/0.7 - Чтение сообщений об ошибках|чтение сообщений traceback]].



Эта проблема встречается в реальной работе с данными. Оценка вроде `5` может поступить из CSV или анкеты как **строка** `"5"` — в зависимости от способа чтения. Проверяйте тип и при необходимости преобразуйте его. Иначе операция может дать неверный ответ даже без ошибки. Проверка типов на уровне таблицы описана в теме [[RUS/Lectures/2 - Pandas для текстовых данных/2.4 - Первичный осмотр данных|осмотр DataFrame]].
