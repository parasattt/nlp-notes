#### Индексы и срезы

Позиции в строке начинаются с **0**. Индекс выбирает один символ. Срез `[start:end]` включает символ на позиции `start` и останавливается **перед** `end`.

Сначала в этом правиле границ легко ошибиться. В `word[0:4]` входят позиции 0, 1, 2 и 3; позиция 4 не входит.



```python
word = "language"
#       01234567

print(word[0])     # first character
print(word[3])     # fourth character
print(word[-1])    # last character
print(word[-2])    # second to last
```


**Сохранённый вывод:**

```text
l
g
e
g
```



```python
print(word[0:4])   # characters 0,1,2,3 -> 'lang'
print(word[:4])    # same thing, start is optional
print(word[4:])    # from 4 to the end
print(word[::-1])  # reversed
```


**Сохранённый вывод:**

```text
lang
lang
uage
egaugnal
```

Отрицательные индексы отсчитывают позиции с конца: `-1` — последний символ. Пропущенное начало или конец среза означает соответствующий край строки. В `[::-1]` шаг `-1` читает строку в обратном порядке.
