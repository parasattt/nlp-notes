### Отмечаем начало и конец предложения

Добавим `<s>` перед каждым ответом и `</s>` после него. Тогда одно правило подсчёта научится учитывать и начальные слова, и точки остановки.

Три из пяти ответов начинаются с `thank`, поэтому $P(\text{thank} \mid \text{<s>}) = 3/5$.

| Предыдущее слово | Следующее слово: частота | Всего |
|---|---|---|
| `<s>` | thank: 3, your: 2 | 5 |
| thank | you: 3 | 3 |
| you | for: 3 | 3 |
| for | your: 2, contacting: 1 | 3 |
| your | order: 3, patience: 1 | 4 |
| order | `</s>`: 1, has: 1, is: 1 | 3 |
| has / is / contacting | shipped / delayed / us: 1 | 1 |
| patience, shipped, delayed, us | `</s>`: по 1 | по 1 |

Чтобы получить вероятность, делим частоту следующего слова на сумму строки.

#### Храним таблицу в Python

Используем словарь с предыдущим словом в качестве ключа. Каждое значение — `Counter` с частотами следующих слов.



`add_marks` добавляет токены начала и конца. Для каждого подготовленного ответа `zip(sent, sent[1:])` перебирает соседние слова и увеличивает соответствующую запись `Counter`. Эти частоты дают ручную таблицу выше.

```python
replies = [
    "thank you for your order",
    "thank you for your patience",
    "your order has shipped",
    "your order is delayed",
    "thank you for contacting us",
]

def add_marks(sentence):
    return ["<s>"] + sentence.split() + ["</s>"]

follows = defaultdict(Counter)                  # follows["for"] = Counter({"your": 2, "contacting": 1})
for sent in map(add_marks, replies):
    for prev, word in zip(sent, sent[1:]):      # neighbouring pairs
        follows[prev][word] += 1

print(add_marks(replies[0]))
for prev in ["<s>", "for", "your", "order"]:
    total = sum(follows[prev].values())
    print(f"after {prev!r:7}: {dict((w, f'{c}/{total}') for w, c in follows[prev].most_common())}")
```


**Сохранённый вывод:**

```text
['<s>', 'thank', 'you', 'for', 'your', 'order', '</s>']
after '<s>'  : {'thank': '3/5', 'your': '2/5'}
after 'for'  : {'your': '2/3', 'contacting': '1/3'}
after 'your' : {'order': '3/4', 'patience': '1/4'}
after 'order': {'</s>': '1/3', 'has': '1/3', 'is': '1/3'}
```



`zip(sent, sent[1:])` соединяет список с его версией, сдвинутой на одну позицию. Поэтому посещается каждая соседняя пара. Сохранённые строки совпадают с ручной таблицей.
