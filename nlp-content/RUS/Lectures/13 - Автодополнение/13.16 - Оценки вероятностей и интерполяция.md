### Сравниваем способы оценки вероятностей

Каждый способ использует интерфейс `p(w, a, b)`: вероятность следующего слова `w` после контекста `a b`.

- **Равномерный:** каждому возможному слову даётся вероятность $1/V$.
- **Униграммный:** использует $\text{count}(w)/N$, учитывая частоту слова, но игнорируя контекст.
- **Биграммный с add-k:** использует последнее слово и уже введённую формулу сглаживания.
- **Триграммный с add-k:** использует последние два слова с той же идеей сглаживания.
- **Интерполяция:** объединяет несглаженные униграммную, биграммную и триграммную оценки:

$$P(w \mid a\,b) = 0.1 \cdot P_{\text{uni}}(w) + 0.3 \cdot P_{\text{bi}}(w \mid b) + 0.6 \cdot P_{\text{tri}}(w \mid a\,b)$$

Три веса равны 0.1, 0.3 и 0.6, поэтому пример больше всего доверяет триграммной оценке. Если триграмма не наблюдалась, $P_{\text{tri}} = 0$, но слагаемые коротких контекстов всё ещё могут дать вклад. Лекция объясняет, что сумма весов 1 позволяет смешивать вероятности.

Исходный код использует упрощённый запасной вариант: если весь длинный контекст невстречавшийся, эта компонента возвращает ноль для каждого кандидата, а оставшиеся веса не перераспределяются. Поэтому сама сумма весов 1 не гарантирует нормированное распределение для любого запасного контекста. Исходные оценки и сообщённые результаты сохранены без изменений.

Код ниже строит суммы контекстов, определяет каждый способ оценки и сравнивает их перплексии. В словаре есть три биграммных значения `k`, поэтому сохранённое сравнение на самом деле содержит семь вариантов.



`bi_ctx` и `tri_ctx` — знаменатели наблюдавшихся контекстов. `N_words` — общее число предсказываемых токенов, `V_yelp` — размер их словаря. Все оценки используют те же частоты; `perplexity` оценивает подготовленные отложенные предложения и возвращает и перплексию, и число токенов.

```python
bi_ctx = Counter()                               # how often each word is followed by something
for (a, _), c in bi.items():
    bi_ctx[a] += c
tri_ctx = Counter()                              # how often each pair is followed by something
for (a, b, _), c in tri.items():
    tri_ctx[(a, b)] += c
N_words = sum(uni.values())
V_yelp = len(uni)

def p_uniform(w, a, b):
    return 1 / V_yelp

def p_unigram(w, a, b):
    return uni[w] / N_words

def p_bigram_k(w, a, b, k):
    return (bi[(b, w)] + k) / (bi_ctx[b] + k * V_yelp)

def p_trigram_k(w, a, b, k):
    return (tri[(a, b, w)] + k) / (tri_ctx[(a, b)] + k * V_yelp)

def p_interp(w, a, b, l1=0.1, l2=0.3, l3=0.6):
    p1 = uni[w] / N_words
    p2 = bi[(b, w)] / bi_ctx[b] if bi_ctx[b] else 0.0
    p3 = tri[(a, b, w)] / tri_ctx[(a, b)] if tri_ctx[(a, b)] else 0.0
    return l1 * p1 + l2 * p2 + l3 * p3

def perplexity(p, sents=test_p):
    log_sum, n = 0.0, 0
    for s in sents:
        padded = ["<s>"] + s                   # one more <s> so the first word has two words before it
        for i in range(2, len(padded)):
            log_sum += math.log(p(padded[i], padded[i - 2], padded[i - 1]))
            n += 1
    return math.exp(-log_sum / n), n

models = {
    "uniform": p_uniform,
    "unigram": p_unigram,
    "bigram, add-1": lambda w, a, b: p_bigram_k(w, a, b, 1),
    "bigram, add-0.1": lambda w, a, b: p_bigram_k(w, a, b, 0.1),
    "bigram, add-0.01": lambda w, a, b: p_bigram_k(w, a, b, 0.01),
    "trigram, add-0.01": lambda w, a, b: p_trigram_k(w, a, b, 0.01),
    "interpolation": p_interp,
}
results = {}
for name, p in models.items():
    results[name], n_test = perplexity(p)
    print(f"{name:18} perplexity {results[name]:9.1f}")
print(f"\n(measured on {n_test:,} test words)")
```
