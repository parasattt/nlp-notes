### Даём невстречавшимся парам небольшую вероятность

**Сглаживание** забирает часть вероятности у наблюдавшихся пар и отдаёт её невстречавшимся. Самый простой способ прибавляет единицу к частоте каждого возможного следующего слова:

$$P_{\text{add-1}}(w \mid \text{prev}) = \frac{\text{count}(\text{prev } w) + 1}{\text{count}(\text{prev}) + V}$$

Здесь `prev` — предыдущее слово, $w$ — возможное следующее слово, $V$ — количество возможных следующих слов. В ответах двенадцать обычных слов плюс `</s>`, поэтому $V=13$. `<s>` не может быть следующим выходным словом.

В каждой строке прибавляем 1 к тринадцати частотам, поэтому к знаменателю тоже прибавляем 13. Вероятности по-прежнему суммируются в 1.

Для `is`, один раз наблюдавшегося перед `delayed`:

- $P(\text{shipped} \mid \text{is})=(0+1)/(1+13)=1/14\approx0.071$.
- $P(\text{delayed} \mid \text{is})=(1+1)/(1+13)=2/14\approx0.143$, что меньше прежней 1.

Невстречавшаяся пара теперь возможна, но знакомая пара потеряла вероятность.

Сравните ту же проблему нулевой частоты в [[RUS/Lectures/7 - Классификация Naive Bayes/7.4 - Сглаживание Лапласа|сглаживании Лапласа для Naive Bayes]].



Словарь исключает `<s>`, поскольку этот токен не предсказывается следующим. `p_add_k` добавляет `k` к частоте кандидата и `k * V` к сумме строки; значение по умолчанию `k=1.0` воспроизводит add-one сглаживание.

```python
vocab = {w for sent in map(add_marks, replies) for w in sent if w != "<s>"}
V = len(vocab)
print("V =", V)

def p_add_k(word, prev, k=1.0):
    total = sum(follows[prev].values())
    return (follows[prev][word] + k) / (total + k * V)

print(f"P(shipped | is) = {p_add_k('shipped', 'is'):.3f}")
print(f"P(delayed | is) = {p_add_k('delayed', 'is'):.3f}")
print()
for s in ["your order is shipped", "your order is delayed"]:
    print(f"no smoothing {sentence_prob(s):.6f}   add-one {sentence_prob(s, p_add_k):.6f}   {s}")
```


**Сохранённый вывод:**

```text
V = 13
P(shipped | is) = 0.071
P(delayed | is) = 0.143

no smoothing 0.000000   add-one 0.000050   your order is shipped
no smoothing 0.100000   add-one 0.000100   your order is delayed
```



У невстречавшегося предложения теперь вероятность около 0.00005. У знакомого *your order is delayed* («ваш заказ задерживается») она падает с 0.1 примерно до 0.0001 — в тысячу раз. Большая часть вероятности после `is` распределена между двенадцатью словами, которые там не наблюдались.

При словаре около 35 000 слов add-one может отдать слишком много вероятности. Позднее результаты Yelp показывают качество хуже униграммной модели, которая вообще игнорирует контекст.

**Add-k сглаживание** добавляет меньшую частоту, например $k=0.01$. В той же формуле заменяем 1 числителя на $k$, а $V$ знаменателя — на $k\cdot V$. Исходная функция `p_add_k` предоставляет эту настройку через аргумент `k`.
