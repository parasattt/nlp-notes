### Предлагаем самые вероятные слова

Найдём слова, следовавшие за последним введённым словом, и упорядочим их по частоте. Следующие функции вычисляют вероятность и возвращают до `k=3` подсказок.



`p_next` делит частоту следующего слова на сумму для предыдущего слова и возвращает 0, если такая строка не наблюдалась. `suggest_toy` возвращает `k` самых частых продолжений и округляет вероятности для вывода.

```python
def p_next(word, prev):
    total = sum(follows[prev].values())
    return follows[prev][word] / total if total else 0.0

def suggest_toy(prev, k=3):
    return [(w, round(p_next(w, prev), 2)) for w, _ in follows[prev].most_common(k)]

print("after 'your' :", suggest_toy("your"))
print("after 'order':", suggest_toy("order"))
```


**Сохранённый вывод:**

```text
after 'your' : [('order', 0.75), ('patience', 0.25)]
after 'order': [('</s>', 0.33), ('has', 0.33), ('is', 0.33)]
```



Подсказка `</s>` после `order` означает, что ответ может здесь закончиться. Лекция предлагает показывать это в редакторе как точку.
