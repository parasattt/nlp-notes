### Строим таблицы частот

Считаем отдельные слова (**униграммы**), соседние пары (**биграммы**) и последовательности трёх слов (**триграммы**). Предсказание триграммной модели может зависеть от двух последних введённых слов.

При формировании триграмм добавляем ещё один `<s>` перед подготовленным предложением. Тогда у первого настоящего слова два предшествующих граничных маркера. Код также строит таблицы поиска с ключами из контекстов одного или двух слов.



`uni`, `bi` и `tri` хранят частоты последовательностей. `next_bi` сопоставляет однословные контексты со счётчиками следующих слов, `next_tri` использует двухсловные контексты. Дополнительный начальный граничный токен готовит первую триграмму.

```python
uni = Counter(w for s in train_p for w in s[1:])                     # single words (not <s>)
bi = Counter(pair for s in train_p for pair in zip(s, s[1:]))         # pairs
tri = Counter(t for s in train_p for t in zip(["<s>"] + s, s, s[1:])) # three in a row

next_bi = defaultdict(Counter)                  # next_bi["the"]            -> words after "the"
for (b, w), c in bi.items():
    next_bi[b][w] = c
next_tri = defaultdict(Counter)                 # next_tri[("i", "would")]  -> words after "i would"
for (a, b, w), c in tri.items():
    next_tri[(a, b)][w] = c

print(f"vocabulary V: {len(uni):,}")
print(f"one word before : {len(next_bi):,} different starts, {len(bi):,} different pairs")
print(f"two words before: {len(next_tri):,} different starts, {len(tri):,} different triples")
```


**Сохранённый вывод:**

```text
vocabulary V: 35,639
one word before : 35,639 different starts, 955,054 different pairs
two words before: 935,935 different starts, 2,897,333 different triples
```
