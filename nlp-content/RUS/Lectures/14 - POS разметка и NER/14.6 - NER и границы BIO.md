### NER и границы BIO

NER определяет тип и полную границу сущности. В BIO метка B означает начало, I — продолжение, O — вне сущности; категории CoNLL: PER, ORG, LOC и MISC. Конечный индекс в коде не включён.

```python
def bio_to_spans(tags):
    # list of BIO tags -> list of (start, end, type); end is one past the last word
    spans, start, kind = [], None, None
    for i, tag in enumerate(list(tags) + ["O"]):          # one extra "O" closes the last span
        if start is not None and (tag == "O" or tag.startswith("B-") or tag[2:] != kind):
            spans.append((start, i, kind))
            start = None
        if tag.startswith("B-") or (tag.startswith("I-") and start is None):
            start, kind = i, tag[2:]
    return spans

words = "Aigerim Bekova joined Kaspi Bank in Almaty .".split()
tags = ["B-PER", "I-PER", "O", "B-ORG", "I-ORG", "O", "B-LOC", "O"]
for start, end, kind in bio_to_spans(tags):
    print(f"{kind:4} {' '.join(words[start:end])}")
```
