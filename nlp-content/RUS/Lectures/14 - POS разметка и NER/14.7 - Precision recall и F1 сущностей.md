### Precision recall и F1 сущностей

Предсказание верно только при совпадении типа и границ. Precision — доля верных среди найденных сущностей, recall — доля найденных среди эталонных, F1 — их гармоническое среднее.

```python
def entity_scores(true_sents, pred_sents):
    tp = fp = fn = 0
    for t, p in zip(true_sents, pred_sents):
        true_set, pred_set = set(bio_to_spans(t)), set(bio_to_spans(p))
        tp += len(true_set & pred_set)       # found and correct
        fp += len(pred_set - true_set)       # found but wrong
        fn += len(true_set - pred_set)       # true but missed
    precision = tp / (tp + fp) if tp + fp else 0.0
    recall = tp / (tp + fn) if tp + fn else 0.0
    f1 = 2 * precision * recall / (precision + recall) if precision + recall else 0.0
    return round(precision, 3), round(recall, 3), round(f1, 3)

predicted = ["B-PER", "I-PER", "O", "B-ORG", "O", "O", "B-LOC", "O"]
print("precision, recall, F1:", entity_scores([tags], [predicted]))
print("word accuracy        :", np.mean([a == b for a, b in zip(tags, predicted)]))
```
