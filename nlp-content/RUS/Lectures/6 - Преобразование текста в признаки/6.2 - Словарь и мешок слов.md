## Строим мешок слов вручную

Идея проста: **создать по столбцу для каждого слова словаря и считать его появления**.

Сначала соберите все различные слова из всех сообщений. Этот набор — **словарь**. Задайте фиксированный порядок слов. Конкретный порядок произволен, но позиция 7 всегда должна относиться к одному и тому же слову.



Разбиение по пробельным символам создаёт список токенов для каждого сообщения. Множество собирает уникальные строки, а сортировка закрепляет общий порядок словаря.

```python
tokenised = [m.split() for m in messages]

vocabulary = sorted({w for msg in tokenised for w in msg})

print("vocabulary size:", len(vocabulary))
print(vocabulary)
```


**Сохранённый вывод:**

```text
vocabulary size: 23
['a', 'before', 'can', 'claim', 'click', 'free', 'here', 'iphone', 'me', 'meeting', 'money', 'moved', 'now', 'prize', 'report', 'send', 'the', 'three', 'to', 'tomorrow', 'win', 'you', 'your']
```



Словарь назначает каждому слову столбец. Для каждого документа функция создаёт нулевой вектор длиной со весь словарь и увеличивает значение в позиции каждого известного слова.

```python
word_to_index = {w: i for i, w in enumerate(vocabulary)}

def to_vector(tokens, vocab, index):
    vec = [0] * len(vocab)
    for w in tokens:
        if w in index:
            vec[index[w]] += 1
    return vec

vectors = [to_vector(t, vocabulary, word_to_index) for t in tokenised]
print(vectors)
print()

for v, m in zip(vectors, messages):
    print(v, " <-", m)
```

Теперь каждое сообщение — ряд чисел. Каждый столбец относится к одному слову словаря, а его значение показывает число появлений этого слова в сообщении.

`word_to_index` хранит фиксированный столбец каждого слова. `to_vector` начинает с нулей и для каждого известного токена добавляет 1 в соответствующий столбец. Следующая ячейка помещает векторы в таблицу для удобного осмотра.



В DataFrame каждый столбец счётчиков назван словом словаря, а каждая строка — сообщением. `LABEL` добавляется отдельно для сравнения; он не входит в исходные 23 словесных признака.

bow = pd.DataFrame(vectors, columns=vocabulary, index=[f"msg{i}" for i in range(len(messages))])

Сравните столбец `free` с `LABEL`: у обоих спам-сообщений счётчик равен 1, у обоих обычных — 0. Модель может использовать эту числовую закономерность. Показанный DataFrame использует словарь как столбцы и добавляет рядом метки с помощью ранее изученных [[RUS/Lectures/2 - Pandas для текстовых данных/2.3 - DataFrame и Series|табличных операций Pandas]].

Это представление называется **мешок слов**, или bag of words. Как при перемешивании слов в мешке, количества сохраняются, а порядок теряется. Позднее лекция возвращается к этому ограничению.
