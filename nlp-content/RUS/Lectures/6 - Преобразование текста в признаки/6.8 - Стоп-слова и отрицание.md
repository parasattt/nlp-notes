## stop_words: снова ловушка отрицания

[[RUS/Lectures/4 - Токенизация/4.6 - Сохранение отрицаний|Удаление отрицаний при предобработке]] может уничтожить смысл предложения. Такая же проблема может возникнуть внутри `CountVectorizer`.



Сначала оставьте словарь по умолчанию, чтобы в отрицательном предложении сохранился признак `not`.

```python
opinions = ["the product is good", "the product is not good"]

keep = CountVectorizer()
keep.fit(opinions)
print("keeping stop words :", keep.get_feature_names_out())
print(keep.transform(opinions).toarray())
```


**Сохранённый вывод:**

```text
keeping stop words : ['good' 'is' 'not' 'product' 'the']
[[1 1 0 1 1]
 [1 1 1 1 1]]
```



Теперь обучите отдельный векторизатор со встроенным английским списком стоп-слов и проверьте утраченное различие.

```python
drop = CountVectorizer(stop_words="english")
drop.fit(opinions)

print("dropping stop words:", drop.get_feature_names_out())
print(drop.transform(opinions).toarray())
```


**Сохранённый вывод:**

```text
dropping stop words: ['good' 'product']
[[1 1]
 [1 1]]
```



При словаре по умолчанию векторы двух отзывов различаются: `not` есть только в отрицательном. После удаления английских стоп-слов оба становятся в точности `[1, 1]` для `good` и `product`.

Классификатор, получающий только эти одинаковые векторы, не может восстановить, какое предложение было отрицательным. Информация утрачена ещё до предсказания.

Английский список `sklearn` включает `not`, `no`, `nor`, `never` и `against`. Для тональности, отзывов, жалоб и любых задач, где важно отрицание, изучите список до использования. Блокнот также приводит медицинские записи как пример текста, чувствительного к смыслу. Следующая ячейка показывает все восемь проверяемых слов, связанных с отрицанием, в сохранённом списке; всего в нём 318 элементов.



Проверьте, какие именно из восьми указанных слов об отрицании есть в английском стоп-списке, затем выведите его полный размер.

```python
from sklearn.feature_extraction.text import ENGLISH_STOP_WORDS

negations = sorted(w for w in ENGLISH_STOP_WORDS
                   if w in {"no", "not", "nor", "never", "none", "cannot", "without", "against"})
print(negations)
print()
print("stop list size:", len(ENGLISH_STOP_WORDS))
```


**Сохранённый вывод:**

```text
['against', 'cannot', 'never', 'no', 'none', 'nor', 'not', 'without']

stop list size: 318
```
