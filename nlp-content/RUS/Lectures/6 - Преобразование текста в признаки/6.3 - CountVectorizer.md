## CountVectorizer

`scikit-learn` предоставляет `CountVectorizer` для построения векторов частот. Ручной пример объясняет его работу, поэтому результат вызова библиотеки легче проверить.



`fit_transform` изучает словарь по `messages` и строит разреженную матрицу счётчиков. `get_feature_names_out()` показывает слова, назначенные её 22 столбцам.

```python
from sklearn.feature_extraction.text import CountVectorizer

vec = CountVectorizer()
X = vec.fit_transform(messages)

print("shape:", X.shape, " (rows = messages, columns = vocabulary)")
print()
print(vec.get_feature_names_out())
print()
print(X.shape[0])
print(X.shape[1])
```


**Сохранённый вывод:**

```text
shape: (4, 22)  (rows = messages, columns = vocabulary)

['before' 'can' 'claim' 'click' 'free' 'here' 'iphone' 'me' 'meeting'
 'money' 'moved' 'now' 'prize' 'report' 'send' 'the' 'three' 'to'
 'tomorrow' 'win' 'you' 'your']

4
22
```



В ручном словаре **23** слова; `CountVectorizer` даёт **22**. Сравните списки и попробуйте найти пропавшее слово, прежде чем продолжить.

Пропавшее слово — `a`. Шаблон токенов по умолчанию убирает его без предупреждения. Подсчёт и осмотр словаря показывают решение библиотеки, которое удалило информацию.
