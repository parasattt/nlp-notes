## Изучайте синтаксис regex по частям

Следующие примеры объясняют, что шаблон может находить, сколько раз элемент может повторяться и где может возникнуть совпадение. Изучайте части постепенно, не пытаясь сразу запомнить всю таблицу.

### Классы символов: какие символы?



```python
sample = "In 2026, 15 students passed. 3 did not."

print(re.findall(r"[0-9]", sample))   # single digits
print(re.findall(r"[0-9]+", sample))  # runs of digits
print(re.findall(r"\d+", sample))     # \d is shorthand for [0-9]
```


**Сохранённый вывод:**

```text
['2', '0', '2', '6', '1', '5', '3']
['2026', '15', '3']
['2026', '15', '3']
```



| Шаблон | Значение |
|---|---|
| `\d` | Цифра. |
| `\D` | Символ, который не является цифрой. |
| `\w` | Символ слова Unicode: буква, цифра или подчёркивание. |
| `\W` | Символ, который не является символом слова. |
| `\s` | Пробельный символ: пробел, табуляция или перевод строки. |
| `\S` | Непробельный символ. |
| `.` | При стандартных настройках — любой символ, кроме перевода строки. |
| `[abc]` | Один из символов `a`, `b` или `c`. |
| `[^abc]` | Любой символ, кроме `a`, `b` или `c`. |
| `[a-z]` | Строчная буква из этого диапазона. |



```python
messy = "word1 \t word2\n\n   word3"
print(repr(messy))
print(re.findall(r"\S+", messy))       # runs of non-whitespace
print(re.split(r"\s+", messy.strip())) # split on any run of whitespace
```


**Сохранённый вывод:**

```text
'word1 \t word2\n\n   word3'
['word1', 'word2', 'word3']
['word1', 'word2', 'word3']
```



Для обычных пробельных символов подходит и `messy.split()`. Regex полезен, когда разделитель более конкретный: например, запятая с необязательными пробелами, точка с запятой или один из нескольких возможных разделителей.



### Квантификаторы: сколько повторений?

| Шаблон | Значение |
|---|---|
| `+` | Один или больше. |
| `*` | Ноль или больше. |
| `?` | Ноль или один; предыдущий элемент необязателен. |
| `{3}` | Ровно три. |
| `{2,4}` | От двух до четырёх. |
| `{2,}` | Два или больше. |



```python
print(re.findall(r"colou?r", "color and colour are both correct"))
print(re.findall(r"\d{4}", "Years: 2024, 2025, 2026 and 12345"))
print(re.findall(r"a+", "a aa aaa b"))
```


**Сохранённый вывод:**

```text
['color', 'colour']
['2024', '2025', '2026', '1234']
['a', 'aa', 'aaa']
```



### Якоря: где может быть совпадение?

| Шаблон | Значение |
|---|---|
| `^` | Начало строки. |
| `$` | Конец строки. |
| `\b` | Граница слова. |



```python
lines = ["ERROR: disk full", "INFO: started", "ERROR: timeout"]
for line in lines:
    if re.match(r"^ERROR: disk", line):     # match() checks from the start
        print(line)
```


**Сохранённый вывод:**

```text
ERROR: disk full
```



**Граница слова**, `\b`, не даёт совпадению с ключевым словом продолжаться внутри более длинного слова. Следующий пример показывает, почему это важно.



```python
text = "The cat sat on a catastrophic catalogue in Cathmandu"

print(re.findall(r"cat", text))         # matches inside other words too
print(re.findall(r"\bcat\b", text))     # only the standalone word
```


**Сохранённый вывод:**

```text
['cat', 'cat', 'cat']
['cat']
```



Ранее поиск отзывов в pandas использовал `.str.contains("battery")`. Обычный поиск `cat` находит также части слов, например *catalogue*, *catastrophe* и *category*.

Такая ошибка часто даёт правдоподобные, но неверные подсчёты вместо исключения. Если окружить ключевое слово `\b`, оно должно находиться на границах слова.

Предыдущий пример pandas находится в теме [[RUS/Lectures/2 - Pandas для текстовых данных/2.7 - Фильтрация текста и категорий|фильтрация строк поиском по тексту]].



### Группы и варианты

Скобки `( )` захватывают часть совпадения. Вертикальная черта `|` означает «или». Пример с датами отдельно захватывает год, месяц и день; следующий выбирает названия животных.



```python
dates = "Deadlines: 2026-03-15, 2026-04-01 and 2026-12-31"

# Capture year, month, day separately
for match in re.findall(r"(\d{4})-(\d{2})-(\d{2})", dates):
    print(match)
    year, month, day = match
    print(f"day {day}, month {month}, year {year}")
```


**Сохранённый вывод:**

```text
('2026', '03', '15')
day 15, month 03, year 2026
('2026', '04', '01')
day 01, month 04, year 2026
('2026', '12', '31')
day 31, month 12, year 2026
```



```python
print(re.findall(r"\b(cat|dog|bird)\b", "I have a cat, a dog and three birds"))
```


**Сохранённый вывод:**

```text
['cat', 'dog']
```



`birds` не совпадает с вариантом `bird`, потому что следующий `s` всё ещё является символом слова. Нужной границы нет.

Regex точно следует заданному шаблону. Поэтому точные шаблоны полезны, но почти правильное правило может пропустить случай, который вы хотели включить.
