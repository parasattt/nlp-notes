## Опишите нужные токены

**Регулярное выражение** — небольшой язык шаблонов для текста. Вместо списка удаляемых символов напишите шаблон, описывающий текст, который нужно сохранить.



```python
print(re.findall(r"[a-zA-Z]+", real))
```


**Сохранённый вывод:**

```text
['Dr', 'Smith', 'said', 'NLP', 'is', 'hard', 'isn', 't', 'it', 'he', 'wasn', 't', 'wrong']
```



Читайте `[a-zA-Z]+` как «одна или несколько букв из a–z или A–Z». `findall` возвращает каждую непересекающуюся последовательность, соответствующую шаблону.

Это заменяет вручную составляемый список пунктуации одним определением токена. Пунктуация исключается, даже если программа раньше не встречала конкретный знак.



```python
print(re.findall(r"[a-zA-Z]+", tricky))
```


**Сохранённый вывод:**

```text
['Email', 'me', 'at', 'ivan', 'mail', 'kz', 'or', 'call', 'Cost', 'off']
```



Новый токенизатор не становится автоматически правильным для любой задачи. Он разбивает `ivan@mail.kz` на `ivan`, `mail` и `kz`, а числа удаляет.

Полезное изменение состоит в том, что политика теперь записана одним шаблоном. Чтобы изменить её, исправьте шаблон, а не расширяйте функцию удаления символов.



```python
# Include numbers and apostrophes: words like "isn't" and "19.99" survive
print(re.findall(r"[a-zA-Z0-9']+", tricky))
```


**Сохранённый вывод:**

```text
['Email', 'me', 'at', 'ivan', 'mail', 'kz', 'or', 'call', '7', '701', '555', '0199', 'Cost', '19', '99', '30', 'off']
```

> [!note] Комментарий источника и сохранённый вывод
> Исходный комментарий говорит, что `19.99` сохраняется этим шаблоном. Однако сохранённый результат содержит отдельные токены `19` и `99`: класс символов не включает десятичную точку. Исходные код, комментарий и сохранённый вывод оставлены без изменений.
