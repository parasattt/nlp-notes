## Удаление HTML-тегов из текстового поля

Веб-текст может содержать разметку, например `<p>`. Такие теги не должны становиться словами в частотном подсчёте.

### Сначала вручную

Следующая функция отслеживает, находится ли текущий символ внутри тега.



```python
html = "<p>The <b>best</b> phone I have <i>ever</i> owned!</p><br/><a href='#'>Read more</a>"

def strip_tags_manual(s):
    out = []
    inside = False
    for ch in s:
        if ch == "<":
            inside = True
        elif ch == ">":
            inside = False
        else:
            if not inside:
                out.append(ch)
    return "".join(out)

print(strip_tags_manual(html))
```


**Сохранённый вывод:**

```text
The best phone I have ever owned!Read more
```



Ручному методу нужны цикл и переменная состояния `inside`. Чтобы понять, обработает ли он тег вроде `<a href="a>b">`, приходится изучать его логику.

### Вариант с regex

Следующий пример выражает то же простое правило удаления в виде шаблона.



```python
print(re.sub(r"<[^>]+>", "", html))
```


**Сохранённый вывод:**

```text
The best phone I have ever owned!Read more
```



Шаблон `<[^>]+>` означает: открывающий `<`, один или несколько символов, отличных от `>`, затем закрывающий `>`. Замена совпадений пустой строкой удаляет эти простые теги.

Лекция указывает и ограничение: для серьёзной работы с HTML нужен HTML-парсер, например BeautifulSoup. Шаблон удаления тегов не понимает вложенность. Помните это ограничение, даже когда короткий шаблон удобен для текстового поля.
