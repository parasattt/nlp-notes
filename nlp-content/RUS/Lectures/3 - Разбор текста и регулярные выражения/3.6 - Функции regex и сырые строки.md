## Выберите функцию поиска совпадений

| Функция | Что возвращает или делает |
|---|---|
| `re.findall(pattern, text)` | Список всех совпадений. |
| `re.search(pattern, text)` | Первое совпадение или `None`. |
| `re.match(pattern, text)` | Проверяет совпадение в **начале** строки. |
| `re.sub(pattern, repl, text)` | Заменяет текст, соответствующий шаблону. |
| `re.split(pattern, text)` | Разбивает текст по совпавшим разделителям. |

В примере с телефоном также показаны `group()` для совпавшего текста и `start()`/`end()` для его позиций.



```python
text = "Call 555-1234 or 555-5678 today"

print(re.findall(r"\d{3}-\d{4}", text))

m = re.search(r"\d{3}-\d{4}", text)
print(m.group())     # the matched text
print(m.start(), m.end())   # where it was found

print(re.sub(r"\d{3}-\d{4}", "[PHONE]", text))
```


**Сохранённый вывод:**

```text
['555-1234', '555-5678']
555-1234
5 13
Call [PHONE] or [PHONE] today
```



### Используйте сырые строки для шаблонов

В `r"..."` Python оставляет обратные слеши для движка regex. Без `r` Python сначала интерпретирует `\b` как символ возврата на один знак, ещё до передачи шаблона regex.

Следующее сохранённое сравнение использует внешне одинаковый шаблон границы с префиксом сырой строки и без него.



```python
print(re.findall("\bcat\b", "the cat sat"))    # no r prefix -> broken, finds nothing
print(re.findall(r"\bcat\b", "the cat sat"))   # with r -> works
```


**Сохранённый вывод:**

```text
[]
['cat']
```
