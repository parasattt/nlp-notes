## Извлечение прямо из столбца pandas

Pandas предоставляет `.str.extract` на основе regex, поэтому цикл извлечения полей часто не нужен. Имена групп становятся именами выходных столбцов.

Строковый интерфейс столбцов был представлен в теме [[RUS/Lectures/2 - Pandas для текстовых данных/2.7 - Фильтрация текста и категорий|строковые операции pandas]].



```python
s = pd.Series([
    "Order #10234 shipped on 2026-03-15",
    "Order #10235 delayed until 2026-04-01",
    "Order #10236 delivered 2026-03-20",
])

s.str.extract(r"#(?P<order>\d+).*?(?P<date>\d{4}-\d{2}-\d{2})")
```


**Сохранённый вывод:**

```text
   order        date
0  10234  2026-03-15
1  10235  2026-04-01
2  10236  2026-03-20
```



`.*?` — **ленивый** вариант: он захватывает как можно меньше, сохраняя возможность совпадения всего шаблона. Жадный `.*` сначала пытается расшириться как можно дальше, а затем отступает назад.

При извлечении между повторяющимися маркерами ленивый вариант может сохранить элементы раздельными. Следующий HTML-пример показывает разницу.



```python
# Greedy vs lazy, side by side
html = "<b>first</b> and <b>second</b>"
print(re.findall(r"<b>.*</b>", html))    # greedy: one huge match
print(re.findall(r"<b>.*?</b>", html))   # lazy: two correct matches
```


**Сохранённый вывод:**

```text
['<b>first</b> and <b>second</b>']
['<b>first</b>', '<b>second</b>']
```
