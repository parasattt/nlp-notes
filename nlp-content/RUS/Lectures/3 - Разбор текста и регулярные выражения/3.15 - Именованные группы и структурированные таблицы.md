Шаблон regex также описывает ожидаемый формат записи. Читатель, понимающий шаблон, видит, какие поля должна содержать подходящая строка.

### Дайте группам захвата имена

Когда полей становится больше, за пронумерованными группами трудно следить. Используйте `(?P<name>...)`, чтобы назвать каждый захват.



```python
pattern = (
    r"\[(?P<timestamp>[^\]]+)\] "
    r"ORDER #(?P<order_id>\d+) "
    r"user=(?P<user>\S+) "
    r"total=(?P<total>\d+)KZT "
    r"status=(?P<status>\w+)"
)

rows = []
for line in log.splitlines():
    m = re.search(pattern, line)
    if m:
        rows.append(m.groupdict())

orders = pd.DataFrame(rows)
orders
```


**Сохранённый вывод:**

```text
             timestamp order_id            user   total     status
0  2026-03-15 09:14:22    10234   aisha@mail.kz  125000    shipped
1  2026-03-15 10:02:05    10235  bolat@shop.com   87500    pending
2  2026-03-16 12:00:00    10236    dana@mail.kz  340000    shipped
3  2026-03-17 08:30:59    10237   erlan@mail.kz   15000  cancelled
```



Результат — DataFrame из полей журнала. `groupdict()` даёт именованные значения для каждой подходящей записи.

Шаблон записан соседними строковыми литералами на нескольких строках. Python объединяет их, поэтому шаблон остаётся читаемым, не превращаясь в одну длинную строку.

Полученная табличная структура объясняется в теме [[RUS/Lectures/2 - Pandas для текстовых данных/2.3 - DataFrame и Series|DataFrame и Series]].
