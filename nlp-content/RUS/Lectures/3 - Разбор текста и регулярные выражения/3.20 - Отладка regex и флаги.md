## Отлаживайте шаблон небольшими шагами

1. **Собирайте постепенно:** проверьте `\d+`, затем `\d+-`, затем остальное. Длинный шаблон, написанный сразу, труднее отлаживать.
2. **Используйте самый маленький вход, на котором ошибка ещё возникает.**
3. **Изучайте совпадения в [regex101](https://regex101.com)**, выбрав вариант Python. Источник рекомендует объяснения шаблонов и подсветку совпадений в реальном времени.
4. **Печатайте фактическое совпадение**, не предполагая, что именно совпало.
5. **Проверяйте префикс сырой строки.** Отсутствие `r` может изменить обратные слеши до того, как их получит regex.

Следующий код показывает поиск без учёта регистра, якоря для каждой строки и шаблон с комментариями, записанный с `re.VERBOSE`.



```python
# Useful flags
text = "Hello WORLD hello world"

print(re.findall(r"hello", text, re.IGNORECASE))

multi = "line one\nline two\nline three"
print(re.findall(r"^line \w+$", multi, re.MULTILINE))   # ^ and $ per line

# re.VERBOSE lets you write a readable, commented pattern
phone_re = re.compile(r"""
    \+?          # optional plus
    \d{1,3}      # country code
    [\s\-]?      # separator
    \(?\d{3}\)?  # area code, maybe in brackets
    [\s\-]?
    \d{3}
    [\s\-]?
    \d{2}
    [\s\-]?
    \d{2}
""", re.VERBOSE)

print(phone_re.findall("Call +7 701 555 01 99 now"))
```


**Сохранённый вывод:**

```text
['Hello', 'hello']
['line one', 'line two', 'line three']
['+7 701 555 01 99']
```



`re.compile()` один раз подготавливает шаблон, чтобы полученный объект можно было использовать снова, не разбирая шаблон заново для каждой строки данных. Лекция рекомендует это при применении одного шаблона к множеству строк. Подробно записанный телефонный пример также показывает, как пробелы и комментарии делают длинный шаблон понятнее.
