## Извлечение хештегов, упоминаний и эмодзи: заголовок источника

Принятые в социальных сетях обозначения — тоже текстовые шаблоны. Следующий пример извлекает **хештеги и упоминания** из Series публикаций, затем подсчитывает и нормализует хештеги. Исходный заголовок также называет эмодзи, но в этом примере их извлечение не реализовано.

> [!note] Границы исходного примера
> Исходный заголовок упоминает эмодзи. Код примера извлекает хештеги и упоминания, но не реализует извлечение эмодзи.



```python
tweets = pd.Series([
    "Loving the new update! #nlp #python @openai_dev",
    "@friend check this out #machinelearning",
    "No tags here, just plain text.",
    "#Kazakhstan #almaty are trending @kaznews",
])

df_t = pd.DataFrame({"tweet": tweets})
#print(df_t)
df_t["hashtags"] = df_t["tweet"].apply(lambda t: re.findall(r"#(\w+)", t))
df_t["mentions"] = df_t["tweet"].apply(lambda t: re.findall(r"@(\w+)", t))
df_t["n_tags"] = df_t["hashtags"].str.len()
df_t
```


**Сохранённый вывод:**

```text
                                             tweet              hashtags  \
0  Loving the new update! #nlp #python @openai_dev         [nlp, python]   
1          @friend check this out #machinelearning     [machinelearning]   
2                   No tags here, just plain text.                    []   
3        #Kazakhstan #almaty are trending @kaznews  [Kazakhstan, almaty]   

       mentions  n_tags  
0  [openai_dev]       2  
1      [friend]       1  
2            []       0  
3     [kaznews]       2  
```



```python
# All hashtags across the corpus, case-normalised
all_tags = [tag.lower() for row in df_t["hashtags"] for tag in row]
Counter(all_tags).most_common()
```


**Сохранённый вывод:**

```text
[('nlp', 1),
 ('python', 1),
 ('machinelearning', 1),
 ('kazakhstan', 1),
 ('almaty', 1)]
```
