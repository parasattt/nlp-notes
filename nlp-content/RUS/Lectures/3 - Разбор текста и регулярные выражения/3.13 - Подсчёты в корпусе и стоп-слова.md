```python
# Remove stop words - the frequent words that carry little meaning
stop_words = {
    "the", "a", "an", "is", "was", "are", "were", "in", "on", "at", "to", "for",
    "of", "and", "but", "or", "it", "this", "that", "i", "you", "me", "my",
    "be", "not", "no", "so", "too", "very", "num", "url", "email", "phone", "date",
}

df["tokens_nostop"] = df["tokens"].apply(
    lambda toks: [t for t in toks if t not in stop_words and len(t) > 2]
)

all_content = [tok for row in df["tokens_nostop"] for tok in row]
Counter(all_content).most_common(15)
```

До удаления стоп-слов в списке частот преобладают грамматические слова. После удаления список больше говорит о теме.

Но есть цена: этот список удаляет `not`, поэтому `not great` и `great` становятся неразличимыми. Для некоторых тематических задач это допустимо, но информация о тональности может быть потеряна.

Единого списка стоп-слов для всех задач нет. Выбирайте его по той информации, которая нужна задаче, а не принимайте настройки по умолчанию без проверки.
