## Нормализация пробельных символов

### Используйте обычный строковый метод, если его достаточно

Разбиение по пробельным символам и объединение через одиночные пробелы сворачивает повторяющиеся пробелы, табуляции и переводы строк.



```python
messy = "Too    many\t\tspaces\n\nand  newlines   here"

# The trick: split on any whitespace, then join with single spaces
print(" ".join(messy.split()))
```


**Сохранённый вывод:**

```text
Too many spaces and newlines here
```

Вариант с обычными строками использует [[RUS/Lectures/1 - Основы Python для работы с текстом/1.9 - Разбиение и объединение текста|split и join]].



Обычный метод split/join в Python уже понятно решает первую задачу. Используйте regex, когда нужно более конкретное правило. Следующий пример сворачивает пробелы и табуляции, сохраняя разделение на абзацы.



```python
# "Collapse repeated spaces but keep paragraph breaks" - not expressible with split()
text = "Line one   has    spaces.\n\nLine two   also.\n\n\n\nLine three."

step1 = re.sub(r"[ \t]+", " ", text)        # collapse spaces and tabs only
step2 = re.sub(r"\n{3,}", "\n\n", step1)    # 3+ newlines become exactly 2
print(step2)
```


**Сохранённый вывод:**

```text
Line one has spaces.

Line two also.

Line three.
```
