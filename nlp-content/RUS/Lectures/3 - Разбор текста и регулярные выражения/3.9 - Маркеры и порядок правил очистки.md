## Заменяйте изменяющиеся детали маркерами

NLP-модели может быть бесполезно запоминать тысячи разных URL. Но сам факт, что **в тексте был URL**, может помочь, особенно при обнаружении спама.

Заменяйте URL, электронные адреса, номера телефонов и даты специальными токенами-маркерами. Это сохраняет тип информации и уменьшает количество разных строк.



```python
post = """Check out https://example.com/deals for 50% off!
Contact us at sales@example.com or support@shop.kz.
Call +7 701 555 0199. Order #12345 shipped 2026-03-15."""

clean = post
clean = re.sub(r"https?://\S+", " <URL> ", clean)
clean = re.sub(r"\S+@\S+\.\S+", " <EMAIL> ", clean)
clean = re.sub(r"\+?\d[\d\s\-()]{7,}\d", " <PHONE> ", clean)
clean = re.sub(r"\d{4}-\d{2}-\d{2}", " <DATE> ", clean)
clean = re.sub(r"\s+", " ", clean).strip()

print(clean)
```


**Сохранённый вывод:**

```text
Check out <URL> for 50% off! Contact us at <EMAIL> or <EMAIL> Call <PHONE> . Order #12345 shipped <PHONE> .
```



### Разберём шаблон URL по частям

Для `https?://\S+`:

- `http` соответствует этим буквам буквально.
- `s?` делает `s` необязательной, допуская HTTP и HTTPS.
- `://` — буквальный текст.
- `\S+` соответствует следующей последовательности непробельных символов.

Источник предлагает сравнить это с решением на основе `find()` и срезов: ручной вариант потребует больше кода и может пропустить URL в конце строки.

### Найдите ошибку в порядке очистки

В сохранённом выводе дата `2026-03-15` превращается в `<PHONE>` вместо `<DATE>`.

Телефонный шаблон `\+?\d[\d\s\-()]{7,}\d` допускает необязательный плюс, цифру, не менее семи символов из цифр, пробелов, дефисов и скобок, а затем последнюю цифру. Дата подходит под эту форму.

Правило телефона выполняется первым и поглощает дату. Когда запускается правило даты, исходной даты уже нет.

Поэтому общее правило перед конкретным может без ошибки создать правдоподобный, но неверный текст. Исправление — сначала применять более конкретное правило.



```python
clean = post
clean = re.sub(r"https?://\S+", " <URL> ", clean)          # URLs first (they contain @ and digits)
clean = re.sub(r"\S+@\S+\.\S+", " <EMAIL> ", clean)        # then emails
clean = re.sub(r"\d{4}-\d{2}-\d{2}", " <DATE> ", clean)     # dates BEFORE phones - specific first
clean = re.sub(r"\+?\d[\d\s\-()]{7,}\d", " <PHONE> ", clean)
clean = re.sub(r"\s+", " ", clean).strip()

print(clean)
```


**Сохранённый вывод:**

```text
Check out <URL> for 50% off! Contact us at <EMAIL> or <EMAIL> Call <PHONE> . Order #12345 shipped <DATE> .
```



В исправленном сохранённом выводе дата остаётся как `<DATE>`.

Применяйте **сначала конкретные шаблоны, затем общие**. Обрабатывайте URL до электронных адресов, потому что URL может содержать `@`. Обрабатывайте даты до телефонов, потому что дата может напоминать номер телефона. Общее правило вроде `\d+`, если оно нужно, ставьте последним. ^specific-before-general

Очистка — последовательность шагов: каждая замена изменяет текст, который получает следующий шаг.
