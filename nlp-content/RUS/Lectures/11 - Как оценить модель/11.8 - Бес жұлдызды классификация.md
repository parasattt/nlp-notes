### Бес жұлдызды классификация

TF-IDF және логистикалық регрессия бес жұлдыз класын болжайды; ноутбукта accuracy шамамен 53%. 5×5 confusion matrix диагоналы дұрыс болжамдарды, көрші ұяшықтар жақын бағаға қателерді көрсетеді. classification_report әр классқа precision, recall және F1 береді; macro average кластарға тең салмақ, weighted average олардың жиілігіне салмақ береді.

```python
clf = LogisticRegression(max_iter=2000).fit(T_train, y_train_df["stars"])
pred = clf.predict(T_test)
print(f"accuracy: {accuracy_score(y_test_df['stars'], pred):.3f}   (baseline about 0.20)")
```

**Сохранённый результат:**

```text
accuracy: 0.534   (baseline about 0.20)
```

```python
cm = confusion_matrix(y_test_df["stars"], pred)

fig, ax = plt.subplots(figsize=(4.6, 3.9))
ax.imshow(cm, cmap="Blues")
for i in range(5):
    for j in range(5):
        ax.text(j, i, cm[i, j], ha="center", va="center", fontsize=9,
                color="white" if cm[i, j] > cm.max() / 2 else "black")
ax.set_xticks(range(5), [1, 2, 3, 4, 5]); ax.set_yticks(range(5), [1, 2, 3, 4, 5])
ax.set_xlabel("predicted stars"); ax.set_ylabel("true stars")
ax.set_title("Confusion matrix, 3 000 test reviews", fontsize=10)
plt.tight_layout()
plt.show()
```
