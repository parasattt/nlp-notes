### Теңгерілмеген кластар

1000 мысалдың 50-і оң класс болса, әрқашан теріс деу 95% accuracy береді, бірақ recall және F1 нөлге тең. Сондықтан сирек маңызды кластарда тек accuracy емес, precision, recall, F1 және confusion matrix қарастырылады.

```python
truth = np.array([1] * 50 + [0] * 950)
lazy = np.zeros(1000, dtype=int)
print(f"accuracy  {accuracy_score(truth, lazy):.3f}")
print(f"recall    {recall_score(truth, lazy):.3f}")
print(f"F1        {f1_score(truth, lazy, zero_division=0):.3f}")
```

**Сохранённый результат:**

```text
accuracy  0.950
recall    0.000
F1        0.000
```
