## Сравниваем с базовым прогнозом по большинству

В настоящем почтовом ящике spam и ham не обязательно поровну. Допустим, спам составляет только 10% входящих сообщений. В следующем примере 2 spam и 18 ham: он показывает, как accuracy скрывает полный провал на меньшем классе.



```python
imbalanced_texts = spam_samples[:2] + ham_samples + ham_samples[:3]
imbalanced_labels = ["spam"] * 2 + ["ham"] * (len(ham_samples) + 3)

print("class balance:", Counter(imbalanced_labels))

class AlwaysHam:
    def predict(self, texts):
        return ["ham"] * len(texts)

lazy = AlwaysHam()
lazy_pred = lazy.predict(imbalanced_texts)

print()
print("accuracy of a model that just says 'ham' every time:",
      round(accuracy_score(imbalanced_labels, lazy_pred), 3))
```


**Сохранённый вывод:**

```text
class balance: Counter({'ham': 18, 'spam': 2})

accuracy of a model that just says 'ham' every time: 0.9
```



`AlwaysHam` вообще не ловит спам, но его accuracy равна `18 / 20 = 0.9`. Единственное правило — для каждого сообщения возвращать `ham`.

На этих данных сама по себе accuracy 90% мало что говорит. Базовый уровень — **доля самого частого класса**, то есть 90%, а не предполагаемые 50%. Полезную модель нужно сравнивать и с этим уровнем, и по ошибкам, которые имеют значение.



```python
print(classification_report(imbalanced_labels, lazy_pred, zero_division=0))
```


**Сохранённый вывод:**

```text
              precision    recall  f1-score   support

         ham       0.90      1.00      0.95        18
        spam       0.00      0.00      0.00         2

    accuracy                           0.90        20
   macro avg       0.45      0.50      0.47        20
weighted avg       0.81      0.90      0.85        20

```



Отчёт по классам сразу показывает провал: recall для spam равна **0.00**, ведь не поймано ни одно из двух спам-сообщений. В сохранённом отчёте precision для spam и F1 тоже нулевые. Всегда изучайте каждый класс, а не только общую accuracy.
