Функция начинает оценку каждого класса с его априорной вероятности, умножает её на вероятность каждого слова сообщения и выбирает большую оценку. Сохранённый вывод позволяет проверить оба расчёта.

```python
def classify_by_hand(message):
    words = message.split()

    score_spam = p_spam
    score_ham = p_ham
    for w in words:
        score_spam *= p_word_given(w, spam_counts, len(spam_words))
        score_ham  *= p_word_given(w, ham_counts,  len(ham_words))

    print(f"message   : {message}")
    print(f"spam score: {score_spam:.10f}")
    print(f"ham score : {score_ham:.10f}")
    print(f"verdict   : {'spam' if score_spam > score_ham else 'ham'}")
    print()

classify_by_hand("free money now")
classify_by_hand("send the report")
```


**Сохранённый вывод:**

```text
message   : free money now
spam score: 0.0010288066
ham score : 0.0000000000
verdict   : spam

message   : send the report
spam score: 0.0000000000
ham score : 0.0002500000
verdict   : ham

```



Оба сообщения получают ожидаемые метки только благодаря подсчёту и умножению. Для `free money now` оценка spam равна `0.5 × (3/18) × (2/18) × (2/18) = 0.0010288066`, а оценка ham — нулю. Для `send the report` оценка ham равна `0.5 × (1/20) × (2/20) × (2/20) = 0.0002500000`.

Эти оценки — **не нормализованные вероятности классов**. Знак пропорциональности в правиле Байеса означает, что общий для классов знаменатель опущен. Для выбора класса достаточно сравнить оценки.
