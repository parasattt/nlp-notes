## Превращаем документную частоту в обратную документную частоту

`the` есть во всех 3 документах, `battery` — в 2, а каждое другое слово словаря — в 1. Слово из меньшего числа документов полезнее для различения документов.

**Обратная документная частота**, или IDF, даёт таким менее частым словам больший вес:

$$\text{idf}(w) = \log \frac{N}{\text{df}(w)}$$

- `w` — слово, вес которого нужно найти.
- $N$ — общее число документов.
- `df(w)` — число документов, содержащих это слово.
- `N / df(w)` растёт, когда слово становится реже.
- Логарифм сжимает это отношение, сохраняя у редких слов больший вес, чем у частых.

### Зачем нужен логарифм?

Следующая таблица представляет магазин с 1,000 отзывов. Сравните исходное отношение и его натуральный логарифм при нескольких документных частотах.



```python
N_shop = 1000
table = pd.DataFrame({"df": [1, 10, 100, 500, 1000]})
table["N / df"] = N_shop / table["df"]
table["log(N / df)"] = np.log(table["N / df"]).round(2)
print(table.to_string(index=False))
```


**Сохранённый вывод:**

```text
  df  N / df  log(N / df)
   1  1000.0         6.91
  10   100.0         4.61
 100    10.0         2.30
 500     2.0         0.69
1000     1.0         0.00
```



У слова в одном из 1,000 отзывов `N / df = 1000`, а у слова в десяти отзывах — `N / df = 100`. Отношение равно **10 к 1**. Исходный абзац говорит «в 100 раз реже» и «в 100 раз больший вес», но его же таблица показывает разницу в десять раз.

Без логарифма разовое слово или опечатка вроде `batery` могли бы получить очень большой вес редкости. Логарифм сохраняет порядок, уменьшая разницу: `1000` превращается примерно в `6.9`, а `100` — примерно в `4.6`.

Можно понимать IDF как меру неожиданности. Слово `the` почти ничего не сообщает о том, какой отзыв вы читаете. Характерное слово вроде `cracked` говорит гораздо больше. Сохранённый график показывает снижение IDF с ростом документной частоты.



Логарифмическая ось документной частоты позволяет показать вместе редкие и частые слова. Подписи размещают опечатку, `cracked`, `is` и `the` на примерных значениях документной частоты.

```python
df_range = np.arange(1, N_shop + 1)

plt.figure(figsize=(6, 3.2))
plt.plot(df_range, np.log(N_shop / df_range))
for d, label in [(1, "a typo"), (10, "'cracked'"), (500, "'is'"), (1000, "'the'")]:
    plt.scatter(d, np.log(N_shop / d), zorder=3)
    plt.annotate(label, (d, np.log(N_shop / d)), textcoords="offset points", xytext=(6, 6))
plt.xscale("log")
plt.ylim(-0.5, 8)
plt.xlabel("document frequency (log scale)")
plt.ylabel("idf")
plt.title("IDF falls as a word gets more common (N = 1000)")
plt.tight_layout()
plt.show()
```
