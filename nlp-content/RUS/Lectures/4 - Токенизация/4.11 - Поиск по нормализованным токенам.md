## Функция поиска

Пользователь ищет по набору обращений в поддержку. Простой поиск сравнивает исходные строки слов и пропускает подходящие обращения с другой формой слова.



`naive_search` переводит запрос и каждое обращение в нижний регистр и разбивает по пробельным символам. `q & ...` — пересечение множеств, поэтому для совпадения достаточно любого общего токена; наличие всех слов запроса не требуется.

```python
tickets = [
    "The battery died after two days",
    "Batteries drain very quickly",
    "My battery is draining fast",
    "Great screen and fast charging",
    "The charger stopped working",
    "Screen cracked when I dropped it",
]

def naive_search(query, docs):
    q = set(query.lower().split())
    return [i for i, d in enumerate(docs) if q & set(d.lower().split())]

hits = naive_search("battery draining", tickets)
print("matched:", hits)
for i in hits:
    print("   ", tickets[i])
```


**Сохранённый вывод:**

```text
matched: [0, 2]
    The battery died after two days
    My battery is draining fast
```



Простой поиск возвращает обращения 0 и 2. Обращение 1, `Batteries drain`, описывает ту же проблему, но `batteries` и `battery` — разные строки.



Улучшенный поиск использует ресурсы WordNet. `normalize` переводит текст в нижний регистр, токенизирует, удаляет небуквенные токены и стоп-слова из списка, сохраняющего отрицания, затем добавляет в множество леммы и существительных (`"n"`), и глаголов (`"v"`). `smart_search` по-прежнему находит совпадение при любом общем нормализованном токене.

```python
from nltk.stem import WordNetLemmatizer

nltk.download("wordnet", quiet=True)
nltk.download("omw-1.4", quiet=True)

wnl = WordNetLemmatizer()

def normalize(text):
    """Tokenize, drop punctuation and stop words, reduce each word to a base form."""
    out = set()
    for w in word_tokenize(text.lower()):
        if not w.isalpha() or w in stop_safe:
            continue
        out.add(wnl.lemmatize(w, "n"))   # as a noun
        out.add(wnl.lemmatize(w, "v"))   # as a verb
    return out

def smart_search(query, docs):
    q = normalize(query)
    return [i for i, d in enumerate(docs) if q & normalize(d)]

hits = smart_search("battery draining", tickets)
print("matched:", hits)
for i in hits:
    print("   ", tickets[i])
```


**Сохранённый вывод:**

```text
matched: [0, 1, 2]
    The battery died after two days
    Batteries drain very quickly
    My battery is draining fast
```



Нормализованный поиск находит три обращения, включая ранее пропущенное `Batteries drain`.

Родственные слова присутствовали с самого начала, но сравнение исходных строк не могло их связать. **Токенизация** выбирает единицы. **Нормализация** выбирает, какие формы считать одинаковыми. Лекция связывает этот процесс с поисковыми системами, обнаружением дубликатов и фильтрацией спама.

Код добавляет в множество леммы и существительных, и глаголов, вместо предварительного выбора правильной части речи. [[RUS/Lectures/5 - Стемминг и лемматизация/5.5 - Лемматизация WordNet и части речи|Следующая лекция]] объясняет, почему часть речи важна.
