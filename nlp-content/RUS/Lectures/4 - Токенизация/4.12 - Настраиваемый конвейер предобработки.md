## Многократно используемый конвейер предобработки



Функция явно задаёт выбор предобработки параметрами. Три вызова меняют только обработку стоп-слов и показывают, почему итоговое представление должно соответствовать задаче.

```python
def preprocess(text, lowercase=True, remove_stop=True, keep_negations=True,
               min_length=2, language="english"):
    """Turn raw text into tokens, with the choices made explicit."""
    if lowercase:
        text = text.lower()

    tokens = word_tokenize(text)
    tokens = [t for t in tokens if t.isalpha()]

    if remove_stop:
        stops = set(stopwords.words(language))
        if keep_negations:
            stops = stops - NEGATIONS
        tokens = [t for t in tokens if t not in stops]

    tokens = [t for t in tokens if len(t) >= min_length]
    return tokens


sample = "I did NOT like the battery life, but the screen is absolutely beautiful!!"

print("default        :", preprocess(sample))
print("keep stop words:", preprocess(sample, remove_stop=False))
print("drop negations :", preprocess(sample, keep_negations=False))
```


**Сохранённый вывод:**

```text
default        : ['not', 'like', 'battery', 'life', 'screen', 'absolutely', 'beautiful']
keep stop words: ['did', 'not', 'like', 'the', 'battery', 'life', 'but', 'the', 'screen', 'is', 'absolutely', 'beautiful']
drop negations : ['like', 'battery', 'life', 'screen', 'absolutely', 'beautiful']
```



Одно предложение даёт три списка токенов из-за разных решений. `lowercase` управляет регистром; `remove_stop` — фильтрацией стоп-слов; `keep_negations` защищает перечисленные отрицания; `min_length` удаляет короткие токены; `language` выбирает список стоп-слов NLTK. `isalpha()` сохраняет только буквенные токены.

По умолчанию `not` сохраняется, а `keep_negations=False` удаляет его. Настройка `remove_stop=False` сохраняет стоп-слова, хотя стандартная минимальная длина всё ещё удаляет однобуквенное `I`. Разным задачам подходят разные настройки. Явный выбор облегчает изучение и отладку конвейера.
