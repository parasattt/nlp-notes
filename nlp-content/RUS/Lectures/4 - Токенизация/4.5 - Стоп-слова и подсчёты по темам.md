## Стоп-слова



Код переводит отзыв в нижний регистр, токенизирует его, сохраняет буквенные токены с `isalpha()` и печатает восемь самых частых слов.

```python
review = """I bought this laptop for my daughter and she loves it. The screen is bright and the
battery lasts all day. It is not the fastest machine in the world but it is more than enough for
the things that she does with it."""

tokens = word_tokenize(review.lower())
words = [t for t in tokens if t.isalpha()]

print(Counter(words).most_common(8))
```


**Сохранённый вывод:**

```text
[('the', 5), ('it', 4), ('is', 3), ('for', 2), ('and', 2), ('she', 2), ('i', 1), ('bought', 1)]
```



Слова вроде `the`, `it`, `is` и `and` мало говорят о теме этого отзыва. Их называют **стоп-словами**. Их удаление может сделать тематические подсчёты слов понятнее, как в [[RUS/Lectures/3 - Разбор текста и регулярные выражения/3.13 - Подсчёты в корпусе и стоп-слова|предыдущем примере подсчётов в корпусе]].



Список английских стоп-слов превращается в множество для проверки принадлежности. Сохранённый вывод сообщает о 198 элементах и показывает первые 20 по алфавиту.

```python
from nltk.corpus import stopwords

stop_en = set(stopwords.words("english"))

print("how many:", len(stop_en))
print("sample  :", sorted(list(stop_en))[:20])
```


**Сохранённый вывод:**

```text
how many: 198
sample  : ['a', 'about', 'above', 'after', 'again', 'against', 'ain', 'all', 'am', 'an', 'and', 'any', 'are', 'aren', "aren't", 'as', 'at', 'be', 'because', 'been']
```



Отфильтруйте токены по этому множеству, затем сравните оставшиеся слова и восемь наибольших частот.

```python
content = [w for w in words if w not in stop_en]

print(content)
print()
print(Counter(content).most_common(8))
```


**Сохранённый вывод:**

```text
['bought', 'laptop', 'daughter', 'loves', 'screen', 'bright', 'battery', 'lasts', 'day', 'fastest', 'machine', 'world', 'enough', 'things']

[('bought', 1), ('laptop', 1), ('daughter', 1), ('loves', 1), ('screen', 1), ('bright', 1), ('battery', 1), ('lasts', 1)]
```



Оставшиеся подсчёты теперь яснее показывают предмет отзыва: `laptop`, `screen`, `battery` и `day`.
