## Токены меньше слов

Словарь слов имеет фиксированный размер. Когда модель встречает слово вне этого словаря, отдельного представления для него может не быть. Это **проблема слов вне словаря**.



Этот фиксированный словарь заменяет любую отсутствующую строку на `<UNK>`. Сравните `unhappiness` с известным родственным словом `unhappy`.

```python
vocab = {"the", "cat", "sat", "on", "mat", "happy", "unhappy"}

sentence = "the unhappiness of the cat"
print([w if w in vocab else "<UNK>" for w in sentence.split()])
```


**Сохранённый вывод:**

```text
['the', '<UNK>', '<UNK>', 'the', 'cat']
```



`unhappiness` становится `<UNK>`, поэтому представление теряет его индивидуальность, хотя словарь содержит родственное `unhappy`. В этом примере `of` тоже становится `<UNK>`.

**Подсловная токенизация** сохраняет частые слова целиком, а менее частые разбивает на часто встречающиеся части. Лекция представляет её как современное решение проблемы неизвестных слов, с отдельными символами как запасным вариантом. Широкая формулировка «ничто никогда не бывает неизвестным» — утверждение лекции; ниже показаны фактические части, полученные названными токенизаторами.

`AutoTokenizer.from_pretrained("bert-base-uncased")` выбирает указанный токенизатор. `.tokenize()` показывает его подсловные части для четырёх слов.

```python
from transformers import AutoTokenizer

bert = AutoTokenizer.from_pretrained("bert-base-uncased")

for w in ["tokenization", "unhappiness", "kazakhstan", "cat"]:
    print(f"{w:15} -> {bert.tokenize(w)}")
```


**Сохранённый вывод:**

```text
tokenization    -> ['token', '##ization']
unhappiness     -> ['un', '##ha', '##pp', '##iness']
kazakhstan      -> ['kazakhstan']
cat             -> ['cat']
```



`cat` остаётся целым. `tokenization` превращается в `token` + `##ization`; `##` отмечает часть, продолжающую предыдущий токен. `unhappiness` представлено несколькими известными частями, поэтому токенизатору не нужна отдельная словарная запись для целого слова.
