## Токенизатор русского текста

Лекция представляет `razdel` как небольшой быстрый токенизатор русского текста. В показанных казахских примерах он тоже работает достаточно хорошо, потому что правила пунктуации похожи. Это утверждение о примерах лекции, а не гарантия для любого казахского текста.



Исходная команда установки подготавливает `razdel`; при этом преобразовании установка не выполняется.

```python
!pip install razdel --quiet
print("done")
```



`sentenize` возвращает фрагменты предложений, а `tokenize` — фрагменты токенов; `.text` читает текст каждого фрагмента. Пунктуация остаётся видимой в виде отдельных токенов.

```python
from razdel import tokenize as rz_tokenize, sentenize as rz_sentenize

print("RU sentences:", [s.text for s in rz_sentenize(ru)])
print("RU tokens   :", [t.text for t in rz_tokenize(ru)])
print()
print("KK sentences:", [s.text for s in rz_sentenize(kk)])
print("KK tokens   :", [t.text for t in rz_tokenize(kk)])
```


**Сохранённый вывод:**

```text
RU sentences: ['Мы купили два новых ноутбука в магазине.', 'Они работали отлично!']
RU tokens   : ['Мы', 'купили', 'два', 'новых', 'ноутбука', 'в', 'магазине', '.', 'Они', 'работали', 'отлично', '!']

KK sentences: ['Мен дүкеннен екі жаңа кітап сатып алдым.', 'Достарыма бердім!', 'Олар қуанды.']
KK tokens   : ['Мен', 'дүкеннен', 'екі', 'жаңа', 'кітап', 'сатып', 'алдым', '.', 'Достарыма', 'бердім', '!', 'Олар', 'қуанды', '.']
```



Сохранённый результат правильно разделяет эти три казахских предложения. Пока это только **разбиение текста**. Понять, что у `кітап` и `кітаптарымызда` общая основа, — другая задача, которая рассматривается в [[RUS/Lectures/5 - Стемминг и лемматизация/5.13 - Агглютинация в казахском языке|стемминге и лемматизации]].
