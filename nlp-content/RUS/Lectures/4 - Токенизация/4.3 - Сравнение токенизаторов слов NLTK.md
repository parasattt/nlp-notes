## Токенизаторы NLTK

`nltk` — давно используемая NLP-библиотека с несколькими токенизаторами. Notebook сообщает, что она уже доступна в Colab; в других средах команда установки — `pip install nltk`.



Подготовка загружает ресурсы токенизации предложений `punkt` и `punkt_tab` и списки стоп-слов. Комментарий источника объясняет, что повторный запуск пропускает уже имеющиеся ресурсы; сохранённая версия — NLTK 3.9.2.

```python
import nltk

# Safe to re-run, it skips anything already present.
nltk.download("punkt", quiet=True)
nltk.download("punkt_tab", quiet=True)
nltk.download("stopwords", quiet=True)

print("nltk", nltk.__version__)
```


**Сохранённый вывод:**

```text
nltk 3.9.2
```



В сравнении одна и та же строка `messy` подаётся самописному токенизатору и трём вариантам NLTK. Изучите, какие единицы каждый сохраняет или разделяет.

```python
from nltk.tokenize import word_tokenize, wordpunct_tokenize, TweetTokenizer

print("ours    :", tokenize_v2(messy))
print()
print("wordpunct:", wordpunct_tokenize(messy))
print()
print("nltk     :", word_tokenize(messy))
print()
print("tweet    :", TweetTokenizer().tokenize(messy))
```


**Сохранённый вывод:**

```text
ours    : ['dr', 'smith', "didn't", 'pay', '$19.99', 'for', 'the', 'u.s.a', 'trip', "wasn't", 'that', 'great', '#nlp', '@ai_lab']

wordpunct: ['Dr', '.', 'Smith', 'didn', "'", 't', 'pay', '$', '19', '.', '99', 'for', 'the', 'U', '.', 'S', '.', 'A', '.', 'trip', '...', 'Wasn', "'", 't', 'that', 'great', '?!', ':)', '#', 'nlp', '@', 'ai_lab']

nltk     : ['Dr.', 'Smith', 'did', "n't", 'pay', '$', '19.99', 'for', 'the', 'U.S.A.', 'trip', '...', 'Was', "n't", 'that', 'great', '?', '!', ':', ')', '#', 'nlp', '@', 'ai_lab']

tweet    : ['Dr', '.', 'Smith', "didn't", 'pay', '$', '19.99', 'for', 'the', 'U', '.', 'S', '.', 'A', '.', 'trip', '...', "Wasn't", 'that', 'great', '?', '!', ':)', '#nlp', '@ai_lab']
```



Внимательно сравните все четыре списка токенов:

- **`wordpunct_tokenize`** разделяет слова и пунктуацию на отдельные группы. Результат предсказуем, но `didn't` превращается в `didn` + `'` + `t`, а `19.99` — в `19` + `.` + `99`.
- **`word_tokenize`** — общий начальный вариант в лекции. Здесь он сохраняет целыми `Dr.`, `U.S.A.` и `19.99`. Он разделяет `didn't` на `did` + `n't`, оставляя отрицание видимым. Однако `:)` он разбивает.
- **`TweetTokenizer`** предназначен для социальных сетей. Среди этих четырёх примеров только он сохраняет целыми `:)`, `#nlp` и `@ai_lab`. Он также разбивает `Dr.` и `U.S.A.`.

Лучшего токенизатора для любого входа нет. Выбирайте подходящий данным и задаче.
