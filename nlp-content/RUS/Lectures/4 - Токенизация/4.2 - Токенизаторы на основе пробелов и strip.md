## Разбиение по пробельным символам

`.split()` разбивает строку по пробельным символам. Для этого аккуратного предложения он подходит. [[RUS/Lectures/1 - Основы Python для работы с текстом/1.9 - Разбиение и объединение текста|Лекция по основам Python]] объясняет лежащие в основе строковые операции.



```python
text = "Natural language processing is useful"
print(text.split())
```


**Сохранённый вывод:**

```text
['Natural', 'language', 'processing', 'is', 'useful']
```



Теперь попробуйте более реалистичную строку.



```python
messy = "Dr. Smith didn't pay $19.99 for the U.S.A. trip... Wasn't that great?! :) #nlp @ai_lab"

print(messy.split())
```


**Сохранённый вывод:**

```text
['Dr.', 'Smith', "didn't", 'pay', '$19.99', 'for', 'the', 'U.S.A.', 'trip...', "Wasn't", 'that', 'great?!', ':)', '#nlp', '@ai_lab']
```



В результате несколько проблем:

- К `great?!` и `trip...` всё ещё присоединена пунктуация. Они становятся другими токенами, чем `great` и `trip`.
- Должно ли `didn't` быть одним токеном или двумя? Это определяется задачей.
- `:)` осталось целым. Это полезно, потому что смайлик передаёт тональность.

Присоединённая пунктуация может незаметно сделать подсчёты слов обманчивыми.



```python
reviews = "great! great. great great?! GREAT"
print(Counter(reviews.split()))
```


**Сохранённый вывод:**

```text
Counter({'great!': 1, 'great.': 1, 'great': 1, 'great?!': 1, 'GREAT': 1})
```



Одно слово упомянуто пять раз, но счётчик сообщает о пяти разных строках с количеством 1 каждая.



## Вторая попытка: удалить пунктуацию с краёв



`tokenize_v2` разбивает по пробельным символам, удаляет перечисленные символы с краёв каждого токена, переводит непустые результаты в нижний регистр и отбрасывает токены, от которых ничего не осталось. Пунктуацию внутри токена он не удаляет.

```python
def tokenize_v2(text):
    tokens = []
    for word in text.split():
        word = word.strip('.,!?;:"()[]{}-\'')
        if word:
            tokens.append(word.lower())
    return tokens

print(tokenize_v2(reviews))
print()
print(tokenize_v2(messy))
```


**Сохранённый вывод:**

```text
['great', 'great', 'great', 'great', 'great']

['dr', 'smith', "didn't", 'pay', '$19.99', 'for', 'the', 'u.s.a', 'trip', "wasn't", 'that', 'great', '#nlp', '@ai_lab']
```



Все пять вариантов `great` теперь совпадают, но изменение создаёт другие проблемы:

- `:)` исчезает полностью. Он состоит только из пунктуации, поэтому удаление оставляет пустую строку.
- `u.s.a.` теряет последнюю точку и больше не совпадёт с другим токеном, записанным как `u.s.a.`.

Правило, исправляющее один пример, может сломать другой. Токенизатор, рассчитанный на такие данные, даёт лучшую отправную точку.
