## Текст не только на английском



Казахская и русская строки примеров сохраняются вместе для следующих сравнений. Первый regex использует только латинские буквы ASCII.

```python
kk = "Мен дүкеннен екі жаңа кітап сатып алдым. Достарыма бердім! Олар қуанды."
ru = "Мы купили два новых ноутбука в магазине. Они работали отлично!"

print("ascii pattern [a-zA-Z]+ on Kazakh:", re.findall(r"[a-zA-Z]+", kk))
```


**Сохранённый вывод:**

```text
ascii pattern [a-zA-Z]+ on Kazakh: []
```



ASCII-шаблон возвращает пустой список для этого казахского текста без ошибки или предупреждения. Использующий его конвейер мог бы незаметно не получить ни одного токена для казахских документов.

`\w+` распознаёт символы слова Unicode и в этих примерах обрабатывает оба алфавита. Это то же различие, которое объясняется в теме [[RUS/Lectures/3 - Разбор текста и регулярные выражения/3.4 - Токены с поддержкой Unicode|regex-токены с поддержкой Unicode]].



Примените regex с поддержкой Unicode к обоим языкам и сравните фактические токены.

```python
print("KK:", re.findall(r"\w+", kk))
print()
print("RU:", re.findall(r"\w+", ru))
```


**Сохранённый вывод:**

```text
KK: ['Мен', 'дүкеннен', 'екі', 'жаңа', 'кітап', 'сатып', 'алдым', 'Достарыма', 'бердім', 'Олар', 'қуанды']

RU: ['Мы', 'купили', 'два', 'новых', 'ноутбука', 'в', 'магазине', 'Они', 'работали', 'отлично']
```



Изменение регистра работает и с кириллицей, включая специфические казахские буквы в исходной строке.

```python
# Lowercasing works on Cyrillic, including Kazakh-specific letters.
print("ӘЛЕМ САЛЕМ Ұлы Қазақстан".lower())
```


**Сохранённый вывод:**

```text
әлем салем ұлы қазақстан
```
