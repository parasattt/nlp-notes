## Что такое токен?

**Токен** — одна единица текста, которую программа считает единым неделимым элементом.

Токен не обязан быть словом или текстом между двумя пробелами. Вы выбираете единицу, важную для вашей задачи:

| Текст | Разумные токены | Тоже разумный вариант |
|---|---|---|
| `don't` | `don't` | `do` + `n't` |
| `New York` | `New` + `York` | `New York` |
| `$19.99` | `$19.99` | `$` + `19.99` |
| `#nlp` | `#nlp` | `#` + `nlp` |
| `кітаптарымызда` | `кітаптарымызда` | `кітап` + `тар` + `ымыз` + `да` |

Каждый выбор может быть полезным. Для анализатора хештегов разделение `#nlp` теряет единицу, которую вы хотите изучать.

**Токенизация** — превращение строки в список токенов. Она происходит в начале почти каждого NLP-конвейера. Последующие шаги получают и её ошибки.

В примере модели из лекции для каждого отдельного токена обучается один вектор. Если два написания обозначают одно и то же, но остаются разными токенами, модель обучает их отдельно, используя меньше данных для каждого.
