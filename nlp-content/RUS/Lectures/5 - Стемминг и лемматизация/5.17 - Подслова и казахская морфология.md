## Альтернатива: статистика частей слов

Многоязычный токенизатор здесь выучил частые шаблоны из текстов на многих языках, включая казахский. Правила казахской грамматики ему не передавались. Это продолжает [[RUS/Lectures/4 - Токенизация/4.10 - Подслова в разных языках и морфемы|предыдущие примеры частей слов]].



Источник устанавливает библиотеку предобученных токенизаторов для сравнения подслов.

```python
!pip install transformers --quiet
print("done")
```


**Сохранённый вывод:**

```text
done
```



Сравните пять казахских строк с частями многоязычного токенизатора. Ниже сохранены и предупреждения, и фактические части токенов.

```python
from transformers import AutoTokenizer

xlmr = AutoTokenizer.from_pretrained("xlm-roberta-base")

for w in ["кітаптарымызда", "достарыма", "дүкеннен", "мектепте", "қала"]:
    print(f"{w:16} -> {xlmr.tokenize(w)}")
```

```text
кітаптарымызда -> ▁кітап  тар  ымыз  да
```

Лекция понимает это как правильное морфемное разбиение, выученное из статистики текста. Частые строки `мектепте` и `қала` остаются целыми в сохранённом выводе.

Другие результаты показывают, почему это не морфологический анализатор:

- `достарыма` становится `до` + `стары` + `ма`, тогда как лекция даёт морфемы `дос` + `тар` + `ым` + `а`.
- `дүкеннен` становится `дүк` + `ен` + `нен`: суффикс исходного падежа найден, но корень разрезан пополам.

Подсловные токенизаторы находят **частые последовательности символов**. Повторяющиеся казахские суффиксы иногда делают их совпадающими с морфемами, но вывод не сообщает, какие разбиения следуют грамматике.

Лекция утверждает, что подслова полезны для языков с меньшим количеством NLP-ресурсов и множеством сочетаний суффиксов: слова всё ещё можно представить частями без правил, написанных экспертом. Она описывает это как отсутствие полного отказа или появления `<UNK>`; сохраняйте это как широкое утверждение источника вместе с фактическими примерами. Наш стеммер по правилам оставляет `достарыма` нетронутым, а токенизатор всё равно создаёт части.

Части не являются леммами: `▁кітап` — не словарная начальная форма. Для подсчёта упоминаний книг лекция предпочитает стеммер. Задача определяет полезный инструмент.

Сохранённые предупреждения загрузки сообщают о тайм-ауте получения секрета `HF_TOKEN`, объясняют, что секреты можно получить только из интерфейса Colab, и предупреждают о более низких лимитах запросов и более медленной загрузке при запросах к Hugging Face Hub без аутентификации. Предупреждения рекомендуют задать `HF_TOKEN`.
