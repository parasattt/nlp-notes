## Лемматизация с pymorphy3

Лекция представляет `pymorphy3` как словарный инструмент с несколькими миллионами форм слов. Он возвращает лемму и грамматическую информацию.



Источник устанавливает используемый ниже морфологический анализатор русского языка.

```python
!pip install pymorphy3 --quiet
print("done")
```


**Сохранённый вывод:**

```text
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 53.9/53.9 kB 2.1 MB/s eta 0:00:00
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 8.4/8.4 MB 65.1 MB/s eta 0:00:00
done
```



`morph.parse(w)[0]` выбирает первый анализ в рейтинге. `normal_form` даёт его лемму, а `tag.POS` — метку части речи.

```python
import pymorphy3

morph = pymorphy3.MorphAnalyzer()

for w in ["ноутбука", "хорошего", "бежавшего", "покупкам", "работали"]:
    p = morph.parse(w)[0]
    print(f"{w:12} -> {p.normal_form:12} ({p.tag.POS})")
```


**Сохранённый вывод:**

```text
ноутбука     -> ноутбук      (NOUN)
хорошего     -> хороший      (ADJF)
бежавшего    -> бежать       (PRTF)
покупкам     -> покупка      (NOUN)
работали     -> работать     (VERB)
```



Вывод содержит полные формы слов и POS-метки. Пример `бежавшего -> бежать` показывает изменение, которое показанный стеммер удаления суффиксов не восстанавливает.
