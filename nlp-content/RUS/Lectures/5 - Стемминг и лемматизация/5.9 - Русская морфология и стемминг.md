## Формы русских слов

Лекция противопоставляет относительно небольшое число изменённых форм английского слова шести падежам, двум числам, согласованию и спряжению русского языка. У одного русского существительного она описывает около дюжины форм.



Эти семь строк — формы одного русского существительного. Следующие правила должны объединить их, не сливая неродственные слова.

```python
forms = ["ноутбук", "ноутбука", "ноутбуку", "ноутбуком", "ноутбуке", "ноутбуки", "ноутбуков"]
print("all of these are the same word:", forms)
```


**Сохранённый вывод:**

```text
all of these are the same word: ['ноутбук', 'ноутбука', 'ноутбуку', 'ноутбуком', 'ноутбуке', 'ноутбуки', 'ноутбуков']
```



## Стемминг русского текста



Правила русского Snowball применяются ко всем семи формам существительного.

```python
ru_stem = SnowballStemmer("russian")

for w in forms:
    print(f"{w:12} -> {ru_stem.stem(w)}")
```


**Сохранённый вывод:**

```text
ноутбук      -> ноутбук
ноутбука     -> ноутбук
ноутбуку     -> ноутбук
ноутбуком    -> ноутбук
ноутбуке     -> ноутбук
ноутбуки     -> ноутбук
ноутбуков    -> ноутбук
```



Все семь перечисленных форм сокращаются до `ноутбук`. Этого достаточно, чтобы они совпадали в поиске. Другие слова показывают знакомые ограничения стемминга:



Теперь проверьте другие русские слова, для которых общая основа может не быть полноценным словом.

```python
for w in ["хорошего", "бежавшего", "покупкам", "магазине", "работали"]:
    print(f"{w:12} -> {ru_stem.stem(w)}")
```


**Сохранённый вывод:**

```text
хорошего     -> хорош
бежавшего    -> бежа
покупкам     -> покупк
магазине     -> магазин
работали     -> работа
```



`хорошего -> хорош` и `бежавшего -> бежа` не дают полноценных слов. Такие основы полезны для сопоставления, но плохо подходят для читаемого вывода.
