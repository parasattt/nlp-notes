## Сравнение трёх языков

Таблица ниже сохраняет сравнение лекции и приблизительное число форм:

| | Английский | Русский | Казахский |
|---|---|---|---|
| Форм на слово | мало (2–5) | много (10–20) | очень много (100+) |
| Токенизатор | `nltk`, `spaCy` | `razdel` | `razdel` (достаточен в этих примерах) |
| Стеммер | Porter, Snowball | Snowball `"russian"` | напишите свой в упражнении |
| Лемматизатор | WordNet, spaCy | `pymorphy3` | в сравнении источника нет готового пакета |
| Список стоп-слов | `nltk` | `nltk` | создайте свой в упражнении |
| Запасной вариант с подсловами | работает | работает | работает; иногда совпадает с морфемами |

Лекция связывает разрыв в инструментах с доступными ресурсами разработки, деньгами и числом говорящих, а не со сложностью языка. Практический урок — проверять, что библиотека фактически делает с вашим текстом. В казахских примерах больше частей конвейера нужно писать вручную.



`normalize(text, lang="en")` выбирает ветвь нужного языка. Английская использует леммы WordNet с учётом POS; русская и казахская вызывают предыдущие функции конвейера. Неподдерживаемый язык вызывает `ValueError`. Английская ветвь сохраняет буквенные стоп-слова, а русская и казахская используют предыдущие фильтры; сохранённые списки показывают различие.

```python
# One normalisation function, three languages.
def normalize(text, lang="en"):
    if lang == "en":
        tagged = nltk.pos_tag(word_tokenize(text.lower()))
        return [wnl.lemmatize(w, wordnet_pos(t)) for w, t in tagged if w.isalpha()]
    if lang == "ru":
        return normalize_ru(text)
    if lang == "kk":
        return normalize_kk(text)
    raise ValueError(f"unsupported language: {lang}")


print("EN:", normalize("The batteries were draining very quickly", "en"))
print("RU:", normalize("Батареи ноутбуков разряжались очень быстро", "ru"))
print("KK:", normalize("Кітаптарды дүкеннен сатып алдым", "kk"))
```


**Сохранённый вывод:**

```text
EN: ['the', 'battery', 'be', 'drain', 'very', 'quickly']
RU: ['батарея', 'ноутбук', 'разряжаться', 'очень', 'быстро']
KK: ['кітап', 'дүкен', 'сатып', 'алдым']
```

Три сохранённых вывода показывают общие базовые формы, например `batteries -> battery`, `Батареи -> батарея` и `Кітаптарды -> кітап`. Они также сохраняют отмеченные разные правила фильтрации; один общий интерфейс ещё не делает предобработку одинаковой.
