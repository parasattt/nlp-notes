`SOFTENING` возвращает четыре смягчённых конечных согласных из источника к предложенным более твёрдым формам. `kk_stem2` сначала удаляет суффиксы, затем меняет подходящий конечный согласный. Код выполняет это последнее изменение при любой перечисленной букве, не проверяя полный грамматический анализ.

```python
# Undo consonant softening at the end of the stem.
SOFTENING = {"б": "п", "г": "к", "ғ": "қ", "д": "т"}

def kk_stem2(word, min_stem=3):
    stem = kk_stem(word, min_stem)
    if stem and stem[-1] in SOFTENING:
        stem = stem[:-1] + SOFTENING[stem[-1]]
    return stem


for w in kk_forms:
    print(f"{w:16} -> {kk_stem2(w)}")
```


**Сохранённый вывод:**

```text
кітап            -> кітап
кітабы           -> кітап
кітаптар         -> кітап
кітаптарды       -> кітап
кітаптарым       -> кітап
кітапхана        -> кітапхана
кітаптарымызда   -> кітап
```



Показанные формы слова «книга» теперь имеют общую `кітап`, а `кітапхана` остаётся отдельным. Источник говорит «все шесть изменённых форм теперь совпадают»; сохранённый список содержит основу `кітап`, ещё пять форм слова «книга» и отдельное слово «библиотека».

## Где правила ошибаются



Попробуйте слова вне примеров, использованных при создании правил. Сравните удачные удаления, неизменённые цепочки суффиксов и ошибочно обрезанные корни.

```python
tricky = ["мектепте", "дүкеннен", "достарыма", "баламен", "алдым",
          "оқушы", "жұмысшы", "сауда", "пайда", "қала"]

for w in tricky:
    print(f"{w:12} -> {kk_stem2(w):12}")
```


**Сохранённый вывод:**

```text
мектепте     -> мектеп      
дүкеннен     -> дүкен       
достарыма    -> достарыма   
баламен      -> баламен     
алдым        -> алдым       
оқушы        -> оқуш        
жұмысшы      -> жұмысш      
сауда        -> сау         
пайда        -> пай         
қала         -> қала        
```



Сохранённый список показывает три результата:

**Полезные изменения:** `мектепте` («в школе») становится `мектеп`, а `дүкеннен` («из магазина») — `дүкен`.

**Без изменений:** `достарыма`, `баламен` и `алдым` остаются целыми. Их цепочки суффиксов отсутствуют в списке правил, поэтому сбой незаметен.

**Повреждение слов:**

- `оқушы` («ученик») становится `оқуш`, а `жұмысшы` («работник») — `жұмысш`. Лекция определяет `-шы`/`-ші` как суффиксы существительных, обозначающих деятеля, но программа удаляет конечное `-ы` как перечисленный притяжательный суффикс.
- `сауда` («торговля») становится `сау`, а `пайда` («прибыль») — `пай`. Здесь `да` принадлежит корню, но выглядит как перечисленный суффикс местного падежа.

Это **чрезмерное усечение**, как слияние `university` и `universe`. Оно может быть хуже отсутствия изменений: `сауда` («торговля») теперь совпадает с `сау` («здоровый»).

Источник говорит, что `қала` («город») сохраняется благодаря `min_stem=3`, и предупреждает, что уменьшение порога его сломает. **Уточнение по чтению кода:** предоставленный список не содержит ни `а`, ни `ла`, поэтому сейчас ни один его суффикс не совпадает с концом `қала`; само снижение порога не добавит такого совпадения. Исходный код не изменён.

Каждое дополнительное правило суффикса может помочь одной цепочке и одновременно обрезать настоящий корень в другом месте.
