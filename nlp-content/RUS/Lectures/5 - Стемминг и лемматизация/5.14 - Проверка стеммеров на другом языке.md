## Проверка доступных инструментов

Турецкий язык тоже тюркский и агглютинативный, поэтому в этом сравнении стоит проверить его стеммер. Первое препятствие: сохранённый список языков Snowball в NLTK не содержит турецкого.



Перед попыткой использовать турецкий через NLTK проверьте непосредственно сохранённый список поддержки языков.

```python
print("turkish available in nltk?", "turkish" in SnowballStemmer.languages)
```


**Сохранённый вывод:**

```text
turkish available in nltk? False
```



Лекция отмечает, что проект Snowball содержит турецкий стеммер в отдельном пакете `snowballstemmer`, хотя NLTK его не поставляет.



Отдельный пакет предоставляет турецкий стеммер для следующей проверки.

```python
!pip install snowballstemmer --quiet
print("done")
```


**Сохранённый вывод:**

```text
done
```



Примените турецкие правила ко всем семи казахским примерам, затем явно проверьте, остался ли выходной список неизменным.

```python
import snowballstemmer

kk_forms = ["кітап", "кітабы", "кітаптар", "кітаптарды",
            "кітаптарым", "кітапхана", "кітаптарымызда"]

tr = snowballstemmer.stemmer("turkish")

print("Turkish stemmer on Kazakh:")
for w, s in zip(kk_forms, tr.stemWords(kk_forms)):
    print(f"   {w:16} -> {s}")

print()
print("unchanged?", tr.stemWords(kk_forms) == kk_forms)
```


**Сохранённый вывод:**

```text
Turkish stemmer on Kazakh:
   кітап            -> кітап
   кітабы           -> кітабы
   кітаптар         -> кітаптар
   кітаптарды       -> кітаптарды
   кітаптарым       -> кітаптарым
   кітапхана        -> кітапхана
   кітаптарымызда   -> кітаптарымызда

unchanged? True
```



Все семь казахских строк не меняются. Чтобы проверить работу самого стеммера, следующая ячейка передаёт турецкий текст латиницей.



Эти настоящие турецкие строки дают сравнение в алфавите, который ожидает стеммер.

```python
print(tr.stemWords(["kitaplarımızda", "evler", "geliyorum"]))
```


**Сохранённый вывод:**

```text
['kitap', 'ev', 'geliyor']
```



Для турецкого `kitaplarımızda` становится `kitap`; сохранённый вывод также даёт `evler -> ev` и `geliyorum -> geliyor`. Лекция объясняет неудачу на казахском алфавитом: турецкие правила используют латинские буквы, а казахские примеры — кириллицу.

Вызов вернул семь строк без ошибки, но ни одна не изменилась. Проверка только того, что конвейер запускается, пропустила бы этот сбой. Всегда изучайте, что нормализатор делает с фактическим текстом.

Следующее сравнение пробует русский стеммер, потому что его правила используют кириллицу.



Примените уже созданный русский стеммер к тем же казахским формам и проверьте, достаточно ли совпадения алфавита.

```python
print("Russian stemmer on Kazakh:")
for w in kk_forms:
    print(f"   {w:16} -> {ru_stem.stem(w)}")
```


**Сохранённый вывод:**

```text
Russian stemmer on Kazakh:
   кітап            -> кітап
   кітабы           -> кітаб
   кітаптар         -> кітаптар
   кітаптарды       -> кітаптард
   кітаптарым       -> кітаптар
   кітапхана        -> кітапха
   кітаптарымызда   -> кітаптарымызд
```



Теперь русские правила повреждают некоторые казахские слова. Например, `кітапхана` («библиотека») становится `кітапха`. Казахское окончание случайно похоже на окончание, удаляемое русским правилом.

Источник говорит: **«Нет `pip install kazakh-lemmatizer`»** — и описывает казахский как язык с меньшим количеством готовых NLP-ресурсов. Считайте это утверждением лекции об обсуждаемых инструментах. Поэтому в упражнении правила суффиксов создаются самостоятельно.
