POS-разметка присваивает каждому токену часть речи с учётом контекста предложения. Сохранённая последовательность тегов служит входом для следующих двух ячеек.

```python

sentence = "The striped bats were hanging on their feet and eating better mice"

tagged = nltk.pos_tag(word_tokenize(sentence))
print(tagged)
```


**Сохранённый вывод:**

```text
[('The', 'DT'), ('striped', 'JJ'), ('bats', 'NNS'), ('were', 'VBD'), ('hanging', 'VBG'), ('on', 'IN'), ('their', 'PRP$'), ('feet', 'NNS'), ('and', 'CC'), ('eating', 'VBG'), ('better', 'JJR'), ('mice', 'NN')]
```



Вспомогательная функция сопоставляет префиксы тегов NLTK с ожидаемыми константами частей речи WordNet. Теги вне ветвей прилагательного, глагола и наречия считаются существительными.

```python
from nltk.corpus import wordnet

def wordnet_pos(nltk_tag):
    """Translate an nltk POS tag into the single letter WordNet wants."""
    if nltk_tag.startswith("J"):
        return wordnet.ADJ
    if nltk_tag.startswith("V"):
        return wordnet.VERB
    if nltk_tag.startswith("R"):
        return wordnet.ADV
    return wordnet.NOUN          # the default, and the most common case
```



Для каждого токена сравните лемматизацию только как существительного и лемматизацию с учётом POS. Добавленная стрелка отмечает различающиеся строки.

```python
print(f"{'word':12}{'tag':6}{'naive':12}{'with POS':12}")
print("-" * 40)
for word, tag in tagged:
    naive = wnl.lemmatize(word.lower())
    smart = wnl.lemmatize(word.lower(), wordnet_pos(tag))
    flag = "  <--" if naive != smart else ""
    print(f"{word:12}{tag:6}{naive:12}{smart:12}{flag}")
```


**Сохранённый вывод:**

```text
word        tag   naive       with POS    
------------------------------------------
The         DT    the         the         
striped     JJ    striped     striped     
bats        NNS   bat         bat         
were        VBD   were        be            <--
hanging     VBG   hanging     hang          <--
on          IN    on          on          
their       PRP$  their       their       
feet        NNS   foot        foot        
and         CC    and         and         
eating      VBG   eating      eat           <--
better      JJR   better      good          <--
mice        NN    mouse       mouse       
```



Передача POS меняет четыре результата сохранённой таблицы: `were -> be`, `hanging -> hang`, `eating -> eat` и `better -> good`. Стрелки отмечают эти различия.

`wordnet_pos` переводит теги NLTK, начинающиеся с `J`, `V` или `R`, в метки прилагательного, глагола или наречия WordNet. Остальные теги используют стандартное существительное. Пример показывает, почему лемматизация только существительных пропускает важные изменения.
