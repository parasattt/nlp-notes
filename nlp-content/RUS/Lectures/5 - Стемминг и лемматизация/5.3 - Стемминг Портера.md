## Стемминг

**Стемминг** удаляет аффиксы по правилам. Он не ищет слова в словаре и не проверяет их значение. Лекция знакомит со **стеммером Портера**, разработанным в 1980 году и всё ещё используемым на практике.



Цикл независимо применяет правила Портера к шести строкам. Сравните регулярные изменения окончаний, неправильную форму прошедшего времени и основы, не являющиеся словами.

```python
from nltk.stem import PorterStemmer

ps = PorterStemmer()

for w in ["running", "runs", "ran", "studies", "studying", "happiness"]:
    print(f"{w:12} -> {ps.stem(w)}")
```


**Сохранённый вывод:**

```text
running      -> run
runs         -> run
ran          -> ran
studies      -> studi
studying     -> studi
happiness    -> happi
```



- `running` и `runs` становятся `run` и теперь совпадают.
- `ran` остаётся `ran`. В нём изменилась гласная; добавленного окончания для удаления правилами нет.
- `studies` становится `studi`, что не является настоящим словом.

Основа стеммера не обязана быть читаемой. Её цель — дать одну строку формам, которые должны совпадать.
