## Стемминг и лемматизация рядом



Пары явно задают POS для каждого вызова WordNet. Показанная основа использует английский объект Snowball `sb`, а не объект Porter `ps`.

```python
pairs = [("running", "v"), ("ran", "v"), ("studies", "n"), ("mice", "n"),
         ("feet", "n"), ("better", "a"), ("was", "v"), ("university", "n"),
         ("universe", "n"), ("happiness", "n")]

print(f"{'word':14}{'stem':14}{'lemma':14}")
print("-" * 42)
for w, pos in pairs:
    print(f"{w:14}{sb.stem(w):14}{wnl.lemmatize(w, pos):14}")
```


**Сохранённый вывод:**

```text
word          stem          lemma         
------------------------------------------
running       run           run           
ran           ran           run           
studies       studi         study         
mice          mice          mouse         
feet          feet          foot          
better        better        good          
was           was           be            
university    univers       university    
universe      univers       universe      
happiness     happi         happiness     
```



| Вопрос | Стемминг | Лемматизация |
|---|---|---|
| Как работает? | удаляет аффиксы по правилам | использует словарную информацию |
| Что возвращает? | часто строку, которая не является настоящим словом | всегда настоящее слово, по описанию лекции |
| Обрабатывает ли неправильные формы, например `mice` и `ran`? | показанные правила — нет | да, с нужной информацией |
| Нужен ли POS? | нет | да, для хороших результатов |
| Скорость | очень быстро | медленнее |
| Нужны ли файлы данных? | нет | да, например WordNet |
| Типичное применение | поиск документов | анализ и читаемый вывод |

Лекция рекомендует стемминг, когда важны скорость и масштаб, а нормализованные токены люди читать не будут, например в поисковом индексе миллионов документов. Лемматизация рекомендуется, когда люди изучают вывод.

Иногда не нужен ни один метод. Лекция объясняет, что трансформеры используют подсловную токенизацию для обработки вариантов слов. Нормализация особенно полезна в классическом NLP: [[RUS/Lectures/8 - TF-IDF и поиск текста/8.5 - TF-IDF вручную|TF-IDF]], [[RUS/Lectures/6 - Преобразование текста в признаки/6.2 - Словарь и мешок слов|мешке слов]] и поиске по ключевым словам. Источник описывает их как широко используемые в рабочих системах.
