## Удаление казахских суффиксов

Лекция объясняет, что написание суффиксов зависит от **гармонии гласных** и звонкости предыдущего согласного. Например, варианты множественного числа включают `-лар`, `-тар` и `-дер`.

Код перечисляет варианты, сначала проверяет самые длинные суффиксы и не оставляет основу короче трёх символов. Удаление повторяется, пока ни один перечисленный суффикс больше нельзя убрать.



Сохраните весь набор суффиксов ниже. Комментарии группируют сочетания притяжательного суффикса с падежом, притяжательные формы, множественное число с винительным падежом, множественное число, родительный падеж, падежные формы и притяжательные формы третьего лица. Сортировка по убыванию длины ставит самого длинного кандидата первым. Цикл удаляет один допустимый суффикс, начинает поиск заново и останавливается, когда ни одно правило не подходит; `min_stem=3` ограничивает оставшуюся длину.

```python
KK_SUFFIXES = [
    # possessive + case, stacked (longest first)
    "ларымызда", "лерімізде", "тарымызда", "терімізде", "дарымызда", "дерімізде",
    # possessive
    "ларым", "лерім", "тарым", "терім", "дарым", "дерім",
    # plural + accusative
    "ларды", "лерді", "тарды", "терді", "дарды", "дерді",
    # plural
    "лар", "лер", "тар", "тер", "дар", "дер",
    # genitive
    "ның", "нің", "дың", "дің", "тың", "тің",
    # locative / ablative / dative / accusative
    "нан", "нен", "дан", "ден", "тан", "тен",
    "да", "де", "та", "те", "ға", "ге", "қа", "ке",
    "ды", "ді", "ты", "ті", "ны", "ні",
    # possessive (3rd person)
    "сы", "сі", "ы", "і",
]

KK_SUFFIXES = sorted(set(KK_SUFFIXES), key=len, reverse=True)


def kk_stem(word, min_stem=3):
    """Strip Kazakh suffixes, longest first. Repeats until nothing more comes off."""
    changed = True
    while changed:
        changed = False
        for suf in KK_SUFFIXES:
            if word.endswith(suf) and len(word) - len(suf) >= min_stem:
                word = word[: -len(suf)]
                changed = True
                break
    return word


for w in kk_forms:
    print(f"{w:16} -> {kk_stem(w)}")
```


**Сохранённый вывод:**

```text
кітап            -> кітап
кітабы           -> кітаб
кітаптар         -> кітап
кітаптарды       -> кітап
кітаптарым       -> кітап
кітапхана        -> кітапхана
кітаптарымызда   -> кітап
```



`кітаптар`, `кітаптарды`, `кітаптарым` и `кітаптарымызда` сокращаются до `кітап`.

Два случая требуют внимания:

- `кітабы` становится `кітаб`, хотя нужная основа — `кітап`. Лекция объясняет, что конечный `п` может смягчаться до `б` перед суффиксом, начинающимся с гласной. Удаление суффикса не обращает это изменение.
- `кітапхана` правильно остаётся без изменений, потому что «библиотека» — отдельное слово. Это происходит из-за отсутствия `хана` в списке суффиксов, а не потому, что программа понимает слово.

Источник называет их «двумя неверными результатами», хотя второй пример явно правильный. Различие выше сохраняет оба наблюдения, не объявляя неизменённую форму слова «библиотека» ошибкой.
