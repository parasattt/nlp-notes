Конвейер объединяет нижний регистр, токены `razdel`, русский список стоп-слов NLTK и первый анализ `pymorphy3`. Сохраняйте исходный отзыв рядом с нормализованным выводом, чтобы видеть изменения.

```python
from razdel import tokenize as rz_tokenize
from nltk.corpus import stopwords

ru_stop = set(stopwords.words("russian"))

def normalize_ru(text):
    out = []
    for t in rz_tokenize(text.lower()):
        w = t.text
        if not w.isalpha() or w in ru_stop:

    return out


ru_reviews = [
    "Купил новый ноутбук, работает отлично!",
    "Ноутбуки этой фирмы очень быстрые",
    "Батарея ноутбука разряжается за час",
    "Экран треснул через неделю",
]

for r in ru_reviews:
    print(f"{r}\n   -> {normalize_ru(r)}\n")
```


**Сохранённый вывод:**

```text
Купил новый ноутбук, работает отлично!
   -> ['купить', 'новый', 'ноутбук', 'работать', 'отлично']

Ноутбуки этой фирмы очень быстрые
   -> ['ноутбук', 'фирма', 'очень', 'быстрый']

Батарея ноутбука разряжается за час
   -> ['батарея', 'ноутбук', 'разряжаться', 'час']

Экран треснул через неделю
   -> ['экран', 'треснуть', 'неделя']

```



Запрос и документ совпадают, когда пересечение их нормализованных множеств токенов непустое. Список результатов возвращает полные исходные документы.

```python
def search_ru(query, docs):
    q = set(normalize_ru(query))
    return [d for d in docs if q & set(normalize_ru(d))]

print("query: 'ноутбуки'")
for hit in search_ru("ноутбуки", ru_reviews):
    print("   ", hit)
```


**Сохранённый вывод:**

```text
query: 'ноутбуки'
    Купил новый ноутбук, работает отлично!
    Ноутбуки этой фирмы очень быстрые
    Батарея ноутбука разряжается за час
```



Запрос `ноутбуки` — именительный падеж множественного числа. Он совпадает с винительным падежом единственного числа `ноутбук` в отзыве 1 и родительным `ноутбука` в отзыве 3, потому что нормализация переводит все три формы в `ноутбук`. Поиск исходных строк совпадает только с отзывом 2.

`normalize_ru` переводит текст в нижний регистр, токенизирует с `razdel`, удаляет небуквенные токены и русские стоп-слова, затем берёт первый вариант `pymorphy3`. `search_ru` находит документ, если его нормализованное множество имеет хотя бы один общий токен с запросом. Неоднозначность `[0]` по-прежнему остаётся.
