### Небольшой реалистичный рабочий процесс

С новым текстовым набором данных начните с загрузки, осмотра, поиска проблем, очистки текста и первого наблюдения. Следующий сохранённый рабочий процесс объединяет эти шаги.



```python
# 1. Load and look
df = pd.read_csv("reviews.csv")
print(df.shape)
df.head(3)
```


**Сохранённый вывод:**

```text
(12, 10)
```


**Сохранённый вывод:**

```text
   review_id product  rating                                                    review  verified  char_count  \
0          1  laptop       5  Excellent laptop, fast and quiet. Battery lasts all day.      True          56   
1          2  laptop       1     Screen died after three weeks. Support was unhelpful.      True          53   
2          3   phone       4               Good phone for the price, camera is decent.     False          43   

   word_count  is_positive  excited  shouty  
0           9         True    False   False  
1           8        False    False   False  
2           8         True    False   False  
```



```python
# 2. Check for the obvious problems
print("Missing values:")
print(df.isna().sum())
print()
print("Duplicate reviews:", df["review"].duplicated().sum())
print()
print("Rating distribution:")
print(df["rating"].value_counts().sort_index())
```

Сохранённая форма повторно загруженного набора — **(12, 10)**. Проверки не находят пропусков и дубликатов текстов отзывов. Количества оценок совпадают с прежним распределением. Осмотр пропусков, дубликатов и меток — полезная начальная проверка перед моделированием.
