```python
# When there is no built-in method, .apply() runs your own function on every row
def has_exclamation(text):
    return "!" in text

df["excited"] = df["review"].apply(has_exclamation)

# Same thing written inline with a lambda
df["shouty"] = df["review"].apply(lambda t: sum(1 for c in t if c.isupper()) > 3)

df[["review", "excited", "shouty"]]
```

`has_exclamation()` проверяет наличие хотя бы одного `!`. Lambda считает заглавные символы и проверяет, больше ли их трёх. `.apply()` выполняет эти правила для каждого отзыва. Все сохранённые значения `excited` и `shouty` в этом наборе равны `False`.



`.apply()` запускает вашу функцию для каждого значения столбца. Используйте его, когда нет подходящей встроенной операции. Блокнот рекомендует по возможности встроенные методы `.str`, потому что `.apply()` может работать медленнее; при этом правильность важнее скорости.
