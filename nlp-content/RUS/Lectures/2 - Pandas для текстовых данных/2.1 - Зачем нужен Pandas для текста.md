**pandas** — библиотека Python для **табличных данных**, организованных в строки и столбцы. Если вы знаете Excel, вам знакомы фильтрация, сортировка и группировка. В pandas эти шаги записываются как повторяемый код. В блокноте сказано, что у pandas нет ограничения строк в стиле электронных таблиц; фактический объём данных всё равно зависит от ресурсов машины.

В NLP рядом с текстом обычно есть другие сведения: авторы и время твитов, оценки отзывов, категории обращений в поддержку или даты публикации статей. Метка, которую нужно предсказать, часто находится в отдельном столбце. Pandas помогает загрузить, осмотреть, отфильтровать и очистить эту таблицу до построения модели.



### Сначала — задача, которую решает pandas

Начнём с решения на обычном Python, чтобы польза pandas стала понятна. Небольшой набор данных ниже — список словарей, а вопрос такой: **какова средняя оценка для каждого товара?**



```python
reviews = [
    {"id": 1, "text": "Great product, works perfectly", "rating": 5, "product": "laptop"},
    {"id": 2, "text": "Broke after two days", "rating": 1, "product": "laptop"},
    {"id": 3, "text": "Good value for the money", "rating": 4, "product": "phone"},
    {"id": 4, "text": "Terrible, do not buy", "rating": 1, "product": "phone"},
    {"id": 5, "text": "Exactly as described", "rating": 5, "product": "tablet"},
]

# Question: what is the average rating per product?
totals = {}
counts = {}
for r in reviews:
    p = r["product"]
    totals[p] = totals.get(p, 0) + r["rating"]
    counts[p] = counts.get(p, 0) + 1

for p in totals:
    print(p, round(totals[p] / counts[p], 2))
```


**Сохранённый вывод:**

```text
laptop 3.0
phone 2.5
tablet 5.0
```

Для каждого отзыва цикл добавляет оценку к общей сумме для товара и увеличивает счётчик на единицу. Деление даёт сохранённые средние: **3.0 для ноутбука**, **2.5 для телефона** и **5.0 для планшета**. Здесь используется [[RUS/Lectures/1 - Основы Python для работы с текстом/1.11 - Словари|шаблон подсчёта со словарём]] из основ Python.



Решение на обычном Python хранит два словаря: суммы оценок и количества, затем делит суммы на количества. Даже такой небольшой вопрос требует нескольких строк и даёт несколько возможностей ошибиться.

Следующая ячейка решает тот же вопрос с помощью pandas.



```python
import pandas as pd

df = pd.DataFrame(reviews)
df.groupby("product")["rating"].mean()
```


**Сохранённый вывод:**

```text
product
laptop    3.0
phone     2.5
tablet    5.0
Name: rating, dtype: float64
```

`pd.DataFrame(reviews)` преобразует список записей в таблицу. `groupby("product")` разделяет строки по товару, `["rating"]` выбирает оценки, а `.mean()` вычисляет среднее каждой группы. Сохранённые результаты совпадают с ручным вариантом.



Когда данные находятся в DataFrame, `df.groupby("product")["rating"].mean()` отвечает на вопрос одной строкой. Чем сложнее вопросы, тем заметнее преимущество.
