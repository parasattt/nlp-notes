### Фильтрация строк

Фильтрация оставляет строки, удовлетворяющие условию. Сначала создайте столбец значений `True` и `False`, затем используйте его внутри `df[...]`, чтобы сохранить строки с `True`.



```python
# A comparison on a column gives a column of True/False
df["rating"] >= 4
```


**Сохранённый вывод:**

```text
0      True
1     False
2      True
3     False
4      True
5     False
6      True
7     False
8      True
9     False
10    False
11     True
Name: rating, dtype: bool
```



```python
# Feed that back into the DataFrame to keep only the True rows
good = df[df["rating"] >= 4]
good
```


**Сохранённый вывод:**

```text
    review_id product  rating                                                    review  verified
0           1  laptop       5  Excellent laptop, fast and quiet. Battery lasts all day.      True
2           3   phone       4               Good phone for the price, camera is decent.     False
4           5  tablet       5         Perfect for reading and taking notes. Very light.      True
6           7   phone       5    Best phone I have owned. Fast, great screen, worth it.      True
8           9  tablet       4        Nice tablet overall, though the speakers are weak.     False
11         12  tablet       5     Fantastic build quality and the display is beautiful.      True
```



```python
# Combine conditions with & (and) and | (or).
# Each condition MUST be wrapped in its own parentheses.
df[(df["rating"] >= 4) & (df["product"] == "phone")]
```


**Сохранённый вывод:**

```text
   review_id product  rating                                                  review  verified
2          3   phone       4             Good phone for the price, camera is decent.     False
6          7   phone       5  Best phone I have owned. Fast, great screen, worth it.      True
```

`df["rating"] >= 4` создаёт **логическую маску** — одно решение на строку. `df[mask]` оставляет подходящие строки; в сохранённых данных этому порогу оценки соответствуют шесть отзывов. Добавление условия `product == "phone"` оставляет два высоко оценённых отзыва о телефоне.



При объединении условий над столбцами важны два правила:

- Используйте `&` для «и» и `|` для «или». Операторы Python `and` и `or` объединяют отдельные логические значения, а здесь нужно объединять условия по целым столбцам.
- Заключайте **каждое условие в скобки**. У таких операторов, как `&`, приоритет выше, чем у `==`, поэтому без скобок Python может понять выражение иначе и выдать запутанную ошибку.
