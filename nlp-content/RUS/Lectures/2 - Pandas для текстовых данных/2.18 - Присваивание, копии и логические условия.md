### Что может запутать

#### Цепочка присваиваний через выборки

Первая запись ниже может не обновить исходную таблицу и выдать предупреждение. Вторая явно указывает выбранные строки и целевой столбец:

```python
df[df["rating"] == 5]["review"] = "changed"     # wrong, may warn
df.loc[df["rating"] == 5, "review"] = "changed" # right
```

Для присваивания значений используйте `.loc[rows, columns]`. `.loc` выбирает по **метке**, а `.iloc` — по **позиции**.

#### Копии и общие данные

`df2 = df` даёт той же таблице второе имя. Изменение через любое из имён затрагивает одни и те же данные. Если нужна независимая таблица, используйте `df2 = df.copy()`.

#### Сравнение целого столбца

`df["rating"] == 5` возвращает Series логических значений — по одному на строку. Это не одно общее логическое значение. Для фильтрации это удобно, но выражение вроде `if df["rating"] == 5:` не даёт единственного значения истинности, нужного обычному `if`.
