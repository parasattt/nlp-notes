### Группировка

Воспринимайте `groupby` как **«для каждого X вычислить Y»**. Выберите столбец группировки, затем измеряемую величину и примените операцию, например `mean()`, `count()` или `agg()`.



```python
df.groupby("product")["rating"].mean()
```


**Сохранённый вывод:**

```text
product
laptop    2.75
phone     3.50
tablet    3.75
Name: rating, dtype: float64
```



```python
df.groupby("product")["rating"].agg(["count", "mean", "min", "max"]).round(2)
```


**Сохранённый вывод:**

```text
         count  mean  min  max
product                       
laptop       4  2.75    1    5
phone        4  3.50    2    5
tablet       4  3.75    1    5
```

Средние оценки по товарам — **2.75 для ноутбука**, **3.50 для телефона** и **3.75 для планшета**. `.agg(["count", "mean", "min", "max"])` запрашивает несколько сводных показателей в одной таблице. `.round(2)` округляет числовой результат до двух знаков после точки.



```python
# Group by more than one thing
df.groupby(["product", "is_positive"])["review_id"].count()
```


**Сохранённый вывод:**

```text
product  is_positive
laptop   False          3
         True           1
phone    False          2
         True           2
tablet   False          1
         True           3
Name: review_id, dtype: int64
```



```python
# A practical question: do positive reviews tend to be longer than negative ones?
df.groupby("is_positive")["word_count"].mean().round(1)
```


**Сохранённый вывод:**

```text
is_positive
False    7.3
True     8.5
Name: word_count, dtype: float64
```

Группировка одновременно по `product` и `is_positive` даёт отдельные количества для каждого товара и флага тональности. Подсчёт `review_id` считает непустые идентификаторы в каждой группе. Группировка только по `is_positive` со средним `word_count` сравнивает длины отзывов двух групп; `.round(1)` оставляет один знак после точки.



Сохранённый результат показывает среднюю длину **8.5 слова для положительных отзывов** и **7.3 для остальных**. Положительными здесь, как в блокноте, считаются отзывы по правилу `rating >= 4`.

Это небольшое наблюдение NLP: длина отзыва может нести информацию, полезную классификатору. Исходник описывает связь длины и тональности как известную закономерность. Эти двенадцать примеров показывают различие в данном наборе, но их самих недостаточно для общего правила.
