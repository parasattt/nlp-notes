### Пропущенные данные

В реальных наборах есть пропуски. Pandas может обозначать их как `NaN` или другими маркерами отсутствующих значений. Нужно решить, что с ними делать, а не пропускать незамеченными в дальнейшие вычисления или модель.



```python
import numpy as np

df2 = df.copy()
df2.loc[2, "review"] = None
df2.loc[5, "rating"] = np.nan
df2[["review_id", "review", "rating"]].head(7)
```


**Сохранённый вывод:**

```text
   review_id                                                    review  rating
0          1  Excellent laptop, fast and quiet. Battery lasts all day.     5.0
1          2     Screen died after three weeks. Support was unhelpful.     1.0
2          3                                                       NaN     4.0
3          4            Battery drains far too quickly, disappointing.     2.0
4          5         Perfect for reading and taking notes. Very light.     5.0
5          6                Does the job but the keyboard feels cheap.     NaN
6          7    Best phone I have owned. Fast, great screen, worth it.     5.0
```

`df.copy()` создаёт отдельную таблицу для опыта с пропусками. `.loc[2, "review"] = None` убирает значение одного отзыва, а `.loc[5, "rating"] = np.nan` — одну оценку. В сохранённой таблице пропуски показаны как `NaN`; оценки в этой копии отображаются дробными числами.



```python
df2.isna().sum()          # count missing values per column
```


**Сохранённый вывод:**

```text
review_id      0
product        0
rating         1
review         1
verified       0
char_count     0
word_count     0
is_positive    0
excited        0
shouty         0
dtype: int64
```



```python
df2.dropna(subset=["review"]).shape    # drop rows with no review text
```


**Сохранённый вывод:**

```text
(11, 10)
```



```python
df2["review"].fillna("")   # or fill the gap with an empty string
```


**Сохранённый вывод:**

```text
0     Excellent laptop, fast and quiet. Battery lasts all day.
1        Screen died after three weeks. Support was unhelpful.
2                                                             
3               Battery drains far too quickly, disappointing.
4            Perfect for reading and taking notes. Very light.
5                   Does the job but the keyboard feels cheap.
6       Best phone I have owned. Fast, great screen, worth it.
7                      Stopped charging within a month. Avoid.
8           Nice tablet overall, though the speakers are weak.
9          Overheats under any real load. Not worth the money.
10              It is fine. Nothing special, nothing terrible.
11       Fantastic build quality and the display is beautiful.
Name: review, dtype: str
```

`.isna().sum()` сообщает об одном пропущенном отзыве и одной оценке. `.dropna(subset=["review"])` оставляет строки с текстом отзыва, получая сохранённую форму **(11, 10)**. `.fillna("")` показывает вариант Series отзывов, где пропуск заменён пустой строкой.

Последние два выражения возвращают результаты, но не присваивают их обратно `df2`. Чтобы сохранить преобразование, нужно сохранить возвращённый результат.



Выбирайте удаление или заполнение исходя из вопроса, на который отвечаете:

- **Удаление** строки позволяет не придумывать текст, но теряет данные.
- **Заполнение** сохраняет строку, но подставляет выбранное вами значение, например пустую строку.

Не допускайте незаметного попадания пропусков в модель. Они могут вызвать сбой или незаметно исказить результаты.
