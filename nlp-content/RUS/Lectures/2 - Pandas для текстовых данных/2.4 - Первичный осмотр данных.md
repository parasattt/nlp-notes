### Сначала посмотрите на данные

Осмотрите новый набор данных до вычисления результатов. Начните с `head()`, `tail()`, `shape` и `info()`, чтобы проверить начало, конец, размер, имена столбцов, типы и пропущенные значения.



```python
df.head(3)        # first 3 rows. df.head() defaults to 5.
```


**Сохранённый вывод:**

```text
   review_id product  rating                                                    review  verified
0          1  laptop       5  Excellent laptop, fast and quiet. Battery lasts all day.      True
1          2  laptop       1     Screen died after three weeks. Support was unhelpful.      True
2          3   phone       4               Good phone for the price, camera is decent.     False
```



```python
df.tail(2)        # last rows - useful for spotting junk at the end of files
```


**Сохранённый вывод:**

```text
    review_id product  rating                                                 review  verified
10         11   phone       3         It is fine. Nothing special, nothing terrible.      True
11         12  tablet       5  Fantastic build quality and the display is beautiful.      True
```



```python
df.shape          # (rows, columns)
```


**Сохранённый вывод:**

```text
(12, 5)
```



```python
df.info()         # column names, types, and how many non-missing values each has
```


**Сохранённый вывод:**

```text
<class 'pandas.DataFrame'>
RangeIndex: 12 entries, 0 to 11
Data columns (total 5 columns):
 #   Column     Non-Null Count  Dtype
---  ------     --------------  -----
 0   review_id  12 non-null     int64
 1   product    12 non-null     str  
 2   rating     12 non-null     int64
 3   review     12 non-null     str  
 4   verified   12 non-null     bool 
dtypes: bool(1), int64(2), str(2)
memory usage: 528.0 bytes
```



`info()` особенно полезен: он сообщает **dtype**, то есть тип данных каждого столбца, и число непустых значений. Неожиданные типы вызывают много непонятных проблем в pandas.

В исходном объяснении сказано, что `review` и `product` имеют тип `object` — обозначение, которое часто использовалось для текста в прежних средах pandas. **Но сохранённый вывод этого блокнота показывает `str`** для обоих столбцов и версию pandas `3.0.5`. Смотрите на фактический сохранённый вывод, а не ожидайте тип из пояснения. В этом примере оба столбца содержат текст.



```python
df.describe()     # summary statistics for the numeric columns only
```


**Сохранённый вывод:**

```text
       review_id     rating
count  12.000000  12.000000
mean    6.500000   3.333333
std     3.605551   1.556998
min     1.000000   1.000000
25%     3.750000   2.000000
50%     6.500000   3.500000
75%     9.250000   5.000000
max    12.000000   5.000000
```



```python
df.columns        # the column names
```


**Сохранённый вывод:**

```text
Index(['review_id', 'product', 'rating', 'review', 'verified'], dtype='str')
```

Сохранённые результаты осмотра показывают 12 строк и 5 столбцов без пропусков в исходных столбцах. `head(3)` показывает первые три строки, а `tail(2)` — последние две. `describe()` даёт статистику числовых столбцов: например, средняя оценка около **3.33**, а диапазон оценок — от 1 до 5. `columns` перечисляет имена пяти столбцов.
