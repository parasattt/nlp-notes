### Чтение и запись файлов

На практике данные часто поступают в **CSV-файле**, а не в словаре Python. Следующие ячейки сохраняют таблицу, показывают исходный файл и снова загружают его.



```python
df.to_csv("reviews.csv", index=False)
print("saved")
```


**Сохранённый вывод:**

```text
saved
```



```python
# Peek at the raw file to see what a CSV actually looks like on disk
!head -3 reviews.csv
```


**Сохранённый вывод:**

```text
review_id,product,rating,review,verified,char_count,word_count,is_positive,excited,shouty
1,laptop,5,"Excellent laptop, fast and quiet. Battery lasts all day.",True,56,9,True,False,False
2,laptop,1,Screen died after three weeks. Support was unhelpful.,True,53,8,False,False,False
```

`to_csv()` записывает текущую таблицу, включая вычисленные признаки. `!head -3 reviews.csv` — команда оболочки, показывающая заголовок и первые две строки данных. Первый отзыв заключён в кавычки, потому что его текст содержит запятую, которую нельзя принять за разделитель столбцов.



`index=False` не даёт pandas сохранить индекс строк отдельным столбцом CSV. Если случайно сохранить индекс, а затем прочитать его как обычные данные, может появиться лишний столбец вроде `Unnamed: 0`.



```python
loaded = pd.read_csv("reviews.csv")
```

`pd.read_csv("reviews.csv")` загружает сохранённый файл в `loaded`. Первые три строки показывают, что в CSV записаны исходные столбцы, добавленные количества и логические признаки.



У `read_csv()` много параметров. В исходнике выделены следующие полезные:

```python
pd.read_csv("file.csv",
            encoding="utf-8",   # or "latin-1", "cp1251" for some older files
            sep=",",            # "\t" for TSV files
            nrows=1000)         # read only the first N rows - do this first on a big file
```

- `encoding` сообщает pandas, как декодировать байты файла в символы.
- `sep` задаёт разделитель; для TSV используется табуляция.
- `nrows` позволяет осмотреть небольшой начальный фрагмент перед загрузкой большого файла.
