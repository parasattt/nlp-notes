```python
# Filtering on text: .str gives you string methods across the whole column
df[df["review"].str.contains("battery", case=False)]
```


**Saved output:**

```text
   review_id product  rating                                                    review  verified
0          1  laptop       5  Excellent laptop, fast and quiet. Battery lasts all day.      True
3          4   phone       2            Battery drains far too quickly, disappointing.      True
```



`.str` applies string operations to every value in a text column. It connects pandas to the [[EN/Lectures/1 - Python Basics for Text/1.5 - String Cleaning and Whitespace|string methods]] from Python basics. Examples include `.str.lower()`, `.str.strip()`, `.str.split()`, `.str.len()`, `.str.replace()`, and `.str.contains()`.

In `.str.contains("battery", case=False)`, `case=False` makes the search ignore capitalization. Without it, the review containing `"Battery drains far too quickly"` would be missed. Small differences like this make simple searches unreliable unless their rules are chosen carefully. [[EN/Lectures/3 - Parsing Text and Regex/3.11 - Cleaning a Dataset with Pandas|Cleaning text with pandas and regex]] develops this further.

```python
# isin() for "is it any of these"
```




```python
# ~ means NOT
df[~df["verified"]]
```


**Saved output:**

```text
   review_id product  rating                                              review  verified
2          3   phone       4         Good phone for the price, camera is decent.     False
5          6  laptop       3          Does the job but the keyboard feels cheap.     False
8          9  tablet       4  Nice tablet overall, though the speakers are weak.     False
```

`.isin(["phone", "tablet"])` keeps rows whose product matches either listed category. `~` reverses a boolean mask, so `df[~df["verified"]]` selects the three unverified reviews.
