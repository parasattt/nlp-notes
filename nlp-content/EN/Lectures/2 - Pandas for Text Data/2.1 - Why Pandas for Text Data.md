The earlier [[EN/Lectures/1 - Python Basics for Text/1.0 - Overview|Python lecture]] used lists and dictionaries to process text. That is manageable for a few sentences, but becomes difficult when the dataset grows to hundreds or thousands of rows.

**pandas** is Python's library for **tabular data**: data organized into rows and columns. If you know Excel, familiar ideas include filtering, sorting, and grouping. In pandas, these steps are written as repeatable code. The notebook describes it as having no spreadsheet-style row limit; the size you can actually handle still depends on the machine's resources.

NLP data usually arrives with information beside the text: tweets with authors and timestamps, reviews with ratings, support tickets with categories, or articles with publication dates. The label you want to predict often occupies another column. Pandas helps you load, inspect, filter, and clean this table before building a model.



### First, the problem pandas solves

Start with the plain Python solution so that the benefit of pandas is clear. The small dataset below is a list of dictionaries, and the question is: **what is the average rating for each product?**



```python
reviews = [
    {"id": 1, "text": "Great product, works perfectly", "rating": 5, "product": "laptop"},
    {"id": 2, "text": "Broke after two days", "rating": 1, "product": "laptop"},
    {"id": 3, "text": "Good value for the money", "rating": 4, "product": "phone"},
    {"id": 4, "text": "Terrible, do not buy", "rating": 1, "product": "phone"},
    {"id": 5, "text": "Exactly as described", "rating": 5, "product": "tablet"},
]

# Question: what is the average rating per product?
totals = {}
counts = {}
for r in reviews:
    p = r["product"]
    totals[p] = totals.get(p, 0) + r["rating"]
    counts[p] = counts.get(p, 0) + 1

for p in totals:
    print(p, round(totals[p] / counts[p], 2))
```


**Saved output:**

```text
laptop 3.0
phone 2.5
tablet 5.0
```

For each review, the loop adds its rating to the product's total and adds one to its count. Dividing gives saved means of **3.0 for laptop**, **2.5 for phone**, and **5.0 for tablet**. This uses the [[EN/Lectures/1 - Python Basics for Text/1.11 - Dictionaries|dictionary counting pattern]] from Python basics.



The plain Python solution keeps two dictionaries, one for rating totals and one for counts, then divides totals by counts. Even this small question needs several lines, with several chances to make a mistake.

The next cell asks the same question using pandas.



```python
import pandas as pd

df = pd.DataFrame(reviews)
df.groupby("product")["rating"].mean()
```


**Saved output:**

```text
product
laptop    3.0
phone     2.5
tablet    5.0
Name: rating, dtype: float64
```

`pd.DataFrame(reviews)` converts the list of records into a table. `groupby("product")` separates rows by product, `["rating"]` selects their ratings, and `.mean()` averages each group. The saved results match the hand-written version.



Once the data is in a DataFrame, `df.groupby("product")["rating"].mean()` answers the question in one line. The advantage grows when you ask more complicated questions.
