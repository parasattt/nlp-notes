### Recap

- A **DataFrame** is a table; a single column is a **Series**.
- Inspect new data with `head()`, `shape`, `info()`, and `value_counts()`.
- Filter using boolean conditions, such as `df[df["rating"] >= 4]`. Combine conditions with `&` and `|`, with parentheses around each condition.
- `.str` applies string operations to a text column.
- `.apply()` runs your own function on values when no suitable built-in method exists.
- `groupby` answers “for each X, compute Y” questions.
- Choose explicitly how to handle missing values.
- Use `read_csv()` and `to_csv(index=False)`, and check encoding.
- Assign through `.loc[rows, columns]`, and use `.copy()` for an independent table.
