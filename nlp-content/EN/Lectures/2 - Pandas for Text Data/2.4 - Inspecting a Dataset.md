### Looking at your data first

Inspect a new dataset before calculating results. Start with `head()`, `tail()`, `shape`, and `info()` to check the beginning, end, size, column names, types, and missing values.



```python
df.head(3)        # first 3 rows. df.head() defaults to 5.
```


**Saved output:**

```text
   review_id product  rating                                                    review  verified
0          1  laptop       5  Excellent laptop, fast and quiet. Battery lasts all day.      True
1          2  laptop       1     Screen died after three weeks. Support was unhelpful.      True
2          3   phone       4               Good phone for the price, camera is decent.     False
```



```python
df.tail(2)        # last rows - useful for spotting junk at the end of files
```


**Saved output:**

```text
    review_id product  rating                                                 review  verified
10         11   phone       3         It is fine. Nothing special, nothing terrible.      True
11         12  tablet       5  Fantastic build quality and the display is beautiful.      True
```



```python
df.shape          # (rows, columns)
```


**Saved output:**

```text
(12, 5)
```



```python
df.info()         # column names, types, and how many non-missing values each has
```


**Saved output:**

```text
<class 'pandas.DataFrame'>
RangeIndex: 12 entries, 0 to 11
Data columns (total 5 columns):
```

`info()` is especially useful because it reports each column's **dtype**, or data type, and its number of non-missing values. Unexpected types cause many confusing pandas problems.

The original explanation says that `review` and `product` appear as `object`, a label commonly used for text in earlier pandas setups. **The saved output in this notebook instead shows `str`** for both columns, together with a saved pandas version of `3.0.5`. Read the actual saved output rather than expecting the prose's dtype label. Both columns contain text in this example.



```python
df.describe()     # summary statistics for the numeric columns only
```


**Saved output:**

```python
df.columns        # the column names
```

The saved inspection results show 12 rows and 5 columns, with no missing values in these original columns. `head(3)` shows the first three rows and `tail(2)` the final two. `describe()` summarizes numeric columns: for example, the mean rating is about **3.33**, with ratings from 1 to 5. `columns` lists the five column names.
