### Things that will confuse you

#### Chained assignment

The first form below may fail to update the original table and may produce a warning. The second makes the selected rows and target column explicit:

```python
df[df["rating"] == 5]["review"] = "changed"     # wrong, may warn
df.loc[df["rating"] == 5, "review"] = "changed" # right
```

Use `.loc[rows, columns]` when assigning values. `.loc` selects by **label**; `.iloc` selects by **position**.

#### Copies versus shared data

`df2 = df` gives another name to the same table. Changing the table through either name affects the same data. Use `df2 = df.copy()` when you need an independent table.

#### A whole-column comparison

`df["rating"] == 5` returns a Series of booleans, one for each row. It does not return one overall boolean. This is useful for filtering, but an expression such as `if df["rating"] == 5:` does not provide the single truth value that an ordinary `if` needs.
