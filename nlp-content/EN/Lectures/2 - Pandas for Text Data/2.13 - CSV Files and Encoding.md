### Reading and writing files

In practice, data often arrives as a **CSV file** rather than a dictionary written in Python. The next cells save the table, inspect the raw file, and load it again.



```python
df.to_csv("reviews.csv", index=False)
print("saved")
```


**Saved output:**

```text
saved
```



```python
# Peek at the raw file to see what a CSV actually looks like on disk
!head -3 reviews.csv
```


**Saved output:**

```text
review_id,product,rating,review,verified,char_count,word_count,is_positive,excited,shouty
1,laptop,5,"Excellent laptop, fast and quiet. Battery lasts all day.",True,56,9,True,False,False
2,laptop,1,Screen died after three weeks. Support was unhelpful.,True,53,8,False,False,False
```

`to_csv()` writes the current table, including the derived feature columns. `!head -3 reviews.csv` is a shell command that shows the header and first two data lines. The first review is quoted because its text contains a comma that must not be treated as a column separator.



`index=False` prevents pandas from saving its row index as an extra CSV column. If you accidentally save the index and then reload it as ordinary data, an extra column such as `Unnamed: 0` may appear.

`read_csv()` has many options. The source highlights these useful ones:

```python
pd.read_csv("file.csv",
            encoding="utf-8",   # or "latin-1", "cp1251" for some older files
            sep=",",            # "\t" for TSV files
            nrows=1000)         # read only the first N rows - do this first on a big file
```

- `encoding` tells pandas how to decode the file's bytes into characters.
- `sep` specifies the separator; a tab is used for TSV files.
- `nrows` lets you inspect a small first portion before loading a large file.
