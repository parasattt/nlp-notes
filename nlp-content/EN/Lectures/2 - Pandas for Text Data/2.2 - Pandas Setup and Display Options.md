### Setting up

The conventional abbreviation for pandas is `pd`, as in `import pandas as pd`. Using this familiar name makes examples and other people's code easier to follow.



```python
import pandas as pd

print(pd.__version__)

# Make wide text columns readable instead of truncated with "..."
pd.set_option("display.max_colwidth", 100)
pd.set_option("display.width", 120)
```


**Saved output:**

```text
3.0.5
```

The saved pandas version is `3.0.5`; this is the version recorded by the notebook, rather than a claim about every environment. `display.max_colwidth` sets how much text pandas displays in a column, and `display.width` controls the display width. These options affect presentation rather than the stored review text.
