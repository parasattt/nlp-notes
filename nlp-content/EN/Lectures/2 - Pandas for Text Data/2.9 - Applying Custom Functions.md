```python
# When there is no built-in method, .apply() runs your own function on every row
def has_exclamation(text):
    return "!" in text

df["excited"] = df["review"].apply(has_exclamation)

# Same thing written inline with a lambda
df["shouty"] = df["review"].apply(lambda t: sum(1 for c in t if c.isupper()) > 3)

df[["review", "excited", "shouty"]]
```

`has_exclamation()` tests for at least one `!`. The lambda counts uppercase characters and tests whether there are more than three. `.apply()` runs these rules for every review. All saved values in `excited` and `shouty` are `False` for this dataset.



`.apply()` runs your own function on each value in a column. Use it when no suitable built-in operation exists. The notebook recommends built-in `.str` methods where possible because `.apply()` can be slower, while putting correct behavior before speed.
