```python
# .loc and .iloc, side by side
print(df.loc[0, "review"])      # by label
print(df.iloc[0, 3])            # by position
print()
print(df.loc[0:2, ["product", "rating"]])   # .loc includes the end, 0,1,2
print()
print(df.iloc[0:2])                          # .iloc excludes it, 0,1
```

The saved `.loc[0, "review"]` and `.iloc[0, 3]` return the same review because label `0` and position `0` coincide here, and `review` is at column position 3.

The slices show a key difference: `.loc[0:2, ...]` includes labels **0, 1, and 2**, whereas `.iloc[0:2]` includes positions **0 and 1** and excludes position 2.
