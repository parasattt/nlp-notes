### Creating new columns

In NLP, new columns can hold **features**: values calculated from the text that a model can use. The next cell adds character count, word count, and a flag based on the star rating. More ways to represent text appear in [[EN/Lectures/6 - Turning Text into Features/6.1 - Why Text Needs Numerical Features|Turning Text into Features]].



```python
df["char_count"] = df["review"].str.len()
df["word_count"] = df["review"].str.split().str.len()
df["is_positive"] = df["rating"] >= 4

df[["review", "char_count", "word_count", "rating", "is_positive"]]
```

`char_count` counts characters, including spaces and punctuation. `word_count` counts whitespace-separated pieces. `is_positive` is `True` for ratings 4 or 5. This last column is derived from the rating rather than predicted from the review text.



Read `df["review"].str.split().str.len()` from left to right:

1. Select the review column.
2. Split each review into a list of words.
3. Take the length of each list.

This describes a whole-column transformation without writing an explicit Python loop. This style is called **vectorized code**. The source emphasizes that built-in column operations are often shorter and faster than manually processing rows.
