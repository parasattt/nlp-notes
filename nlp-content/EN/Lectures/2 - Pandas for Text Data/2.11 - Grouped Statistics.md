### Grouping

Think of `groupby` as **“for each X, compute Y.”** Choose the column that defines groups, select what you want to measure, and apply an operation such as `mean()`, `count()`, or `agg()`.



```python
df.groupby("product")["rating"].mean()
```


**Saved output:**

```text
product
laptop    2.75
phone     3.50
tablet    3.75
Name: rating, dtype: float64
```



```python
df.groupby("product")["rating"].agg(["count", "mean", "min", "max"]).round(2)
```


**Saved output:**

```text
         count  mean  min  max
product                       
laptop       4  2.75    1    5
phone        4  3.50    2    5
tablet       4  3.75    1    5
```

The mean rating by product is **2.75 for laptop**, **3.50 for phone**, and **3.75 for tablet**. `.agg(["count", "mean", "min", "max"])` requests several summaries in one table. `.round(2)` formats the numerical result to two decimal places.



```python
# Group by more than one thing
df.groupby(["product", "is_positive"])["review_id"].count()
```


**Saved output:**

```text
product  is_positive
laptop   False          3
         True           1
phone    False          2
         True           2
tablet   False          1
         True           3
Name: review_id, dtype: int64
```



```python
# A practical question: do positive reviews tend to be longer than negative ones?
df.groupby("is_positive")["word_count"].mean().round(1)
```


**Saved output:**

```text
is_positive
False    7.3
True     8.5
Name: word_count, dtype: float64
```

Grouping by both `product` and `is_positive` gives separate counts for each product and sentiment flag. Counting `review_id` counts the non-missing IDs in each group. Grouping only by `is_positive` and averaging `word_count` compares the review lengths of the two groups; `.round(1)` keeps one decimal place.



The saved result shows a mean word count of **8.5 for positive reviews** and **7.3 for the other reviews**, using the notebook's `rating >= 4` definition of positive.

This is a small NLP observation: review length may contain information that a classifier could use. The source describes length and sentiment as a known relationship. These twelve examples show a difference in this dataset; they are too few to establish a general rule by themselves.
