### A realistic mini-workflow

With a new text dataset, start by loading it, inspecting it, checking for problems, cleaning the text, and finding an initial observation. The following saved workflow brings these steps together.



```python
# 1. Load and look
df = pd.read_csv("reviews.csv")
print(df.shape)
df.head(3)
```

```python
# 2. Check for the obvious problems
print("Missing values:")
print(df.isna().sum())
print()
print("Duplicate reviews:", df["review"].duplicated().sum())
print()
print("Rating distribution:")
```
