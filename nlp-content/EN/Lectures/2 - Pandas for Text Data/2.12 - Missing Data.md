### Missing data

Real datasets contain missing values. Pandas can represent them as `NaN` or other missing-value markers. You need to choose how to handle them, rather than allowing them to pass unnoticed into later calculations or a model.



```python
import numpy as np

df2 = df.copy()
df2.loc[2, "review"] = None
df2.loc[5, "rating"] = np.nan
df2[["review_id", "review", "rating"]].head(7)
```


**Saved output:**

```text
   review_id                                                    review  rating
0          1  Excellent laptop, fast and quiet. Battery lasts all day.     5.0
1          2     Screen died after three weeks. Support was unhelpful.     1.0
2          3                                                       NaN     4.0
3          4            Battery drains far too quickly, disappointing.     2.0
4          5         Perfect for reading and taking notes. Very light.     5.0
5          6                Does the job but the keyboard feels cheap.     NaN
6          7    Best phone I have owned. Fast, great screen, worth it.     5.0
```

`df.copy()` creates a separate table for the missing-data experiment. `.loc[2, "review"] = None` removes one review value, while `.loc[5, "rating"] = np.nan` removes one rating. The saved table shows the missing entries as `NaN`; the rating values are displayed as decimals in this copy.



```python
df2.isna().sum()          # count missing values per column
```


**Saved output:**

```text
review_id      0
product        0
rating         1
review         1
verified       0
char_count     0
word_count     0
is_positive    0
excited        0
shouty         0
dtype: int64
```



```python
df2.dropna(subset=["review"]).shape    # drop rows with no review text
```


**Saved output:**

```text
(11, 10)
```



```python
df2["review"].fillna("")   # or fill the gap with an empty string
```


**Saved output:**

```text
0     Excellent laptop, fast and quiet. Battery lasts all day.
1        Screen died after three weeks. Support was unhelpful.
2                                                             
3               Battery drains far too quickly, disappointing.
4            Perfect for reading and taking notes. Very light.
5                   Does the job but the keyboard feels cheap.
6       Best phone I have owned. Fast, great screen, worth it.
7                      Stopped charging within a month. Avoid.
8           Nice tablet overall, though the speakers are weak.
9          Overheats under any real load. Not worth the money.
10              It is fine. Nothing special, nothing terrible.
11       Fantastic build quality and the display is beautiful.
Name: review, dtype: str
```

`.isna().sum()` reports one missing review and one missing rating. `.dropna(subset=["review"])` keeps rows that have review text, leaving a saved shape of **(11, 10)**. `.fillna("")` shows a version of the review Series with its missing value replaced by an empty string.

These last two expressions return results; they do not assign them back to `df2`. To keep such a transformation, you would need to store the returned result.



Choose between dropping and filling according to the question you are answering:

- **Dropping** a row avoids inventing text, but loses data.
- **Filling** keeps the row, but substitutes a value you chose, such as an empty string.

Do not let missing values enter a model unnoticed. They can cause a crash or quietly produce misleading results.
