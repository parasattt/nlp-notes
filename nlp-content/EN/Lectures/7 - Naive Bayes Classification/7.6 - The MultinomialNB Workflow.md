## Use the same calculation through `MultinomialNB`

The full method is now familiar: count words, smooth the counts, add log probabilities, and compare the class scores. `MultinomialNB` provides that classifier, while `CountVectorizer` makes the input count matrix.



The vectorizer learns one shared vocabulary from the eight training messages. `MultinomialNB(alpha=1.0)` learns the class priors and smoothed word likelihoods from the resulting count matrix.

```python
from sklearn.naive_bayes import MultinomialNB

vec = CountVectorizer()
X_train = vec.fit_transform(train_texts)

model = MultinomialNB(alpha=1.0)
model.fit(X_train, train_labels)

print("classes:", model.classes_)
print("vocabulary size:", len(vec.get_feature_names_out()))
```


**Saved output:**

```text
classes: ['ham' 'spam']
vocabulary size: 26
```



`alpha=1.0` requests the same Laplace smoothing used above; the source also identifies it as the default. Smoothing is why a word with zero observed count does not make a class probability collapse to zero.

Keep the four steps in this order:

1. `vec.fit_transform(train_texts)` learns the training vocabulary and builds the feature matrix.
2. `model.fit(X, labels)` learns the classifier from those features and answers.
3. `vec.transform(new_texts)` builds features using the **same** vocabulary; do not fit again.
4. `model.predict(X_new)` returns the chosen labels.

The saved vocabulary contains 26 words, and the class order is `['ham', 'spam']`. The columns returned by `predict_proba` follow that class order.

The distinction between fitting and transforming is developed in [[EN/Lectures/6 - Turning Text into Features/6.4 - Fitting and Transforming|Fitting and Transforming]].



```python
new_messages = [
    "free money tomorrow",
    "send the report tomorrow",
    "urgent click to claim your prize",
    "the meeting is ready for review",
]

X_new = vec.transform(new_messages)
predictions = model.predict(X_new)
probabilities = model.predict_proba(X_new)

for msg, pred, prob in zip(new_messages, predictions, probabilities):
    confidence = max(prob)
    print(f"{pred:5} ({confidence:.1%}) | {msg}")
```


**Saved output:**

```text
spam  (82.0%) | free money tomorrow
ham   (97.8%) | send the report tomorrow
spam  (98.9%) | urgent click to claim your prize
ham   (98.7%) | the meeting is ready for review
```



`predict_proba` returns one probability per class. The loop prints the largest as confidence. The saved examples range from 82.0% spam for `free money tomorrow` to 98.9% spam for the prize message; the two legitimate examples receive high ham probabilities.

Probabilities support different actions for different confidence levels. The source's example is to show a warning for borderline mail and use a stronger action for a very confident decision. A 51% prediction and a 99.9% prediction need not be handled in the same way.
