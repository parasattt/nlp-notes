The function starts each class score at its prior, multiplies by one word likelihood for every message word, then chooses the larger score. The saved output lets you check both example calculations.

```python
def classify_by_hand(message):
    words = message.split()

    score_spam = p_spam
    score_ham = p_ham
    for w in words:
        score_spam *= p_word_given(w, spam_counts, len(spam_words))
        score_ham  *= p_word_given(w, ham_counts,  len(ham_words))

    print(f"message   : {message}")
    print(f"spam score: {score_spam:.10f}")
    print(f"ham score : {score_ham:.10f}")
    print(f"verdict   : {'spam' if score_spam > score_ham else 'ham'}")
    print()

classify_by_hand("free money now")
classify_by_hand("send the report")
```

Both example messages receive the expected label using only counting and multiplication. For `free money now`, the spam score is `0.5 × (3/18) × (2/18) × (2/18) = 0.0010288066`. The ham score is zero. For `send the report`, the ham score is `0.5 × (1/20) × (2/20) × (2/20) = 0.0002500000`.

These scores are **not normalised class probabilities**. The proportionality sign in Bayes' rule leaves out a denominator shared by the classes. Comparing the scores is enough to choose the larger one.
