## Read the confusion matrix before trusting accuracy



```python
from sklearn.metrics import confusion_matrix

cm = confusion_matrix(y_te, y_pred, labels=["ham", "spam"])

print(pd.DataFrame(cm,
                   index=["actually ham", "actually spam"],
                   columns=["predicted ham", "predicted spam"]))
```


**Saved output:**

```text
               predicted ham  predicted spam
actually ham               5               0
actually spam              0               4
```



All nine saved predictions lie on the matrix's diagonal: 5 ham correctly predicted ham and 4 spam correctly predicted spam. Both off-diagonal mistake counts are zero.

Do not treat this as proof of a strong spam filter. These spam messages and formal office emails share little vocabulary, so this particular task is easy. Thirty total messages and nine test cases also give weak evidence. Real spam is more varied and can be written to evade a filter.

The two off-diagonal cells mean different things:

| Cell | Name | Cost in this example |
|---|---|---|
| actually ham → predicted spam | false positive | Legitimate mail is hidden in spam, perhaps a job offer. |
| actually spam → predicted ham | false negative | A junk message reaches the inbox and needs deleting. |

Accuracy counts both as mistakes, but does not describe their different costs.

- **Spam precision** asks: of the messages flagged as spam, what fraction really are spam? Low precision means legitimate messages are being lost.
- **Spam recall** asks: of all actual spam messages, what fraction did the filter catch? Low recall means more junk gets through.

For the spam-filter use case in this lecture, losing real email is much worse than receiving junk. That makes precision on the spam class more important than recall. Choose the important error for the task before deciding which metric to emphasise.



```python
from sklearn.metrics import classification_report

print(classification_report(y_te, y_pred))
```


**Saved output:**

```text
              precision    recall  f1-score   support

         ham       1.00      1.00      1.00         5
        spam       1.00      1.00      1.00         4

    accuracy                           1.00         9
   macro avg       1.00      1.00      1.00         9
weighted avg       1.00      1.00      1.00         9

```



`support` is the number of test examples in each class: just 5 ham and 4 spam here. Read it before believing the `1.00` scores. With nine test messages, one mistake could change a precision score by more than ten percentage points.

A perfect result on nine examples and a perfect result on nine thousand examples can both print as `1.00`, but the evidence is very different. This report demonstrates how to evaluate a classifier; it does not establish how well the filter would handle real mail.
