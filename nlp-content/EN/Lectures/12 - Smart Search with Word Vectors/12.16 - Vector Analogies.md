### Arithmetic with word vectors

Vector differences can capture relationships. In the example, the change from `man` to `woman` is roughly like the change from `king` to `queen`:

$$v_{\text{king}} - v_{\text{man}} + v_{\text{woman}} \approx v_{\text{queen}}$$

Here, $v_{\text{word}}$ means that word's vector. Start with `king`, subtract the `man` vector, add the `woman` vector, then find a nearby vocabulary word. This is a **word analogy**.

The gensim call `most_similar(positive=[...], negative=[...])` performs the addition and subtraction. The helper below asks “a is to b as c is to what?” by searching near $b-a+c$.



For each analogy, `positive=[b, c]` adds two vectors and `negative=[a]` subtracts one. `topn=1` returns the single nearest answer.

```python
def analogy(a, b, c, kv=glove):
    # a is to b as c is to ?   ->   b - a + c
    return kv.most_similar(positive=[b, c], negative=[a], topn=1)[0][0]

print("man : king    = woman :", analogy("man", "king", "woman"))
print("walk : walked = swim  :", analogy("walk", "walked", "swim"))
print("france : paris = kazakhstan :", analogy("france", "paris", "kazakhstan"))
print("man : doctor  = woman :", analogy("man", "doctor", "woman"))
```


**Saved output:**

```text
man : king    = woman : queen
walk : walked = swim  : swam
france : paris = kazakhstan : almaty
man : doctor  = woman : nurse
```



The first two saved answers are `queen` and `swam`, matching the relationships the example asks for.
