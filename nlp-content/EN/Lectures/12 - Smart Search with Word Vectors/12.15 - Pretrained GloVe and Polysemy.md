### Use a pretrained model

The model trained here has read restaurant reviews only. Training on billions of words requires more computing resources. A **pretrained model** is one that another group has already trained and shared.

The source uses **GloVe** (Stanford, 2014): six billion words from Wikipedia and news, a vocabulary of 400,000 words, and 100 values per vector. GloVe is trained differently from Word2Vec, but its vectors can be used with the same lookup and similarity functions.

The source describes a 128 MB model and roughly a 30-second download. The following code loads the published files and inspects several words.



```python
base = "https://huggingface.co/fse/glove-wiki-gigaword-100/resolve/main/"
for name in ["glove-wiki-gigaword-100.model", "glove-wiki-gigaword-100.model.vectors.npy"]:
    if not os.path.exists(name):
        urllib.request.urlretrieve(base + name, name)

glove = KeyedVectors.load("glove-wiki-gigaword-100.model")
print(f"{len(glove):,} words, {glove.vector_size} numbers each")

for word in ["sofa", "almaty", "apple", "python"]:
    print(f"{word:7} -> {', '.join(w for w, _ in glove.most_similar(word, topn=8))}")
```


**Saved output:**

```text
400,000 words, 100 numbers each
sofa    -> couches, sofas, recliner, cushions, upholstered, couch, mattress, pillows
almaty  -> ashgabat, ulan, bator, ashkhabad, kazakhstan, dushanbe, kazakstan, kazakh
apple   -> microsoft, ibm, intel, software, dell, pc, macintosh, iphone
python  -> monty, php, perl, cleese, flipper, ruby, spamalot, javascript
```



The GloVe neighbors for `sofa` include `couches`, `sofas`, and `couch`, which are useful for the search task.

The examples for `apple` and `python` show a limitation. `apple` is near computer companies rather than fruit. `python` is near programming languages and Monty Python. Each word has **one vector**, so its different uses are mixed together, with common uses having more influence.
