### A simple keyword search

Start with a small catalogue. Split a product name into words, then return a product when its word set overlaps the query's word set. The code below contains the entire example catalogue and search function.



`words_of` lowercases and extracts ASCII letter sequences. `keyword_search` converts query/product words to sets, then uses `&` to test whether they overlap. It checks for shared words, not shared meaning.

```python
catalogue = [
    "Grey three-seat couch with cushions",
    "Corner couch, beige fabric",
    "Oak dining table for six",
    "Leather recliner armchair",
    "Kitchen chair, set of 4",
    "Queen size mattress, memory foam",
    "Bookshelf with five shelves",
    "Glass coffee table",
]

def words_of(text):
    return re.findall(r"[a-z]+", text.lower())      # "Corner couch, beige" -> ["corner", "couch", "beige"]

def keyword_search(query, catalogue):
    q = set(words_of(query))
    return [p for p in catalogue if q & set(words_of(p))]    # & = words they have in common

for query in ["couch", "sofa", "table", "desk"]:
    print(f"{query!r:8} -> {keyword_search(query, catalogue)}")
```


**Saved output:**

```text
'couch'  -> ['Grey three-seat couch with cushions', 'Corner couch, beige fabric']
'sofa'   -> []
'table'  -> ['Oak dining table for six', 'Glass coffee table']
'desk'   -> []
```



The saved search finds both couch products for `couch`, but nothing for `sofa`. It also returns nothing for `desk`.

A hand-written synonym list could repair selected cases, but it would never cover every query. The next goal is to learn that `sofa` and `couch` are related from text.
