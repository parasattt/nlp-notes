With the block list, only the two couch products remain. The next experiment clears the cache, times the first `table` search, then averages the time for 1,000 repeated searches.



```python
search.cache.clear()
start = time.perf_counter()
search.search("table")
first = time.perf_counter() - start

start = time.perf_counter()
for _ in range(1000):
    search.search("table")
cached = (time.perf_counter() - start) / 1000

print(f"first time : {first * 1000:.1f} ms")
print(f"from cache : {cached * 1000:.3f} ms")
```


**Saved output:**

```text
first time : 3.3 ms
from cache : 0.001 ms
```



The saved first search takes a few milliseconds; a cached search takes about a thousandth of a millisecond. Repeated customer queries make caching useful.
