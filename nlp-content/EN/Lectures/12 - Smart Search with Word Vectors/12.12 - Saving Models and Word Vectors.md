### Train once, then load for search

Training takes time, but a search request needs a fast answer. Save the trained objects to files and load them when the service starts instead of retraining for each request.

`w2v.wv` contains just the word vectors—the center vectors $v$ from the toy model. Those are enough for the search example.



The first save keeps the full trainable model. The second saves only word vectors. `size_mb` counts every file sharing the prefix because gensim may save large arrays in extra files.

```python
w2v.save("yelp_w2v.model")                  # everything, so training can continue later
w2v.wv.save("yelp_vectors.kv")              # only the word vectors

def size_mb(prefix):
    # gensim may write big arrays to extra files with the same name prefix
    return sum(os.path.getsize(f) for f in os.listdir(".") if f.startswith(prefix)) / 1e6

print(f"full model  : {size_mb('yelp_w2v.model'):.1f} MB")
print(f"vectors only: {size_mb('yelp_vectors.kv'):.1f} MB")

from gensim.models import KeyedVectors
yelp_vectors = KeyedVectors.load("yelp_vectors.kv")
print(f"loaded {len(yelp_vectors):,} word vectors")
```


**Saved output:**

```text
full model  : 16.8 MB
vectors only: 8.7 MB
loaded 20,184 word vectors
```



The saved vectors-only files are about half the size of the full model. The full model also contains the neighbor vectors $u$, which are needed to continue training but not for this search.
