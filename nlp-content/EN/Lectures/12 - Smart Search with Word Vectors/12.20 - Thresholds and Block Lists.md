The expanded query now finds both couch products for `sofa`. The unknown typo `sofaaa` gives no matches instead of raising an error.

However, the same query also finds a **recliner armchair** and a **mattress**. Their words passed the threshold because word vectors capture related uses, not exact product equivalence.

`desk` still returns nothing. Its closest word, `desks`, scores only 0.61, below the 0.65 threshold.

Raising the threshold to 0.7 would also remove the useful `couch` neighbor, whose saved score is 0.68. The example therefore uses a block list to remove specific bad additions.

Compare these meaning-related failures with [[EN/Lectures/8 - TF-IDF and Text Search/8.9 - TF-IDF Search and Meaning Limitations|the limits of TF-IDF search]].



```python
search = SynonymSearch(glove, catalogue, block=["recliner", "mattress", "cushions", "pillows"])
print("terms for 'sofa':", search.expand("sofa"))
print("results         :", search.search("sofa"))
```
