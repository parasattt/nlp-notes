# Part 4. Finding the best line

### 4.1 Try many values

Keep $b = 1.8$ fixed for a moment and try 200 values of $w$ between 5 and 15. For each, compute the
MSE:

```python
ws = np.linspace(5, 15, 200)
losses = [mse(predict(x, w, 1.8), y) for w in ws]
best_w = ws[np.argmin(losses)]

plt.figure(figsize=(5, 3.2))
plt.plot(ws, losses)
plt.scatter([best_w], [min(losses)], color="red", zorder=3, label=f"lowest at w = {best_w:.2f}")
plt.xlabel("w (minutes per 100 words)"); plt.ylabel("MSE")
plt.title("Loss for each value of w (b fixed at 1.8)", fontsize=10)
plt.legend(fontsize=8)
plt.tight_layout()
plt.show()
```

The loss as a function of the weight is a **bowl**: high on both sides, lowest at the best $w$
(10.0). Training means finding the bottom of this bowl.

Trying every value works for one parameter. With two parameters you need $200 \times 200 = 40\,000$
tries; with 20 000 parameters (one per word, Part 5) the number of combinations is astronomically
large. We need a way to walk to the bottom without looking at the whole bowl.

### 4.2 Which way is down? The slope

Stand at some $w$, for example $w = 7$. Move $w$ a tiny bit - **nudge** it by 0.001 - and see how
the loss changes:

```python
def loss_w(w, b=1.8):
    return mse(predict(x, w, b), y)

w0, nudge = 7.0, 0.001
slope = (loss_w(w0 + nudge) - loss_w(w0)) / nudge
print(f"loss at w = {w0}      : {loss_w(w0):.4f}")
print(f"loss at w = {w0 + nudge}  : {loss_w(w0 + nudge):.4f}")
print(f"slope = change / nudge: {slope:.2f}")
```

**Saved output:**

```text
loss at w = 7.0      : 99.5600
loss at w = 7.001  : 99.4940
slope = change / nudge: -65.99
```

The loss **drops** when $w$ grows, at a rate of about −66 units of loss per unit of $w$. This rate
is the **derivative** of the loss with respect to $w$, or simply the **slope** of the bowl at that
point:

- slope negative → going right is downhill → **increase** $w$
- slope positive → going left is downhill → **decrease** $w$
- slope near zero → we are near the bottom

For MSE there is a formula for the slope, so nudging is not needed:

$$\text{slope for } w = \frac{2}{n} \sum (\hat{y}_i - y_i)\, x_i \qquad \text{slope for } b = \frac{2}{n} \sum (\hat{y}_i - y_i)$$

Read it in words: **error times input, averaged**. If the model predicts too little ($\hat{y} < y$)
on long texts (large $x$), the slope for $w$ is negative and $w$ must grow. You do not need to derive
the formula; check that it gives the same number as nudging:

```python
def slopes(w, b):
    error = predict(x, w, b) - y
    return 2 * np.mean(error * x), 2 * np.mean(error)

print("formula slope for w at w = 7:", round(slopes(7.0, 1.8)[0], 2))
```

**Saved output:**

```text
formula slope for w at w = 7: -66.0
```
