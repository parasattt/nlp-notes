# Part 1. What machine learning is

There are two ways to make a computer filter spam.

**Rules.** A programmer writes: *if the message contains `free money` or `you won`, mark it spam.*
The programmer must know the answer in advance and write it down. Every new trick the spammers
invent needs a new rule.

**Learning.** You collect 10 000 messages that people have already marked as spam or not spam, and
an algorithm finds the rules by itself - for example, which words should count, and how much. When
spammers change, you collect new examples and train again.

**Machine learning (ML)** is the second way: the program's behaviour is *learned from examples*
instead of written by hand.

### The vocabulary

| term | meaning | spam example |
|---|---|---|
| **example** (also *sample*, *instance*) | one item in the data | one message |
| **feature** | one number describing an example | how many times `free` occurs |
| **label** (also *target*) | the correct answer for an example | spam / not spam |
| **dataset** | a collection of examples, usually with labels | 10 000 marked messages |
| **model** | a formula with adjustable numbers that maps features to an answer | Naive Bayes, logistic regression |
| **parameters** | the adjustable numbers inside the model | one weight per word |
| **training** (*fitting*) | choosing the parameters using the dataset - `fit` | |
| **prediction** (*inference*) | using the trained model on a new example - `predict` | is *this* new message spam? |

### Kinds of problems

- **Supervised learning**: every training example has a label, and the model learns to predict it.
  Everything in this course so far.
  - **Classification**: the label is a category. Spam / not spam; positive / negative; which team
    should answer a ticket.
  - **Regression**: the label is a number. How many stars a review gives; how many minutes a
    translation will take; a product's price.
- **Unsupervised learning**: no labels. The algorithm looks for structure by itself, for example
  grouping similar news articles together (**clustering**). Word2Vec in week 7 is a relative of this.

This notebook uses **regression**, because its loss is the easiest to see: a prediction of 3.5 stars
for a 5-star review is simply 1.5 stars off.
