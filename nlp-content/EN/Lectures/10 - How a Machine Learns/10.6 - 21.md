### 4.3 Gradient descent

The list of slopes, one per parameter, is called the **gradient**. **Gradient descent** repeats one
step:

$$w \leftarrow w - \eta \cdot \text{slope}_w \qquad\qquad b \leftarrow b - \eta \cdot \text{slope}_b$$

($\leftarrow$ means "replace with".) $\eta$ (the Greek letter *eta*) is the **learning rate**: how
big a step to take. The minus sign makes every step go downhill. Each repetition is called an
**iteration** (or a **step**).

Start from $w = 0, b = 0$ - a model that predicts 0 minutes for everything:

```python
def gradient_descent(lr, steps, w=0.0, b=0.0):
    path = [(w, b)]
    for _ in range(steps):
        sw, sb = slopes(w, b)
        w, b = w - lr * sw, b - lr * sb
        path.append((w, b))
    return np.array(path)

path = gradient_descent(lr=0.02, steps=1000)
for step in [0, 1, 2, 5, 20, 100, 1000]:
    w, b = path[step]
    print(f"step {step:4}:  w = {w:6.2f}   b = {b:5.2f}   MSE = {mse(predict(x, w, b), y):8.2f}")
```

The first steps cover most of the distance: the loss falls from 1 212 to 337 after one step, and
below 3 after five. Then progress slows down, because near the bottom the slope is small and so are
the steps. After 1 000 steps the
answer is $w = 10.0$, $b = 1.8$: **10 minutes per 100 words, plus 1.8 minutes of fixed overhead**.

The picture: every point of this map is one choice of $(w, b)$, and its colour is the loss. Gradient
descent walks downhill on it.

```python
W, Bb = np.meshgrid(np.linspace(-1, 14, 150), np.linspace(-10, 14, 150))
L = np.array([[mse(predict(x, wi, bi), y) for wi, bi in zip(wr, br)] for wr, br in zip(W, Bb)])

fig, axes = plt.subplots(1, 2, figsize=(9.5, 3.6))
cs = axes[0].contourf(W, Bb, np.log10(L), levels=25, cmap="viridis_r")
fig.colorbar(cs, ax=axes[0], label="log10(MSE)")
axes[0].plot(path[:60, 0], path[:60, 1], "o-", color="white", ms=2, lw=0.8)
axes[0].scatter(*path[0], color="red", zorder=3, label="start (0, 0)")
axes[0].scatter(*path[-1], color="orange", zorder=3, label="after 1000 steps")
axes[0].set_xlabel("w"); axes[0].set_ylabel("b"); axes[0].legend(fontsize=7, loc="lower left")
axes[0].set_title("Gradient descent on the loss map", fontsize=10)

axes[1].scatter(x, y, zorder=3)
xs = np.linspace(0, 6, 10)
for step, alpha in [(1, 0.3), (5, 0.5), (1000, 1)]:
    w, b = path[step]
    axes[1].plot(xs, predict(xs, w, b), alpha=alpha, label=f"after {step} steps")
axes[1].set_xlabel("words (hundreds)"); axes[1].set_ylabel("minutes")
axes[1].set_title("The line after some steps", fontsize=10); axes[1].legend(fontsize=7)
plt.tight_layout()
plt.show()
```
