### Loops

A `for` loop runs its body once for each item in a collection. The next examples print information about words, build a filtered list, and use `enumerate()` to obtain each item's position as well as its value.



```python
words = ["cat", "elephant", "dog", "hippopotamus"]

for word in words:
    print(word, "has", len(word), "letters")
```


**Saved output:**

```text
cat has 3 letters
elephant has 8 letters
dog has 3 letters
hippopotamus has 12 letters
```



```python
# Building a new list as you go
long_words = []

for word in words:
    if len(word) > 3:
        long_words.append(word)

print(long_words)
```


**Saved output:**

```text
['elephant', 'hippopotamus']
```



```python
# enumerate() gives you the position as well as the item
for i, word in enumerate(words):
    print(i, word)
```


**Saved output:**

```text
0 cat
1 elephant
2 dog
3 hippopotamus
```

The ordinary loop visits each word in order. The second example starts with an empty list and appends words longer than three characters. `enumerate(words)` provides positions starting at zero together with the words.



#### Indentation is the syntax

Python uses **indentation** to show which statements belong inside a loop or another block. The usual convention is four spaces. There is no closing brace or `end` keyword.

In the next cell, the indented `print()` runs for every word. The final unindented `print()` runs only once, after the loop.



```python
for word in ["a", "b", "c"]:
    print("inside the loop:", word)
print("outside the loop, runs once")
```


**Saved output:**

```text
inside the loop: a
inside the loop: b
inside the loop: c
outside the loop, runs once
```
