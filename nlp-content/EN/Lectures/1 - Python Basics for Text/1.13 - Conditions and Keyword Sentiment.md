### Conditions

Use `if`, `elif`, and `else` to choose between actions. Each condition line ends with a colon, and indentation marks its body. Python checks the branches in order and runs the first matching branch; `else` handles the remaining case.



```python
review = "The film was boring and far too long"
list_of_good_review_words = ["good", "amaing"]
list_of_bad_review_words = ["trash", "bad"]

if "excellent" in review or "great" in review:
    sentiment = "positive"
elif "boring" in review or "bad" in review:
    sentiment = "negative"
else:
    sentiment = "unclear"

print(sentiment)
```


**Saved output:**

```text
negative
```

The example selects `negative` because `"boring"` occurs in the review. The two lists declared above the condition are preserved from the source, including the spelling `"amaing"`; this code does not use either list in its decision.



This is a **keyword-based sentiment classifier**: it uses selected words to label text as positive, negative, or unclear. Early sentiment systems used this general approach.

The rule is easy to fool. `"The film was not boring"` still contains `"boring"`, so this code would call it negative. It does not understand negation. Keep this limitation in mind when moving to [[EN/Lectures/2 - Pandas for Text Data/2.17 - Sentiment Scores and Baseline Evaluation|a larger sentiment baseline]] and later learned classifiers.



```python
# Comparison operators
print(5 > 3)
print(5 == 5)      # == compares, = assigns. Mixing these up is a classic error.
print(5 != 3)
print("a" < "b")   # strings compare alphabetically (by character code)

# Combining conditions
n = 7
print(n > 5 and n < 10)
print(n < 5 or n > 6)
print(not (n == 7))
```


**Saved output:**

```text
True
True
True
True
True
True
False
```

`==` compares values; `=` assigns a value. `!=` means “not equal.” `and`, `or`, and `not` combine or reverse individual boolean conditions. The string comparison uses character-code ordering.
