### Putting it together: a word frequency counter

Now combine the earlier skills for a real text task: counting how often each word occurs in a **corpus**, a collection of text.

Word frequency is often one of the first things you calculate for a new corpus. It also supports [[EN/Lectures/6 - Turning Text into Features/6.2 - Vocabulary and Bag of Words|bag-of-words features]] and [[EN/Lectures/8 - TF-IDF and Text Search/8.5 - TF-IDF by Hand|TF-IDF]]. The following steps normalize case, split text, clean punctuation, count words, and rank the counts.



```python
text = """
The cat sat on the mat. The mat was warm.
The cat liked the warm mat, and the cat slept.
"""

# Step 1: normalise the case so "The" and "the" count as the same word
text_lower = text.lower()

# Step 2: split into words
words = text_lower.split()
print(words)
```


**Saved output:**

```text
['the', 'cat', 'sat', 'on', 'the', 'mat.', 'the', 'mat', 'was', 'warm.', 'the', 'cat', 'liked', 'the', 'warm', 'mat,', 'and', 'the', 'cat', 'slept.']
```



Inspect the saved tokens carefully. `'mat.'`, `'mat,'`, and `'mat'` are separate strings because punctuation is still attached. Counting them separately would split the frequency of what a reader considers the same word.

The next cell uses a simple temporary fix: strip selected punctuation from each token's ends and skip tokens that become empty. [[EN/Lectures/3 - Parsing Text and Regex/3.3 - Regex Tokenization|Regex tokenization]] later gives a more deliberate rule for what a word should look like.



```python
cleaned = []
for w in words:
    w = w.strip(".,!?;:\"'")     # remove these characters from both ends
    if w:                        # skip anything that became empty
        cleaned.append(w)

print(cleaned)
```


**Saved output:**

```text
['the', 'cat', 'sat', 'on', 'the', 'mat', 'the', 'mat', 'was', 'warm', 'the', 'cat', 'liked', 'the', 'warm', 'mat', 'and', 'the', 'cat', 'slept']
```

`.strip(".,!?;:\"'")` removes any of these characters from the **ends** of a token. It does not remove punctuation inside the token. `if w` skips an empty string, so a piece containing only stripped punctuation is not counted as a word.
