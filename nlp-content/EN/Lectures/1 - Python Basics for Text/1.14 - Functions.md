### Functions

A **function** gives a name to a reusable piece of code. You can call it again with different inputs instead of copying the same statements.



```python
def clean_text(text):
    """Lowercase the text and strip surrounding whitespace."""
    # Hello
    return text.strip().lower()



print(clean_text("   HELLO World   "))
print(clean_text("  Another EXAMPLE "))
```


**Saved output:**

```text
hello world
another example
```



Read the function definition as follows:

- `def` begins a function definition.
- `clean_text` is its name.
- `text` is a **parameter**: the input value supplied by the caller.
- The indented statements form the **body**.
- `return` sends the result back to the caller. A function without a returned value returns `None`.
- The triple-quoted string is a **docstring**. The notebook help command `clean_text?` can display it.

When you find yourself copying the same few lines repeatedly, consider putting them in a function.



```python
def count_words(text):
    return len(text.split())

def average_word_length(text):
    words = text.split()
    if len(words) == 0:          # guard against dividing by zero
        return 0
    total = sum(len(w) for w in words)
    return total / len(words)


sample = "Natural language processing is mostly data cleaning"
print(count_words(sample))
print(round(average_word_length(sample), 1))
```


**Saved output:**

```text
7
6.4
```

`count_words()` counts whitespace-separated pieces. `average_word_length()` splits the text, returns `0` for an empty list to avoid dividing by zero, sums the character lengths, and divides by the number of words. The saved sample contains **7 words** with a mean length rounded to **6.4**.



```python
# Default values for parameters
def preview(text, n=30, p = 10):
    if len(text) <= n or not len(text) > n+p:
        return text
    return text[:n+p] + "..."


long_text = "Python is a programming language that is widely used in data science and NLP"
print(preview(long_text))
print(preview(long_text, 50, 50))
print(preview(long_text, n=10, p=5))
```


**Saved output:**

```text
Python is a programming language that is...
Python is a programming language that is widely used in data science and NLP
Python is a pro...
```

`n=30` and `p=10` are default parameter values. This particular function uses **`n + p` as its truncation length**, not just `n`. It keeps the original text when it fits within that threshold; otherwise it takes `text[:n+p]` and adds `"..."`.

The first call uses a threshold of 40 characters. The second passes `50, 50`, giving a threshold of 100, so the saved result is the whole text. The named-argument call uses `10 + 5 = 15`, giving the saved preview `Python is a pro...`.
