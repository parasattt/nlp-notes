### Comprehensions

A **list comprehension** is a shorter way to express a loop that builds a list. You will see it often, so learn to read it even if you prefer writing an ordinary loop.

In `[len(w) for w in words]`, read `for w in words` as the iteration and `len(w)` as the value placed in the new list. A final `if` can keep only the items that match a condition.



```python
words = ["cat", "elephant", "dog", "hippopotamus"]

# The long way
lengths = []
for w in words:
    lengths.append(len(w))
print(lengths)

# The same thing as a comprehension
lengths = [len(w) for w in words]
print(lengths)
```


**Saved output:**

```text
[3, 8, 3, 12]
[3, 8, 3, 12]
```



```python
# With a filter
long_words = [w for w in words if len(w) > 3]
print(long_words)

# Transform and filter together
print([w.upper() for w in words if w.startswith("d") or w.startswith("e")])
```


**Saved output:**

```text
['elephant', 'hippopotamus']
['ELEPHANT', 'DOG']
```

The ordinary loop and the first comprehension both produce `[3, 8, 3, 12]`. Adding an `if` filters items: words longer than three characters are kept, and the last example uppercases words starting with `d` or `e`.
