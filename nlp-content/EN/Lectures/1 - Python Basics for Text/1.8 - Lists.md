### Lists

A **list** is an ordered collection. Lists of words are used throughout text processing. Like strings, lists support positions starting at zero, negative positions from the end, and slices.



```python
words = ["the", "quick", "brown", "fox"]

print(words)
print(len(words))
print(words[0])
print(words[-1])
print(words[1:3])
```


**Saved output:**

```text

```



```python
words.append("jumps")       # add to the end
print(words)

words.insert(0, "and")      # add at a position
print(words)

words.remove("and")         # remove by value
print(words)

last = words.pop()          # remove and return the last item
print(last, "|", words)
```
