#### String methods you will actually use

Python has many string methods. The following examples introduce methods used regularly to clean and inspect text.



```python
messy = "   The Movie Was GREAT!!!   "

print(repr(messy.strip()))          # remove whitespace at both ends
print(messy.strip().lower())        # chain them together
print(messy.replace("GREAT", "good"))
print(messy.strip().split("Was"))        # split on whitespace into a list
```


**Saved output:**

```text
'The Movie Was GREAT!!!'
the movie was great!!!
   The Movie Was good!!!   
['The Movie ', ' GREAT!!!']
```

`strip()` removes surrounding whitespace, `lower()` changes case, and `replace("GREAT", "good")` replaces that exact substring. Chaining `.strip().lower()` applies the operations in sequence.

**Source detail:** the final code uses `.split("Was")`, so it splits on the literal word `Was`, producing `['The Movie ', ' GREAT!!!']`. Its original inline comment says “split on whitespace”; that description would fit `.split()` with no argument, rather than the code saved here. The original code and comment are preserved.



`repr()` displays a string with its quotes and escape characters visible. It is especially useful for inspecting whitespace: an extra space at the end may be hard to see in normal output, but it still changes a comparison.



```python
a = "cat "
b = "cat"
print(a == b)          # False - and you cannot see why from the printout
print(repr(a), repr(b))# now you can
print(a.strip() == b)  # True
```


**Saved output:**

```text
False
'cat ' 'cat'
True
```
