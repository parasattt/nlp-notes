#### Sorting

`sorted()` creates a sorted list. Its `key` parameter controls the value used for comparison, and `reverse=True` reverses the ordering.



```python
words = ["banana", "Apple", "cherry", "apple"]

print(sorted(words))                    # capitals come first - ASCII order
print(sorted(words, key=str.lower))     # case-insensitive
print(sorted(words, key=len))           # by length
print(sorted(words, reverse=True))
```


**Saved output:**

```text
['Apple', 'apple', 'banana', 'cherry']
['Apple', 'apple', 'banana', 'cherry']
['Apple', 'apple', 'banana', 'cherry']
['cherry', 'banana', 'apple', 'Apple']
```

`key=str.lower` compares lowercase versions while keeping the original strings in the returned list. `key=len` compares lengths. `reverse=True` reverses the usual comparison order. The saved outputs happen to give the same first three orderings for this small list.



In the saved example, plain `sorted()` places `"Apple"` before `"apple"`. The computer compares character codes, which can differ from the alphabetical order a person expects.

This introduces a recurring NLP problem: a computer's exact representation of a word may differ from a person's idea of that word. Text processing often means choosing rules that reduce this gap.
