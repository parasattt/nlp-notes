```python
review = "The service was slow but the food was excellent"

print(review.startswith("The"))
print(review.endswith("."))
print("food" in review)            # substring test - very common
print(review.count("was"))
print(review.find("food"))         # position, or -1 if not found
```


**Saved output:**

```text
True
False
True
2
29
```

`startswith()` and `endswith()` test the string's ends. `in` looks for a substring anywhere. `count("was")` finds two occurrences, and `find("food")` gives its starting character position, `29`, or would give `-1` if it were absent.



The `in` operator checks whether one string appears inside another. This gives you a simple **keyword search**. It is useful, but it does not decide what counts as a whole word or handle every text pattern. [[EN/Lectures/2 - Pandas for Text Data/2.7 - Filtering Text and Categories|Filtering text columns]] applies searching to many rows, and [[EN/Lectures/3 - Parsing Text and Regex/3.3 - Regex Tokenization|regular expressions]] give more control over text patterns.
