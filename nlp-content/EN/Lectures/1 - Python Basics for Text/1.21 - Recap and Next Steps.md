### Recap

- Variables have types. Inspect them with `type()`; incompatible types cause many beginner errors.
- Useful string operations include `strip`, `lower`, `replace`, `split`, `join`, `in`, and f-strings.
- Lists keep items in order. `split()` and `join()` move between text and lists of strings.
- Dictionaries map keys to values. `counts.get(word, 0) + 1` is a useful counting pattern.
- `for` loops and `if` statements use colons and indentation.
- Functions defined with `def` let you reuse code.
- Comprehensions are compact ways to build collections with loops.
- Use `with open(..., encoding="utf-8")` for text files.
