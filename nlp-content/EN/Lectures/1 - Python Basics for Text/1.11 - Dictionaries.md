### Dictionaries

A **dictionary** maps **keys** to **values**. A common text-processing use is word counting: the key is a word and the value is the number of times it appeared.



```python
counts = {"the": 12, "cat": 3, "sat": 1}

print(counts["the"])
print(len(counts))

counts["mat"] = 5          # add a new key
counts["the"] = 13         # change an existing one
print(counts)
```


**Saved output:**

```text
12
3
{'the': 13, 'cat': 3, 'sat': 1, 'mat': 5}
```

`counts["the"]` looks up a value. `len(counts)` counts keys, rather than adding their values. Assigning to a new key adds it, while assigning to an existing key replaces its previous value.

Both the original code and the actual saved error are kept.



```python
# .get() is the safe version: returns a default instead of crashing.
print(counts.get("dog"))         # None
print(counts.get("dog", 0))      # 0  <- this is the useful one for counting
print("dog" in counts)           # False
```


**Saved output:**

```text
None
0
False
```



```python
# Looping over a dictionary
for word, n in counts.items():
    print(f"{word:>5} : {n}")
```


**Saved output:**

```text
  the : 13
  cat : 3
  sat : 1
  mat : 5
```

`.get("dog")` returns `None` when the key is missing, while `.get("dog", 0)` supplies zero as a default. `"dog" in counts` tests keys. `.items()` yields `(key, value)` pairs for the loop, and `:>5` aligns a word to the right in a field five characters wide.
