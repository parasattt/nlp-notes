```python
# Python has a built-in counter that does all of the above in one line.
from collections import Counter

counter = Counter(cleaned)
print(counter.most_common(5))
```


**Saved output:**

```text
[('the', 6), ('cat', 3), ('mat', 3), ('warm', 2), ('sat', 1)]
```

`Counter(cleaned)` creates word counts from the cleaned tokens. `.most_common(5)` returns the five highest-frequency `(word, count)` pairs. The saved result begins with `('the', 6)`, followed by `cat` and `mat` with three occurrences each.



Python's `Counter` could have done the counting from the beginning. Building the count by hand first shows what the shortcut does, which helps you understand unexpected results later.
