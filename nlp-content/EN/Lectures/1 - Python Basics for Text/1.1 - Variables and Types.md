### Variables

A **variable** is a name that refers to a value. Use `=` to assign a value to a name.



```python
course = "Natural Language Processing"
year = 2026
passing_grade = 50.0
is_fun = True

print(course)
print(year)
```


**Saved output:**

```text
Natural Language Processing
2026
```

The assignments store a string, an integer, a decimal number, and a boolean. The cell prints only `course` and `year`; the other values remain available in the shared notebook session.



Python works out each value's **type** automatically; you do not declare the type when creating these variables. The type still matters. If an operation behaves strangely, check it with `type()`.



```python
print(type(course))       # str   - text
print(type(year))         # int   - whole number
print(type(passing_grade))# float - number with a decimal point
print(type(is_fun))       # bool  - True or False
```


**Saved output:**

```text
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```



Use these naming rules and habits:

- Names can contain letters, digits, and `_`, but cannot start with a digit.
- Prefer lowercase words separated by underscores, such as `word_count`, rather than `WordCount` or an unclear abbreviation such as `wc`.
- Names are case sensitive: `Text` and `text` are different variables.
- A clear name can explain more than a comment.
