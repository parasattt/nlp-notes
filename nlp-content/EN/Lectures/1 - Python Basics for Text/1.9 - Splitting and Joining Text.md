#### Splitting and joining: two operations used constantly

`split()` turns a string into a list of pieces. With no separator argument, it splits on whitespace. `join()` combines strings from a list into one string, using the separator before `.join()`.

A common text-processing pattern is: split the text, work on the pieces, then join them again. For the limits of this first approach, see [[EN/Lectures/3 - Parsing Text and Regex/3.2 - Tokenization with String Methods|tokenization with string methods]].



```python
sentence = "natural language processing is useful"

tokens = sentence.split()
print(tokens)

back_together = " ".join(tokens)
print(back_together)

with_dashes = "-".join(tokens)
print(with_dashes)
```


**Saved output:**

```text
['natural', 'language', 'processing', 'is', 'useful']
natural language processing is useful
natural-language-processing-is-useful
```



```python
# split() takes an argument if you do not want to split on spaces.
csv_line = "Aisha,Almaty,87"
print(csv_line.split(","))

path = "data/raw/reviews.txt"
print(path.split("/"))
```


**Saved output:**

```text
['Aisha', 'Almaty', '87']
['data', 'raw', 'reviews.txt']
```

With no argument, `split()` separates words on whitespace. With `","` it separates comma-delimited fields; with `"/"` it separates path components. The string before `.join()` is the separator, so `" ".join(tokens)` restores spaces while `"-".join(tokens)` inserts dashes.
