```python
# Step 3: count
counts = {}
for w in cleaned:
    counts[w] = counts.get(w, 0) + 1

print(counts)
```


**Saved output:**

```text
{'the': 6, 'cat': 3, 'sat': 1, 'on': 1, 'mat': 3, 'was': 1, 'warm': 2, 'liked': 1, 'and': 1, 'slept': 1}
```



The important counting pattern is `counts.get(w, 0) + 1`. For each word `w`, get its current count; use zero if the word has not appeared before; then add one and store the result.



```python
# Step 4: sort by count, most frequent first
ranked = sorted(counts.items(), key=lambda pair: pair[1], reverse=True)

for word, n in ranked:
    print(f"{word:>6} : {n}")
```


**Saved output:**

```text
   the : 6
   cat : 3
   mat : 3
  warm : 2
   sat : 1
    on : 1
   was : 1
 liked : 1
   and : 1
 slept : 1
```



`lambda pair: pair[1]` is a small unnamed function. Each dictionary item is a pair `(word, count)`, and `pair[1]` selects its count. Sorting by that value with `reverse=True` puts the highest counts first.

The top words are *the*, *cat*, and *mat*. Here, *cat* and *mat* help describe the text, while *the* gives little information about its topic. Common words such as *the*, *a*, *is*, and *and* are called **stop words**. Deciding whether to keep them is a recurring NLP choice; see [[EN/Lectures/3 - Parsing Text and Regex/3.13 - Corpus Counts and Stop Words|corpus counts and stop words]].
