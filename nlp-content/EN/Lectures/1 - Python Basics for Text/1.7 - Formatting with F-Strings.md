#### f-strings: putting values inside text

Put `f` before a string's opening quote. Inside it, `{variable}` inserts a value, and braces can also contain expressions such as `name.upper()` or `len(name)`.

The format `:.1f` displays a number with one decimal place.



```python
name = "Aisha"
score = 87.6531

print(f"{name} scored {score} points.")
print(f"{name} scored {score:.1f} points.")   # .1f = one decimal place
print(f"{name.upper()} — {len(name)} letters")# any expression works inside braces
```


**Saved output:**

```text
Aisha scored 87.6531 points.
Aisha scored 87.7 points.
AISHA — 5 letters
```
