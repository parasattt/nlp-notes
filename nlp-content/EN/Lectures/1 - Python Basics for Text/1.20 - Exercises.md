### Exercises

Work in new notebook cells. The source asks you to try these yourself before searching for answers; the effort of working through a problem is part of the learning.

1. Write `initials(full_name)` so that `"Ernest Miller Hemingway"` becomes `"E.M.H."`.
2. For `text = "the rain in spain falls mainly on the plain"`, count the words containing `"ain"`.
3. Write `longest_word(text)` to return the longest word. Test `"Hello, world!"`: should `"Hello,"` count as six letters? Handle the punctuation issue.
4. Read the `reviews.txt` created above. Label each line positive or negative using keyword lists. Then give a sentence your classifier would label incorrectly and explain why.
5. Build a dictionary mapping each word length to the number of words of that length in `reviews.txt`, such as `{5: 12, 3: 8, ...}`.
