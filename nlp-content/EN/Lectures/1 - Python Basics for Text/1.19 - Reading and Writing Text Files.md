### Reading text from a file

In this course, data will come from files as well as strings typed into cells. The next cells first create a sample file so the notebook can work from a clean machine, then demonstrate reading the whole file and reading its lines.



```python
# First create a file to read, so this notebook works from a clean machine.
sample_text = """Product arrived on time and works perfectly.
Terrible quality, broke after two days.
Good value for the price, would buy again.
The packaging was damaged but the item was fine.
Absolutely useless, do not waste your money.
"""

with open("reviews.txt", "w", encoding="utf-8") as f:
    f.write(sample_text)

print("File created.")
```


**Saved output:**

```text
File created.
```



```python
# Read the whole file as one string
with open("reviews.txt", "r", encoding="utf-8") as f:
    content = f.read()

print(content)
```


**Saved output:**

```text
Product arrived on time and works perfectly.
Terrible quality, broke after two days.
Good value for the price, would buy again.
The packaging was damaged but the item was fine.
Absolutely useless, do not waste your money.
```



```python
# Read it as a list of lines - usually what you want
with open("reviews.txt", "r", encoding="utf-8") as f:
    lines = f.read().splitlines()

for i, line in enumerate(lines, start=1):
    print(f"{i}. ({len(line.split())} words) {line}")
```


**Saved output:**

```text
1. (7 words) Product arrived on time and works perfectly.
2. (6 words) Terrible quality, broke after two days.
3. (8 words) Good value for the price, would buy again.
4. (9 words) The packaging was damaged but the item was fine.
5. (7 words) Absolutely useless, do not waste your money.
```

`read()` loads one string containing the whole file. `read().splitlines()` makes a list of review lines. `enumerate(lines, start=1)` labels them from 1 for display, while `len(line.split())` counts whitespace-separated words in each line. The saved line lengths are 7, 6, 8, 9, and 7 words.



Use `with open(...) as f:` to work with a file. Python closes it when the block finishes, including when an error occurs inside the block.

Use `splitlines()` to separate lines rather than assuming every file uses only `"\n"`. Windows-style line endings use `"\r\n"`; `splitlines()` handles these without leaving a stray `"\r"` attached to each line. Explicit UTF-8 encoding is explained in [[EN/Lectures/0 - Jupyter and Colab/0.11 - UTF-8 and Text Encoding|files and UTF-8 encoding]].
