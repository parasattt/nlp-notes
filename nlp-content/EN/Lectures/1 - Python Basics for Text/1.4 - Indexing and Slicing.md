#### Indexing and slicing

String positions start at **0**. An index selects one character. A slice `[start:end]` includes the character at `start` and stops **before** `end`.

This boundary rule is easy to get wrong at first. In `word[0:4]`, positions 0, 1, 2, and 3 are included; position 4 is excluded.



```python
word = "language"
#       01234567

print(word[0])     # first character
print(word[3])     # fourth character
print(word[-1])    # last character
print(word[-2])    # second to last
```


**Saved output:**

```text
l
g
e
g
```



```python
print(word[0:4])   # characters 0,1,2,3 -> 'lang'
print(word[:4])    # same thing, start is optional
print(word[4:])    # from 4 to the end
print(word[::-1])  # reversed
```


**Saved output:**

```text
lang
lang
uage
egaugnal
```

Negative indices count backward from the end: `-1` is the last character. Omitting the start or end of a slice means the corresponding edge of the string. In `[::-1]`, the step `-1` reads the string backward.
