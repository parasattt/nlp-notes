## A reusable preprocessing pipeline



This function makes its preprocessing choices explicit through parameters. The three calls change only stop word handling and show why the resulting representation must match the task.

```python
def preprocess(text, lowercase=True, remove_stop=True, keep_negations=True,
               min_length=2, language="english"):
    """Turn raw text into tokens, with the choices made explicit."""
    if lowercase:
        text = text.lower()

    tokens = word_tokenize(text)
    tokens = [t for t in tokens if t.isalpha()]

    if remove_stop:
        stops = set(stopwords.words(language))
        if keep_negations:
            stops = stops - NEGATIONS
        tokens = [t for t in tokens if t not in stops]

    tokens = [t for t in tokens if len(t) >= min_length]
    return tokens


sample = "I did NOT like the battery life, but the screen is absolutely beautiful!!"

print("default        :", preprocess(sample))
print("keep stop words:", preprocess(sample, remove_stop=False))
print("drop negations :", preprocess(sample, keep_negations=False))
```


**Saved output:**

```text
default        : ['not', 'like', 'battery', 'life', 'screen', 'absolutely', 'beautiful']
keep stop words: ['did', 'not', 'like', 'the', 'battery', 'life', 'but', 'the', 'screen', 'is', 'absolutely', 'beautiful']
drop negations : ['like', 'battery', 'life', 'screen', 'absolutely', 'beautiful']
```



The same sentence produces three token lists because the choices differ. `lowercase` controls case conversion; `remove_stop` controls stop word filtering; `keep_negations` protects the listed negations; `min_length` removes short tokens; and `language` selects the NLTK stop word list. `isalpha()` keeps only alphabetic tokens.

The default keeps `not`, while `keep_negations=False` removes it. Setting `remove_stop=False` keeps stop words, though the default minimum length still removes the one-letter `I`. Each setting may suit a different task. Keeping the choices visible makes the pipeline easier to inspect and debug.
