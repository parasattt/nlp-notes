## What is a token?

A **token** is one unit of text that a program treats as a single, indivisible item.

A token does not have to be a word or the text between two spaces. You choose the unit that matters for your task:

| Text | Reasonable tokens | Also reasonable |
|---|---|---|
| `don't` | `don't` | `do` + `n't` |
| `New York` | `New` + `York` | `New York` |
| `$19.99` | `$19.99` | `$` + `19.99` |
| `#nlp` | `#nlp` | `#` + `nlp` |
| `кітаптарымызда` | `кітаптарымызда` | `кітап` + `тар` + `ымыз` + `да` |

Each choice can be useful. For a hashtag analyser, splitting `#nlp` loses the item you want to study.

**Tokenization** means turning a string into a list of tokens. It happens near the start of almost every NLP pipeline. Later steps receive its mistakes too.

The lecture's model example learns one vector for each distinct token. If two spellings represent the same thing but remain separate tokens, the model learns them separately, using less evidence for each.
