## NLTK tokenizers

`nltk` is a long-established NLP library with several tokenizers. The notebook says it is already available in Colab; elsewhere, its installation command is `pip install nltk`.



The setup downloads the sentence-tokenizer resources `punkt` and `punkt_tab` and the stop word lists. The source comment explains that rerunning skips resources already present; the saved version is NLTK 3.9.2.

```python
import nltk

# Safe to re-run, it skips anything already present.
nltk.download("punkt", quiet=True)
nltk.download("punkt_tab", quiet=True)
nltk.download("stopwords", quiet=True)

print("nltk", nltk.__version__)
```


**Saved output:**

```text
nltk 3.9.2
```



This comparison uses the same `messy` string for the handwritten tokenizer and three NLTK alternatives. Inspect which units each preserves or splits.

```python
from nltk.tokenize import word_tokenize, wordpunct_tokenize, TweetTokenizer

print("ours    :", tokenize_v2(messy))
print()
print("wordpunct:", wordpunct_tokenize(messy))
print()
print("nltk     :", word_tokenize(messy))
print()
print("tweet    :", TweetTokenizer().tokenize(messy))
```


**Saved output:**

```text
ours    : ['dr', 'smith', "didn't", 'pay', '$19.99', 'for', 'the', 'u.s.a', 'trip', "wasn't", 'that', 'great', '#nlp', '@ai_lab']

wordpunct: ['Dr', '.', 'Smith', 'didn', "'", 't', 'pay', '$', '19', '.', '99', 'for', 'the', 'U', '.', 'S', '.', 'A', '.', 'trip', '...', 'Wasn', "'", 't', 'that', 'great', '?!', ':)', '#', 'nlp', '@', 'ai_lab']

nltk     : ['Dr.', 'Smith', 'did', "n't", 'pay', '$', '19.99', 'for', 'the', 'U.S.A.', 'trip', '...', 'Was', "n't", 'that', 'great', '?', '!', ':', ')', '#', 'nlp', '@', 'ai_lab']

tweet    : ['Dr', '.', 'Smith', "didn't", 'pay', '$', '19.99', 'for', 'the', 'U', '.', 'S', '.', 'A', '.', 'trip', '...', "Wasn't", 'that', 'great', '?', '!', ':)', '#nlp', '@ai_lab']
```



Compare all four token lists carefully:

- **`wordpunct_tokenize`** splits words and punctuation into separate groups. Its result is predictable, but it breaks `didn't` into `didn` + `'` + `t`, and `19.99` into `19` + `.` + `99`.
- **`word_tokenize`** is the lecture's general starting choice. Here it keeps `Dr.`, `U.S.A.` and `19.99` whole. It splits `didn't` into `did` + `n't`, which keeps negation visible. However, it breaks up `:)`.
- **`TweetTokenizer`** is designed for social media. Among these four examples, it is the only one that keeps `:)`, `#nlp` and `@ai_lab` whole. It also breaks `Dr.` and `U.S.A.`.

There is no best tokenizer for every input. Choose one that fits the data and the task.
