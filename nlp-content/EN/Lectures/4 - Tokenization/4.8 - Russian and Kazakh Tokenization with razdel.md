## A Russian tokenizer

The lecture presents `razdel` as a small, fast Russian tokenizer. It also works reasonably on the Kazakh examples here because their punctuation conventions are similar. This is a claim about the lecture's examples, rather than a guarantee for all Kazakh text.



The source installation command prepares `razdel`; no installation is performed during this conversion.

```python
!pip install razdel --quiet
print("done")
```



`sentenize` returns sentence spans and `tokenize` returns token spans; `.text` reads each span’s text. Punctuation remains visible as its own tokens.

```python
from razdel import tokenize as rz_tokenize, sentenize as rz_sentenize

print("RU sentences:", [s.text for s in rz_sentenize(ru)])
print("RU tokens   :", [t.text for t in rz_tokenize(ru)])
print()
print("KK sentences:", [s.text for s in rz_sentenize(kk)])
print("KK tokens   :", [t.text for t in rz_tokenize(kk)])
```


**Saved output:**

```text

RU tokens   : ['Мы', 'купили', 'два', 'новых', 'ноутбука', 'в', 'магазине', '.', 'Они', 'работали', 'отлично', '!']
```

The saved result correctly splits these three Kazakh sentences. This is still only **splitting text**.
