## A search function

A user searches a collection of support tickets. A simple search compares raw word strings, so it misses relevant tickets written with another form of a word.



`naive_search` lowercases and whitespace-splits the query and each ticket. `q & ...` is a set intersection, so any shared token is enough for a hit; it does not require every query word.

```python
tickets = [
    "The battery died after two days",
    "Batteries drain very quickly",
    "My battery is draining fast",
    "Great screen and fast charging",
    "The charger stopped working",
    "Screen cracked when I dropped it",
]

def naive_search(query, docs):
    q = set(query.lower().split())
    return [i for i, d in enumerate(docs) if q & set(d.lower().split())]

hits = naive_search("battery draining", tickets)
print("matched:", hits)
for i in hits:
    print("   ", tickets[i])
```


**Saved output:**

```text
matched: [0, 2]
    The battery died after two days
    My battery is draining fast
```



The simple search returns tickets 0 and 2. Ticket 1, `Batteries drain`, describes the same problem, but `batteries` and `battery` are different strings.



The improved search uses WordNet resources. `normalize` lowercases, tokenizes, removes nonalphabetic tokens and the negation-safe stop words, then adds both noun (`"n"`) and verb (`"v"`) lemmas to a set. `smart_search` still matches on any shared normalized token.

```python
from nltk.stem import WordNetLemmatizer

nltk.download("wordnet", quiet=True)
nltk.download("omw-1.4", quiet=True)

wnl = WordNetLemmatizer()

def normalize(text):
    """Tokenize, drop punctuation and stop words, reduce each word to a base form."""
    out = set()
    for w in word_tokenize(text.lower()):
        if not w.isalpha() or w in stop_safe:
            continue
        out.add(wnl.lemmatize(w, "n"))   # as a noun
        out.add(wnl.lemmatize(w, "v"))   # as a verb
    return out

def smart_search(query, docs):
    q = normalize(query)
    return [i for i, d in enumerate(docs) if q & normalize(d)]

hits = smart_search("battery draining", tickets)
print("matched:", hits)
for i in hits:
    print("   ", tickets[i])
```


**Saved output:**

```text
matched: [0, 1, 2]
    The battery died after two days
    Batteries drain very quickly
    My battery is draining fast
```



The normalized search finds three tickets, including the previously missed `Batteries drain` ticket.

The related words were present from the start, but raw string comparison could not connect them. **Tokenization** chooses the units. **Normalization** chooses which forms count as equal. The lecture connects this process to search engines, duplicate detection and spam filtering.

The code adds both noun and verb lemmas to a set, rather than first deciding the correct part of speech. [[EN/Lectures/5 - Stemming and Lemmatization/5.5 - WordNet Lemmatization and Parts of Speech|The next lecture]] explains why part of speech matters.
