## Check what raw-count features contain

Before changing the weights, inspect what the vectorizer sees. Its tokenization rules have already changed the original text before the search calculation begins.



```python
tokenize = counts_vec.build_analyzer()

print(tokenize("I DON'T like it!!! 10/10 😂 gr8 $89"))
```


**Saved output:**

```text
['don', 'like', 'it', '10', '10', 'gr8', '89']
```



The saved analyzer output shows the defaults clearly. It lowercases the text, removes punctuation and emoji, turns `DON'T` into `don`, and splits `10/10` into two `10` tokens. The `t` from the contraction is only one character long, so the default token rule drops it.

These rules are useful to know, but they also remove information: `!!!` and the laughing emoji carried meaning that the model can no longer use. The next cell counts the resulting tokens across all 120 reviews.

These defaults connect to [[EN/Lectures/6 - Turning Text into Features/6.7 - Token Patterns and Unicode|Token Patterns and Unicode]] and the broader [[EN/Lectures/4 - Tokenization/4.1 - Tokens and Tokenization Decisions|tokenization decisions]].



```python
word_counts = Counter(w for r in reviews for w in tokenize(r))

print(word_counts.most_common(10))
```


**Saved output:**

```text
[('the', 60), ('and', 36), ('it', 34), ('is', 19), ('quality', 16), ('not', 14), ('product', 13), ('this', 13), ('but', 13), ('very', 11)]
```



`the` occurs 60 times. Most words in the top ten are common linking or grammatical words rather than clear sentiment clues; `not` and `quality` are useful exceptions in the notebook's discussion.

Now inspect one review as a count vector to see how these frequent words affect its features.



`transform` uses the fitted corpus vocabulary. `nonzero()` selects features present in this review, and sorting by descending count exposes which word gets the largest raw value.

```python
review = "the item arrived damaged and the quality is terrible"

row = counts_vec.transform([review]).toarray()[0]
names = counts_vec.get_feature_names_out()

present = sorted(((names[i], int(row[i])) for i in row.nonzero()[0]), key=lambda x: -x[1])
print(present)
```


**Saved output:**

```text
[('the', 2), ('and', 1), ('arrived', 1), ('damaged', 1), ('is', 1), ('item', 1), ('quality', 1), ('terrible', 1)]
```



`the` has count 2, making it the largest feature in this review. `damaged` and `terrible` each have count 1, exactly like `and` and `is`, even though they tell a reader much more about the complaint.

Counts answer “how often is this word used here?” Search also needs “how much does this word distinguish this document from the others?” A word used in nearly every document gives little help in choosing a particular document.
