## Exercises

### 1. Compute one TF-IDF row yourself

Use the three-document corpus to calculate the TF-IDF vector for `"the screen is sharp and the battery is great"`. Use only `numpy`: first compute the displayed smoothed `sklearn` IDF, then apply L2 normalisation, without calling `TfidfVectorizer`.

Compare your answer with row 1 of `lib`. `the` and `is` both occur twice in this document. Which gets the larger final weight, and why?

### 2. Break the search and test possible fixes

Use either `search()` on the teaching reviews or `search_amazon()` on the real reviews.

1. Find two new queries where a top-three result has the opposite sentiment. Name the word responsible for each match.
2. Rebuild with `TfidfVectorizer(ngram_range=(1, 2))`. Report what happens to each query, including any that get worse.
3. Rebuild with `analyzer="char_wb", ngram_range=(3, 5)`. Find one query with a clearly better top result than word features, and one with a clearly worse top result.

For every improvement or failure, explain it in one sentence by naming the responsible feature.

### 3. When do character features help, and when do they mislead?

Use the complete list below:

```python
messages = [
    "my order never arrived",
    "my ordr nevr arived",
    "the order arrived on time",
    "the seller was helpful",
    "the seller was unhelpful",
    "the charger is not working",
    "the charger is working fine",
    "i recieved the wrong colour",
]
```

1. Build word-level and `char_wb` (3–5) TF-IDF matrices. Print both full similarity matrices, rounded to two decimals.
2. Find the pair whose similarity increases the most when switching to characters. Does its meaning justify the increase?
3. Find opposite statements that are close under **both** representations. Explain why neither separates them; consider their shared words.
4. For a support search box where customers type quickly and make mistakes, would you use words, character n-grams, or both? Explain which kinds of error your choice accepts.
