## Learn all vocabulary weights and a bias

The same method now uses every TF-IDF feature, with one weight per vocabulary word and a separate bias. Positive labels become 1; negative labels become 0.

The split keeps 25% of the 120 reviews for testing: 90 training reviews and 30 test reviews. `stratify=y` preserves class balance and `random_state=0` keeps the split repeatable. The vectorizer fits only on training text, then transforms test text with that fitted vocabulary.

`w` starts as a zero for each feature, `b` starts at 0, and `step_size=1.0` controls the update size. On each iteration the code:

1. Computes `X_tr @ w + b` and applies sigmoid to get current positive probabilities.
2. Subtracts true labels to get `error`.
3. Updates each weight using the average error multiplied by its feature.
4. Updates the bias using the mean error, since the bias affects every review.
5. Records loss, training accuracy, and test accuracy so their behaviour can be compared.

The code is retained exactly. In particular, `p` is calculated before this iteration's update and is used for the recorded training loss and training accuracy; test accuracy is computed from the updated weights. No cell has been run during conversion.



```python
y = np.array([1 if l == "positive" else 0 for l in review_labels])

tr_txt, te_txt, y_tr, y_te = train_test_split(
    reviews, y, test_size=0.25, random_state=0, stratify=y
)

tfidf = TfidfVectorizer()
X_tr = tfidf.fit_transform(tr_txt).toarray()
X_te = tfidf.transform(te_txt).toarray()

w = np.zeros(X_tr.shape[1])   # one weight per word, all starting at zero
b = 0.0
step_size = 1.0
history = []

for step in range(1, 2001):
    p = sigmoid(X_tr @ w + b)                  # current predictions
    error = p - y_tr                           # how wrong, and in which direction
    w -= step_size * X_tr.T @ error / len(y_tr)
    b -= step_size * error.mean()

    loss = -np.mean(y_tr * np.log(p) + (1 - y_tr) * np.log(1 - p))
    train_acc = ((p > 0.5) == y_tr).mean()
    test_acc = ((sigmoid(X_te @ w + b) > 0.5) == y_te).mean()
    history.append((step, loss, train_acc, test_acc))
    if step in (1, 10, 100, 500, 1000, 2000):
        print(f"step {step:4}  loss {loss:.4f}  train acc {train_acc:.2f}  test acc {test_acc:.2f}")

print()
print("vocabulary:", X_tr.shape[1], "words   test set:", len(y_te), "reviews")
```
