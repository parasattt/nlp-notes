## Ask whether more training data would help

The notebook cites Ng and Jordan (2002) for the pattern that Naive Bayes can reach good performance with less data, while logistic regression can improve further when enough data is available. Here that is a claim introduced by the source, to be examined using learning curves.

A **learning curve** measures test performance at different training sizes. The next code uses 16, 32, 48, 64, 80, and 96 training reviews. At each size it averages across the five folds, then across five shuffles. Comparing the resulting curves shows whether adding data is still helping.



```python
from sklearn.model_selection import learning_curve

sizes = [16, 32, 48, 64, 80, 96]
plt.figure(figsize=(6, 3.2))
for name in ["NB  + counts", "LR  + tf-idf"]:
    curves = []
    for s in range(5):
        _, _, test_scores = learning_curve(
            setups[name], reviews, review_labels, train_sizes=sizes,
            cv=StratifiedKFold(5, shuffle=True, random_state=s),
            shuffle=True, random_state=s,
        )
        curves.append(test_scores.mean(axis=1))
    mean_curve = np.mean(curves, axis=0)
    print(f"{name:14}", "  ".join(f"{n}:{v:.3f}" for n, v in zip(sizes, mean_curve)))
    plt.plot(sizes, mean_curve, "o-", label=name.replace("  ", " "))
plt.xlabel("training reviews"); plt.ylabel("cross-validated accuracy")
plt.title("Learning curve on our 120 reviews")
plt.legend()
plt.tight_layout()
plt.show()
```

The saved LR curve is still rising at 96 training reviews: from 0.522 with 16 reviews to 0.648 with 96. Naive Bayes rises from 0.532 to 0.658 and flattens around 80 reviews.

Increasing training size from 16 to 96 adds roughly twelve percentage points for either model. Changing the model changes the score by only about one or two points. On this evidence, the amount of training data matters much more than choosing between these classifiers.
