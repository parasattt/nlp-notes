## Compare with the library implementation

`LogisticRegression` uses the same model form, with a better optimiser and an added penalty on large weights called regularisation. The next code fits it on the same training matrix, then compares its weights and decisions with the hand-written loop.



```python
sk = LogisticRegression(max_iter=2000)
sk.fit(X_tr, y_tr)

print("correlation between your weights and sklearn's:",
      np.corrcoef(w, sk.coef_[0])[0, 1].round(3))
print("test predictions that agree:",
      ((sigmoid(X_te @ w + b) > 0.5) == sk.predict(X_te)).mean().round(3))
```


**Saved output:**

```text
correlation between your weights and sklearn's: 0.976
test predictions that agree: 0.967
```



The saved weight correlation is `0.976`, and test predictions agree `0.967` of the time. The two implementations have learned nearly the same model. The earlier loop is an implementation of logistic regression, rather than an unrelated simplified rule.
