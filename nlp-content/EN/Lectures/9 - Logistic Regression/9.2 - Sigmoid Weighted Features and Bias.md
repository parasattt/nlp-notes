## Convert a score into a probability

A weighted score can be any real number, such as -7, 0.3, or 42. A probability must be between 0 and 1. The **sigmoid** function maps a score to that range:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

`z` is the score. The exponential `e^{-z}` changes with that score; adding 1 and taking the reciprocal produces a value between 0 and 1. We interpret that output here as the model's probability of the positive class.

The next function calculates the formula directly, then prints probabilities for several scores. The saved curve shows the same relationship.



```python
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

for z in [-6, -2, -1, 0, 1, 2, 6]:
    print(f"score {z:3} -> probability {sigmoid(z):.3f}")
```

z = np.linspace(-8, 8, 200)

## Features, weights, and bias

At score 0, sigmoid returns 0.5: neither class is preferred. Large positive scores approach probability 1, and large negative scores approach 0. Changing a score from 0 to 2 has a large effect (`0.500` to `0.881`); changing an already large positive score, such as 6 to 8, has little effect because the curve is flattening near 1.

The complete model is:

$$P(\text{positive} \mid x) = \sigma(w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b)$$

- $x_i$ is the TF-IDF value of feature `i` in this review.
- $w_i$ is the learned weight for that feature, one per vocabulary word.
- Multiply each feature by its weight, then add the contributions.
- $b$ is the **bias**, an extra value added before sigmoid.
- Finally, apply sigmoid to turn the total score into a positive-class probability.

The bias is the model's starting preference before it reads any words. For an empty feature vector, all word contributions are zero and the score is just $b$. The notebook's example is a shop where 80% of reviews are positive: a sensible starting preference leans positive, so $b > 0$, and negative evidence must pull the score down. This teaching corpus is balanced 50/50, so the source expects $b$ near zero.

Keep this calculation in mind: the next lecture calls this same form **one artificial neuron**.
