### What is a notebook, really?

A normal program is usually a file that runs from start to finish, prints its results, and stops.

A notebook is a **list of cells**. You can run cells one at a time, and their results stay beside the code that produced them. You can also run them out of order, although this can cause problems.

There are two kinds of cells:

- **Code cells** contain Python code and can produce output.
- **Text cells**, written in Markdown, contain notes, explanations, and headings.

This suits text and data analysis because analysis often involves trying an idea, inspecting the result, and trying something else. You do not need to run the whole notebook each time.
