### Files in Colab

The **Colab machine is temporary**. After a period of inactivity, the session can be removed and files stored on that machine can disappear. The notebook file saved in Google Drive remains, but files created by its code need their own saving or downloading step.

Write your notebook so that it can recreate the data it needs from scratch. The next cells demonstrate writing a small text file and then reading it back.



```python
# Write a small text file to the temporary machine.
with open("example.txt", "w", encoding="utf-8") as f:
    f.write("First line of the file.\n")
    f.write("Second line of the file.\n")

print("File written.")
```


**Saved output:**

```text
File written.
```



```python
# Read it back.
with open("example.txt", "r", encoding="utf-8") as f:
    content = f.read()

print(content)
```


**Saved output:**

```text
First line of the file.
Second line of the file.

```

In the writing cell, `"w"` opens the file for writing and each `\n` ends a line. In the reading cell, `"r"` opens it for reading and `read()` returns the whole contents as one string. Both operations specify UTF-8, and `with` closes the file when its block ends. More file-reading examples appear in [[EN/Lectures/1 - Python Basics for Text/1.19 - Reading and Writing Text Files|reading and writing text files]].



```python
# List the files on the machine. You should see example.txt in there.
!ls -la
```

`!ls -la` lists files, including hidden entries, with details. The saved source output is a very large listing from a personal local directory rather than a clean Colab example. Unrelated filenames are intentionally omitted here. The important lesson is to inspect the session's files and find the `example.txt` created above; temporary session files need to be recreated or saved elsewhere.



The **folder icon** in Colab's left sidebar opens the file panel. You can drag files into it to upload them, or right-click a file to download it.
