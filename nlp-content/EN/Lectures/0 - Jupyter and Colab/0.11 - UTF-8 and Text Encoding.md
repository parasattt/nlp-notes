### UTF-8 and text encoding

Always pay attention to `encoding="utf-8"`. An **encoding** tells Python how the bytes saved in a file correspond to characters. This matters for Kazakh, Russian, emoji, accented letters, and other text. Reading or writing with the wrong encoding can damage how the text is represented, so specify it explicitly.

The examples in [[EN/Lectures/0 - Jupyter and Colab/0.10 - Temporary Files in Colab|temporary files]] specify this encoding both when writing and when reading. The same choice matters when [[EN/Lectures/2 - Pandas for Text Data/2.13 - CSV Files and Encoding|loading CSV text]].
