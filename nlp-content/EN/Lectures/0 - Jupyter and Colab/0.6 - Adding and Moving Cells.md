### Adding and moving cells

- Hover between cells to reveal **+ Code** and **+ Text**, then choose the kind of cell to insert.
- Select a cell and use the **trash icon** in its toolbar to delete it.

For these shortcuts, press **Esc** first to leave text editing and enter command mode:

| Keys | Action |
|---|---|
| `Esc` then `a` | insert a cell **above** |
| `Esc` then `b` | insert a cell **below** |
| `Esc` then `d d` | **delete** the cell; press `d` twice |
| `Esc` then `z` | undo cell deletion |
| `Ctrl + M M` | convert the cell to text (Markdown) |
| `Shift + Enter` | run the cell and move to the next one |
| `Ctrl + Enter` | run the cell and stay there |

Practice by inserting a cell below this point and printing your own name.
