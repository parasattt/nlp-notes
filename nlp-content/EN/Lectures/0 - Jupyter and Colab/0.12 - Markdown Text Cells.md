### A word about Markdown: text cells

Double-click a text cell to see its Markdown source. Press **Shift + Enter** to display the formatted version again.

These are the basic forms used in the notebook:

```markdown
# Big heading
## Smaller heading

**bold**   *italic*   `code`

- bullet
- another bullet

1. numbered
2. list
```

Use text cells to explain your reasoning in homework; the explanation is part of the grade. A notebook containing only code is hard to follow, and unexplained analysis is easy to misunderstand.
