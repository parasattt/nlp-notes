### Your turn

Add new cells and complete this small exercise:

1. Create a variable named `my_name` containing your name.
2. Print a sentence that uses it, such as `My name is Aisha and it has 5 letters.` Use `len(my_name)` for the number of letters.
3. Add a **text cell** below the code with one sentence explaining what you did.
4. Use **Runtime → Restart session and run all** and check that the notebook still works from a clean session.

Step 4 is the main exercise: it tests reproducibility. The earlier steps give you something small to test.
