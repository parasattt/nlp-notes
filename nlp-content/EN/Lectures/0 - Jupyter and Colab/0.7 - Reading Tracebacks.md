### When a cell breaks

Errors are a normal part of programming. The notebook asks you to run the next cell deliberately, even though its variable does not exist, so that you can learn to read the error.



```python
print(undefined_variable_that_does_not_exist)
```


**Saved notebook error:**

```text
---------------------------------------------------------------------------
NameError                                 Traceback (most recent call last)
Cell In[9], line 1
----> 1 print(undefined_variable_that_does_not_exist)

NameError: name 'undefined_variable_that_does_not_exist' is not defined
```



The error block is a **traceback**. Start at its bottom line:

```text
NameError: name 'undefined_variable_that_does_not_exist' is not defined
```

This line tells you the actual problem. The lines above it show where Python was when the problem happened. Reading the last line first often gives you the information you need without getting lost in the whole traceback.

Common errors in this course are:

- `NameError`: a variable does not exist, perhaps because of a typo or because its defining cell has not run.
- `TypeError`: an operation received the wrong kind of value, such as `"5" + 5`.
- `SyntaxError`: Python cannot read the code, often because a `)` or `:` is missing.
- `IndexError` or `KeyError`: you requested an item that is not there.
- `ModuleNotFoundError`: the library you tried to import is not installed.
