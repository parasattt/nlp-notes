### The last line is displayed automatically

In a normal Python script, you usually call `print()` to display a value. In a notebook, an expression on the **last line** of a cell is displayed automatically.

This automatic display applies only to the last expression. Use `print()` when you need to show more than one result.



```python
2 + 2 + test
```


**Saved output:**

```text
14
```

The saved result is `14`: the expression uses `test`, whose value was set to 10 in an earlier cell. If that variable were changed before this cell ran, the result could change too.



```python
# But only the LAST line. This cell shows just 20, not 10 and 20.
5 + 5
10 + 10
```


**Saved output:**

```text
20
```

Both expressions are evaluated, but only the final expression's value, `20`, is displayed automatically.



```python
# If you want to see both, print them explicitly.
print(5 + 5)
print(10 + 10)
```


**Saved output:**

```text
10
20
```

There are two explicit calls to `print()`, so both results are displayed: first `10`, then `20`.
