### Cells share memory

Every cell runs in the same Python session. A variable created in one cell can be used in another cell. This is useful, but it also means that the order of execution matters.

The notebook asks you to run the next two cells in order. The first creates `sentence`; the second reads that same variable.



```python
sentence = "Natural language processing is mostly text cleaning."
```



```python
# This cell knows about `sentence` even though we never defined it here.
print(sentence)
test = 20
print("Number of characters:", len(sentence))
```


**Saved output:**

```text
Natural language processing is mostly text cleaning.
Number of characters: 52
```

The second cell reads `sentence` from shared session memory and shows its length, including spaces and punctuation: **52 characters**. It also changes `test` to 20. That change could affect an earlier cell if you run it again.
