### Recap

- A notebook contains cells you run separately, with results shown beside the code.
- **Shift + Enter** runs a cell.
- Cells share memory, so **execution order matters**. Restart and run all to check a clean run.
- The last expression in a cell is displayed automatically.
- Read a traceback from the bottom line upward.
- `?`, `dir()`, `type()`, and Tab completion help answer everyday Python questions.
- `!` runs shell commands, and files on a Colab machine are temporary.
- Use `encoding="utf-8"` when opening text files.
