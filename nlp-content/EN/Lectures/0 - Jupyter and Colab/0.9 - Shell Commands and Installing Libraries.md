### Shell commands and installing libraries

A line beginning with `!` is sent to the machine's **shell** rather than interpreted as Python. The notebook describes the usual Colab machine as a Linux machine.

The first example asks for the Python version. The second shows how to install a library. The notebook says Colab already includes the libraries needed for the course, so an installation may report that the requirement is already satisfied.



```python
!python --version
```



```python
# Colab already has the libraries we need for this course, so this will just say
# "already satisfied". This is how you would install something new.
!pip install pandas --quiet
print("done")
```

`!python --version` requests the environment's Python version. `!pip install pandas --quiet` shows package installation, with `--quiet` reducing routine messages. The final Python line would print `done`. Neither cell has a saved output in the source, so no new result is supplied here.
