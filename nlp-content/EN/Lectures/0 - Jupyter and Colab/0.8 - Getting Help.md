### Getting help without leaving the notebook

The next cells show three useful tools: documentation with `?` or `help()`, available methods with `dir()`, and a value's type with `type()`.



```python
# 1. A question mark shows the documentation for anything.
#    In Colab this opens a help panel at the bottom of the screen.
#    Run it and look down there - the output area here stays empty.
str.upper?
```



```python
# help() does the same thing but prints inline, so it works everywhere.
help(str.upper)
```


**Saved output:**

```text
Help on method_descriptor:

upper(self, /) unbound builtins.str method
    Return a copy of the string converted to uppercase.

```

`str.upper?` is notebook-specific help syntax. `help(str.upper)` prints the documentation inline. The saved description says that `.upper()` returns an uppercase copy of a string.



```python
# 2. dir() lists everything you can do with an object.
#    Ignore the names starting with underscores for now.
text = "hello"
[name for name in dir(text) if not name.startswith("_")]
```

`dir(text)` lists attributes and methods available on the string. The comprehension filters out names starting with `_`, leaving the methods intended for ordinary use. The saved list is preserved so you can inspect examples such as `lower`, `split`, `strip`, and `upper`.



```python
# 3. type() tells you what something is. When confused, always ask this first.
print(type("hello"))
print(type(5))
print(type([1, 2, 3]))
```


**Saved output:**

```text
<class 'str'>
<class 'int'>
<class 'list'>
```

The three values have types `str` (text), `int` (whole number), and `list` (an ordered collection). Checking types is a useful first debugging step. These types are introduced in [[EN/Lectures/1 - Python Basics for Text/1.1 - Variables and Types|variables and types]].



Colab also supports **Tab completion**. Type `text.` and press **Tab** to see available methods. Use this regularly; you do not need to memorize all method names.
