### Running your first cell

Click a code cell once to select it. Then use any of these methods:

- **Shift + Enter** runs the cell and moves to the next one.
- **Ctrl + Enter** runs the cell and keeps it selected.
- The **play button** on the left runs the cell.

The notebook asks you to try this with the following cell.



```python
print("Hello. The notebook is working.")
test = 10
```


**Saved output:**

```text
Hello. The notebook is working.
```

`print()` displays the greeting. `test = 10` also creates a variable that later cells can use, even though this assignment does not display a result.



The first Colab cell may take a few seconds because Colab is starting a machine for your session in a Google data center. Later cells normally start more quickly.

A spinning circle beside a cell means it is still running. A number such as `[1]` means it finished. This is the cell's **execution number**: it records the order in which you ran cells, which may differ from their order on the page.
