# Part 4. Regularisation: a tax on large weights

**Regularisation** means changing the training so that the model prefers simpler solutions. The most
common form adds a second term to the loss:

$$\text{loss} = \underbrace{\text{MSE}}_{\text{fit the data}} + \underbrace{\alpha \sum_j w_j^2}_{\text{keep weights small}}$$

The first term wants to fit every training example. The second is a **penalty** that grows with the
size of every weight - a tax on large weights. $\alpha$ (the Greek letter *alpha*) sets the tax rate.
A weight now only grows large if it lowers the MSE by more than it costs in tax, which happens for
words that matter in **many** reviews (`worst`, `amazing`), not for a word that happens to appear in
one 4-star review.

Linear regression with this penalty is called **Ridge** regression (the penalty on squared weights
is also called **L2 regularisation**). In logistic regression the same penalty is controlled by `C`,
which works the other way round: `C` = 1 / tax rate, so a small `C` means strong regularisation.
That is the `C` from week 5.

Try several tax rates on the same 12 000 reviews:

```python
tfidf = TfidfVectorizer(min_df=2)
T_train = tfidf.fit_transform(y_train_df["text"])
T_test = tfidf.transform(y_test_df["text"])

alphas = [0.01, 0.1, 0.3, 1, 3, 10, 100]
rows = []
for a in alphas:
    r = Ridge(alpha=a).fit(T_train, y_train_df["stars"])
    rows.append((a, mae(r.predict(T_train), y_train_df["stars"]),
                 mae(r.predict(T_test), y_test_df["stars"]), np.abs(r.coef_).mean()))
ridge_table = pd.DataFrame(rows, columns=["alpha", "train MAE", "test MAE", "average |weight|"])
print(ridge_table.round(3).to_string(index=False))
```

plt.figure(figsize=(5.8, 3.4))

Read the plot from left to right:

- **small alpha**: almost no tax. Training error is low, test error high: overfitting, like the
  degree-7 curve.
- **alpha around 1 to 3**: the test error is lowest, about 0.73 - the value notebook 10 used.
- **large alpha**: the tax is so high that all weights shrink toward zero (see the last column of
  the table), the model can barely use the words, and both errors climb back toward the baseline:
  underfitting, like the flat line.

The train and test curves move apart as the tax goes down. That gap, again, is the overfitting.
