About 53% exactly right. Is that bad? The confusion matrix shows **which** mistakes it makes - with
five classes it is a 5 × 5 table, best shown as a picture:

```python
cm = confusion_matrix(y_test_df["stars"], pred)

fig, ax = plt.subplots(figsize=(4.6, 3.9))
ax.imshow(cm, cmap="Blues")
for i in range(5):
    for j in range(5):
        ax.text(j, i, cm[i, j], ha="center", va="center", fontsize=9,
                color="white" if cm[i, j] > cm.max() / 2 else "black")
ax.set_xticks(range(5), [1, 2, 3, 4, 5]); ax.set_yticks(range(5), [1, 2, 3, 4, 5])
ax.set_xlabel("predicted stars"); ax.set_ylabel("true stars")
ax.set_title("Confusion matrix, 3 000 test reviews", fontsize=10)
plt.tight_layout()
plt.show()
```

**Saved figure:**

![[EN/Lectures/11 - Does the Model Work/Assets/11-8-2-0.png]]

Most of the counts sit on the **diagonal** (correct) or right next to it. A 4-star review is often
called 3 or 5, rarely 1. The model mostly confuses **neighbouring** ratings - which people do too:
the difference between a 4-star and a 5-star review is often a matter of the writer's habits, not
the text.

`classification_report` gives precision, recall and F1 for every class:

```python
from sklearn.metrics import classification_report
print(classification_report(y_test_df["stars"], pred, digits=3))
```
