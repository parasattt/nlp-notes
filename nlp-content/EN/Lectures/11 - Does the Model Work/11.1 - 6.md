# Part 1. The perfect memoriser

Here is a "model" for star ratings: store every training review together with its stars. To
predict, look the review up. If it is not in the store, answer the average rating.

```python
class Memoriser:
    def fit(self, texts, stars):
        self.store = dict(zip(texts, stars))
        self.avg = np.mean(stars)
        return self
    def predict(self, texts):
        return np.array([self.store.get(t, self.avg) for t in texts])

memo = Memoriser().fit(y_train_df["text"], y_train_df["stars"])
print("MAE on the training reviews:", round(mae(memo.predict(y_train_df["text"]), y_train_df["stars"]), 3))
print("MAE on the test reviews    :", round(mae(memo.predict(y_test_df["text"]), y_test_df["stars"]), 3))
```

**Saved output:**

```text
MAE on the training reviews: 0.0
MAE on the test reviews    : 1.173
```

Zero error on the training data: a perfect score. On the test reviews it is 1.173 - exactly the
baseline from notebook 10, because every test review is new and it falls back to the average.

The training score said nothing about how useful the model is. What we actually want is
**generalisation**: good predictions on new examples from the same kind of data. The only way to
measure it is on examples the model did not train on:

- **training set**: the examples used to fit the parameters
- **test set**: examples kept aside, used only to measure the final model

A real model is never this extreme, but every model memorises a little. The rest of this notebook is
about how much, and what to do about it.
