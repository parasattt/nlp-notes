### Letter bigrams by hand

Add a start and end marker and count adjacent pairs. The next-letter probability is the pair count divided by the count for the current letter. A bigram only remembers one letter and may copy names, stop early or repeat.

```python
toy = ["dana", "dias", "aida", "asan", "sana", "nadia"]
```

```python
pairs = defaultdict(Counter)
for name in toy:
    s = "." + name + "."
    for cur, nxt in zip(s, s[1:]):
        pairs[cur][nxt] += 1

table = pd.DataFrame(pairs).T.fillna(0).astype(int)
table = table.loc[[".", "a", "d", "i", "n", "s"], [".", "a", "d", "i", "n", "s"]]
table["total"] = table.sum(axis=1)
table
```

```python
def generate_bigram(pairs, rng):
    name, cur = "", "."
    while True:
        options = pairs[cur]
        cur = rng.choices(list(options), weights=list(options.values()))[0]
        if cur == ".":
            return name
        name += cur

rng = random.Random(1)
print([generate_bigram(pairs, rng) for _ in range(12)])
```
