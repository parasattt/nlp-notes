## The cost of extra phrase features

This extra phrase information increases the vocabulary, as the following example shows.



Keep the same four reviews while increasing the maximum n-gram length from one to three. Only the representation changes.

```python
reviews = [
    "the battery life is not good at all",
    "battery life is good and the screen is bright",
    "not worth the money the screen cracked",
    "worth the money and the battery lasts",
]

for rng in [(1, 1), (1, 2), (1, 3)]:
    v = CountVectorizer(ngram_range=rng)
    v.fit(reviews)
    print(f"ngram_range={rng}: {len(v.get_feature_names_out()):3} features")
```


**Saved output:**

```text
ngram_range=(1, 1):  15 features
ngram_range=(1, 2):  35 features
ngram_range=(1, 3):  56 features
```



On just four short reviews, the saved feature counts grow from **15** unigrams to **35** unigrams plus bigrams, then **56** when trigrams are included. The lecture notes that a real vocabulary of 50,000 words can grow to millions of phrase features.

Many phrases occur only once, so they add columns without recurring evidence. A common compromise is to include bigrams and apply a `min_df` threshold to remove the least frequent phrases.



Combine unigrams and bigrams with a two-document frequency floor. Check the complete surviving feature list rather than only its size.

```python
combo = CountVectorizer(ngram_range=(1, 2), min_df=2)
combo.fit(reviews)

print(len(combo.get_feature_names_out()), "features")
print(combo.get_feature_names_out())
```


**Saved output:**

```text
17 features
['and' 'and the' 'battery' 'battery life' 'good' 'is' 'life' 'life is'
 'money' 'not' 'screen' 'the' 'the battery' 'the money' 'the screen'
 'worth' 'worth the']
```



The combined settings leave **17** features. `not good` does not survive: it appears in only one of these four reviews, so [[EN/Lectures/6 - Turning Text into Features/6.9 - Document Frequency Filtering|the `min_df=2` filter]] removes it.

The lecture explains that on a much larger corpus, using bigrams with a frequency floor can control memory while keeping negation phrases that recur. This small example shows that the same threshold can also remove a phrase you wanted.
