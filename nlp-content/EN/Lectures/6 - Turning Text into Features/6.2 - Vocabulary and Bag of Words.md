## Build bag of words by hand

The idea is simple: **make one column for every vocabulary word and count its occurrences**.

First collect every distinct word from all the messages. This collection is the **vocabulary**. Give its words a fixed order. The particular order is arbitrary, but position 7 must always refer to the same word.



Whitespace splitting creates one token list per message. A set gathers unique strings and sorting fixes a shared vocabulary order.

```python
tokenised = [m.split() for m in messages]

vocabulary = sorted({w for msg in tokenised for w in msg})

print("vocabulary size:", len(vocabulary))
print(vocabulary)
```


**Saved output:**

```text
vocabulary size: 23
['a', 'before', 'can', 'claim', 'click', 'free', 'here', 'iphone', 'me', 'meeting', 'money', 'moved', 'now', 'prize', 'report', 'send', 'the', 'three', 'to', 'tomorrow', 'win', 'you', 'your']
```



The dictionary assigns every word a column. For each document, the function creates a vector of zeros with the full vocabulary length and increments the position of each known word.

```python
word_to_index = {w: i for i, w in enumerate(vocabulary)}

def to_vector(tokens, vocab, index):
    vec = [0] * len(vocab)
    for w in tokens:
        if w in index:
            vec[index[w]] += 1
    return vec

vectors = [to_vector(t, vocabulary, word_to_index) for t in tokenised]
print(vectors)
print()

for v, m in zip(vectors, messages):
    print(v, " <-", m)
```

Each message is now a row of numbers. Each column refers to one vocabulary word, and its value counts how many times that word appears in the message.

`word_to_index` stores the fixed column for each word. `to_vector` starts with zeros and adds 1 to the matching column for every known token. The next cell puts the vectors into a table for easier inspection.



The DataFrame names each count column after its vocabulary word and each row after its message. `LABEL` is added separately for comparison; it is not one of the original 23 word features.

```python
bow = pd.DataFrame(vectors, columns=vocabulary, index=[f"msg{i}" for i in range(len(messages))])
```

Compare the `free` column with `LABEL`: both spam messages have a count of 1, while both ham messages have 0. A model can use this numerical pattern. The displayed DataFrame uses the vocabulary as its columns and adds the labels beside them, using the [[EN/Lectures/2 - Pandas for Text Data/2.3 - DataFrames and Series|Pandas table operations]] introduced earlier.

This representation is called **bag of words**. Like shaking words in a bag, it keeps their counts but loses their order. The lecture returns to this limitation later.
