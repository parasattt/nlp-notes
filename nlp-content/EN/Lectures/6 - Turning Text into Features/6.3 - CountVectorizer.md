## CountVectorizer

`scikit-learn` provides `CountVectorizer` to build count vectors. The hand-built example explains what it does, so the library call is easier to inspect.



`fit_transform` learns the vocabulary from `messages` and builds their sparse count matrix. `get_feature_names_out()` reveals the words assigned to its 22 columns.

```python
from sklearn.feature_extraction.text import CountVectorizer

vec = CountVectorizer()
X = vec.fit_transform(messages)

print("shape:", X.shape, " (rows = messages, columns = vocabulary)")
print()
print(vec.get_feature_names_out())
print()
print(X.shape[0])
print(X.shape[1])
```

The hand-built vocabulary has **23** words; `CountVectorizer` produces **22**. Compare the lists and try to identify the missing word before continuing.

The missing word is `a`. The default token pattern drops it without a warning. The later [[EN/Lectures/6 - Turning Text into Features/6.7 - Token Patterns and Unicode|token-pattern example]] explains why. Counting and inspecting the vocabulary reveals a library choice that removed information.
