This saved experiment compares `token_pattern=r"\w+"`, the default token pattern and default tokens with `min_df=2` on five Kazakh sentences. It prints their dense arrays, but does not print vocabulary names or sizes and does not try the ASCII-only pattern requested by the later exercise. It is preserved as partial experimental work.

```python
kk_corpus = [
    "мен бүгін кітап оқыдым",
    "ол кеше мектепке барды",
    "біз дүкеннен нан алдық",
    "сен кітапханада кітап оқыдың",
    "олар үйде фильм көрді",
]

t1 = CountVectorizer(token_pattern = r"\w+")
t2 = CountVectorizer()
t3 = CountVectorizer(min_df=2)

x1 = t1.fit_transform(kk_corpus)
x2 = t2.fit_transform(kk_corpus)
x3 = t3.fit_transform(kk_corpus)

print(x1.toarray())
print()
print(x2.toarray())
print()
print(x3.toarray())
```
