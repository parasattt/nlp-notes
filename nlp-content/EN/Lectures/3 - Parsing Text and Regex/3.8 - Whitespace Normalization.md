## Normalize whitespace

### Use a plain-string method when it is enough

Splitting on whitespace and joining with single spaces collapses repeated spaces, tabs, and newlines.



```python
messy = "Too    many\t\tspaces\n\nand  newlines   here"

# The trick: split on any whitespace, then join with single spaces
print(" ".join(messy.split()))
```


**Saved output:**

```text
Too many spaces and newlines here
```

The plain-string alternative uses [[EN/Lectures/1 - Python Basics for Text/1.9 - Splitting and Joining Text|split and join]].



Python's plain split/join method already handles the first problem clearly. Use regex when a more specific rule is needed. The next example collapses spaces and tabs while preserving paragraph breaks.



```python
# "Collapse repeated spaces but keep paragraph breaks" - not expressible with split()
text = "Line one   has    spaces.\n\nLine two   also.\n\n\n\nLine three."

step1 = re.sub(r"[ \t]+", " ", text)        # collapse spaces and tabs only
step2 = re.sub(r"\n{3,}", "\n\n", step1)    # 3+ newlines become exactly 2
print(step2)
```


**Saved output:**

```text
Line one has spaces.

Line two also.

Line three.
```
