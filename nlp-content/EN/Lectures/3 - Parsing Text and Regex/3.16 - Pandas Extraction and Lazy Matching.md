## Extract directly from a pandas column

Pandas provides regex-based `.str.extract`, so the field-extraction loop is often unnecessary. Named groups become output column names.

The column-wise string interface was introduced in [[EN/Lectures/2 - Pandas for Text Data/2.7 - Filtering Text and Categories|pandas string operations]].



```python
s = pd.Series([
    "Order #10234 shipped on 2026-03-15",
    "Order #10235 delayed until 2026-04-01",
    "Order #10236 delivered 2026-03-20",
])

s.str.extract(r"#(?P<order>\d+).*?(?P<date>\d{4}-\d{2}-\d{2})")
```


**Saved output:**

```text
   order        date
0  10234  2026-03-15
1  10235  2026-04-01
2  10236  2026-03-20
```



`.*?` is **lazy**: it matches as little as possible while still allowing the full pattern to match. The greedy `.*` first tries to extend as far as possible, then backtracks.

When extracting between repeated markers, the lazy form can keep separate items separate. The next HTML example shows the difference.



```python
# Greedy vs lazy, side by side
html = "<b>first</b> and <b>second</b>"
print(re.findall(r"<b>.*</b>", html))    # greedy: one huge match
print(re.findall(r"<b>.*?</b>", html))   # lazy: two correct matches
```


**Saved output:**

```text
['<b>first</b> and <b>second</b>']
['<b>first</b>', '<b>second</b>']
```
