## Remove HTML tags from a text field

Web text can contain markup such as `<p>`. Those tags should not become words in a frequency count.

### First, a manual method

The following function tracks whether the current character is inside a tag.



```python
html = "<p>The <b>best</b> phone I have <i>ever</i> owned!</p><br/><a href='#'>Read more</a>"

def strip_tags_manual(s):
    out = []
    inside = False
    for ch in s:
        if ch == "<":
            inside = True
        elif ch == ">":
            inside = False
        else:
            if not inside:
                out.append(ch)
    return "".join(out)

print(strip_tags_manual(html))
```


**Saved output:**

```text
The best phone I have ever owned!Read more
```



The manual method needs a loop and an `inside` state variable. To know whether it handles a tag such as `<a href="a>b">`, a reader must inspect its logic.

### The regex version

The next example expresses the same simple stripping rule as a pattern.



```python
print(re.sub(r"<[^>]+>", "", html))
```


**Saved output:**

```text
The best phone I have ever owned!Read more
```



The pattern `<[^>]+>` means: an opening `<`, one or more characters other than `>`, then a closing `>`. Replacing matches with an empty string removes those simple tags.

The lecture also gives a limit: serious HTML work needs an HTML parser such as BeautifulSoup. A tag-stripping pattern does not understand nesting. Keep that limit in mind even when the short pattern is convenient for a text field.
