## Choose the matching function

| Function | What it returns or does |
|---|---|
| `re.findall(pattern, text)` | Lists all matches. |
| `re.search(pattern, text)` | Finds the first match, or returns `None`. |
| `re.match(pattern, text)` | Checks for a match at the **start** of the string. |
| `re.sub(pattern, repl, text)` | Replaces matching text. |
| `re.split(pattern, text)` | Splits text at the matching separators. |

The phone example below also shows `group()` for the matched text and `start()`/`end()` for its positions.



```python
text = "Call 555-1234 or 555-5678 today"

print(re.findall(r"\d{3}-\d{4}", text))

m = re.search(r"\d{3}-\d{4}", text)
print(m.group())     # the matched text
print(m.start(), m.end())   # where it was found

print(re.sub(r"\d{3}-\d{4}", "[PHONE]", text))
```


**Saved output:**

```text
['555-1234', '555-5678']
555-1234
5 13
Call [PHONE] or [PHONE] today
```



### Use raw strings for patterns

In `r"..."`, Python leaves backslashes available for the regex engine. Without the `r`, Python reads `\b` as a backspace character before regex receives it.

The next saved comparison uses the same apparent boundary pattern with and without the raw-string prefix.



```python
print(re.findall("\bcat\b", "the cat sat"))    # no r prefix -> broken, finds nothing
print(re.findall(r"\bcat\b", "the cat sat"))   # with r -> works
```


**Saved output:**

```text
[]
['cat']
```
