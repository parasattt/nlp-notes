## Recap

- Ordinary string methods handle clean text; real text often needs more precise rules.
- Regex describes **the shape to match**, instead of only listing characters to remove.
- Character choices include `\w \d \s .`; repetition uses `+ * ? {n,m}`; positions use `^ $ \b`; captures use `( )`; alternatives use `|`.
- The main operations are `findall`, `search`, `sub`, `split`, and `compile`. Use raw strings, `r"..."`, for patterns.
- Word boundaries prevent a keyword from matching inside a longer word.
- Apply specific cleaning rules before general ones.
- Extract raw-text signals before normalization removes them.
- Named captures and `.str.extract` turn text into structured columns.
- Use parsers for nested structures and established tools for production sentence splitting.

These examples cover tokenization, normalization, feature extraction, and information extraction—the preparation needed by the later course methods.
