```python
# Remove stop words - the frequent words that carry little meaning
stop_words = {
    "the", "a", "an", "is", "was", "are", "were", "in", "on", "at", "to", "for",
    "of", "and", "but", "or", "it", "this", "that", "i", "you", "me", "my",
    "be", "not", "no", "so", "too", "very", "num", "url", "email", "phone", "date",
}

df["tokens_nostop"] = df["tokens"].apply(
    lambda toks: [t for t in toks if t not in stop_words and len(t) > 2]
)

all_content = [tok for row in df["tokens_nostop"] for tok in row]
Counter(all_content).most_common(15)
```

Before stop-word removal, grammar words dominate the count list. After removal, the list says more about the topic.

There is a cost: this stop list removes `not`, so `not great` and `great` become indistinguishable. That may be acceptable for some topic tasks but can ruin sentiment information.

No single stop list is right for every task. Choose one based on the information the task needs rather than accepting a default without checking it.

The positive/negative collision and a protected-negation list are developed in [[EN/Lectures/4 - Tokenization/4.6 - Preserving Negation|the stop-word negation trap]].
