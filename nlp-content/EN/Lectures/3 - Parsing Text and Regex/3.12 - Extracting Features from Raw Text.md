```python
# Extra features, extracted with regex before we lowercase away the evidence
df["n_exclaim"] = df["raw"].str.count(r"!")
df["n_caps_words"] = df["raw"].apply(lambda t: len(re.findall(r"\b[A-Z]{2,}\b", t)))
df["has_url"] = df["raw"].str.contains(r"https?://", regex=True)
df["n_digits"] = df["raw"].str.count(r"\d")

df[["raw", "n_exclaim", "n_caps_words", "has_url", "n_digits"]]
```

`\b[A-Z]{2,}\b` finds whole words made entirely of at least two ASCII capital letters. Together with exclamation counts, these are inexpensive candidate features for spam or sentiment models.

Calculate such features from `raw` before lowercasing removes the evidence. Once a signal is normalized away, later steps cannot recover it. Extract the features first or keep the original column. ^raw-features-first
