## Debug a pattern in small steps

1. **Build it gradually:** check `\d+`, then `\d+-`, then the rest. A long pattern written at once is harder to debug.
2. **Use the smallest input that still fails.**
3. **Inspect matches with [regex101](https://regex101.com)**, using the Python flavor. The source recommends its pattern explanations and live highlighting.
4. **Print the actual match**, rather than assuming what matched.
5. **Check the raw-string prefix.** A missing `r` can change backslashes before regex sees them.

The next code demonstrates case-insensitive matching, per-line anchors, and a commented pattern written with `re.VERBOSE`.



```python
# Useful flags
text = "Hello WORLD hello world"

print(re.findall(r"hello", text, re.IGNORECASE))

multi = "line one\nline two\nline three"
print(re.findall(r"^line \w+$", multi, re.MULTILINE))   # ^ and $ per line

# re.VERBOSE lets you write a readable, commented pattern
phone_re = re.compile(r"""
    \+?          # optional plus
    \d{1,3}      # country code
    [\s\-]?      # separator
    \(?\d{3}\)?  # area code, maybe in brackets
    [\s\-]?
    \d{3}
    [\s\-]?
    \d{2}
    [\s\-]?
    \d{2}
""", re.VERBOSE)

print(phone_re.findall("Call +7 701 555 01 99 now"))
```


**Saved output:**

```text
['Hello', 'hello']
['line one', 'line two', 'line three']
['+7 701 555 01 99']
```



`re.compile()` prepares a pattern once so the resulting pattern object can be reused without parsing the pattern again for every row. The lecture recommends it when the same pattern is applied to many rows. The verbose phone example also shows how whitespace and comments can make a long pattern easier to read.
