## Describe the tokens you want

A **regular expression** is a small pattern language for text. Instead of maintaining a list of characters to remove, write a pattern describing the text you want to keep.



```python
print(re.findall(r"[a-zA-Z]+", real))
```


**Saved output:**

```text
['Dr', 'Smith', 'said', 'NLP', 'is', 'hard', 'isn', 't', 'it', 'he', 'wasn', 't', 'wrong']
```



Read `[a-zA-Z]+` as “one or more letters from a–z or A–Z.” `findall` returns each non-overlapping sequence that matches.

This replaces the hand-maintained punctuation list with one definition of a token. Punctuation is excluded even when the program has not seen that particular punctuation before.



```python
print(re.findall(r"[a-zA-Z]+", tricky))
```


**Saved output:**

```text
['Email', 'me', 'at', 'ivan', 'mail', 'kz', 'or', 'call', 'Cost', 'off']
```



The new tokenizer is not automatically right for every task. It splits `ivan@mail.kz` into `ivan`, `mail`, and `kz`, and removes the numbers.

The useful change is that the policy is now written in one pattern. To change that policy, edit the pattern instead of extending a stripping function.



```python
# Include numbers and apostrophes: words like "isn't" and "19.99" survive
print(re.findall(r"[a-zA-Z0-9']+", tricky))
```


**Saved output:**

```text
['Email', 'me', 'at', 'ivan', 'mail', 'kz', 'or', 'call', '7', '701', '555', '0199', 'Cost', '19', '99', '30', 'off']
```

> [!note] Source comment and saved output
> The original comment says that `19.99` survives this pattern. The saved result instead contains separate `19` and `99` tokens: the character class does not include a decimal point. The original code, comment, and saved output are retained unchanged.
