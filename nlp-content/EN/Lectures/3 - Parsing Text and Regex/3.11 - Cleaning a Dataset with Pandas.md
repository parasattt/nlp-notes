## Apply the rules to a whole dataset

The next example combines the earlier techniques with pandas. Start with eight raw posts, keep them in a DataFrame, and apply one cleaning function to each text value.

raw_posts = [
    "<p>LOVE this phone!!! Best purchase EVER. https://shop.kz/p/123</p>",
    "Terrible. Broke in 2 days. Contact me at angry@mail.com for details.",
    "Decent laptop for 250000 KZT. Delivered 2026-02-14, no problems.",

```python
def clean_text(text):
    """Normalise a raw social/review post into model-ready text."""
    t = text
    t = re.sub(r"<[^>]+>", " ", t)              # strip HTML tags
    t = re.sub(r"https?://\S+", " <URL> ", t)   # URLs
    t = re.sub(r"\S+@\S+\.\S+", " <EMAIL> ", t)  # emails
    t = re.sub(r"\d{4}-\d{2}-\d{2}", " <DATE> ", t)          # ISO dates (before phones!)
    t = re.sub(r"\+?\d[\d\s\-()]{7,}\d", " <PHONE> ", t)  # phone numbers
    t = re.sub(r"\d+", " <NUM> ", t)            # any remaining numbers, last of all
    t = re.sub(r"\s+", " ", t)                  # collapse whitespace
    return t.strip().lower()


df["clean"] = df["raw"].apply(clean_text)
df[["raw", "clean"]]
```

The function puts date masking before phone masking and leaves the catch-all `\d+` rule until the end. If the number rule runs first, it changes the digits inside dates, phones, and prices before their specific patterns can recognize them.
