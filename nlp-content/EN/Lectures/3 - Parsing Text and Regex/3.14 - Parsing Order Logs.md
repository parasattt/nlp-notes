## Extract structured information from prose

Cleaning changes text into a more consistent form. **Extraction** pulls particular fields out of it. The lecture connects this to rule-based information extraction and named entity recognition.

### Parse an order log

The example log contains order records and an ERROR line. Compare a manual parser with regex captures.



```python
log = """
[2026-03-15 09:14:22] ORDER #10234 user=aisha@mail.kz total=125000KZT status=shipped
[2026-03-15 10:02:05] ORDER #10235 user=bolat@shop.com total=87500KZT status=pending
[2026-03-16 11:47:31] ERROR payment gateway timeout for ORDER #10235
[2026-03-16 12:00:00] ORDER #10236 user=dana@mail.kz total=340000KZT status=shipped
[2026-03-17 08:30:59] ORDER #10237 user=erlan@mail.kz total=15000KZT status=cancelled
""".strip()

print(log)
```


**Saved output:**

```text

[2026-03-15 10:02:05] ORDER #10235 user=bolat@shop.com total=87500KZT status=pending
```

### Parse the fields manually



```python
def parse_manual(line):
    if "ORDER #" not in line or "user=" not in line:
        return None
    # Find the order number
    start = line.index("ORDER #") + len("ORDER #")
    end = start
    while end < len(line) and line[end].isdigit():
        end += 1
    order_id = line[start:end]
    # Find the user
    ustart = line.index("user=") + len("user=")
    uend = line.index(" ", ustart)
    user = line[ustart:uend]
    # Find the total
    tstart = line.index("total=") + len("total=")
    tend = line.index("KZT", tstart)
    total = line[tstart:tend]
    return order_id, user, total


for line in log.splitlines():
    print(parse_manual(line))
```


**Saved output:**

```text
('10234', 'aisha@mail.kz', '125000')
('10235', 'bolat@shop.com', '87500')
None
('10236', 'dana@mail.kz', '340000')
('10237', 'erlan@mail.kz', '15000')
```



The manual parser works for this log, but it uses many index calculations. Missing fields or a different field order can break it, and its expected format is hard to see at a glance.

### Capture the fields with regex



```python
pattern = r"\[(\S+ \S+)\] ORDER #(\d+) user=(\S+) total=(\d+)KZT status=(\w+)"

for line in log.splitlines():
    m = re.search(pattern, line)
    if m:
        print(m.groups())
```
