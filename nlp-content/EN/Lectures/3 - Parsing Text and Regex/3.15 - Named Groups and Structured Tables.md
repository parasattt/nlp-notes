The regex pattern also describes the expected record format. A reader who understands the pattern can see which fields a valid line must contain.

### Give capture groups names

Numbered groups become difficult to track as the field count grows. Use `(?P<name>...)` to name each capture.



```python
pattern = (
    r"\[(?P<timestamp>[^\]]+)\] "
    r"ORDER #(?P<order_id>\d+) "
    r"user=(?P<user>\S+) "
    r"total=(?P<total>\d+)KZT "
    r"status=(?P<status>\w+)"
)

rows = []
for line in log.splitlines():
    m = re.search(pattern, line)
    if m:
        rows.append(m.groupdict())

orders = pd.DataFrame(rows)
orders
```


**Saved output:**

```text
             timestamp order_id            user   total     status
0  2026-03-15 09:14:22    10234   aisha@mail.kz  125000    shipped
1  2026-03-15 10:02:05    10235  bolat@shop.com   87500    pending
2  2026-03-16 12:00:00    10236    dana@mail.kz  340000    shipped
3  2026-03-17 08:30:59    10237   erlan@mail.kz   15000  cancelled
```



The result is a DataFrame built from the log's fields. `groupdict()` supplies named values for each matching record.

The pattern is written as adjacent string literals across several lines. Python joins them, so the pattern can stay readable without becoming one long line.

For the resulting table structure, see [[EN/Lectures/2 - Pandas for Text Data/2.3 - DataFrames and Series|DataFrames and Series]].
