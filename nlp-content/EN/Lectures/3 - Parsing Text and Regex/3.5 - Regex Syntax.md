## Learn regex syntax in groups

The next examples introduce what a pattern can match, how often it can repeat, and where a match can occur. Learn the pieces gradually rather than trying to memorize a whole table at once.

### Character classes: which characters?



```python
sample = "In 2026, 15 students passed. 3 did not."

print(re.findall(r"[0-9]", sample))   # single digits
print(re.findall(r"[0-9]+", sample))  # runs of digits
print(re.findall(r"\d+", sample))     # \d is shorthand for [0-9]
```


**Saved output:**

```text
['2', '0', '2', '6', '1', '5', '3']
['2026', '15', '3']
['2026', '15', '3']
```



| Pattern | Meaning |
|---|---|
| `\d` | A digit. |
| `\D` | A character that is not a digit. |
| `\w` | A Unicode word character: letters, digits, or underscore. |
| `\W` | A character that is not a word character. |
| `\s` | Whitespace, such as a space, tab, or newline. |
| `\S` | A non-whitespace character. |
| `.` | Any character except a newline, with the default settings. |
| `[abc]` | One of `a`, `b`, or `c`. |
| `[^abc]` | Any character except `a`, `b`, or `c`. |
| `[a-z]` | A lowercase letter in that range. |



```python
messy = "word1 \t word2\n\n   word3"
print(repr(messy))
print(re.findall(r"\S+", messy))       # runs of non-whitespace
print(re.split(r"\s+", messy.strip())) # split on any run of whitespace
```


**Saved output:**

```text
'word1 \t word2\n\n   word3'
['word1', 'word2', 'word3']
['word1', 'word2', 'word3']
```



For ordinary whitespace, `messy.split()` can do the job too. Regex becomes useful when the separator is more specific—for example, a comma with optional spaces, a semicolon, or one of several possible separators.



### Quantifiers: how many repetitions?

| Pattern | Meaning |
|---|---|
| `+` | One or more. |
| `*` | Zero or more. |
| `?` | Zero or one; the preceding item is optional. |
| `{3}` | Exactly three. |
| `{2,4}` | Between two and four. |
| `{2,}` | Two or more. |



```python
print(re.findall(r"colou?r", "color and colour are both correct"))
print(re.findall(r"\d{4}", "Years: 2024, 2025, 2026 and 12345"))
print(re.findall(r"a+", "a aa aaa b"))
```


**Saved output:**

```text
['color', 'colour']
['2024', '2025', '2026', '1234']
['a', 'aa', 'aaa']
```



### Anchors: where can the match occur?

| Pattern | Meaning |
|---|---|
| `^` | Start of the string. |
| `$` | End of the string. |
| `\b` | A word boundary. |



```python
lines = ["ERROR: disk full", "INFO: started", "ERROR: timeout"]
for line in lines:
    if re.match(r"^ERROR: disk", line):     # match() checks from the start
        print(line)
```


**Saved output:**

```text
ERROR: disk full
```



A **word boundary**, `\b`, prevents a keyword match from continuing inside a longer word. The next example shows why this matters.



```python
text = "The cat sat on a catastrophic catalogue in Cathmandu"

print(re.findall(r"cat", text))         # matches inside other words too
print(re.findall(r"\bcat\b", text))     # only the standalone word
```


**Saved output:**

```text
['cat', 'cat', 'cat']
['cat']
```



The earlier pandas review search used `.str.contains("battery")`. A plain search for `cat` can also find pieces of words such as *catalogue*, *catastrophe*, and *category*.

This kind of error often produces believable but incorrect counts rather than an exception. Surrounding the keyword with `\b` requires it to stand at word boundaries.

### Groups and alternatives

Parentheses `( )` capture a part of a match. The vertical bar `|` means “or.” The date example captures year, month, and day separately; the next example chooses among animal names.



```python
dates = "Deadlines: 2026-03-15, 2026-04-01 and 2026-12-31"

# Capture year, month, day separately
for match in re.findall(r"(\d{4})-(\d{2})-(\d{2})", dates):
    print(match)
    year, month, day = match
    print(f"day {day}, month {month}, year {year}")
```


**Saved output:**

```text
('2026', '03', '15')
day 15, month 03, year 2026
('2026', '04', '01')
day 01, month 04, year 2026
('2026', '12', '31')
day 31, month 12, year 2026
```



```python
print(re.findall(r"\b(cat|dog|bird)\b", "I have a cat, a dog and three birds"))
```


**Saved output:**

```text
['cat', 'dog']
```



`birds` does not match the `bird` alternative because the following `s` is still a word character. The required boundary is missing.

Regex follows the specified pattern exactly. That makes precise patterns useful, but also means a nearly correct rule can miss a case you intended to include.
