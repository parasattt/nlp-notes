POS tagging labels each token in its sentence context. The saved tag sequence is the input for the next two cells.

```python

sentence = "The striped bats were hanging on their feet and eating better mice"

tagged = nltk.pos_tag(word_tokenize(sentence))
print(tagged)
```


**Saved output:**

```text
[('The', 'DT'), ('striped', 'JJ'), ('bats', 'NNS'), ('were', 'VBD'), ('hanging', 'VBG'), ('on', 'IN'), ('their', 'PRP$'), ('feet', 'NNS'), ('and', 'CC'), ('eating', 'VBG'), ('better', 'JJR'), ('mice', 'NN')]
```



The helper maps NLTK tag prefixes to WordNet’s expected POS constants. Tags outside the adjective, verb and adverb branches fall back to nouns.

```python
from nltk.corpus import wordnet

def wordnet_pos(nltk_tag):
    """Translate an nltk POS tag into the single letter WordNet wants."""
    if nltk_tag.startswith("J"):
        return wordnet.ADJ
    if nltk_tag.startswith("V"):
        return wordnet.VERB
    if nltk_tag.startswith("R"):
        return wordnet.ADV
    return wordnet.NOUN          # the default, and the most common case
```



For every token, compare noun-only lemmatization with POS-aware lemmatization. The added arrow marks where their strings differ.

```python
print(f"{'word':12}{'tag':6}{'naive':12}{'with POS':12}")
print("-" * 40)
for word, tag in tagged:
    naive = wnl.lemmatize(word.lower())
    smart = wnl.lemmatize(word.lower(), wordnet_pos(tag))
    flag = "  <--" if naive != smart else ""
    print(f"{word:12}{tag:6}{naive:12}{smart:12}{flag}")
```

```text
bats        NNS   bat         bat

```



Supplying POS changes four results in the saved table: `were -> be`, `hanging -> hang`, `eating -> eat` and `better -> good`. The arrows mark those differences.

`wordnet_pos` translates NLTK tags beginning with `J`, `V` or `R` to WordNet adjective, verb or adverb labels. Other tags use the noun default. The example shows why noun-only lemmatization misses important changes.
