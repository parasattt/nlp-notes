## A Kazakh suffix stripper

The lecture explains that suffix spellings depend on **vowel harmony** and whether the preceding consonant is voiced. For example, plural variants include `-лар`, `-тар` and `-дер`.

The code lists variants, tests the longest suffixes first and avoids leaving a stem shorter than three characters. It repeats removal until no listed suffix can be removed.



Preserve the entire suffix inventory below. The comments group stacked possessive-plus-case, possessive, plural-plus-accusative, plural, genitive, case and third-person possessive forms. Sorting by decreasing length gives the longest candidate first. The loop removes one permitted suffix, restarts the search and stops once no rule applies; `min_stem=3` guards the remaining length.

```python
KK_SUFFIXES = [
    # possessive + case, stacked (longest first)
    "ларымызда", "лерімізде", "тарымызда", "терімізде", "дарымызда", "дерімізде",
    # possessive
    "ларым", "лерім", "тарым", "терім", "дарым", "дерім",
    # plural + accusative
    "ларды", "лерді", "тарды", "терді", "дарды", "дерді",
    # plural
    "лар", "лер", "тар", "тер", "дар", "дер",
    # genitive
    "ның", "нің", "дың", "дің", "тың", "тің",
    # locative / ablative / dative / accusative
    "нан", "нен", "дан", "ден", "тан", "тен",
    "да", "де", "та", "те", "ға", "ге", "қа", "ке",
    "ды", "ді", "ты", "ті", "ны", "ні",
    # possessive (3rd person)
    "сы", "сі", "ы", "і",
]

KK_SUFFIXES = sorted(set(KK_SUFFIXES), key=len, reverse=True)


def kk_stem(word, min_stem=3):
    """Strip Kazakh suffixes, longest first. Repeats until nothing more comes off."""
    changed = True
    while changed:
        changed = False
        for suf in KK_SUFFIXES:
            if word.endswith(suf) and len(word) - len(suf) >= min_stem:
                word = word[: -len(suf)]
                changed = True
                break
    return word


for w in kk_forms:
    print(f"{w:16} -> {kk_stem(w)}")
```


**Saved output:**

```text
кітап            -> кітап
кітабы           -> кітаб
кітаптар         -> кітап
кітаптарды       -> кітап
кітаптарым       -> кітап
кітапхана        -> кітапхана
кітаптарымызда   -> кітап
```



`кітаптар`, `кітаптарды`, `кітаптарым` and `кітаптарымызда` all reduce to `кітап`.

Two cases need attention:

- `кітабы` becomes `кітаб`, while the intended base is `кітап`. The lecture explains that a final `п` can soften to `б` before a suffix beginning with a vowel. Removing the suffix does not reverse that change.
- `кітапхана` stays unchanged, correctly, because “library” is a separate word. This happens because `хана` is absent from the suffix list, rather than because the program understands the word.

The source calls these “two results wrong”, although its second example is explicitly correct. The distinction above preserves both observations without treating the unchanged library form as an error.
