## Three stemmers with different levels of cutting



Each row passes the same word to Porter, English Snowball and Lancaster. This isolates the effect of choosing a stemmer.

```python
from nltk.stem import SnowballStemmer, LancasterStemmer

sb = SnowballStemmer("english")
lc = LancasterStemmer()

words = ["running", "ran", "studies", "university", "universe",
         "organization", "was", "caring", "happiness", "argued"]

print(f"{'word':14}{'porter':12}{'snowball':12}{'lancaster':12}")
print("-" * 50)
for w in words:
    print(f"{w:14}{ps.stem(w):12}{sb.stem(w):12}{lc.stem(w):12}")
```


**Saved output:**

```text
word          porter      snowball    lancaster   
--------------------------------------------------
running       run         run         run         
ran           ran         ran         ran         
studies       studi       studi       study       
university    univers     univers     univers     
universe      univers     univers     univers     
organization  organ       organ       org         
was           wa          was         was         
caring        care        care        car         
happiness     happi       happi       happy       
argued        argu        argu        argu        
```



Porter and Snowball both turn `university` and `universe` into `univers`. A search for a university could now retrieve a document about the universe. This is **over-stemming**: different words are incorrectly merged, without an error message.

Lancaster removes more. For example, it turns `caring` into `car`. More matches can also mean more incorrect matches.

The lecture presents Snowball, also called Porter2, as an improved Porter and a useful starting choice. It supports several languages.
