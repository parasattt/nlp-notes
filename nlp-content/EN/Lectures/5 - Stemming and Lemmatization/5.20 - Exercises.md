**1. Build the comparison yourself.**

```python
words = ["flies", "flying", "flew", "better", "best", "worse",
         "children", "geese", "running", "ran", "studies", "studied"]
```

Build a table with four columns: the original word, its Porter stem, its Snowball stem and its WordNet lemma. Supply the correct POS manually.

Then:

- Which words does the lemmatizer handle correctly while both stemmers fail? What do these words have in common?
- Does a **stemmer** give a more useful answer for any word? Explain your choice.
- Make both `best` and `better` reduce to `good`. Explain what extra information you supplied.

**2. Does normalisation actually help? Measure it.**

```python
docs = [
    "The battery died after two days of light use",
    "Batteries drain extremely quickly on this model",
    "My laptop is running very hot when gaming",
    "It runs hot and the fan is loud",
    "The screen cracked when I dropped it",
    "Cracks appeared on the display after a week",
    "Fast delivery and excellent packaging",
]

queries = ["battery draining", "running hot", "cracked screen", "fast delivery"]
```

Run three searches for every query: raw token overlap, stemming and lemmatization. Report the number of documents found by each.

Choose the query with the largest disagreement. Identify a document found by one method but missed by another, the token causing the difference and whether the extra result is relevant.

Create a query where **stemming returns an irrelevant document**. Use words from `docs`; use the `university`/`universe` collision only as a hint.
