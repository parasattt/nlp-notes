`SOFTENING` maps the source’s four softened final consonants back to their proposed harder forms. `kk_stem2` first strips suffixes, then changes a matching final consonant. The code applies that final change whenever it sees a listed letter, rather than checking a full grammatical analysis.

```python
# Undo consonant softening at the end of the stem.
SOFTENING = {"б": "п", "г": "к", "ғ": "қ", "д": "т"}

def kk_stem2(word, min_stem=3):
    stem = kk_stem(word, min_stem)
    if stem and stem[-1] in SOFTENING:
        stem = stem[:-1] + SOFTENING[stem[-1]]
    return stem


for w in kk_forms:
    print(f"{w:16} -> {kk_stem2(w)}")
```

```text

кітабы           -> кітап
кітаптар         -> кітап
кітаптарды       -> кітап
кітаптарым       -> кітап
кітапхана        -> кітапхана
кітаптарымызда   -> кітап
```



The displayed book forms now share `кітап`, while `кітапхана` remains separate. The source says “all six inflected forms now agree”; the saved list contains the base `кітап`, five other book forms and the separate library word.

## Where the rules break



Try words beyond the examples used to write the rules. Compare successful removals, unchanged suffix chains and wrongly cut roots.

```python
tricky = ["мектепте", "дүкеннен", "достарыма", "баламен", "алдым",
          "оқушы", "жұмысшы", "сауда", "пайда", "қала"]

for w in tricky:
    print(f"{w:12} -> {kk_stem2(w):12}")
```


**Saved output:**

```text
мектепте     -> мектеп      
дүкеннен     -> дүкен       
достарыма    -> достарыма   
баламен      -> баламен     
алдым        -> алдым       
оқушы        -> оқуш        
жұмысшы      -> жұмысш      
сауда        -> сау         
пайда        -> пай         
қала         -> қала        
```



The saved list shows three outcomes:

**Useful changes:** `мектепте` (“at school”) becomes `мектеп`, and `дүкеннен` (“from the shop”) becomes `дүкен`.

**No change:** `достарыма`, `баламен` and `алдым` stay whole. Their suffix chains are missing from this rule list, so the failure is silent.

**Damage to words:**

- `оқушы` (“pupil”) becomes `оқуш`, and `жұмысшы` (“worker”) becomes `жұмысш`. The lecture identifies `-шы`/`-ші` as agent-noun endings, but the program removes a final `-ы` as though it were the listed possessive ending.
- `сауда` (“trade”) becomes `сау`, and `пайда` (“profit”) becomes `пай`. Here `да` belongs to the root but looks like the listed locative suffix.

This is **over-stemming**, like merging `university` and `universe`. It can be worse than leaving words unchanged: `сауда` (“trade”) now collides with `сау` (“healthy”).

The source says `қала` (“city”) survives because of `min_stem=3`, and warns that reducing the threshold would break it. **Code-reading clarification:** the supplied suffix list contains neither `а` nor `ла`, so no listed suffix currently matches the end of `қала`; lowering the threshold alone would not add such a match. The source code is unchanged.

Every additional suffix rule may help one chain while cutting a genuine root elsewhere.
