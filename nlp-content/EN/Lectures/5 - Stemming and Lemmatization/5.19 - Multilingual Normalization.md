## Comparing the three languages

The table below preserves the lecture's comparison and approximate form counts:

| | English | Russian | Kazakh |
|---|---|---|---|
| Forms per word | few (2–5) | many (10–20) | very many (100+) |
| Tokenizer | `nltk`, `spaCy` | `razdel` | `razdel` (adequate in these examples) |
| Stemmer | Porter, Snowball | Snowball `"russian"` | write your own in this exercise |
| Lemmatizer | WordNet, spaCy | `pymorphy3` | no packaged option in the source's comparison |
| Stop word list | `nltk` | `nltk` | make your own in this exercise |
| Subword fallback | works | works | works; sometimes matches morphemes |

The lecture connects the tooling gap to available development resources, money and speaker counts, rather than the difficulty of a language. Its practical lesson is to check what a library actually does to your text. In these Kazakh examples, more of the pipeline has to be written by hand.



`normalize(text, lang="en")` dispatches to the appropriate language branch. English uses POS-aware WordNet lemmas; Russian and Kazakh call the earlier pipeline functions. An unsupported language raises `ValueError`. The English branch keeps alphabetic stop words, while the Russian and Kazakh branches use their earlier stop filters; the saved lists show that difference.

```python
# One normalisation function, three languages.
def normalize(text, lang="en"):
    if lang == "en":
        tagged = nltk.pos_tag(word_tokenize(text.lower()))
        return [wnl.lemmatize(w, wordnet_pos(t)) for w, t in tagged if w.isalpha()]
    if lang == "ru":
        return normalize_ru(text)
    if lang == "kk":
        return normalize_kk(text)
    raise ValueError(f"unsupported language: {lang}")


print("EN:", normalize("The batteries were draining very quickly", "en"))
print("RU:", normalize("Батареи ноутбуков разряжались очень быстро", "ru"))
print("KK:", normalize("Кітаптарды дүкеннен сатып алдым", "kk"))
```


**Saved output:**

```text
EN: ['the', 'battery', 'be', 'drain', 'very', 'quickly']
RU: ['батарея', 'ноутбук', 'разряжаться', 'очень', 'быстро']
KK: ['кітап', 'дүкен', 'сатып', 'алдым']
```

The three saved outputs demonstrate shared base forms such as `batteries -> battery`, `Батареи -> батарея` and `Кітаптарды -> кітап`. They also retain the different filtering policies noted above; a common interface alone does not make the preprocessing identical.
