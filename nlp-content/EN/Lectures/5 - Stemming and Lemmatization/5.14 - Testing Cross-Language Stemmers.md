## Trying the available tools

Turkish is also Turkic and agglutinative, which makes its stemmer worth examining in this comparison. The first obstacle is that NLTK’s saved Snowball language list does not include Turkish.



Check the saved language support list directly before trying Turkish through NLTK.

```python
print("turkish available in nltk?", "turkish" in SnowballStemmer.languages)
```


**Saved output:**

```text
turkish available in nltk? False
```



The lecture notes that the Snowball project has a Turkish stemmer in the separate `snowballstemmer` package, although NLTK does not ship it.



The separate package supplies the Turkish stemmer tested next.

Apply the Turkish rules to all seven Kazakh examples, then explicitly test whether the output list is unchanged.

```python
import snowballstemmer

kk_forms = ["кітап", "кітабы", "кітаптар", "кітаптарды",
            "кітаптарым", "кітапхана", "кітаптарымызда"]

tr = snowballstemmer.stemmer("turkish")

print("Turkish stemmer on Kazakh:")
for w, s in zip(kk_forms, tr.stemWords(kk_forms)):
    print(f"   {w:16} -> {s}")

print()
print("unchanged?", tr.stemWords(kk_forms) == kk_forms)
```


**Saved output:**

```text
Turkish stemmer on Kazakh:
   кітап            -> кітап
   кітабы           -> кітабы
   кітаптар         -> кітаптар
   кітаптарды       -> кітаптарды
   кітаптарым       -> кітаптарым
   кітапхана        -> кітапхана
   кітаптарымызда   -> кітаптарымызда

unchanged? True
```



All seven Kazakh strings stay unchanged. To check whether the stemmer itself works, the next cell supplies Turkish written in the Latin alphabet.



These genuine Turkish strings provide a comparison in the alphabet expected by the stemmer.

```python
print(tr.stemWords(["kitaplarımızda", "evler", "geliyorum"]))
```


**Saved output:**

```text
['kitap', 'ev', 'geliyor']
```



For Turkish, `kitaplarımızda` becomes `kitap`; the saved output also gives `evler -> ev` and `geliyorum -> geliyor`. The lecture explains the Kazakh failure by the alphabet: these Turkish rules use Latin letters, while the Kazakh examples use Cyrillic.

The call returned seven strings without an error, yet none changed. Merely checking that a pipeline runs would miss this failure. Always inspect what a normalizer does to the actual text.

The next comparison tries a Russian stemmer because its rules use Cyrillic.



Apply the already-created Russian stemmer to exactly the same Kazakh forms to check whether matching the alphabet is enough.

The Russian rules now damage some Kazakh words. For example, `кітапхана` (“library”) becomes `кітапха`. A Kazakh ending happens to resemble an ending that a Russian rule removes.
