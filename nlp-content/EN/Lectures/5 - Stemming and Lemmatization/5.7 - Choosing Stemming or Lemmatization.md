## Stemming and lemmatization side by side



The pairs explicitly supply the POS for each WordNet call. The displayed stem uses the English Snowball object `sb`, rather than the Porter object `ps`.

```python
pairs = [("running", "v"), ("ran", "v"), ("studies", "n"), ("mice", "n"),
         ("feet", "n"), ("better", "a"), ("was", "v"), ("university", "n"),
         ("universe", "n"), ("happiness", "n")]

print(f"{'word':14}{'stem':14}{'lemma':14}")
print("-" * 42)
for w, pos in pairs:
    print(f"{w:14}{sb.stem(w):14}{wnl.lemmatize(w, pos):14}")
```

| Question | Stemming | Lemmatization |
|---|---|---|
| How does it work? | removes affixes using rules | uses dictionary information |
| What does it return? | often a string that is not a real word | always a real word, in the lecture's description |
| Does it handle irregulars such as `mice` and `ran`? | the illustrated rules do not | yes, with the right information |
| Does it need POS? | no | yes, for good results |
| Speed | very fast | slower |
| Does it need data files? | no | yes, such as WordNet |
| Typical use | search and retrieval | analysis and readable output |

The lecture recommends stemming when speed and scale matter and people will not read the normalized tokens, such as a search index with millions of documents. It recommends lemmatization when people inspect the output.

Sometimes neither is needed. The lecture explains that transformer models use subword tokenization to handle word variation. Normalization is especially useful in classical NLP: [[EN/Lectures/8 - TF-IDF and Text Search/8.5 - TF-IDF by Hand|TF-IDF]], [[EN/Lectures/6 - Turning Text into Features/6.2 - Vocabulary and Bag of Words|bag of words]] and keyword search. The source describes these as widely used in production.
