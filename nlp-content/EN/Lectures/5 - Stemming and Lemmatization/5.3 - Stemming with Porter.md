## Stemming

**Stemming** removes affixes using rules. It does not look words up in a dictionary or check their meaning. The lecture introduces the **Porter stemmer**, developed in 1980 and still used in practice.



The loop applies Porter rules independently to six strings. Compare regular ending changes, an irregular past tense and nonword stems.

```python
from nltk.stem import PorterStemmer

ps = PorterStemmer()

for w in ["running", "runs", "ran", "studies", "studying", "happiness"]:
    print(f"{w:12} -> {ps.stem(w)}")
```


**Saved output:**

```text
running      -> run
runs         -> run
ran          -> ran
studies      -> studi
studying     -> studi
happiness    -> happi
```



- `running` and `runs` both become `run`, so they now match.
- `ran` stays `ran`. Its vowel changed; there is no added ending for the rules to remove.
- `studies` becomes `studi`, which is not a real word.

A stem does not have to be readable. Its purpose is to give the same string to forms that should match. The next [[EN/Lectures/5 - Stemming and Lemmatization/5.4 - Comparing Stemmers and Over-Stemming|stemmer comparison]] also shows what happens when unrelated words become equal.
