## Lemmatization

**Lemmatization** uses dictionary information to find a word's **lemma**, its headword or base form. The lecture describes its output as always being a real word and says it handles irregular forms, unlike the illustrated stemming rules.



No POS argument is supplied here, so every call uses WordNet’s noun default. The saved results below are retained exactly.

```python
from nltk.stem import WordNetLemmatizer

wnl = WordNetLemmatizer()

for w in ["studies", "mice", "feet", "geese", "better", "was"]:
    print(f"{w:10} -> {wnl.lemmatize(w)}")
```


**Saved output:**

```text
studies    -> study
mice       -> mouse
feet       -> foot
geese      -> goose
better     -> better
was        -> wa
```



`mice` becomes `mouse`, and `feet` becomes `foot`. Removing an ending alone cannot explain these changes.

`better` stays `better`. The source prose also says that `was` stays `was`, but the saved output above is `was -> wa`. Preserve this discrepancy when interpreting the example: the default noun setting does not give the intended verb lemma `be`.

## The part-of-speech trap

`WordNetLemmatizer` assumes a word is a **noun** unless you supply another part of speech (POS).



Compare the same strings under noun, verb (`"v"`) and adjective (`"a"`) assumptions. The selected POS changes which lemma is sought.

```python
print("as noun:", wnl.lemmatize("was"), "|", wnl.lemmatize("running"), "|", wnl.lemmatize("better"))
print("as verb:", wnl.lemmatize("was", "v"), "|", wnl.lemmatize("running", "v"), "|", wnl.lemmatize("better", "v"))
print("as adj :", wnl.lemmatize("better", "a"))
```


**Saved output:**

```text
as noun: wa | running | better
as verb: be | run | better
as adj : good
```



With the correct POS argument, `was` becomes `be`, `running` becomes `run`, and adjective `better` becomes `good`. The same string can need different treatment depending on how it is used.

For this code, `"v"` requests a verb lemma and `"a"` an adjective lemma. Leaving out POS can quietly give an unsuitable result. The next step tags the sentence before lemmatizing it.
