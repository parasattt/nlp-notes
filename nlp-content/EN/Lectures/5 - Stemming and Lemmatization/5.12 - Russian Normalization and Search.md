The pipeline combines lowercasing, `razdel` tokens, an NLTK Russian stop list and the first `pymorphy3` analysis. Keep the original review next to the normalized output to see what changed.

```python
from razdel import tokenize as rz_tokenize
from nltk.corpus import stopwords

ru_stop = set(stopwords.words("russian"))

def normalize_ru(text):
    out = []
    for t in rz_tokenize(text.lower()):
        w = t.text
        if not w.isalpha() or w in ru_stop:
            continue
        out.append(morph.parse(w)[0].normal_form)
    return out


ru_reviews = [
    "Купил новый ноутбук, работает отлично!",
    "Ноутбуки этой фирмы очень быстрые",
    "Батарея ноутбука разряжается за час",
    "Экран треснул через неделю",
]

for r in ru_reviews:
    print(f"{r}\n   -> {normalize_ru(r)}\n")
```

A query and document match when their normalized token sets have a nonempty intersection. The result list returns full original documents.

```python
def search_ru(query, docs):
    q = set(normalize_ru(query))
    return [d for d in docs if q & set(normalize_ru(d))]

print("query: 'ноутбуки'")
for hit in search_ru("ноутбуки", ru_reviews):
    print("   ", hit)
```


**Saved output:**

```text
query: 'ноутбуки'
    Купил новый ноутбук, работает отлично!
    Ноутбуки этой фирмы очень быстрые
    Батарея ноутбука разряжается за час
```



The query `ноутбуки` is plural nominative. It matches singular accusative `ноутбук` in review 1 and genitive `ноутбука` in review 3 because normalization maps all three to `ноутбук`. A raw string search matches only review 2.

`normalize_ru` lowercases, tokenizes with `razdel`, removes nonalphabetic tokens and Russian stop words, then takes the first `pymorphy3` reading. `search_ru` finds a document when its normalized set shares at least one token with the query. The ambiguity of `[0]` still applies.
