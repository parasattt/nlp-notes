### Gazetteers and ambiguity

A gazetteer finds known names but misses new names and can confuse a person, place, or product. Context and full entity boundaries matter.

```python
gazetteer = {"Apple": "ORG", "Kaspi Bank": "ORG", "Almaty": "LOC", "Jordan": "LOC", "Washington": "LOC"}

def find_with_list(text):
    found = []
    for name, kind in gazetteer.items():
        for m in re.finditer(r"\b" + re.escape(name) + r"\b", text):
            found.append((m.group(), kind))
    return found

for text in ["Kaspi Bank opened a new branch in Almaty.",
             "Apple shares fell after the report from Washington."]:
    print(f"{text:55} -> {find_with_list(text)}")
```
