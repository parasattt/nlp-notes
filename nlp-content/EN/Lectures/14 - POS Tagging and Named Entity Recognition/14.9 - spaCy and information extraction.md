### spaCy and information extraction

A spaCy pipeline provides token POS tags and entity spans. Process articles in batches with nlp.pipe and count distinct articles per entity. Check actual predictions: dataset and annotation differences make cross-domain comparisons imperfect.

```python
import spacy
nlp = spacy.load("en_core_web_sm")

doc = nlp("Michael Jordan visited Jordan, and Kaspi Bank paid $5 million for a startup in Almaty.")
print(f"{'token':10} {'pos_':6} {'ent_iob_':8} ent_type_")
for token in doc:
    print(f"{token.text:10} {token.pos_:6} {token.ent_iob_:8} {token.ent_type_}")
print()
for ent in doc.ents:
    print(f"{ent.text:15} {ent.label_:7} {spacy.explain(ent.label_)}")
```

rows = []
for article_id, d in enumerate(nlp.pipe(ag["text"], batch_size=64)):

entities = pd.DataFrame(rows)
