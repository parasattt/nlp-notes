### Fall back when the longer context is missing

First look for the last two typed words in the trigram table. If that pair was never observed, use the last word's bigram table instead. This switch to a shorter context is **backoff**.

The suggestion function uses observed counts rather than inventing counts for an unseen two-word context.



`suggest` pads empty/short input, uses the final two tokens when that context exists, and otherwise uses the final token alone. It ranks observed continuations and returns up to `k=4`, divided by the chosen row total.

```python
def suggest(typed, k=4):
    words = ["<s>", "<s>"] + typed.lower().split()
    a, b = words[-2], words[-1]
    table = next_tri[(a, b)] if (a, b) in next_tri else next_bi[b]
    total = sum(table.values())
    return [(w, round(c / total, 2)) for w, c in table.most_common(k)]

for typed in ["", "the food was", "the service was", "i would", "i would not", "the pizza"]:
    print(f"{typed!r:18} -> {suggest(typed)}")
```


**Saved output:**

```text
''                 -> [('i', 0.15), ('the', 0.12), ('we', 0.04), ('it', 0.03)]
'the food was'     -> [('good', 0.12), ('ok', 0.05), ('great', 0.05), ('just', 0.04)]
'the service was'  -> [('great', 0.09), ('good', 0.09), ('very', 0.05), ('excellent', 0.04)]
'i would'          -> [('have', 0.16), ('not', 0.07), ('recommend', 0.05), ('definitely', 0.05)]
'i would not'      -> [('recommend', 0.19), ('be', 0.13), ('go', 0.07), ('have', 0.07)]
'the pizza'        -> [('was', 0.2), ('is', 0.14), ('</s>', 0.1), ('and', 0.06)]
```

This fallback has the same practical purpose as the unknown-word handling in [[EN/Lectures/12 - Smart Search with Word Vectors/12.14 - Unknown Words|word-vector search]]: an unobserved case needs a defined response.



The saved suggestions depend on the context: after *the food was*, common next words include *good*, *ok*, and *great*; after *i would not*, *recommend* is common.

An empty input produces common sentence-opening words. A `</s>` suggestion after *the pizza* says that this phrase sometimes ends a sentence, as in *we ordered the pizza*.
