### Generate a word, then repeat

A language model can produce text by choosing a next word, adding it to the context, and repeating. Choosing the most likely next word at each step is **greedy decoding**. The complete generator also supports probability-weighted sampling.



`generate` uses the same trigram/bigram fallback as suggestions. `greedy=True` chooses the largest count; otherwise `rng.choices` samples using counts as weights. Generation stops at `</s>` or `max_words=25`; `seed` fixes the random generator for an example.

```python
def generate(start="", greedy=False, max_words=25, seed=None):
    rng = random.Random(seed)
    words = ["<s>", "<s>"] + start.split()
    for _ in range(max_words):
        a, b = words[-2], words[-1]
        table = next_tri[(a, b)] if (a, b) in next_tri else next_bi[b]
        if greedy:
            w = table.most_common(1)[0][0]
        else:                                   # pick a word with probability = its share of the counts
            w = rng.choices(list(table), weights=list(table.values()))[0]
        if w == "</s>":
            break
        words.append(w)
    return " ".join(words[2:])

print("greedy:", generate("the food", greedy=True))
```


**Saved output:**

```text
greedy: the food was good
```



Greedy decoding produces *the food was good* in the saved example, then stops at `</s>`. With the same start and model, it makes the same choices every time.

For variety, **sample** a word at random with probabilities based on the counts. Common words still have larger chances, but they are not selected every time. The next examples use fixed random seeds so their stored samples can be compared.



```python
for seed in range(6):
    print("-", generate("the food" if seed < 3 else "the waiter", seed=seed))
```

The generated fragments resemble review language, but a full sentence can lose its topic because the model remembers only two words.

The original explanation says that every generated triple came from training. The code also permits backoff to a bigram table, so that sentence should be read as the lecture's description of local imitation, not a guarantee for every fallback step.

The lecture compares the next-word-and-repeat process with ChatGPT. Its stated distinction is how the next-word probability $P(\text{next word}\mid\text{previous words})$ is calculated: a neural model uses learned representations and a much longer context, instead of only counting the last two words. It also connects the comparison to perplexity.
