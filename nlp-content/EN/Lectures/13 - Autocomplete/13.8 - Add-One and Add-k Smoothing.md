### Give unseen pairs a small probability

**Smoothing** moves some probability away from observed pairs and gives it to unseen ones. The simplest method adds one to every possible next-word count:

$$P_{\text{add-1}}(w \mid \text{prev}) = \frac{\text{count}(\text{prev } w) + 1}{\text{count}(\text{prev}) + V}$$

Here, `prev` is the preceding word, $w$ is a possible next word, and $V$ is the number of possible next words. The replies contain twelve ordinary words plus `</s>`, so $V=13$; `<s>` is not a possible next output word.

For each row, add 1 to thirteen counts, so add 13 to the denominator as well. The probabilities still add to 1.

For `is`, observed once before `delayed`:

- $P(\text{shipped} \mid \text{is})=(0+1)/(1+13)=1/14\approx0.071$.
- $P(\text{delayed} \mid \text{is})=(1+1)/(1+13)=2/14\approx0.143$, reduced from 1.

The unseen pair is now possible, but the familiar pair has lost probability.

Compare the same zero-count problem in [[EN/Lectures/7 - Naive Bayes Classification/7.4 - Laplace Smoothing|Laplace smoothing for Naive Bayes]].



The vocabulary excludes `<s>` because it is not a predicted next token. `p_add_k` adds `k` to a candidate count and `k * V` to the row total; its default `k=1.0` reproduces add-one smoothing.

```python
vocab = {w for sent in map(add_marks, replies) for w in sent if w != "<s>"}
V = len(vocab)
print("V =", V)

def p_add_k(word, prev, k=1.0):
    total = sum(follows[prev].values())
    return (follows[prev][word] + k) / (total + k * V)

print(f"P(shipped | is) = {p_add_k('shipped', 'is'):.3f}")
print(f"P(delayed | is) = {p_add_k('delayed', 'is'):.3f}")
print()
for s in ["your order is shipped", "your order is delayed"]:
    print(f"no smoothing {sentence_prob(s):.6f}   add-one {sentence_prob(s, p_add_k):.6f}   {s}")
```


**Saved output:**

```text
V = 13
P(shipped | is) = 0.071
P(delayed | is) = 0.143

no smoothing 0.000000   add-one 0.000050   your order is shipped
no smoothing 0.100000   add-one 0.000100   your order is delayed
```



The unseen sentence now has probability about 0.00005. The familiar *your order is delayed* falls from 0.1 to about 0.0001, a thousandfold drop. Most probability after `is` has been shared with twelve words never observed there.

With a vocabulary around 35,000, add-one can give away too much probability. The later Yelp results show it performing worse than a unigram model that ignores context.

**Add-k smoothing** uses a smaller added count, such as $k=0.01$. In the same formula, replace the numerator's 1 with $k$, and replace $V$ in the denominator with $k\cdot V$. The source's `p_add_k` function exposes this through its `k` argument.
