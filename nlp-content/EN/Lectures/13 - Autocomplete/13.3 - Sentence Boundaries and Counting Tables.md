### Mark sentence starts and ends

Add `<s>` before each reply and `</s>` after it. This lets the same counting rule learn starting words and stopping points.

Three of five replies start with `thank`, so $P(\text{thank} \mid \text{<s>}) = 3/5$.

| Previous word | Next word: count | Total |
|---|---|---|
| `<s>` | thank: 3, your: 2 | 5 |
| thank | you: 3 | 3 |
| you | for: 3 | 3 |
| for | your: 2, contacting: 1 | 3 |
| your | order: 3, patience: 1 | 4 |
| order | `</s>`: 1, has: 1, is: 1 | 3 |
| has / is / contacting | shipped / delayed / us: 1 | 1 |
| patience, shipped, delayed, us | `</s>`: 1 each | 1 each |

Divide a next-word count by its row total to get its probability.

#### Store the table in Python

Use a dictionary keyed by the previous word. Each value is a `Counter` that stores the following-word counts.



`add_marks` adds the start/end tokens. For each prepared reply, `zip(sent, sent[1:])` visits adjacent words and increments the corresponding `Counter` entry. These stored counts produce the hand table above.

```python
replies = [
    "thank you for your order",
    "thank you for your patience",
    "your order has shipped",
    "your order is delayed",
    "thank you for contacting us",
]

def add_marks(sentence):
    return ["<s>"] + sentence.split() + ["</s>"]

follows = defaultdict(Counter)                  # follows["for"] = Counter({"your": 2, "contacting": 1})
for sent in map(add_marks, replies):
    for prev, word in zip(sent, sent[1:]):      # neighbouring pairs
        follows[prev][word] += 1

print(add_marks(replies[0]))
for prev in ["<s>", "for", "your", "order"]:
    total = sum(follows[prev].values())
    print(f"after {prev!r:7}: {dict((w, f'{c}/{total}') for w, c in follows[prev].most_common())}")
```


**Saved output:**

```text
['<s>', 'thank', 'you', 'for', 'your', 'order', '</s>']
after '<s>'  : {'thank': '3/5', 'your': '2/5'}
after 'for'  : {'your': '2/3', 'contacting': '1/3'}
after 'your' : {'order': '3/4', 'patience': '1/4'}
after 'order': {'</s>': '1/3', 'has': '1/3', 'is': '1/3'}
```



`zip(sent, sent[1:])` pairs the list with a version shifted by one position. It therefore visits every adjacent pair. The saved rows match the hand-counted table.
