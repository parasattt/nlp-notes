### Compare probability estimators

Each estimator uses the interface `p(w, a, b)`: the probability of next word `w` after context `a b`.

- **Uniform:** each possible word has probability $1/V$.
- **Unigram:** use $\text{count}(w)/N$, which captures word frequency but ignores context.
- **Bigram with add-k:** use the last word and the smoothing formula already introduced.
- **Trigram with add-k:** use the last two words with the same smoothing idea.
- **Interpolation:** combine the unsmoothed unigram, bigram, and trigram estimates:

$$P(w \mid a\,b) = 0.1 \cdot P_{\text{uni}}(w) + 0.3 \cdot P_{\text{bi}}(w \mid b) + 0.6 \cdot P_{\text{tri}}(w \mid a\,b)$$

The three weights are 0.1, 0.3, and 0.6, so this example trusts the trigram estimate most. If the trigram was never observed, $P_{\text{tri}} = 0$, but shorter-context terms can still contribute. The lecture explains that weights adding to 1 allow probabilities to be mixed.

The source code uses a simplified fallback: when an entire longer context is unseen, that component returns zero for every candidate word, and the remaining weights are not redistributed. Therefore, weights adding to 1 do not by themselves guarantee a normalized distribution for every fallback context. The original estimators and reported results are kept unchanged.

The code below builds context totals, defines each estimator, and compares their perplexities. Its dictionary includes three bigram values of `k`, so the saved comparison actually has seven entries.



`bi_ctx` and `tri_ctx` are denominators for observed contexts. `N_words` is the total predicted-token count and `V_yelp` is its vocabulary size. Each estimator uses these same counts; `perplexity` scores the held-out prepared sentences and returns both perplexity and token count.

```python
bi_ctx = Counter()                               # how often each word is followed by something
for (a, _), c in bi.items():
    bi_ctx[a] += c
tri_ctx = Counter()                              # how often each pair is followed by something
for (a, b, _), c in tri.items():
    tri_ctx[(a, b)] += c
N_words = sum(uni.values())
V_yelp = len(uni)

def p_uniform(w, a, b):
    return 1 / V_yelp

def p_unigram(w, a, b):
    return uni[w] / N_words

def p_bigram_k(w, a, b, k):
    return (bi[(b, w)] + k) / (bi_ctx[b] + k * V_yelp)

def p_trigram_k(w, a, b, k):
    return (tri[(a, b, w)] + k) / (tri_ctx[(a, b)] + k * V_yelp)

def p_interp(w, a, b, l1=0.1, l2=0.3, l3=0.6):
    p1 = uni[w] / N_words
    p2 = bi[(b, w)] / bi_ctx[b] if bi_ctx[b] else 0.0
    p3 = tri[(a, b, w)] / tri_ctx[(a, b)] if tri_ctx[(a, b)] else 0.0
    return l1 * p1 + l2 * p2 + l3 * p3

def perplexity(p, sents=test_p):
    log_sum, n = 0.0, 0
    for s in sents:
        padded = ["<s>"] + s                   # one more <s> so the first word has two words before it
        for i in range(2, len(padded)):
            log_sum += math.log(p(padded[i], padded[i - 2], padded[i - 1]))
            n += 1
    return math.exp(-log_sum / n), n

models = {
    "uniform": p_uniform,
    "unigram": p_unigram,
    "bigram, add-1": lambda w, a, b: p_bigram_k(w, a, b, 1),
    "bigram, add-0.1": lambda w, a, b: p_bigram_k(w, a, b, 0.1),
    "bigram, add-0.01": lambda w, a, b: p_bigram_k(w, a, b, 0.01),
    "trigram, add-0.01": lambda w, a, b: p_trigram_k(w, a, b, 0.01),
    "interpolation": p_interp,
}
results = {}
for name, p in models.items():
    results[name], n_test = perplexity(p)
    print(f"{name:18} perplexity {results[name]:9.1f}")
print(f"\n(measured on {n_test:,} test words)")
```
