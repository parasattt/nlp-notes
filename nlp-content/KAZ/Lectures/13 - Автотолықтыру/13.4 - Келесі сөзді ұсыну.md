### Ықтималдығы ең жоғары сөздерді ұсынамыз

Соңғы терілген сөзден кейін келген сөздерді тауып, жиілігі бойынша реттейміз. Келесі функциялар ықтималдықты есептеп, ең көбі `k=3` ұсыныс қайтарады.



`p_next` келесі сөз жиілігін сол алдыңғы сөзге арналған жалпы санға бөледі; жол кездеспесе 0 қайтарады. `suggest_toy` ең жиі `k` жалғасын қайтарып, көрсету үшін ықтималдықтарды дөңгелектейді.

```python
def p_next(word, prev):
    total = sum(follows[prev].values())
    return follows[prev][word] / total if total else 0.0

def suggest_toy(prev, k=3):
    return [(w, round(p_next(w, prev), 2)) for w, _ in follows[prev].most_common(k)]

print("after 'your' :", suggest_toy("your"))
print("after 'order':", suggest_toy("order"))
```


**Сақталған нәтиже:**

```text
after 'your' : [('order', 0.75), ('patience', 0.25)]
after 'order': [('</s>', 0.33), ('has', 0.33), ('is', 0.33)]
```



`order` сөзінен кейін `</s>` ұсынылуы жауаптың осында аяқталуы мүмкін екенін білдіреді. Лекция редактор мұны нүкте түрінде көрсете алатынын айтады.
