### Сөз генерациялап, қайталаймыз

Тілдік модель келесі сөзді таңдап, оны контекске қосып, осыны қайталау арқылы мәтін шығарады. Әр қадамда ең ықтимал келесі сөзді таңдау — **ашкөз декодтау**, яғни greedy decoding. Толық генератор ықтималдық салмақтарымен кездейсоқ таңдауды да қолдайды.



`generate` ұсыныстардағыдай триграмма/биграмма қосалқы жолын қолданады. `greedy=True` ең үлкен жиілікті таңдайды; әйтпесе `rng.choices` жиіліктерді салмақ ретінде қолданып, кездейсоқ таңдайды. Генерация `</s>` не `max_words=25` кезінде тоқтайды; `seed` мысал үшін кездейсоқ генераторды бекітеді.

```python
def generate(start="", greedy=False, max_words=25, seed=None):
    rng = random.Random(seed)
    words = ["<s>", "<s>"] + start.split()
    for _ in range(max_words):
        a, b = words[-2], words[-1]
        table = next_tri[(a, b)] if (a, b) in next_tri else next_bi[b]
        if greedy:
            w = table.most_common(1)[0][0]
        else:                                   # pick a word with probability = its share of the counts
            w = rng.choices(list(table), weights=list(table.values()))[0]
        if w == "</s>":
            break
        words.append(w)
    return " ".join(words[2:])

print("greedy:", generate("the food", greedy=True))
```


**Сақталған нәтиже:**

```text
greedy: the food was good
```



Сақталған мысалда ашкөз декодтау *the food was good* («тамақ жақсы болды») шығарып, `</s>` кезінде тоқтайды. Бірдей бастау мен модель болса, әрдайым бір таңдаулар жасайды.

Әртүрлілік үшін жиіліктерге негізделген ықтималдықтармен сөзді **кездейсоқ таңдаңыз**. Жиі сөздердің мүмкіндігі көбірек, бірақ олар әр жолы таңдалмайды. Келесі мысалдар сақталған таңдауларды салыстыру үшін random seed мәндерін бекітеді.



```python
for seed in range(6):
    print("-", generate("the food" if seed < 3 else "the waiter", seed=seed))
```

Генерацияланған үзінділер пікір тіліне ұқсайды, бірақ толық сөйлем тақырыбын жоғалтуы мүмкін, себебі модель тек екі сөзді есте сақтайды.

Бастапқы түсіндірме әр генерацияланған үштік оқытуда болған дейді. Код биграмма кестесіне backoff жасауға да рұқсат етеді, сондықтан бұл сөйлемді әр қосалқы қадамға кепілдік емес, лекцияның жергілікті еліктеуді сипаттауы деп оқу керек.

Лекция «келесі сөзді таңдау және қайталау» үдерісін ChatGPT-мен салыстырады. Айтылған айырма — келесі сөз ықтималдығы $P(\text{next word}\mid\text{previous words})$ қалай есептелетіні: нейрондық модель тек соңғы екі сөзді санаудың орнына үйренілген ұсынулар мен әлдеқайда ұзын контекст қолданады. Салыстыру перплексиямен де байланыстырылады.
