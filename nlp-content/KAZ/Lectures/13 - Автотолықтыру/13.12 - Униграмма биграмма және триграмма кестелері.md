### Жиілік кестелерін құрамыз

Жеке сөздерді (**униграммалар**), көрші жұптарды (**биграммалар**) және үш сөз тізбегін (**триграммалар**) санаймыз. Триграммалық болжам соңғы екі терілген сөзге тәуелді бола алады.

Триграммалар құрғанда дайын сөйлем алдына тағы бір `<s>` қосамыз. Сонда алғашқы нақты сөздің алдында екі шекара маркері болады. Код бір не екі сөздік контекст кілт болатын іздеу кестелерін де құрады.



`uni`, `bi` және `tri` тізбек жиіліктерін сақтайды. `next_bi` бір сөздік контексті келесі сөздер санауышымен байланыстырады; `next_tri` екі сөздік контекст қолданады. Қосымша бастапқы шекара токені алғашқы триграмманы дайындайды.

```python
uni = Counter(w for s in train_p for w in s[1:])                     # single words (not <s>)
bi = Counter(pair for s in train_p for pair in zip(s, s[1:]))         # pairs
tri = Counter(t for s in train_p for t in zip(["<s>"] + s, s, s[1:])) # three in a row

next_bi = defaultdict(Counter)                  # next_bi["the"]            -> words after "the"
for (b, w), c in bi.items():
    next_bi[b][w] = c
next_tri = defaultdict(Counter)                 # next_tri[("i", "would")]  -> words after "i would"
for (a, b, w), c in tri.items():
    next_tri[(a, b)][w] = c

print(f"vocabulary V: {len(uni):,}")
print(f"one word before : {len(next_bi):,} different starts, {len(bi):,} different pairs")
print(f"two words before: {len(next_tri):,} different starts, {len(tri):,} different triples")
```
