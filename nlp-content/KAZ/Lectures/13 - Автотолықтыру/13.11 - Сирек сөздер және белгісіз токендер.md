### Сирек және белгісіз сөздерді қалай белгілейміз

Тест пікірлеріндегі есімдер мен қате жазылған сөздер оқытуда мүлде кездеспеуі мүмкін. **Кемінде екі рет** кездескен сөздерден тұрақты сөздік құрамыз. Басқаларын «белгісіз» деген `<unk>` маркеріне ауыстырамыз.

Оқытудағы осы маркер мысалдары модельге сирек сөздердің қай жерде келетінін үйретеді. Тестте кездеспеген сөздерді сол маркерге ауыстыру әр жаңа жазылуға бөлек жиілік талап етпейді.



`vocab_yelp` оқыту сөздерінің жиіліктерінен үйреніледі. `prepare` басқа сөздерді `<unk>` маркеріне ауыстырып, оқыту және тест сөйлемдеріне шекара маркерлерін қосады.

```python
word_counts = Counter(w for s in train_sents for w in s)
vocab_yelp = {w for w, c in word_counts.items() if c >= 2}
print(f"different words in training: {len(word_counts):,}   kept (seen 2+ times): {len(vocab_yelp):,}")

def prepare(sent):
    return ["<s>"] + [w if w in vocab_yelp else "<unk>" for w in sent] + ["</s>"]

train_p = [prepare(s) for s in train_sents]
test_p = [prepare(s) for s in test_sents]
print(" ".join(test_p[3]))
```
