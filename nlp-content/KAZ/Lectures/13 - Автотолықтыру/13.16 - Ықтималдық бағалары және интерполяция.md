### Ықтималдықты бағалау тәсілдерін салыстырамыз

Әр тәсіл `p(w, a, b)` интерфейсін қолданады: `a b` контексінен кейінгі `w` сөзінің ықтималдығы.

- **Біркелкі:** әр мүмкін сөздің ықтималдығы $1/V$.
- **Униграмма:** $\text{count}(w)/N$ қолданып, сөз жиілігін ескереді, бірақ контексті елемейді.
- **Add-k бар биграмма:** соңғы сөз бен бұрын енгізілген тегістеу формуласын қолданады.
- **Add-k бар триграмма:** сол тегістеу идеясымен соңғы екі сөзді қолданады.
- **Интерполяция:** тегістелмеген униграмма, биграмма және триграмма бағаларын біріктіреді:

$$P(w \mid a\,b) = 0.1 \cdot P_{\text{uni}}(w) + 0.3 \cdot P_{\text{bi}}(w \mid b) + 0.6 \cdot P_{\text{tri}}(w \mid a\,b)$$

Үш салмақ 0.1, 0.3 және 0.6, сондықтан бұл мысал триграмма бағасына көбірек сенеді. Триграмма кездеспесе, $P_{\text{tri}} = 0$, бірақ қысқа контекст мүшелері үлес қоса алады. Лекция қосындысы 1 болатын салмақтар ықтималдықтарды араластыруға мүмкіндік беретінін түсіндіреді.

Бастапқы код жеңілдетілген қосалқы жолды қолданады: егер ұзын контекст түгел кездеспесе, оның компоненті әр кандидат сөзге нөл қайтарады, ал қалған салмақтар қайта бөлінбейді. Сондықтан салмақтар қосындысының 1 болуы әр қосалқы контексте нормаланған үлестірімді өздігінен кепілдемейді. Бастапқы бағалаушылар мен көрсетілген нәтижелер өзгеріссіз сақталған.

Төмендегі код контекстің жалпы сандарын құрып, әр тәсілді анықтайды және перплексияларын салыстырады. Оның сөздігінде биграмма үшін `k` шамасының үш мәні бар, сондықтан сақталған салыстыруда шын мәнінде жеті нұсқа бар.



`bi_ctx` және `tri_ctx` — байқалған контекстердің бөлімдері. `N_words` — болжанатын токендердің жалпы саны, `V_yelp` — оның сөздік көлемі. Әр тәсіл осы бір жиіліктерді қолданады; `perplexity` дайын бөлек сөйлемдерді бағалап, перплексия мен токен санын бірге қайтарады.

```python
bi_ctx = Counter()                               # how often each word is followed by something
for (a, _), c in bi.items():
    bi_ctx[a] += c
tri_ctx = Counter()                              # how often each pair is followed by something
for (a, b, _), c in tri.items():
    tri_ctx[(a, b)] += c
N_words = sum(uni.values())
V_yelp = len(uni)

def p_uniform(w, a, b):
    return 1 / V_yelp

def p_unigram(w, a, b):
    return uni[w] / N_words

def p_bigram_k(w, a, b, k):
    return (bi[(b, w)] + k) / (bi_ctx[b] + k * V_yelp)

def p_trigram_k(w, a, b, k):
    return (tri[(a, b, w)] + k) / (tri_ctx[(a, b)] + k * V_yelp)

def p_interp(w, a, b, l1=0.1, l2=0.3, l3=0.6):
    p1 = uni[w] / N_words
    p2 = bi[(b, w)] / bi_ctx[b] if bi_ctx[b] else 0.0
    p3 = tri[(a, b, w)] / tri_ctx[(a, b)] if tri_ctx[(a, b)] else 0.0
    return l1 * p1 + l2 * p2 + l3 * p3

def perplexity(p, sents=test_p):
    log_sum, n = 0.0, 0
    for s in sents:
        padded = ["<s>"] + s                   # one more <s> so the first word has two words before it
        for i in range(2, len(padded)):
            log_sum += math.log(p(padded[i], padded[i - 2], padded[i - 1]))
            n += 1
    return math.exp(-log_sum / n), n

models = {
    "uniform": p_uniform,
    "unigram": p_unigram,
    "bigram, add-1": lambda w, a, b: p_bigram_k(w, a, b, 1),
    "bigram, add-0.1": lambda w, a, b: p_bigram_k(w, a, b, 0.1),
    "bigram, add-0.01": lambda w, a, b: p_bigram_k(w, a, b, 0.01),
    "trigram, add-0.01": lambda w, a, b: p_trigram_k(w, a, b, 0.01),
    "interpolation": p_interp,
}
results = {}
for name, p in models.items():
    results[name], n_test = perplexity(p)
    print(f"{name:18} perplexity {results[name]:9.1f}")
print(f"\n(measured on {n_test:,} test words)")
```
