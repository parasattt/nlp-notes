### Ұзын контекст болмаса, қысқасына ораламыз

Алдымен соңғы екі терілген сөзді триграмма кестесінен іздейміз. Ондай жұп кездеспесе, соңғы сөздің биграмма кестесін қолданамыз. Қысқалау контекске осылай ауысу **backoff** деп аталады.

Ұсыну функциясы кездеспеген екі сөздік контекске жасанды жиілік бермей, байқалған жиіліктерді қолданады.



`suggest` бос не қысқа кірісті толықтырады, соңғы екі токеннің контексі бар болса соны, әйтпесе тек соңғы токенді қолданады. Байқалған жалғастарды реттеп, ең көбі `k=4` жалғасын таңдалған жолдың жалпы санына бөліп қайтарады.

```python
def suggest(typed, k=4):
    words = ["<s>", "<s>"] + typed.lower().split()
    a, b = words[-2], words[-1]
    table = next_tri[(a, b)] if (a, b) in next_tri else next_bi[b]
    total = sum(table.values())
    return [(w, round(c / total, 2)) for w, c in table.most_common(k)]

for typed in ["", "the food was", "the service was", "i would", "i would not", "the pizza"]:
    print(f"{typed!r:18} -> {suggest(typed)}")
```


**Сақталған нәтиже:**

```text
''                 -> [('i', 0.15), ('the', 0.12), ('we', 0.04), ('it', 0.03)]
'the food was'     -> [('good', 0.12), ('ok', 0.05), ('great', 0.05), ('just', 0.04)]
'the service was'  -> [('great', 0.09), ('good', 0.09), ('very', 0.05), ('excellent', 0.04)]
'i would'          -> [('have', 0.16), ('not', 0.07), ('recommend', 0.05), ('definitely', 0.05)]
'i would not'      -> [('recommend', 0.19), ('be', 0.13), ('go', 0.07), ('have', 0.07)]
'the pizza'        -> [('was', 0.2), ('is', 0.14), ('</s>', 0.1), ('and', 0.06)]
```

Бұл қосалқы жолдың мақсаты [[KAZ/Lectures/12 - Сөз векторларымен ақылды іздеу/12.14 - Белгісіз сөздер|сөз векторларымен іздеудегі]] белгісіз сөзді өңдеумен бірдей: кездеспеген жағдай үшін анық жауап керек.



Сақталған ұсыныстар контекске тәуелді: *the food was* («тамақ … болды») тіркесінен кейін *good*, *ok* және *great* жиі келеді; *i would not* («мен … етпес едім») тіркесінен кейін *recommend* («ұсыну») жиі кездеседі.

Бос кіріс сөйлемді жиі бастайтын сөздерді береді. *the pizza* тіркесінен кейін `</s>` ұсынылуы бұл тіркес кейде сөйлемді аяқтайтынын білдіреді, мысалы *we ordered the pizza* («біз пиццаға тапсырыс бердік»).
