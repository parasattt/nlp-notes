### Overfitting with Text Features

Переобучение на признаках текста

```python
rows = []
for n in [300, 3000, 12000]:
    vec = TfidfVectorizer().fit(y_train_df["text"][:n])
    Xn, Xt = vec.transform(y_train_df["text"][:n]), vec.transform(y_test_df["text"])
    plain = LinearRegression().fit(Xn, y_train_df["stars"][:n])
    rows.append((n, Xn.shape[1],
                 mae(plain.predict(Xn), y_train_df["stars"][:n]),
                 mae(plain.predict(Xt), y_test_df["stars"])))
print(pd.DataFrame(rows, columns=["training reviews", "weights", "train MAE", "test MAE"]).round(3).to_string(index=False))
print("\nbaseline (always the average): 1.173")
```
