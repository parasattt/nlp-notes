### Notebook ішінен шықпай анықтама алу

Келесі ұяшықтар үш пайдалы құралды көрсетеді: `?` немесе `help()` арқылы құжаттама, `dir()` арқылы қолжетімді әдістер және `type()` арқылы мәннің типі.



```python
# 1. A question mark shows the documentation for anything.
#    In Colab this opens a help panel at the bottom of the screen.
#    Run it and look down there - the output area here stays empty.
str.upper?
```



```python
# help() does the same thing but prints inline, so it works everywhere.
help(str.upper)
```


**Сақталған нәтиже:**

```text
Help on method_descriptor:

upper(self, /) unbound builtins.str method
    Return a copy of the string converted to uppercase.

```

`str.upper?` — notebook үшін арнайы анықтама синтаксисі. `help(str.upper)` құжаттаманы нәтижелердің ішінде басып шығарады. Сақталған сипаттамада `.upper()` жолдың бас әріптерге ауыстырылған көшірмесін қайтаратыны айтылған.



```python
# 2. dir() lists everything you can do with an object.
#    Ignore the names starting with underscores for now.
text = "hello"
[name for name in dir(text) if not name.startswith("_")]
```

`dir(text)` жолдың қолжетімді атрибуттары мен әдістерін тізеді. Тізімдік өрнек `_` таңбасынан басталатын атауларды алып тастап, күнделікті қолдануға арналған әдістерді қалдырады. `lower`, `split`, `strip` және `upper` сияқты мысалдарды қарау үшін сақталған тізім толық берілген.



```python
# 3. type() tells you what something is. When confused, always ask this first.
print(type("hello"))
print(type(5))
print(type([1, 2, 3]))
```
