### Shell командалары және кітапханаларды орнату

`!` таңбасынан басталатын жол Python ретінде түсіндірілмей, машинаның **командалық қабықшасына (shell)** жіберіледі. Notebook әдеттегі Colab машинасын Linux машинасы деп сипаттайды.

Алғашқы мысал Python нұсқасын сұрайды. Екіншісі кітапхананы орнатуды көрсетеді. Notebook бойынша, курсқа қажет кітапханалар Colab ішінде бар, сондықтан орнату кезінде талаптың орындалып тұрғаны хабарлануы мүмкін.



```python
!python --version
```



```python
# Colab already has the libraries we need for this course, so this will just say
# "already satisfied". This is how you would install something new.
!pip install pandas --quiet
print("done")
```

`!python --version` ортадағы Python нұсқасын сұрайды. `!pip install pandas --quiet` пакет орнатуды көрсетеді, ал `--quiet` әдеттегі қызметтік хабарларды азайтады. Соңғы Python жолы `done` шығарар еді. Дереккөзде екі ұяшықтың да сақталған нәтижесі жоқ, сондықтан мұнда жаңа нәтиже берілмейді.
