### Markdown туралы: мәтіндік ұяшықтар

Мәтіндік ұяшықты екі рет басып, оның Markdown бастапқы мәтінін көріңіз. Пішімделген түрін қайта көрсету үшін **Shift + Enter** басыңыз.

Notebook ішінде қолданылатын негізгі жазылу түрлері:

```markdown
# Big heading
## Smaller heading

**bold**   *italic*   `code`

- bullet
- another bullet

1. numbered
2. list
```

Үй жұмысында ойыңызды түсіндіру үшін мәтіндік ұяшықтарды қолданыңыз: түсіндірме бағаның бір бөлігі. Тек кодтан тұратын notebook түсінуге қиын, ал түсіндірілмеген талдауды қате ұғу оңай.
