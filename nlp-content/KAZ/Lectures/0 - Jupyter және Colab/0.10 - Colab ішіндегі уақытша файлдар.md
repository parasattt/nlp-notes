### Colab ішіндегі файлдар

**Colab машинасы уақытша**. Біраз уақыт әрекет болмаса, сеанс жойылып, сол машинадағы файлдар жоғалуы мүмкін. Google Drive ішінде сақталған notebook файлы қалады, бірақ оның коды жасаған файлдарды бөлек сақтау немесе жүктеп алу қажет.

Notebook қажетті деректерді басынан қайта жасай алатындай жазыңыз. Келесі ұяшықтар шағын мәтіндік файлға жазуды және оны қайта оқуды көрсетеді.



```python
# Write a small text file to the temporary machine.
with open("example.txt", "w", encoding="utf-8") as f:
    f.write("First line of the file.\n")
    f.write("Second line of the file.\n")

print("File written.")
```


**Сақталған нәтиже:**

```text
File written.
```



```python
# Read it back.
with open("example.txt", "r", encoding="utf-8") as f:
    content = f.read()

print(content)
```


**Сақталған нәтиже:**

```text
First line of the file.
Second line of the file.

```

Жазу ұяшығында `"w"` файлды жазуға ашады, ал әр `\n` жолды аяқтайды. Оқу ұяшығында `"r"` файлды оқуға ашады, ал `read()` оның бүкіл мазмұнын бір жол ретінде қайтарады. Екі операцияда да UTF-8 көрсетілген, ал `with` блогы біткенде файлды жабады. Басқа мысалдар [[KAZ/Lectures/1 - Мәтінмен жұмыс істеуге арналған Python негіздері/1.19 - Мәтіндік файлдарды оқу және жазу|мәтіндік файлдарды оқу және жазу]] тақырыбында бар.



```python
# List the files on the machine. You should see example.txt in there.
!ls -la
```

`!ls -la` жасырын файлдарды қоса, файлдарды толық мәліметімен тізеді. Дереккөзде таза Colab мысалы емес, жеке жергілікті буманың өте ұзын тізімі сақталған. Сабаққа қатысы жоқ файл атаулары мұнда әдейі берілмеген. Негізгі ой — сеанс файлдарын қарап, жоғарыда жасалған `example.txt` файлын табу; уақытша файлдарды қайта жасау немесе басқа жерге сақтау қажет.



Colab сол жақ панеліндегі **бума белгішесі** файлдар панелін ашады. Файлдарды жүктеу үшін осы жерге сүйреп апаруға немесе жүктеп алу үшін файлды тінтуірдің оң жақ батырмасымен басуға болады.
