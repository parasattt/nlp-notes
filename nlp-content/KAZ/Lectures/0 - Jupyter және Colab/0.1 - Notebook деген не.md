NLP курсына қош келдіңіз. Python кодын жазбас бұрын **Google Colab** ішіндегі **Jupyter notebook** құралын қолдануды үйреніңіз. Семестр бойы осы ортада жұмыс істейміз.

Бұл лекция NLP ұғымдарының өзіне емес, жұмыс ортасына арналған. Онымен танысуға кеткен бірнеше минут кейін көптеген сағаттық түсінбеушіліктің алдын алады.



### Notebook деген не?

Кәдімгі бағдарлама көбіне басынан аяғына дейін орындалып, нәтижесін шығарып, жұмысын аяқтайтын файл болады.

Notebook — **ұяшықтар тізімі**. Ұяшықтарды бір-бірден іске қосуға болады, ал нәтижелер оларды шығарған кодтың жанында қалады. Ұяшықтарды ретсіз де іске қосуға болады, бірақ бұл мәселе туғызуы мүмкін.

Ұяшықтардың екі түрі бар:

- **Код ұяшықтарында** Python коды болады және олар нәтиже шығара алады.
- Markdown тілінде жазылған **мәтіндік ұяшықтарда** жазбалар, түсіндірмелер мен тақырыптар болады.

Бұл мәтін мен деректерді талдауға ыңғайлы: талдау кезінде бір ойды тексеріп, нәтижесін қарап, басқа тәсілді сынау жиі қажет болады. Әр жолы бүкіл notebook файлын қайта орындаудың қажеті жоқ.
