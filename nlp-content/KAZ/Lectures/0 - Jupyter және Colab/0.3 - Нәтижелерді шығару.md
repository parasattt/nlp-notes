### Соңғы жол автоматты түрде көрсетіледі

Кәдімгі Python скриптінде мәнді көрсету үшін әдетте `print()` шақырылады. Notebook ішінде ұяшықтың **соңғы жолындағы** өрнектің мәні автоматты түрде көрсетіледі.

Бұл автоматты көрсету тек соңғы өрнекке қатысты. Бірнеше нәтижені көрсету қажет болса, `print()` қолданыңыз.



```python
2 + 2 + test
```


**Сақталған нәтиже:**

```text
14
```

Сақталған нәтиже — `14`: өрнек алдыңғы ұяшықта 10 мәні берілген `test` айнымалысын қолданады. Егер осы ұяшық орындалмай тұрып айнымалы өзгерсе, нәтиже де өзгеруі мүмкін.



```python
# But only the LAST line. This cell shows just 20, not 10 and 20.
5 + 5
10 + 10
```


**Сақталған нәтиже:**

```text
20
```

Екі өрнек те есептеледі, бірақ тек соңғысының `20` мәні автоматты түрде көрсетіледі.



```python
# If you want to see both, print them explicitly.
print(5 + 5)
print(10 + 10)
```


**Сақталған нәтиже:**

```text
10
20
```

Мұнда `print()` екі рет ашық шақырылған, сондықтан екі нәтиже де көрсетіледі: алдымен `10`, содан кейін `20`.
