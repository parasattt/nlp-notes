### Ұяшық қате берсе

Қателер — бағдарламалаудың қалыпты бөлігі. Қате хабарын оқуды үйрену үшін notebook айнымалысы жоқ келесі ұяшықты әдейі іске қосуды ұсынады.



```python
print(undefined_variable_that_does_not_exist)
```


**Notebook ішінде сақталған қате:**

```text
---------------------------------------------------------------------------
NameError                                 Traceback (most recent call last)
Cell In[9], line 1
----> 1 print(undefined_variable_that_does_not_exist)

NameError: name 'undefined_variable_that_does_not_exist' is not defined
```



Қате блогы **traceback**, яғни қатенің орындалу ізі деп аталады. Оны ең төменгі жолынан оқи бастаңыз:

```text
NameError: name 'undefined_variable_that_does_not_exist' is not defined
```

Осы жол нақты мәселені айтады. Жоғарыдағы жолдар қате болғанда Python кодтың қай жерінде тұрғанын көрсетеді. Алдымен соңғы жолды оқу көбіне бүкіл traceback ішінде адаспай, қажетті ақпаратты табуға көмектеседі.

Бұл курста жиі кездесетін қателер:

- `NameError`: айнымалы жоқ; атауда қате болуы немесе оны жасайтын ұяшық әлі орындалмауы мүмкін.
- `TypeError`: операцияға сәйкес емес типтегі мән берілген, мысалы `"5" + 5`.
- `SyntaxError`: Python кодты оқи алмайды; көбіне `)` немесе `:` жетіспейді.
- `IndexError` немесе `KeyError`: жоқ элементті сұрадыңыз.
- `ModuleNotFoundError`: импортталатын кітапхана орнатылмаған.
