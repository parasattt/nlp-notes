#### Мәселе қайдан шығады: ұяшықтарды ретсіз орындау

Notebook күйі ұяшықтардың экрандағы ретіне ғана емес, **оларды қандай ретпен орындағаныңызға** байланысты. Python 10-ұяшықты, одан кейін 3-ұяшықты, содан соң 7-ұяшықты іске қосуға мүмкіндік береді.

Сондықтан notebook авторда жұмыс істеп, оны ашып, жоғарыдан төмен орындаған басқа адамда қате беруі мүмкін. Автордың сеансында бұрынғы орындаудан қалған мәндер болуы ықтимал, ал жаңа сеанста олар жоқ.

Келесі мысал осы мәселені әдейі көрсетеді: алдымен `total` мәнін нөлге қойыңыз, кейін мәнді өсіретін ұяшықты бірнеше рет іске қосыңыз.



```python
# Run this cell FIRST.
total = 0
```



```python
# Then run this one a few times in a row. Watch the number change each time.
total = total + 1
print("total is now:", total)
```


**Сақталған нәтиже:**

```text
total is now: 1
```

Әр іске қосу `total` ағымдағы мәніне бірді қосады. Сақталған нәтиже нөлге түсіргеннен кейінгі бір орындауды ғана тіркеп, `1` көрсетеді; бұл бүкіл notebook басынан жаңадан орындалды деген сөз емес.



Мәнді өсіретін ұяшықты нөлге түсіргеннен кейін үш рет орындасаңыз, `total` мәні 3 болады. Notebook файлын жаңа сеанста бір рет орындаған адам 1 алады. Көрсетілген ұяшықтың өзінен оның неше рет орындалғанын білу мүмкін емес.

Мына әдетті қалыптастырыңыз: жұмысты аяқтағанда **Runtime → Restart session and run all** таңдаңыз. Барлығы таза күйден бастап, беттегі ретімен жұмыс істейтінін тексеріңіз. Нәтижені басқа таза орындауда қайта алуға болса, ол **қайта алынатын нәтиже** болады. Егер notebook жасырын сеанс тарихын қажет етсе, оның нәтижесін әзірге сенімді түрде қайта алу мүмкін емес.
