### Ұяшықтар ортақ жадты қолданады

Барлық ұяшық бір Python сеансында орындалады. Бір ұяшықта жасалған айнымалыны екіншісінде қолдануға болады. Бұл ыңғайлы, бірақ орындалу ретінің маңызды екенін де білдіреді.

Notebook келесі екі ұяшықты ретімен орындауды сұрайды. Біріншісі `sentence` жасайды, ал екіншісі сол айнымалыны оқиды.



```python
sentence = "Natural language processing is mostly text cleaning."
```



```python
# This cell knows about `sentence` even though we never defined it here.
print(sentence)
test = 20
print("Number of characters:", len(sentence))
```


**Сақталған нәтиже:**

```text
Natural language processing is mostly text cleaning.
Number of characters: 52
```

Екінші ұяшық `sentence` айнымалысын сеанстың ортақ жадынан оқып, бос орындар мен тыныс белгілерін қоса алғандағы ұзындығын көрсетеді: **52 таңба**. Ол `test` мәнін 20-ға да өзгертеді. Бұрынғы ұяшықты қайта іске қоссаңыз, бұл өзгеріс оның нәтижесіне әсер етуі мүмкін.
