## Сәйкестік іздеу функциясын таңдау

| Функция | Не қайтарады немесе не істейді |
|---|---|
| `re.findall(pattern, text)` | Барлық сәйкестікті тізімге жинайды. |
| `re.search(pattern, text)` | Бірінші сәйкестікті немесе `None` қайтарады. |
| `re.match(pattern, text)` | Жолдың **басындағы** сәйкестікті тексереді. |
| `re.sub(pattern, repl, text)` | Сәйкес келген мәтінді ауыстырады. |
| `re.split(pattern, text)` | Мәтінді сәйкес келген бөлгіштер бойынша бөледі. |

Төмендегі телефон мысалында сәйкес мәтін үшін `group()`, ал оның орындары үшін `start()`/`end()` да көрсетілген.



```python
text = "Call 555-1234 or 555-5678 today"

print(re.findall(r"\d{3}-\d{4}", text))

m = re.search(r"\d{3}-\d{4}", text)
print(m.group())     # the matched text
print(m.start(), m.end())   # where it was found

print(re.sub(r"\d{3}-\d{4}", "[PHONE]", text))
```


**Сақталған нәтиже:**

```text
['555-1234', '555-5678']
555-1234
5 13
Call [PHONE] or [PHONE] today
```



### Өрнектерге raw жолдарды қолданыңыз

`r"..."` ішінде Python кері қиғаш сызықтарды regex механизміне қалдырады. `r` болмаса, Python `\b` таңбасын regex-ке жеткізбей тұрып бір таңба кері жылжу таңбасы ретінде оқиды.

Келесі сақталған салыстыруда сырттай бірдей шекара өрнегі raw жол префиксімен және онсыз қолданылады.



```python
print(re.findall("\bcat\b", "the cat sat"))    # no r prefix -> broken, finds nothing
print(re.findall(r"\bcat\b", "the cat sat"))   # with r -> works
```


**Сақталған нәтиже:**

```text
[]
['cat']
```
