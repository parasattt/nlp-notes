## Өрнек қатесін шағын қадамдармен түзетіңіз

1. **Біртіндеп құрастырыңыз:** алдымен `\d+`, кейін `\d+-`, содан соң қалғанын тексеріңіз. Бірден жазылған ұзын өрнектің қатесін табу қиынырақ.
2. **Қате әлі де шығатын ең шағын кіріс мысалын қолданыңыз.**
3. **Сәйкестіктерді [regex101](https://regex101.com) арқылы қараңыз**, Python нұсқасын таңдаңыз. Дереккөз оның өрнек түсіндірмелері мен сәйкестіктерді бірден бояп көрсетуін ұсынады.
4. **Нақты сәйкес келген мәтінді шығарыңыз**, не сәйкес келді деп жорамалдамаңыз.
5. **Raw жол префиксін тексеріңіз.** `r` жоқ болса, кері қиғаш сызықтар regex-ке жетпей өзгеруі мүмкін.

Келесі код үлкен-кіші әріпті ескермейтін іздеуді, әр жолға арналған шекара шарттарын және `re.VERBOSE` арқылы комментариймен жазылған өрнекті көрсетеді.



```python
# Useful flags
text = "Hello WORLD hello world"

print(re.findall(r"hello", text, re.IGNORECASE))

multi = "line one\nline two\nline three"
print(re.findall(r"^line \w+$", multi, re.MULTILINE))   # ^ and $ per line

# re.VERBOSE lets you write a readable, commented pattern
phone_re = re.compile(r"""
    \+?          # optional plus
    \d{1,3}      # country code
    [\s\-]?      # separator
    \(?\d{3}\)?  # area code, maybe in brackets
    [\s\-]?
    \d{3}
    [\s\-]?
    \d{2}
    [\s\-]?
    \d{2}
""", re.VERBOSE)

print(phone_re.findall("Call +7 701 555 01 99 now"))
```


**Сақталған нәтиже:**

```text
['Hello', 'hello']
['line one', 'line two', 'line three']
['+7 701 555 01 99']
```



`re.compile()` өрнекті бір рет дайындайды. Содан кейін дайын өрнек объектісін әр дерек жолы үшін қайта талдамай қолдануға болады. Лекция бір өрнекті көп жолға қолданғанда осыны ұсынады. Толық жазылған телефон мысалы бос орын мен комментарийлердің ұзын өрнекті қалай түсінікті ететінін де көрсетеді.
