Regex өрнегі жазбаның күтілетін форматын да сипаттайды. Өрнекті түсінетін адам дұрыс жолда қандай өрістер болуы керегін көре алады.

### Алынатын топтарға атау беру

Өріс саны өскенде нөмірленген топтарды қадағалау қиындайды. Әр топқа атау беру үшін `(?P<name>...)` қолданыңыз.



```python
pattern = (
    r"\[(?P<timestamp>[^\]]+)\] "
    r"ORDER #(?P<order_id>\d+) "
    r"user=(?P<user>\S+) "
    r"total=(?P<total>\d+)KZT "
    r"status=(?P<status>\w+)"
)

rows = []
for line in log.splitlines():
    m = re.search(pattern, line)
    if m:
        rows.append(m.groupdict())

orders = pd.DataFrame(rows)
orders
```


**Сақталған нәтиже:**

```text
             timestamp order_id            user   total     status
0  2026-03-15 09:14:22    10234   aisha@mail.kz  125000    shipped
1  2026-03-15 10:02:05    10235  bolat@shop.com   87500    pending
2  2026-03-16 12:00:00    10236    dana@mail.kz  340000    shipped
3  2026-03-17 08:30:59    10237   erlan@mail.kz   15000  cancelled
```



Нәтиже — журнал өрістерінен құрылған DataFrame. `groupdict()` әр сәйкес жазба үшін атауы бар мәндерді береді.

Өрнек бірнеше жолдағы қатар орналасқан жол литералдарымен жазылған. Python оларды біріктіреді, сондықтан өрнек бір ұзын жолға айналмай, оқуға түсінікті қалады.

Алынған кесте құрылымы үшін [[KAZ/Lectures/2 - Мәтіндік деректерге арналған Pandas/2.3 - DataFrame және Series|DataFrame және Series]] тақырыбын қараңыз.



```python
# Now everything from notebook 02 applies
orders["total"] = orders["total"].astype(int)
orders["domain"] = orders["user"].str.split("@").str[1]

print(orders.groupby("status")["total"].agg(["count", "sum"]))
print()
print(orders["domain"].value_counts())
```
