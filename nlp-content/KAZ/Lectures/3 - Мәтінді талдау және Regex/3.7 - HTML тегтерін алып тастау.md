## Мәтін өрісінен HTML тегтерін алып тастау

Веб-мәтінде `<p>` сияқты белгілеу болуы мүмкін. Мұндай тегтер сөз жиілігін санағанда сөзге айналмауы керек.

### Алдымен қолмен жасалатын әдіс

Келесі функция ағымдағы таңбаның тег ішінде тұрғанын қадағалайды.



```python
html = "<p>The <b>best</b> phone I have <i>ever</i> owned!</p><br/><a href='#'>Read more</a>"

def strip_tags_manual(s):
    out = []
    inside = False
    for ch in s:
        if ch == "<":
            inside = True
        elif ch == ">":
            inside = False
        else:
            if not inside:
                out.append(ch)
    return "".join(out)

print(strip_tags_manual(html))
```


**Сақталған нәтиже:**

```text
The best phone I have ever owned!Read more
```



Қолмен жасалған әдіске цикл мен күйді сақтайтын `inside` айнымалысы қажет. Оның `<a href="a>b">` сияқты тегті дұрыс өңдейтінін білу үшін логикасын оқу керек.

### Regex нұсқасы

Келесі мысал дәл осы қарапайым жою ережесін өрнек арқылы көрсетеді.



```python
print(re.sub(r"<[^>]+>", "", html))
```


**Сақталған нәтиже:**

```text
The best phone I have ever owned!Read more
```



`<[^>]+>` өрнегі мынаны білдіреді: ашылатын `<`, `>` таңбасынан басқа бір не бірнеше таңба, соңында жабылатын `>`. Сәйкестіктерді бос жолмен ауыстыру осы қарапайым тегтерді жояды.

Лекция шектеуін де айтады: HTML-мен күрделі жұмысқа BeautifulSoup сияқты HTML парсері керек. Тег жоятын өрнек ішкі қабаттасуды түсінбейді. Қысқа өрнек мәтін өрісі үшін ыңғайлы болса да, осы шектеуді есте сақтаңыз.
