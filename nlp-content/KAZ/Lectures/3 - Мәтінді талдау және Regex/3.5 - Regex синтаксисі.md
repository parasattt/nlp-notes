## Regex синтаксисін бөліктермен үйреніңіз

Келесі мысалдар өрнектің нені табатынын, элементтің неше рет қайталанатынын және сәйкестік қай жерде болатынын түсіндіреді. Бүкіл кестені бірден жаттамай, бөліктерді біртіндеп үйреніңіз.

### Таңбалар кластары: қандай таңбалар?



```python
sample = "In 2026, 15 students passed. 3 did not."

print(re.findall(r"[0-9]", sample))   # single digits
print(re.findall(r"[0-9]+", sample))  # runs of digits
print(re.findall(r"\d+", sample))     # \d is shorthand for [0-9]
```


**Сақталған нәтиже:**

```text
['2', '0', '2', '6', '1', '5', '3']
['2026', '15', '3']
['2026', '15', '3']
```



| Өрнек | Мағынасы |
|---|---|
| `\d` | Цифр. |
| `\D` | Цифр емес таңба. |
| `\w` | Unicode сөз таңбасы: әріп, цифр немесе астын сызу таңбасы. |
| `\W` | Сөз таңбасына жатпайтын таңба. |
| `\s` | Пробел, табуляция не жол ауыстыру сияқты бос орын таңбасы. |
| `\S` | Бос орын таңбасы емес таңба. |
| `.` | Әдепкі баптауда жол ауыстырудан басқа кез келген таңба. |
| `[abc]` | `a`, `b` немесе `c` таңбаларының бірі. |
| `[^abc]` | `a`, `b` немесе `c` таңбаларынан басқа кез келген таңба. |
| `[a-z]` | Осы диапазондағы кіші әріп. |



```python
messy = "word1 \t word2\n\n   word3"
print(repr(messy))
print(re.findall(r"\S+", messy))       # runs of non-whitespace
print(re.split(r"\s+", messy.strip())) # split on any run of whitespace
```


**Сақталған нәтиже:**

```text
'word1 \t word2\n\n   word3'
['word1', 'word2', 'word3']
['word1', 'word2', 'word3']
```



Кәдімгі бос орын таңбаларымен `messy.split()` да жұмыс істейді. Бөлгіш нақтырақ болғанда regex пайдалы: мысалы, міндетті емес бос орындары бар үтір, нүктелі үтір немесе бірнеше мүмкін бөлгіштің бірі.



### Квантификаторлар: неше рет қайталанады?

| Өрнек | Мағынасы |
|---|---|
| `+` | Бір не одан көп. |
| `*` | Нөл не одан көп. |
| `?` | Нөл немесе бір; алдыңғы элемент міндетті емес. |
| `{3}` | Дәл үш. |
| `{2,4}` | Екіден төртке дейін. |
| `{2,}` | Екі не одан көп. |



```python
print(re.findall(r"colou?r", "color and colour are both correct"))
print(re.findall(r"\d{4}", "Years: 2024, 2025, 2026 and 12345"))
print(re.findall(r"a+", "a aa aaa b"))
```


**Сақталған нәтиже:**

```text
['color', 'colour']
['2024', '2025', '2026', '1234']
['a', 'aa', 'aaa']
```



### Шекара шарттары: сәйкестік қай жерде болады?

| Өрнек | Мағынасы |
|---|---|
| `^` | Жолдың басы. |
| `$` | Жолдың соңы. |
| `\b` | Сөз шекарасы. |



```python
lines = ["ERROR: disk full", "INFO: started", "ERROR: timeout"]
for line in lines:
    if re.match(r"^ERROR: disk", line):     # match() checks from the start
        print(line)
```


**Сақталған нәтиже:**

```text
ERROR: disk full
```



**Сөз шекарасы** `\b` кілт сөздің ұзынырақ сөздің ішінде сәйкес келуіне жол бермейді. Келесі мысал мұның неге маңызды екенін көрсетеді.



```python
text = "The cat sat on a catastrophic catalogue in Cathmandu"

print(re.findall(r"cat", text))         # matches inside other words too
print(re.findall(r"\bcat\b", text))     # only the standalone word
```


**Сақталған нәтиже:**

```text
['cat', 'cat', 'cat']
['cat']
```



Алдыңғы pandas пікірлерін іздеу мысалы `.str.contains("battery")` қолданған. `cat` үшін жай іздеу *catalogue*, *catastrophe* және *category* сияқты сөздердің бөліктерін де табады.

Мұндай қате көбіне exception шығармай, сенімді көрінетін, бірақ қате санақтар береді. Кілт сөздің екі жағына `\b` қойсаңыз, ол сөз шекараларында тұруы керек болады.

Алдыңғы pandas мысалы [[KAZ/Lectures/2 - Мәтіндік деректерге арналған Pandas/2.7 - Мәтін мен санаттарды сүзу|жолдарды мәтін бойынша іздеп сүзу]] тақырыбында берілген.



### Топтар мен баламалар

`( )` жақшалары сәйкестіктің бір бөлігін сақтап алады. `|` тік сызығы «немесе» дегенді білдіреді. Күн мысалы жылды, айды және күнді бөлек алады; келесі мысал жануар атауларының арасынан таңдайды.



```python
dates = "Deadlines: 2026-03-15, 2026-04-01 and 2026-12-31"

# Capture year, month, day separately
for match in re.findall(r"(\d{4})-(\d{2})-(\d{2})", dates):
    print(match)
    year, month, day = match
    print(f"day {day}, month {month}, year {year}")
```


**Сақталған нәтиже:**

```text
('2026', '03', '15')
day 15, month 03, year 2026
('2026', '04', '01')
day 01, month 04, year 2026
('2026', '12', '31')
day 31, month 12, year 2026
```



```python
print(re.findall(r"\b(cat|dog|bird)\b", "I have a cat, a dog and three birds"))
```


**Сақталған нәтиже:**

```text
['cat', 'dog']
```



`birds` жолы `bird` баламасына сәйкес келмейді, өйткені кейінгі `s` әлі де сөз таңбасы. Қажетті шекара жоқ.

Regex берілген өрнекті дәл орындайды. Сондықтан нақты өрнектер пайдалы, бірақ аз ғана қатесі бар ереже қосқыңыз келген жағдайды өткізіп алуы мүмкін.
