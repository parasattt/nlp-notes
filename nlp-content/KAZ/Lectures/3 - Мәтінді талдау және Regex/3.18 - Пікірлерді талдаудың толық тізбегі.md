Бұл рет [[KAZ/Lectures/3 - Мәтінді талдау және Regex/3.12 - Бастапқы мәтіннен белгілерді алу#^raw-features-first|бастапқы мәтін белгілерін сақтау қағидасына]] сай келеді.



```python
# --- Step 2: clean ---
def clean(t):
    t = re.sub(r"<[^>]+>", " ", t)
    t = re.sub(r"https?://\S+", " <url> ", t)
    t = re.sub(r"\S+@\S+\.\S+", " <email> ", t)
    t = re.sub(r"\d{4}-\d{2}-\d{2}", " <date> ", t)     # specific before general
    t = re.sub(r"\+?\d[\d\s\-()]{7,}\d", " <phone> ", t)
    t = t.lower()
    t = re.sub(r"\s+", " ", t)
    return t.strip()

df["clean"] = df["raw"].apply(clean)
df[["raw", "clean"]].head(4)
```

Тазалау тізбегі [[KAZ/Lectures/3 - Мәтінді талдау және Regex/3.9 - Арнайы маркерлер және тазалау ережелерінің реті#^specific-before-general|нақты өрнектерді жалпы өрнектерден бұрын қолдануды]] қайта пайдаланады.



```python
# --- Step 3: tokenize ---
STOP = {"the","a","an","is","was","are","were","in","on","at","to","for","of",
        "and","but","or","it","this","that","i","my","me","you","be","so","very",
        "url","email","phone","date"}

def tokenize(t):
    tokens = re.findall(r"[a-z]+", t)
    return [w for w in tokens if w not in STOP and len(w) > 2]

df["tokens"] = df["clean"].apply(tokenize)
df["n_tokens"] = df["tokens"].str.len()
df[["clean", "tokens"]].head(4)
```

# --- Step 4: analyse ---

df["sentiment"] = df["rating"].apply(lambda r: "positive" if r >= 4 else ("negative" if r <= 2 else "neutral"))

neg_words = [w for row in df.loc[df["sentiment"] == "negative", "tokens"] for w in row]

print("Top words in POSITIVE reviews:")
for w, n in Counter(pos_words).most_common(8):
    print(f"   {w:<12} {n}")

print("\nTop words in NEGATIVE reviews:")
for w, n in Counter(neg_words).most_common(8):
    print(f"   {w:<12} {n}")

Бұл рейтингтерге сақ қараңыз. Бар болғаны сегіз пікір бар, ал көп сөз бір рет кездеседі. Сондықтан «ең жиі сегіз сөз» кластар туралы сенімді дәлелден гөрі «алғаш кездескен сегіз сөзге» жақын болады.

Дереккөз оң сөздер ретінде *great*, *love*, *excellent*, ал теріс сөздер ретінде *broke*, *terrible*, *worst* сөздерін атайды. Бақылау осынша аз болғанда тізімге пайдалы сигнал да, шу да әсер етеді.

Осы әдіс он мың пікірде әлдеқайда пайдалы ақпарат беруі мүмкін. Дұрыс әдісті сенімді қорытынды жасауға тым шағын таңдамада қолданудан ажыратыңыз.
