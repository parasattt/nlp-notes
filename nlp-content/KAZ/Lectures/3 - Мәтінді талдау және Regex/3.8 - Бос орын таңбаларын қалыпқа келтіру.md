## Бос орын таңбаларын қалыпқа келтіру

### Қарапайым жол әдісі жеткілікті болса, соны қолданыңыз

Бос орын таңбалары бойынша бөліп, бір пробелмен қайта біріктіру қайталанған пробелдерді, табуляцияларды және жол ауыстыруларды біріктіреді.



```python
messy = "Too    many\t\tspaces\n\nand  newlines   here"

# The trick: split on any whitespace, then join with single spaces
print(" ".join(messy.split()))
```


**Сақталған нәтиже:**

```text
Too many spaces and newlines here
```

Қарапайым жол нұсқасы [[KAZ/Lectures/1 - Мәтінмен жұмыс істеуге арналған Python негіздері/1.9 - Мәтінді бөлу және біріктіру|split және join]] қолданады.



Python-ның қарапайым split/join әдісі бірінші есепті онсыз да түсінікті шешеді. Нақтырақ ереже керек болса, regex қолданыңыз. Келесі мысал абзацтар арасындағы бөліністі сақтап, пробелдер мен табуляцияларды біріктіреді.



```python
# "Collapse repeated spaces but keep paragraph breaks" - not expressible with split()
text = "Line one   has    spaces.\n\nLine two   also.\n\n\n\nLine three."

step1 = re.sub(r"[ \t]+", " ", text)        # collapse spaces and tabs only
step2 = re.sub(r"\n{3,}", "\n\n", step1)    # 3+ newlines become exactly 2
print(step2)
```


**Сақталған нәтиже:**

```text
Line one has spaces.

Line two also.

Line three.
```
