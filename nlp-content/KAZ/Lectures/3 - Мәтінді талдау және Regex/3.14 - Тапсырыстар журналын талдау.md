## Қарапайым мәтіннен құрылымды ақпарат алу

Тазалау мәтінді бірізді түрге келтіреді. **Ақпарат алу** оның ішінен нақты өрістерді шығарады. Лекция мұны ережеге негізделген ақпарат алу және атаулы нысандарды танумен байланыстырады.

### Тапсырыстар журналын талдау

Мысал журналында тапсырыс жазбалары және ERROR жолы бар. Қолмен жасалған парсерді regex арқылы бөліктерді алумен салыстырыңыз.



```python
log = """

[2026-03-15 10:02:05] ORDER #10235 user=bolat@shop.com total=87500KZT status=pending
[2026-03-16 11:47:31] ERROR payment gateway timeout for ORDER #10235
[2026-03-16 12:00:00] ORDER #10236 user=dana@mail.kz total=340000KZT status=shipped
[2026-03-17 08:30:59] ORDER #10237 user=erlan@mail.kz total=15000KZT status=cancelled

print(log)
```

### Өрістерді қолмен талдау



```python
def parse_manual(line):
    if "ORDER #" not in line or "user=" not in line:
        return None
    # Find the order number
    start = line.index("ORDER #") + len("ORDER #")
    end = start
    while end < len(line) and line[end].isdigit():
        end += 1
    order_id = line[start:end]
    # Find the user
    ustart = line.index("user=") + len("user=")
    uend = line.index(" ", ustart)
    user = line[ustart:uend]
    # Find the total
    tstart = line.index("total=") + len("total=")
    tend = line.index("KZT", tstart)
    total = line[tstart:tend]
    return order_id, user, total


for line in log.splitlines():
    print(parse_manual(line))
```

```text
None

```



Қолмен жасалған парсер осы журналға жарайды, бірақ индекстерді көп есептейді. Өріс жетіспесе немесе өрістердің реті өзгерсе, ол бұзылуы мүмкін. Қандай формат күтетінін бір қарағанда түсіну де қиын.
