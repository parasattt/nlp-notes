## Ақпаратты pandas бағанынан тікелей алу

Pandas regex-ке негізделген `.str.extract` әдісін береді, сондықтан өрістерді алатын цикл көбіне қажет емес. Атаулы топтардың аттары нәтиже бағандарының аттарына айналады.

Бағандағы жолдармен жұмыс істеу интерфейсі [[KAZ/Lectures/2 - Мәтіндік деректерге арналған Pandas/2.7 - Мәтін мен санаттарды сүзу|pandas жол операциялары]] тақырыбында берілген.



```python
s = pd.Series([
    "Order #10234 shipped on 2026-03-15",
    "Order #10235 delayed until 2026-04-01",
    "Order #10236 delivered 2026-03-20",
])

s.str.extract(r"#(?P<order>\d+).*?(?P<date>\d{4}-\d{2}-\d{2})")
```


**Сақталған нәтиже:**

```text
   order        date
0  10234  2026-03-15
1  10235  2026-04-01
2  10236  2026-03-20
```



`.*?` — **lazy** нұсқа: ол бүкіл өрнектің сәйкес келуіне мүмкіндік қалдырып, мүмкіндігінше аз таңба алады. Greedy нұсқа `.*` алдымен барынша алысқа дейін созылып, кейін кері шегінеді.

Қайталанатын маркерлердің арасынан ақпарат алғанда lazy нұсқа бөлек элементтерді бөлек сақтай алады. Келесі HTML мысалы айырмашылықты көрсетеді.



```python
# Greedy vs lazy, side by side
html = "<b>first</b> and <b>second</b>"
print(re.findall(r"<b>.*</b>", html))    # greedy: one huge match
print(re.findall(r"<b>.*?</b>", html))   # lazy: two correct matches
```


**Сақталған нәтиже:**

```text
['<b>first</b> and <b>second</b>']
['<b>first</b>', '<b>second</b>']
```
