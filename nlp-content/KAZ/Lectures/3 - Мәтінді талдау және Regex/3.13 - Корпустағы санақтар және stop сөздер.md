# Remove stop words - the frequent words that carry little meaning
stop_words = {
    "the", "a", "an", "is", "was", "are", "were", "in", "on", "at", "to", "for",
    "of", "and", "but", "or", "it", "this", "that", "i", "you", "me", "my",
    "be", "not", "no", "so", "too", "very", "num", "url", "email", "phone", "date",
}

df["tokens_nostop"] = df["tokens"].apply(
    lambda toks: [t for t in toks if t not in stop_words and len(t) > 2]
)

all_content = [tok for row in df["tokens_nostop"] for tok in row]
Counter(all_content).most_common(15)

Stop сөздерді жойғанға дейін санақ тізімінде грамматикалық сөздер басым болады. Жойғаннан кейін тізім тақырыпты жақсырақ сипаттайды.

Бірақ жоғалатын ақпарат бар: бұл stop тізімі `not` сөзін жояды, сондықтан `not great` пен `great` ажыратылмай қалады. Кейбір тақырыптық есепте бұл жарамды болуы мүмкін, бірақ пікір тональдігі туралы ақпаратты бұзады.

Барлық есепке бірдей дұрыс stop тізімі жоқ. Әдепкі тізімді тексермей қабылдамай, оны есепке қажет ақпаратқа қарай таңдаңыз.

Оң және теріс сөйлемдердің бірдей болып қалуы және қорғалған терістеулер тізімі [[KAZ/Lectures/4 - Токенизация/4.6 - Терістеуді сақтау|stop сөздердегі терістеу тұзағы]] тақырыбында қаралады.
