## Алдымен бос орын таңбалары бойынша бөлу

Бірінші есеп — сөйлемді сөздер тізіміне айналдыру. Таза жазылған сөйлем үшін бос орын таңбалары бойынша бөлу жеткілікті сияқты көрінеді.



```python
text = "Natural language processing is useful"
print(text.split())
```


**Сақталған нәтиже:**

```text
['Natural', 'language', 'processing', 'is', 'useful']
```



Таза мысал дұрыс жұмыс істейді. Енді тыныс белгілері, қысқарған сөз формасы, тырнақша және адамның аты алдындағы қысқартуы бар мәтінді көріңіз.



```python
real = "Dr. Smith said: \"NLP is hard, isn't it?\" -- he wasn't wrong!"
print(real.split())
```


**Сақталған нәтиже:**

```text
['Dr.', 'Smith', 'said:', '"NLP', 'is', 'hard,', "isn't", 'it?"', '--', 'he', "wasn't", 'wrong!']
```



Сақталған нәтижедегі токендерге қараңыз:

- `'said:'` соңында қос нүкте қалған.
- `'"NLP'` басында ашылатын тырнақша қалған.
- `'hard,'` және `'hard'` бөлек саналады.
- `'it?"'` токеніне екі тыныс белгісі жалғанған.
- `'--'` сөз болып есептеледі.

Бұлар тек экранда көрсету мәселелері емес. Бір сөздің кездесулері әртүрлі токендерге бөлінсе, сөз санақтары мен солардан жасалған белгілердің пайдасы азаяды. Бұл кейінгі модельге де кері әсер етуі мүмкін.

### Тыныс белгілерін шеттерінен алып көрейік

Келесі функция әр токеннің шеттерінен берілген тыныс белгілерін алып, қалған мәтінді кіші әріпке айналдырады.



```python
def tokenize_v2(text):
    tokens = []
    for word in text.split():
        word = word.strip('.,!?;:"()[]{}-\'')
        if word:
            tokens.append(word.lower())
    return tokens

print(tokenize_v2(real))
```


**Сақталған нәтиже:**

```text
['dr', 'smith', 'said', 'nlp', 'is', 'hard', "isn't", 'it', 'he', "wasn't", 'wrong']
```

Негізгі жол операциялары үшін [[KAZ/Lectures/1 - Мәтінмен жұмыс істеуге арналған Python негіздері/1.5 - Жолдарды тазалау және бос орын таңбалары|жолды тазалау әдістерін]] және [[KAZ/Lectures/1 - Мәтінмен жұмыс істеуге арналған Python негіздері/1.9 - Мәтінді бөлу және біріктіру|мәтінді бөлу мен біріктіруді]] қараңыз.



Бірінші мысал жақсарды. Енді email, телефон нөмірі, баға және пайызы бар мәтінді тексерейік.



```python
tricky = "Email me at ivan@mail.kz or call +7-701-555-0199. Cost: $19.99 (30% off!)"
print(tokenize_v2(tricky))
```


**Сақталған нәтиже:**

```text
['email', 'me', 'at', 'ivan@mail.kz', 'or', 'call', '+7-701-555-0199', 'cost', '$19.99', '30%', 'off']
```



Сақталған нәтиже:

```text
['email', 'me', 'at', 'ivan@mail.kz', 'or', 'call',
 '+7-701-555-0199', 'cost', '$19.99', '30%', 'off']
```

Email, телефон және баға **тұтас** қалған. Бұл пайдалы ма, жоқ па — есепке байланысты. Бірақ токенизатор бұл таңдауды ашық түрде белгілемеген.

`strip()` таңбаларды токеннің тек **шеттерінен** жояды. Ортадағы тыныс белгілері бағдарлама email не бағаны танығандықтан емес, тұрған орнына байланысты сақталады. Келесі мысалдарда тыныс белгілері ортадан шетке ауысады.



```python
print(tokenize_v2("Ready? (yes) -- the answer's 42."))
print(tokenize_v2("He said 'hello'."))
print(tokenize_v2("Rating: 4/5. Cost-benefit: good."))
```


**Сақталған нәтиже:**

```text
['ready', 'yes', 'the', "answer's", '42']
['he', 'said', 'hello']
['rating', '4/5', 'cost-benefit', 'good']
```



Бір апостроф екі орында әртүрлі өңделеді: `answer's` ішінде сақталады, ал `'hello'` айналасындағы екі апостроф та жойылады. Сол сияқты `4/5` тұтас қалады, ал `(yes)` жақшаларынан айырылады.

Жоятын таңбалар тізімін ұзарту негізгі мәселені шешпейді. Функция үлкейеді, ерекше жағдайлардың себептерін есте сақтау қиындайды, ал токендердің өңделуі әлі де таңбаның орнына тәуелді болады.

Бұл тәсіл **нені жою керегін** сипаттайды. Пайдалырақ ереже **сөздің қандай болуы керегін** сипаттай алады.
