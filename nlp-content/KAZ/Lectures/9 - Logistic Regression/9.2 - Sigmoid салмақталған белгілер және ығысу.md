## Бағаны ықтималдыққа айналдырамыз

Салмақталған баға кез келген нақты сан болуы мүмкін: мысалы, -7, 0.3 немесе 42. Ықтималдық 0 мен 1 арасында болуы керек. **Sigmoid** функциясы бағаны осы аралыққа ауыстырады:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

`z` — баға. `e^{-z}` экспонентасы сол бағаға қарай өзгереді; оған 1 қосып, кері шамасын алғанда 0 мен 1 арасындағы мән шығады. Бұл нәтижені модельдің оң класқа берген ықтималдығы деп түсінеміз.

Келесі функция формуланы тікелей есептеп, бірнеше баға үшін ықтималдықтарды шығарады. Сақталған қисық осы тәуелділікті көрсетеді.



```python
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

for z in [-6, -2, -1, 0, 1, 2, 6]:
    print(f"score {z:3} -> probability {sigmoid(z):.3f}")
```


**Сақталған нәтиже:**

```text
score  -6 -> probability 0.002
score  -2 -> probability 0.119
score  -1 -> probability 0.269
score   0 -> probability 0.500
score   1 -> probability 0.731
score   2 -> probability 0.881
score   6 -> probability 0.998
```



```python
z = np.linspace(-8, 8, 200)

plt.figure(figsize=(6, 3.2))
plt.plot(z, sigmoid(z))
plt.axhline(0.5, color="grey", lw=0.8, ls="--")
plt.axvline(0, color="grey", lw=0.8, ls="--")
for s, label, offset in [(-4, "'terrible ... waste'", (8, 8)),
                         (0, "no opinion words", (8, -12)),
                         (3, "'excellent ... happy'", (8, -12))]:
    plt.scatter(s, sigmoid(s), zorder=3)
    plt.annotate(label, (s, sigmoid(s)), textcoords="offset points", xytext=offset, fontsize=8)
plt.xlabel("score  z = w·x + b"); plt.ylabel("P(positive)")
plt.title("The sigmoid squashes any score into (0, 1)")
plt.tight_layout()
plt.show()
```

## Белгілер, салмақтар және ығысу

Баға 0 болса, sigmoid 0.5 қайтарады: ешбір класқа басымдық жоқ. Үлкен оң бағалар ықтималдықты 1-ге, үлкен теріс бағалар 0-ге жақындатады. Бағаны 0-ден 2-ге өзгерту қатты әсер етеді: `0.500` мәнінен `0.881` мәніне. Бірақ үлкен оң бағаны, мысалы 6-дан 8-ге өсіру аз әсер етеді, себебі қисық 1 маңында жазықталады.

Толық модель:

$$P(\text{positive} \mid x) = \sigma(w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b)$$

- $x_i$ — осы пікірдегі `i` белгісінің TF-IDF мәні.
- $w_i$ — сол белгінің үйренілген салмағы; сөздіктегі әр сөздің өз салмағы бар.
- Әр белгіні өз салмағына көбейтіп, үлестерін қосамыз.
- $b$ — **ығысу**, sigmoid алдында қосылатын қосымша мән.
- Соңында жалпы бағаға sigmoid қолданып, оң класс ықтималдығын аламыз.

Ығысу — модельдің сөздерді оқымай тұрып беретін бастапқы басымдығы. Белгілер векторы бос болса, барлық сөз үлесі нөл, ал баға тек $b$ болады. Notebook мысалында дүкен пікірлерінің 80%-ы оң: орынды бастапқы басымдық оң жаққа бағытталады, сондықтан $b > 0$, ал теріс дәлел бағаны төмендетуі керек. Бұл оқу корпусы 50/50 теңгерілген, сондықтан дереккөз $b$ нөлге жақын болады деп күтеді.

Осы есептеуді есте сақтаңыз: келесі лекция дәл осы түрді **бір жасанды нейрон** деп атайды.
