## Бүкіл сөздіктің салмақтары мен ығысуын үйренеміз

Енді сол әдіс барлық TF-IDF белгісін қолданады: сөздіктегі әр сөзге бір салмақ және бөлек ығысу. Оң белгілер 1, теріс белгілер 0 болады.

120 пікірдің 25%-ы тестке қалады: 90 оқыту және 30 тест пікірі. `stratify=y` кластар теңгерімін сақтайды, `random_state=0` бөлуді қайталауға мүмкіндік береді. Векторизатор тек оқыту мәтіндеріне үйреніп, тест мәтіндерін сол үйренілген сөздікпен түрлендіреді.

`w` әр белгі үшін нөлден, `b` 0-ден басталады, ал `step_size=1.0` жаңарту өлшемін басқарады. Әр итерацияда код:

1. `X_tr @ w + b` есептеп, қазіргі оң ықтималдықтарды алу үшін sigmoid қолданады.
2. Дұрыс белгілерді шегеріп, `error` алады.
3. Әр салмақты оның белгісіне көбейтілген орташа қате бойынша жаңартады.
4. Ығысуды орташа қате бойынша жаңартады, өйткені ығысу әр пікірге әсер етеді.
5. Олардың өзгерісін салыстыру үшін loss, оқыту accuracy және тест accuracy мәндерін сақтайды.

Код өзгеріссіз сақталған. Атап айтқанда, `p` осы итерацияның жаңартуынан бұрын есептеліп, оқыту loss және accuracy мәндерін жазуға қолданылады; тест accuracy жаңартылған салмақтармен есептеледі. Түрлендіру кезінде ешбір ұяшық орындалмады.



```python
y = np.array([1 if l == "positive" else 0 for l in review_labels])

tr_txt, te_txt, y_tr, y_te = train_test_split(
    reviews, y, test_size=0.25, random_state=0, stratify=y
)

tfidf = TfidfVectorizer()
X_tr = tfidf.fit_transform(tr_txt).toarray()
X_te = tfidf.transform(te_txt).toarray()

w = np.zeros(X_tr.shape[1])   # one weight per word, all starting at zero
b = 0.0
step_size = 1.0
history = []

for step in range(1, 2001):
    p = sigmoid(X_tr @ w + b)                  # current predictions
    error = p - y_tr                           # how wrong, and in which direction
    w -= step_size * X_tr.T @ error / len(y_tr)
    b -= step_size * error.mean()

    loss = -np.mean(y_tr * np.log(p) + (1 - y_tr) * np.log(1 - p))
    train_acc = ((p > 0.5) == y_tr).mean()
    test_acc = ((sigmoid(X_te @ w + b) > 0.5) == y_te).mean()
    history.append((step, loss, train_acc, test_acc))
    if step in (1, 10, 100, 500, 1000, 2000):
        print(f"step {step:4}  loss {loss:.4f}  train acc {train_acc:.2f}  test acc {test_acc:.2f}")

print()
print("vocabulary:", X_tr.shape[1], "words   test set:", len(y_te), "reviews")
```
