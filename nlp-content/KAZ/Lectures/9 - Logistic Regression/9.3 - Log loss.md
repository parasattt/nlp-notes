## Ықтималдық қателерін log loss арқылы өлшейміз

Салмақтарды үйрену үшін модельге қазіргі ықтималдықтарының қаншалықты қате екенін көрсететін сан қажет. Дереккөз **log loss** қолданады:

$$\text{loss} = -\log(\text{probability the model gave to the correct answer})$$

Алдымен дұрыс класқа берілген ықтималдықты, содан кейін оның натурал логарифмін алып, таңбасын ауыстырамыз. Дұрыс жауаптың ықтималдығы жоғары болса, loss аз. Дұрыс жауаптың ықтималдығы өте төмен болса, loss үлкен.

«99% күн ашық болады» деп болжап, жаңбыр жауғанда қателескен синоптикті елестетіңіз. Бұл сол жаңбырдың алдында «50/50» деуден жаман. Екеуі де қате белгі беруі мүмкін, бірақ тек біріншісі сенімді түрде қателесті. Log loss осы айырманы ескереді. Келесі сақталған кесте дұрыс класс ықтималдығының әртүрлі мәндеріндегі нақты айыпты көрсетеді.



```python
for p_correct in [0.99, 0.9, 0.6, 0.5, 0.1, 0.01, 0.001, 0.0001, 0.00001, 0.000001, 0.0000001]:
    print(f"gave the correct class {p_correct:4} -> loss {-np.log(p_correct):.3f}")
```


**Сақталған нәтиже:**

```text
gave the correct class 0.99 -> loss 0.010
gave the correct class  0.9 -> loss 0.105
gave the correct class  0.6 -> loss 0.511
gave the correct class  0.5 -> loss 0.693
gave the correct class  0.1 -> loss 2.303
gave the correct class 0.01 -> loss 4.605
gave the correct class 0.001 -> loss 6.908
gave the correct class 0.0001 -> loss 9.210
gave the correct class 1e-05 -> loss 11.513
gave the correct class 1e-06 -> loss 13.816
gave the correct class 1e-07 -> loss 16.118
```



Дұрыс класс ықтималдығы 0.99 болса, loss небәрі 0.010. Ықтималдық 0.5 болса, loss 0.693. Ал 0.01 кезінде 4.605-ке өседі: бұл жаңбыр жауғандағы сенімді, бірақ қате «99% күн ашық» болжамы. Сақталған кесте `1e-07` мәніне дейін жалғасады; онда loss 16.118.

Демек, log loss жеңген кластың дұрыстығын да, сенімділікті де бағалайды. Оқыту салмақтарды өзгертіп, оқыту мысалдарындағы **орташа** loss мәнін азайтады.
