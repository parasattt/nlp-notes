`SOFTENING` дереккөздегі төрт ұяңданған соңғы дауыссызды ұсынылған қатаң нұсқаларына қайтарады. `kk_stem2` алдымен қосымшаларды жойып, кейін сәйкес соңғы дауыссызды өзгертеді. Код толық грамматикалық талдау жасамай, тізімдегі әріпті көрген сайын осы соңғы өзгерісті қолданады.

```python
# Undo consonant softening at the end of the stem.
SOFTENING = {"б": "п", "г": "к", "ғ": "қ", "д": "т"}

def kk_stem2(word, min_stem=3):
    stem = kk_stem(word, min_stem)
    if stem and stem[-1] in SOFTENING:
        stem = stem[:-1] + SOFTENING[stem[-1]]
    return stem


for w in kk_forms:
    print(f"{w:16} -> {kk_stem2(w)}")
```


**Сақталған нәтиже:**

```text
кітап            -> кітап
кітабы           -> кітап
кітаптар         -> кітап
кітаптарды       -> кітап
кітаптарым       -> кітап
кітапхана        -> кітапхана
кітаптарымызда   -> кітап
```



Көрсетілген кітап формалары енді ортақ `кітап` негізіне келеді, ал `кітапхана` бөлек қалады. Дереккөз «алты түрленген форма да енді сәйкес» дейді; сақталған тізімде `кітап` негізі, кітаптың тағы бес формасы және бөлек кітапхана сөзі бар.

## Ережелер қай жерде қателеседі?



Ереже жасауға қолданылған мысалдардан басқа сөздерді көріңіз. Дұрыс жоюларды, өзгермеген қосымша тізбектерін және қате кесілген түбірлерді салыстырыңыз.

```python
tricky = ["мектепте", "дүкеннен", "достарыма", "баламен", "алдым",
          "оқушы", "жұмысшы", "сауда", "пайда", "қала"]

for w in tricky:
    print(f"{w:12} -> {kk_stem2(w):12}")
```


**Сақталған нәтиже:**

```text
мектепте     -> мектеп      
дүкеннен     -> дүкен       
достарыма    -> достарыма   
баламен      -> баламен     
алдым        -> алдым       
оқушы        -> оқуш        
жұмысшы      -> жұмысш      
сауда        -> сау         
пайда        -> пай         
қала         -> қала        
```



Сақталған тізім үш нәтиже көрсетеді:

**Пайдалы өзгерістер:** `мектепте` («мектепте») сөзі `мектеп`, ал `дүкеннен` («дүкеннен») сөзі `дүкен` болады.

**Өзгеріс жоқ:** `достарыма`, `баламен` және `алдым` тұтас қалады. Олардың қосымша тізбектері ереже тізімінде жоқ, сондықтан сәтсіздік үнсіз өтеді.

**Сөздерді бұзу:**

- `оқушы` («оқушы») сөзі `оқуш`, ал `жұмысшы` («жұмысшы») сөзі `жұмысш` болады. Лекция `-шы`/`-ші` қосымшаларын әрекет иесін білдіретін зат есім жұрнақтары деп көрсетеді. Бірақ бағдарлама соңғы `-ы` таңбасын тізімдегі тәуелдік жалғауы деп жояды.
- `сауда` («сауда») сөзі `сау`, ал `пайда` («пайда») сөзі `пай` болады. Мұнда `да` түбірге тиесілі, бірақ тізімдегі жатыс септік жалғауына ұқсайды.

Бұл — `university` пен `universe` сөздерін біріктіргендей **артық қысқарту**. Сөзді өзгертпей қалдырудан да жаман болуы мүмкін: `сауда` («сауда») енді `сау` («дені сау») сөзімен бірдей болады.

Дереккөз `қала` («қала») сөзі `min_stem=3` арқасында сақталатынын, ал шекті азайту оны бұзатынын айтады. **Кодты оқу бойынша нақтылау:** берілген қосымша тізімінде `а` да, `ла` да жоқ. Сондықтан қазір тізімдегі еш қосымша `қала` сөзінің соңына сәйкес келмейді; тек шекті төмендету мұндай сәйкестікті қоспайды. Бастапқы код өзгермеген.

Әр қосымша ереже бір тізбекке көмектесіп, басқа жерде шынайы түбірді кесуі мүмкін.
