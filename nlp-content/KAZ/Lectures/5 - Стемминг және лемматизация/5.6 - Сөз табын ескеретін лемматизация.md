POS белгілеуі әр токенге сөйлемдегі контекстіне сай сөз табын тағайындайды. Сақталған тег тізбегі келесі екі ұяшыққа кіріс болады.

```python

sentence = "The striped bats were hanging on their feet and eating better mice"

tagged = nltk.pos_tag(word_tokenize(sentence))
print(tagged)
```


**Сақталған нәтиже:**

```text
[('The', 'DT'), ('striped', 'JJ'), ('bats', 'NNS'), ('were', 'VBD'), ('hanging', 'VBG'), ('on', 'IN'), ('their', 'PRP$'), ('feet', 'NNS'), ('and', 'CC'), ('eating', 'VBG'), ('better', 'JJR'), ('mice', 'NN')]
```



Көмекші функция NLTK тегтерінің басын WordNet күтетін POS тұрақтыларына сәйкестендіреді. Сын есім, етістік және үстеу тармақтарына кірмейтін тегтер зат есімге ауысады.

```python
from nltk.corpus import wordnet

def wordnet_pos(nltk_tag):
    """Translate an nltk POS tag into the single letter WordNet wants."""
    if nltk_tag.startswith("J"):
        return wordnet.ADJ
    if nltk_tag.startswith("V"):
        return wordnet.VERB
    if nltk_tag.startswith("R"):
        return wordnet.ADV
    return wordnet.NOUN          # the default, and the most common case
```



Әр токен үшін тек зат есім ретінде лемматизациялауды POS ескеретін лемматизациямен салыстырыңыз. Қосылған жебе жолдар айырмашылығын белгілейді.

```python
print(f"{'word':12}{'tag':6}{'naive':12}{'with POS':12}")
print("-" * 40)
for word, tag in tagged:
    naive = wnl.lemmatize(word.lower())
    smart = wnl.lemmatize(word.lower(), wordnet_pos(tag))
    flag = "  <--" if naive != smart else ""
    print(f"{word:12}{tag:6}{naive:12}{smart:12}{flag}")
```


**Сақталған нәтиже:**

```text
word        tag   naive       with POS    
------------------------------------------
The         DT    the         the         
striped     JJ    striped     striped     
bats        NNS   bat         bat         
were        VBD   were        be            <--
hanging     VBG   hanging     hang          <--
on          IN    on          on          
their       PRP$  their       their       
feet        NNS   foot        foot        
and         CC    and         and         
eating      VBG   eating      eat           <--
better      JJR   better      good          <--
mice        NN    mouse       mouse       
```



POS беру сақталған кестедегі төрт нәтижені өзгертеді: `were -> be`, `hanging -> hang`, `eating -> eat` және `better -> good`. Жебелер осы айырмашылықтарды көрсетеді.

`wordnet_pos` басы `J`, `V` не `R` болатын NLTK тегтерін WordNet сын есім, етістік немесе үстеу белгілеріне ауыстырады. Басқа тегтер әдепкі зат есімді қолданады. Мысал тек зат есім ретінде лемматизациялау неге маңызды өзгерістерді өткізіп алатынын көрсетеді.
