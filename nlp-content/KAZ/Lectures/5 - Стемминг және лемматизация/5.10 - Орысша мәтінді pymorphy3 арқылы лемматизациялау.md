## pymorphy3 арқылы лемматизация

Лекция `pymorphy3` құралын бірнеше миллион сөз формасы бар, сөздікке негізделген құрал ретінде көрсетеді. Ол лемма мен грамматикалық ақпарат қайтарады.



Дереккөз төменде қолданылатын орыс тілінің морфологиялық талдаушысын орнатады.

```python
!pip install pymorphy3 --quiet
print("done")
```


**Сақталған нәтиже:**

```text
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 53.9/53.9 kB 2.1 MB/s eta 0:00:00
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 8.4/8.4 MB 65.1 MB/s eta 0:00:00
done
```



`morph.parse(w)[0]` бағалау ретінде бірінші тұрған талдауды таңдайды. `normal_form` оның леммасын, ал `tag.POS` POS белгісін береді.

```python
import pymorphy3

morph = pymorphy3.MorphAnalyzer()

for w in ["ноутбука", "хорошего", "бежавшего", "покупкам", "работали"]:
    p = morph.parse(w)[0]
    print(f"{w:12} -> {p.normal_form:12} ({p.tag.POS})")
```


**Сақталған нәтиже:**

```text
ноутбука     -> ноутбук      (NOUN)
хорошего     -> хороший      (ADJF)
бежавшего    -> бежать       (PRTF)
покупкам     -> покупка      (NOUN)
работали     -> работать     (VERB)
```



Нәтижеде толық сөз формалары және POS белгілері бар. `бежавшего -> бежать` мысалы көрсетілген қосымша жою стеммері қалпына келтірмейтін өзгерісті көрсетеді.
