## Үш тілді салыстыру

Төменгі кесте лекциядағы салыстыру мен формалардың жуық сандарын сақтайды:

| | Ағылшын | Орыс | Қазақ |
|---|---|---|---|
| Бір сөздің формалары | аз (2–5) | көп (10–20) | өте көп (100+) |
| Токенизатор | `nltk`, `spaCy` | `razdel` | `razdel` (осы мысалдарға жеткілікті) |
| Стеммер | Porter, Snowball | Snowball `"russian"` | осы жаттығуда өзіңіз жазыңыз |
| Лемматизатор | WordNet, spaCy | `pymorphy3` | дереккөз салыстыруында дайын пакет жоқ |
| Stop сөз тізімі | `nltk` | `nltk` | осы жаттығуда өзіңіз жасаңыз |
| Subword баламасы | жұмыс істейді | жұмыс істейді | жұмыс істейді; кейде морфемаларға сай келеді |

Лекция құралдар айырмашылығын тіл қиындығымен емес, қолжетімді әзірлеу ресурстарымен, қаржымен және сөйлеушілер санымен байланыстырады. Практикалық сабақ — кітапхананың нақты мәтініңізге не істейтінін тексеру. Осы қазақша мысалдарда өңдеу тізбегінің көбірек бөлігін қолмен жазу керек.



`normalize(text, lang="en")` керекті тіл тармағын таңдайды. Ағылшын тармағы POS ескеретін WordNet леммаларын қолданады; орыс және қазақ тармақтары алдыңғы функцияларды шақырады. Қолдау көрсетілмейтін тіл `ValueError` қатесін шығарады. Ағылшын тармағы әріптік stop сөздерді қалдырады, ал орыс және қазақ тармақтары алдыңғы stop сүзгілерін қолданады; сақталған тізімдер осы айырмашылықты көрсетеді.

```python
# One normalisation function, three languages.
def normalize(text, lang="en"):
    if lang == "en":
        tagged = nltk.pos_tag(word_tokenize(text.lower()))
        return [wnl.lemmatize(w, wordnet_pos(t)) for w, t in tagged if w.isalpha()]
    if lang == "ru":
        return normalize_ru(text)
    if lang == "kk":
        return normalize_kk(text)
    raise ValueError(f"unsupported language: {lang}")


print("EN:", normalize("The batteries were draining very quickly", "en"))
print("RU:", normalize("Батареи ноутбуков разряжались очень быстро", "ru"))
print("KK:", normalize("Кітаптарды дүкеннен сатып алдым", "kk"))
```


**Сақталған нәтиже:**

```text
EN: ['the', 'battery', 'be', 'drain', 'very', 'quickly']
RU: ['батарея', 'ноутбук', 'разряжаться', 'очень', 'быстро']
KK: ['кітап', 'дүкен', 'сатып', 'алдым']
```

Үш сақталған нәтиже `batteries -> battery`, `Батареи -> батарея` және `Кітаптарды -> кітап` сияқты ортақ бастапқы формаларды көрсетеді. Жоғарыда аталған әртүрлі сүзгілеу ережелері де сақталған; ортақ интерфейс алдын ала өңдеуді өздігінен бірдей етпейді.
