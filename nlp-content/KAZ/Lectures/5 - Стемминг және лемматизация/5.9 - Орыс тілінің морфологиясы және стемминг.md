## Орыс тіліндегі сөз формалары

Лекция ағылшын тіліндегі салыстырмалы аз өзгеретін формаларды орыс тіліндегі алты септікпен, екі сан формасымен, қиысумен және етістіктің жіктелуімен салыстырады. Бір орысша зат есімнің шамамен он екі формасы бар деп сипаттайды.



Бұл жеті жол — бір орысша зат есімнің формалары. Кейінгі ережелер оларды біріктіріп, туыстас емес сөздерді біріктірмеуі керек.

```python
forms = ["ноутбук", "ноутбука", "ноутбуку", "ноутбуком", "ноутбуке", "ноутбуки", "ноутбуков"]
print("all of these are the same word:", forms)
```


**Сақталған нәтиже:**

```text
all of these are the same word: ['ноутбук', 'ноутбука', 'ноутбуку', 'ноутбуком', 'ноутбуке', 'ноутбуки', 'ноутбуков']
```



## Орысша мәтін стеммингі



Орысша Snowball ережелері зат есімнің жеті формасына да қолданылады.

```python
ru_stem = SnowballStemmer("russian")

for w in forms:
    print(f"{w:12} -> {ru_stem.stem(w)}")
```


**Сақталған нәтиже:**

```text
ноутбук      -> ноутбук
ноутбука     -> ноутбук
ноутбуку     -> ноутбук
ноутбуком    -> ноутбук
ноутбуке     -> ноутбук
ноутбуки     -> ноутбук
ноутбуков    -> ноутбук
```



Жеті форманың бәрі `ноутбук` түріне қысқарады. Бұл олардың іздеуде сәйкес келуіне жеткілікті. Басқа сөздер стеммингтің таныс шектеулерін көрсетеді:



Енді ортақ негізі толық сөз болмауы мүмкін басқа орысша сөздерді тексеріңіз.

```python
for w in ["хорошего", "бежавшего", "покупкам", "магазине", "работали"]:
    print(f"{w:12} -> {ru_stem.stem(w)}")
```


**Сақталған нәтиже:**

```text
хорошего     -> хорош
бежавшего    -> бежа
покупкам     -> покупк
магазине     -> магазин
работали     -> работа
```



`хорошего -> хорош` және `бежавшего -> бежа` толық сөз бермейді. Мұндай негіздер сәйкестендіруге пайдалы, бірақ оқуға түсінікті нәтиже үшін қолайсыз.
