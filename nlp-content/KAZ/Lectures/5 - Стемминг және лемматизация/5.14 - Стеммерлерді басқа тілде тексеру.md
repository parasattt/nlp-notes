## Бар құралдарды тексеру

Түрік тілі де түркі және агглютинативті болғандықтан, осы салыстыруда оның стеммерін тексеріп көру орынды. Бірінші кедергі: NLTK ішіндегі сақталған Snowball тілдер тізімінде түрік тілі жоқ.



Түрік тілін NLTK арқылы қолданбай тұрып, сақталған тіл қолдауы тізімін тікелей тексеріңіз.

```python
print("turkish available in nltk?", "turkish" in SnowballStemmer.languages)
```


**Сақталған нәтиже:**

```text
turkish available in nltk? False
```



Лекция Snowball жобасының жеке `snowballstemmer` пакетінде түрік стеммері бар екенін, бірақ NLTK оны бірге бермейтінін айтады.



Бөлек пакет келесі тексеруге түрік стеммерін береді.

```python
!pip install snowballstemmer --quiet
print("done")
```


**Сақталған нәтиже:**

```text
done
```



Түрік ережелерін жеті қазақша мысалға да қолданып, нәтиже тізімінің өзгермегенін ашық тексеріңіз.

```python
import snowballstemmer

kk_forms = ["кітап", "кітабы", "кітаптар", "кітаптарды",
            "кітаптарым", "кітапхана", "кітаптарымызда"]

tr = snowballstemmer.stemmer("turkish")

print("Turkish stemmer on Kazakh:")
for w, s in zip(kk_forms, tr.stemWords(kk_forms)):
    print(f"   {w:16} -> {s}")

print()
print("unchanged?", tr.stemWords(kk_forms) == kk_forms)
```


**Сақталған нәтиже:**

```text
Turkish stemmer on Kazakh:
   кітап            -> кітап
   кітабы           -> кітабы
   кітаптар         -> кітаптар
   кітаптарды       -> кітаптарды
   кітаптарым       -> кітаптарым
   кітапхана        -> кітапхана
   кітаптарымызда   -> кітаптарымызда

unchanged? True
```



Жеті қазақша жолдың бәрі өзгермейді. Стеммердің өзі жұмыс істейтінін тексеру үшін келесі ұяшық латын әліпбиіндегі түрік мәтінін береді.



Бұл шынайы түрік жолдары стеммер күтетін әліпбиде салыстыру жасауға мүмкіндік береді.

```python
print(tr.stemWords(["kitaplarımızda", "evler", "geliyorum"]))
```


**Сақталған нәтиже:**

```text
['kitap', 'ev', 'geliyor']
```



Түрік тілінде `kitaplarımızda` сөзі `kitap` болады; сақталған нәтиже `evler -> ev` және `geliyorum -> geliyor` өзгерістерін де көрсетеді. Лекция қазақшадағы сәтсіздікті әліпбимен түсіндіреді: түрік ережелері латын әріптерін, қазақша мысалдар кириллицаны қолданады.

Шақыру жеті жолды қатесіз қайтарды, бірақ ешқайсысы өзгерген жоқ. Тек өңдеу тізбегінің орындалуын тексерсеңіз, бұл сәтсіздік байқалмайды. Нормализатордың нақты мәтінмен не істегенін әрдайым қараңыз.

Келесі салыстыру ережелері кириллицаны қолданатын орысша стеммерді байқайды.



Әліпбидің сәйкес болуы жеткілікті ме екенін тексеру үшін бұрын құрылған орысша стеммерді дәл сол қазақша формаларға қолданыңыз.

```python
print("Russian stemmer on Kazakh:")
for w in kk_forms:
    print(f"   {w:16} -> {ru_stem.stem(w)}")
```


**Сақталған нәтиже:**

```text
Russian stemmer on Kazakh:
   кітап            -> кітап
   кітабы           -> кітаб
   кітаптар         -> кітаптар
   кітаптарды       -> кітаптард
   кітаптарым       -> кітаптар
   кітапхана        -> кітапха
   кітаптарымызда   -> кітаптарымызд
```



Енді орысша ережелер кейбір қазақша сөздерді бұзады. Мысалы, `кітапхана` («кітапхана») сөзі `кітапха` болады. Қазақша сөздің соңы орысша ереже жоятын жалғауға кездейсоқ ұқсайды.

Дереккөз **«`pip install kazakh-lemmatizer` жоқ»** деп, қазақ тілінде дайын NLP ресурстары азырақ екенін айтады. Мұны лекцияның өзі қарастырған құралдар туралы тұжырымы деп қабылдаңыз. Сондықтан жаттығуда қосымша ережелері өз қолымызбен жасалады.
