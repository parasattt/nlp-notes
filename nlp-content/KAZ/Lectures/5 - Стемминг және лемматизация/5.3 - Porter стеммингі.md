## Стемминг

**Стемминг** аффикстерді ережелермен жояды. Ол сөзді сөздіктен іздемейді және мағынасын тексермейді. Лекция 1980 жылы жасалған және практикада әлі қолданылатын **Porter стеммерін** таныстырады.



Цикл алты жолдың әрқайсысына Porter ережелерін бөлек қолданады. Қалыпты жалғау өзгерістерін, ерекше өткен шақ формасын және нақты сөз болмайтын негіздерді салыстырыңыз.

```python
from nltk.stem import PorterStemmer

ps = PorterStemmer()

for w in ["running", "runs", "ran", "studies", "studying", "happiness"]:
    print(f"{w:12} -> {ps.stem(w)}")
```


**Сақталған нәтиже:**

```text
running      -> run
runs         -> run
ran          -> ran
studies      -> studi
studying     -> studi
happiness    -> happi
```



- `running` пен `runs` екеуі де `run` болады, сондықтан енді сәйкес келеді.
- `ran` сол `ran` күйінде қалады. Онда дауысты өзгерген; ереже алып тастайтын қосылған жалғау жоқ.
- `studies` сөзі `studi` болады, ал бұл нақты сөз емес.

Стеммердің негізі оқуға жарамды сөз болуы міндетті емес. Мақсаты — сәйкес болуы керек формаларға бір жол беру.
