## Лемматизация

**Лемматизация** сөздік ақпаратын пайдаланып, сөздің **леммасын**, яғни сөздіктегі негізгі не бастапқы формасын табады. Лекция оның нәтижесін әрқашан нақты сөз деп сипаттап, көрсетілген стемминг ережелерінен айырмасы ретінде ерекше формаларды өңдейтінін айтады.



Мұнда POS аргументі берілмеген, сондықтан барлық шақыру WordNet әдепкі зат есім нұсқасын қолданады. Төмендегі сақталған нәтижелер дәл сол күйінде қалдырылған.

```python
from nltk.stem import WordNetLemmatizer

wnl = WordNetLemmatizer()

for w in ["studies", "mice", "feet", "geese", "better", "was"]:
    print(f"{w:10} -> {wnl.lemmatize(w)}")
```


**Сақталған нәтиже:**

```text
studies    -> study
mice       -> mouse
feet       -> foot
geese      -> goose
better     -> better
was        -> wa
```



`mice` сөзі `mouse`, ал `feet` сөзі `foot` болады. Тек жалғауды жою бұл өзгерістерді түсіндірмейді.

`better` сол `better` күйінде қалады. Дереккөз мәтінінде `was` сол `was` күйінде қалады делінген, бірақ жоғарыдағы сақталған нәтиже — `was -> wa`. Мысалды түсінгенде осы сәйкессіздікті ескеріңіз: әдепкі зат есім баптауы керекті `be` етістік леммасын бермейді.

## Сөз табы тұзағы

Басқа сөз табын (POS) бермесеңіз, `WordNetLemmatizer` сөзді **зат есім** деп есептейді.



Бірдей жолдарды зат есім, етістік (`"v"`) және сын есім (`"a"`) ретінде салыстырыңыз. Таңдалған POS ізделетін лемманы өзгертеді.

```python
print("as noun:", wnl.lemmatize("was"), "|", wnl.lemmatize("running"), "|", wnl.lemmatize("better"))
print("as verb:", wnl.lemmatize("was", "v"), "|", wnl.lemmatize("running", "v"), "|", wnl.lemmatize("better", "v"))
print("as adj :", wnl.lemmatize("better", "a"))
```


**Сақталған нәтиже:**

```text
as noun: wa | running | better
as verb: be | run | better
as adj : good
```



POS аргументі дұрыс берілгенде `was` сөзі `be`, `running` сөзі `run`, ал `better` сын есімі `good` болады. Бір жол қолданылуына қарай әртүрлі өңдеуді қажет етуі мүмкін.

Бұл кодта `"v"` етістік леммасын, ал `"a"` сын есім леммасын сұрайды. POS берілмесе, жарамсыз нәтиже үнсіз шығуы мүмкін. Келесі қадам лемматизациядан бұрын сөйлемнің сөз таптарын белгілейді.
