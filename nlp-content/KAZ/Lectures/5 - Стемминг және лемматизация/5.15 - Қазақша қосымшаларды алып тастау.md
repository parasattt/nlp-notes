## Қазақша қосымшаларды алып тастау

Лекция қосымшалардың жазылуы **дауыстылар үндестігіне** және алдындағы дауыссыздың ұяң не қатаң болуына тәуелді екенін түсіндіреді. Мысалы, көптік нұсқаларына `-лар`, `-тар` және `-дер` кіреді.

Код нұсқаларды тізіп, ең ұзын қосымшаларды бірінші тексереді және қалған негізді үш таңбадан қысқартпайды. Тізімдегі еш қосымшаны жою мүмкін болмай қалғанша, жоюды қайталайды.



Төмендегі толық қосымшалар тізімін сақтаңыз. Комментарийлер тәуелдік пен септіктің қосындысын, тәуелдікті, көптік пен табыс септікті, көптікті, ілік септікті, септік формаларын және үшінші жақ тәуелдікті топтайды. Ұзындығы бойынша кему ретімен сұрыптау ең ұзын нұсқаны бірінші қояды. Цикл бір рұқсат етілген қосымшаны жойып, іздеуді қайта бастайды; еш ереже қолданылмағанда тоқтайды. `min_stem=3` қалған ұзындықты қорғайды.

```python
KK_SUFFIXES = [
    # possessive + case, stacked (longest first)
    "ларымызда", "лерімізде", "тарымызда", "терімізде", "дарымызда", "дерімізде",
    # possessive
    "ларым", "лерім", "тарым", "терім", "дарым", "дерім",
    # plural + accusative
    "ларды", "лерді", "тарды", "терді", "дарды", "дерді",
    # plural
    "лар", "лер", "тар", "тер", "дар", "дер",
    # genitive
    "ның", "нің", "дың", "дің", "тың", "тің",
    # locative / ablative / dative / accusative
    "нан", "нен", "дан", "ден", "тан", "тен",
    "да", "де", "та", "те", "ға", "ге", "қа", "ке",
    "ды", "ді", "ты", "ті", "ны", "ні",
    # possessive (3rd person)
    "сы", "сі", "ы", "і",
]

KK_SUFFIXES = sorted(set(KK_SUFFIXES), key=len, reverse=True)


def kk_stem(word, min_stem=3):
    """Strip Kazakh suffixes, longest first. Repeats until nothing more comes off."""
    changed = True
    while changed:
        changed = False
        for suf in KK_SUFFIXES:
            if word.endswith(suf) and len(word) - len(suf) >= min_stem:
                word = word[: -len(suf)]
                changed = True
                break
    return word

```


**Сақталған нәтиже:**

```text
кітап            -> кітап
кітабы           -> кітаб
кітаптар         -> кітап
кітаптарды       -> кітап
кітаптарым       -> кітап
кітапхана        -> кітапхана
кітаптарымызда   -> кітап
```



`кітаптар`, `кітаптарды`, `кітаптарым` және `кітаптарымызда` бәрі `кітап` түріне қысқарады.

Екі жағдайға назар аудару керек:

- `кітабы` сөзі `кітаб` болады, ал керекті негіз — `кітап`. Лекция дауыстыдан басталған қосымшаның алдында соңғы `п` таңбасы `б` болып ұяңдануы мүмкін екенін түсіндіреді. Қосымшаны жою бұл өзгерісті кері қайтармайды.
- `кітапхана` өзгермей дұрыс қалады, өйткені «кітапхана» — жеке сөз. Бұл бағдарлама сөзді түсінгендіктен емес, `хана` қосымша тізімінде жоқ болғандықтан болады.

Дереккөз бұларды «екі қате нәтиже» деп атайды, бірақ екінші мысалдың дұрыс екенін өзі айтады. Жоғарыдағы айырмашылық екі бақылауды да сақтап, өзгермеген «кітапхана» формасын қате деп санамайды.
