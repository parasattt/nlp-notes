Тізбек кіші әріпке айналдыруды, `razdel` токендерін, NLTK орысша stop тізімін және `pymorphy3` бірінші талдауын біріктіреді. Өзгерістерді көру үшін бастапқы пікірді нормализацияланған нәтиженің қасында сақтаңыз.

```python
from razdel import tokenize as rz_tokenize
from nltk.corpus import stopwords

ru_stop = set(stopwords.words("russian"))

def normalize_ru(text):
    out = []
    for t in rz_tokenize(text.lower()):

ru_reviews = [
    "Купил новый ноутбук, работает отлично!",
    "Ноутбуки этой фирмы очень быстрые",
    "Батарея ноутбука разряжается за час",
    "Экран треснул через неделю",
]

for r in ru_reviews:
    print(f"{r}\n   -> {normalize_ru(r)}\n")
```

```text
   -> ['экран', 'треснуть', 'неделя']

```



Сұрау мен құжаттың нормализацияланған токен жиындарының қиылысуы бос болмаса, олар сәйкес келеді. Нәтиже тізімі толық бастапқы құжаттарды қайтарады.

```python
def search_ru(query, docs):
    q = set(normalize_ru(query))
    return [d for d in docs if q & set(normalize_ru(d))]

print("query: 'ноутбуки'")
for hit in search_ru("ноутбуки", ru_reviews):
    print("   ", hit)
```


**Сақталған нәтиже:**

```text
query: 'ноутбуки'
    Купил новый ноутбук, работает отлично!
    Ноутбуки этой фирмы очень быстрые
    Батарея ноутбука разряжается за час
```



`ноутбуки` сұрауы — көпше атау септік формасы. Ол 1-пікірдегі жекеше табыс септіктегі `ноутбук` және 3-пікірдегі ілік септіктегі `ноутбука` формаларына сәйкес келеді, өйткені нормализация үшеуін де `ноутбук` түріне келтіреді. Бастапқы жолмен іздеу тек 2-пікірді табады.

`normalize_ru` кіші әріпке айналдырады, `razdel` арқылы токенизациялайды, әріптен тұрмайтын токендер мен орысша stop сөздерді жояды, кейін `pymorphy3` бірінші талдауын алады. `search_ru` құжат жиыны мен сұрауда кемінде бір ортақ нормализацияланған токен болса, құжатты табады. `[0]` таңдауының екіұштылығы бәрібір сақталады.
