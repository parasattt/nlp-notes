## Қазақша шағын өңдеу тізбегі



Бұл шағын тізбек қолмен жасалған stop сөздер жиынын қолданады, өйткені дереккөз NLTK қазақша тізімін қолданбайды. Ол кіші әріпке айналдырады, `razdel` арқылы токенизациялайды, әріптік құрам мен ұзындықты тексереді, кейін толық емес қосымша ережелерін орындайды.

```python
from razdel import tokenize as rz_tokenize

# No Kazakh stop word list in nltk, so here is a small hand-made one.
KK_STOP = {"және", "бірақ", "мен", "бен", "пен", "да", "де", "та", "те",
           "бұл", "сол", "ол", "осы", "үшін", "кейін", "деп", "ғана"}

def normalize_kk(text):
    out = []
    for t in rz_tokenize(text.lower()):
        w = t.text
        if not w.isalpha() or w in KK_STOP or len(w) < 3:
            continue
        out.append(kk_stem2(w))
    return out


kk_reviews = [
    "Кітаптарды дүкеннен сатып алдым, өте жақсы",
    "Бұл кітап маған қатты ұнады",
    "Кітапханада көп кітаптар бар",
    "Телефонның батареясы тез бітеді",
]

for r in kk_reviews:
    print(f"{r}\n   -> {normalize_kk(r)}\n")
```


**Сақталған нәтиже:**

```text
Кітаптарды дүкеннен сатып алдым, өте жақсы
   -> ['кітап', 'дүкен', 'сатып', 'алдым', 'өте', 'жақ']

Бұл кітап маған қатты ұнады
   -> ['кітап', 'маған', 'қат', 'ұна']

Кітапханада көп кітаптар бар
   -> ['кітапхана', 'көп', 'кітап', 'бар']

Телефонның батареясы тез бітеді
   -> ['телефон', 'батарея', 'тез', 'біте']

```



Бұл үш тікелей шақыру келесі іздеу түсіндірмесінде қолданылатын кітап сөзінің ортақ негізін тексереді.

```python
print("кітаптарды  ->", kk_stem2("кітаптарды"))
print("кітап       ->", kk_stem2("кітап"))
print("кітаптар    ->", kk_stem2("кітаптар"))
```


**Сақталған нәтиже:**

```text
кітаптарды  -> кітап
кітап       -> кітап
кітаптар    -> кітап
```



`кітаптарды`, `кітап` және `кітаптар` енді ортақ `кітап` негізіне келеді. Сондықтан нормализацияланған сәйкестендіру кітапқа қатысты үш пікірдің бәрін таба алады.

Код лекциядағы шағын қолмен жасалған `KK_STOP` тізімін қолданып, әріптен тұрмайтын токендер мен үш таңбадан қысқа сөздерді тастайды, кейін `kk_stem2` шақырады. Сақталған нәтижелерде `жақ`, `қат` және `біте` сияқты жетілмеген негіздер де бар. Бұлар әр токен дұрыс лемма деген тұжырым емес, ереже шектеулерінің мысалдары.
