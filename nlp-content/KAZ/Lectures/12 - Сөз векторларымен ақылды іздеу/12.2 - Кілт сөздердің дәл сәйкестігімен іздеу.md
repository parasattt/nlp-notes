### Кілт сөзбен қарапайым іздеу

Шағын каталогтан бастайық. Тауар атауын сөздерге бөліп, оның сөздер жиыны сұрау сөздерімен қиылысса, тауарды қайтарамыз. Төмендегі код мысал каталогы мен іздеу функциясын толық қамтиды.



`words_of` кіші әріпке ауыстырып, ASCII әріп тізбектерін алады. `keyword_search` сұрау мен тауар сөздерін жиынға айналдырып, `&` арқылы ортақ сөз барын тексереді. Ол ортақ мағынаны емес, ортақ сөзді іздейді.

```python
catalogue = [
    "Grey three-seat couch with cushions",
    "Corner couch, beige fabric",
    "Oak dining table for six",
    "Leather recliner armchair",
    "Kitchen chair, set of 4",
    "Queen size mattress, memory foam",
    "Bookshelf with five shelves",
    "Glass coffee table",
]

def words_of(text):
    return re.findall(r"[a-z]+", text.lower())      # "Corner couch, beige" -> ["corner", "couch", "beige"]

def keyword_search(query, catalogue):
    q = set(words_of(query))
    return [p for p in catalogue if q & set(words_of(p))]    # & = words they have in common

for query in ["couch", "sofa", "table", "desk"]:
    print(f"{query!r:8} -> {keyword_search(query, catalogue)}")
```


**Сақталған нәтиже:**

```text
'couch'  -> ['Grey three-seat couch with cushions', 'Corner couch, beige fabric']
'sofa'   -> []
'table'  -> ['Oak dining table for six', 'Glass coffee table']
'desk'   -> []
```



Сақталған іздеу `couch` сұрауымен екі диван тауарын да табады, бірақ `sofa` үшін ештеңе таппайды. `desk` үшін де нәтиже жоқ.

Қолмен жасалған синоним тізімі кей жағдайды түзетер еді, бірақ барлық сұрауды қамти алмайды. Келесі мақсат — `sofa` және `couch` сөздерінің байланысын мәтіннен үйрену.
