Алып тастау тізімімен тек екі диван тауары қалады. Келесі тәжірибе кэшті тазалап, алғашқы `table` іздеуін өлшейді, кейін 1,000 қайталанған іздеудің орташа уақытын табады.



```python
search.cache.clear()
start = time.perf_counter()
search.search("table")
first = time.perf_counter() - start

start = time.perf_counter()
for _ in range(1000):
    search.search("table")
cached = (time.perf_counter() - start) / 1000

print(f"first time : {first * 1000:.1f} ms")
print(f"from cache : {cached * 1000:.3f} ms")
```


**Сақталған нәтиже:**

```text
first time : 3.3 ms
from cache : 0.001 ms
```



Сақталған алғашқы іздеу бірнеше миллисекунд, кэштен іздеу шамамен миллисекундтың мыңнан бір бөлігін алады. Клиент сұраулары қайталанғанда кэш пайдалы.

#### Іздеуді нақты сайтта қолданар алдында

- Шекті бір мысал сөзден емес, клиенттердің нақты іздеулерінен таңдаңыз.
- Кликке әкелмеген іздеулерді қарап, алып тастау тізімін толықтырыңыз.
- Модель өзгерген сайын оның тексерулерін қайта орындаңыз.
- Жұмыс, несие не баспана сияқты адамдарға әсер ететін қолданыстарда модельдің біржақтылығын тексеріңіз.
