### 4-қадам: жауаптан кейін векторларды өзгерту

$p$ — болжанған ықтималдық, $y$ — дұрыс белгі болсын: нақты жұпқа 1, жасанды жұпқа 0. Орталық векторды былай жаңартамыз:

$$v \leftarrow v - \eta \, (p - y) \, u$$

Жаңартуды ретімен оқыңыз:

1. $p-y$ қатесін есептеңіз.
2. Қатені $u$ көрші векторына көбейтіңіз.
3. Өзгерісті қадам өлшемін беретін $\eta$ оқыту жылдамдығына көбейтіңіз.
4. Осы өзгерісті ескі $v$ орталық векторынан азайтыңыз.

Бұл — курстағы градиенттік түсу ойы: қатені азайту үшін параметрлерді аздап өзгерту.

- $p=0.3$ болатын **нақты** жұп үшін қате $= 0.3 - 1 = -0.7$. Теріс өзгерісті азайту $v$ векторын $u$ жағына жылжытып, келесі скаляр көбейтіндіні үлкейтеді.
- $p=0.8$ болатын **жасанды** жұп үшін қате $= 0.8 - 0 = +0.8$. Өзгеріс $v$ векторын $u$ векторынан алшақтатады.

Келесі код төрт қадамды он екі сөйлемде біріктіреді.

Жаңарту [[KAZ/Lectures/9 - Logistic Regression/9.4 - Екі белгі арқылы градиенттік түсу|екі белгімен градиенттік түсу]] тәсіліне сүйенеді.



Шағын код бес өлшемді векторларды, әр нақты жұпқа үш жасанды көршіні және 0.05 оқыту жылдамдығын қолданады. Жасанды сөз ықтималдықтары жиіліктің 0.75 дәрежесіне пропорционал. `v_old` көрші векторын жаңартқанда орталық вектордың жаңартуға дейінгі мәнін пайдалануға мүмкіндік береді.

```python
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

print("sigmoid of -2, 0, 2:", sigmoid(np.array([-2, 0, 2])))

index = {w: i for i, w in enumerate(vocab)}
pairs = [(index[w], index[s[j]])                                       # step 1
         for s in toy for i, w in enumerate(s)
         for j in range(max(0, i - WINDOW), min(len(s), i + WINDOW + 1)) if j != i]
print("training pairs:", len(pairs), " first three:", [(vocab[c], vocab[o]) for c, o in pairs[:3]])

rng = np.random.default_rng(0)
DIM, NEGATIVES, LR = 5, 3, 0.05
v = rng.normal(0, 0.5, (len(vocab), DIM))      # centre vectors: random at the start
u = rng.normal(0, 0.5, (len(vocab), DIM))      # neighbour vectors

# how often each word is picked as a fake: frequency to the power 0.75, as in Word2Vec
freq = np.bincount([o for _, o in pairs], minlength=len(vocab)) ** 0.75
noise = freq / freq.sum()

def sims(vectors):
    return {f"{a}/{b}": round(float(cosine(vectors[index[a]], vectors[index[b]])), 2)
            for a, b in [("pizza", "burger"), ("waiter", "waitress"), ("pizza", "waiter"), ("delicious", "rude")]}

print("before training:", sims(v))

for epoch in range(300):                       # one epoch = one pass over all pairs
    for c, o in rng.permutation(pairs):
        fakes = rng.choice(len(vocab), NEGATIVES, p=noise)            # step 3
        for target, label in [(o, 1)] + [(f, 0) for f in fakes]:
            p = sigmoid(v[c] @ u[target])                             # step 2
            error = p - label
            v_old = v[c].copy()
            v[c] -= LR * error * u[target]                            # step 4
            u[target] -= LR * error * v_old

print("after training :", sims(v))
```


**Сақталған нәтиже:**

```text
sigmoid of -2, 0, 2: [0.12 0.5  0.88]
training pairs: 128  first three: [('the', 'pizza'), ('the', 'was'), ('pizza', 'the')]
before training: {'pizza/burger': -0.39, 'waiter/waitress': -0.1, 'pizza/waiter': -0.14, 'delicious/rude': 0.41}
after training : {'pizza/burger': 1.0, 'waiter/waitress': 0.99, 'pizza/waiter': 0.68, 'delicious/rude': 0.63}
```



Сақталған ұқсастықтар басында кездейсоқ. Жұптар бойынша 300 өтуден кейін `pizza`/`burger` және `waiter`/`waitress` мәндері 1-ге жуық; `pizza`/`waiter` және `delicious`/`rude` төменірек.

Оқыту деректері еш сөздің мағынасын тікелей айтпайды. Модель тек нақты көрші жұптарды кездейсоқ жұптардан ажыратуға тырысады. Көршілері ұқсас сөздердің векторлары да ұқсас болады.
