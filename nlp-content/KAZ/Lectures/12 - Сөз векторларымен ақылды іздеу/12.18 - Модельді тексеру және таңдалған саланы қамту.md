### Модельді анық күтілімдермен тексереміз

Модельді таңдамас бұрын жоспарланған қолдануға сай болуы тиіс қатынастарды жазыңыз. Келесі код жақын болуы тиіс жұптарды, алыс жұптарды және аналогия жауаптарын тексереді. Әр тексеру сәтті өтуді, қатені немесе белгісіз сөз үшін өткізіп жіберуді көрсетеді.



Жақын жұптардың ұқсастығы 0.5-тен жоғары, алыс жұптардыкі 0.3-тен төмен болуы керек. Аналогия тексеруі болжанған астананы күтілетін сөзбен салыстырады. Сөздікте жоқ сөз сәтті тест болып саналмас үшін белгісіз сөздер өткізіліп жіберілді деп көрсетіледі.

```python
# kind "close":   similarity must be above 0.5
# kind "far":     similarity must be below 0.3
# kind "analogy": france : paris = a : expected
CHECKS = [
    ("close",   "sofa",       "couch",     None),
    ("close",   "waiter",     "server",    None),
    ("far",     "sofa",       "banana",    None),
    ("far",     "cheap",      "expensive", None),
    ("far",     "good",       "bad",       None),
    ("analogy", "kazakhstan", None,        "astana"),
    ("analogy", "japan",      None,        "tokyo"),
]

def run_checks(kv, name):
    print(name)
    for kind, a, b, expected in CHECKS:
        if a not in kv or (b and b not in kv):
            print(f"  SKIP  {a} / {b}: unknown word")
            continue
        if kind == "analogy":
            got = analogy("france", "paris", a, kv)
            ok, detail = got == expected, f"capital of {a}: got {got}, expected {expected}"
        else:
            s = kv.similarity(a, b)
            ok = s > 0.5 if kind == "close" else s < 0.3
            detail = f"{a} / {b} should be {kind}: {s:.2f}"
        print(f"  {'PASS' if ok else 'FAIL'}  {detail}")

run_checks(glove, "GloVe")
run_checks(yelp_vectors, "Yelp Word2Vec")
```


**Сақталған нәтиже:**

```text
GloVe
  PASS  sofa / couch should be close: 0.68
  FAIL  waiter / server should be close: 0.07
  PASS  sofa / banana should be far: 0.22
  FAIL  cheap / expensive should be far: 0.77
  FAIL  good / bad should be far: 0.77
  FAIL  capital of kazakhstan: got almaty, expected astana
  PASS  capital of japan: got tokyo, expected tokyo
Yelp Word2Vec
  PASS  sofa / couch should be close: 0.83
  PASS  waiter / server should be close: 0.94
  PASS  sofa / banana should be far: 0.27
  FAIL  cheap / expensive should be far: 0.68
  FAIL  good / bad should be far: 0.69
  SKIP  kazakhstan / None: unknown word
  FAIL  capital of japan: got carlo, expected tokyo
```



#### Тексерулерді түсіндіреміз

- **Екі модель де қарама-қарсы сөздерді жақындатады.** `cheap`/`expensive` және `good`/`bad` қателері шағын мысалдағы ортақ контекст шектеуін қайталайды.
- **GloVe `waiter`/`server` үшін 0.07 береді.** Оның жаңалықтар мен Wikipedia деректерінде `server` жиі компьютерге қатысты. Бір вектор сол мағыналарды араластырады. Қазақстан астанасы аналогиясы да күтілген дұрыс жауапты бермейді.
- **Yelp Word2Vec синоним тексерулерінен өтеді**, бірақ Жапония астанасына Monte Carlo-мен байланысты `carlo` деп жауап береді. Мейрамхана пікірлері астана аналогияларын үйренуге нашар материал.

Модельдің білімі оқыған мәтініне тәуелді. Жиһаз дүкені үшін келесі тексеру — клиент іздейтін сөздерді модель біле ме?



```python
furniture_queries = ["sofa", "couch", "armchair", "recliner", "bookshelf", "wardrobe",
                     "dresser", "nightstand", "ottoman", "mattress", "headboard", "loveseat"]

for name, kv in [("GloVe", glove), ("Yelp Word2Vec", yelp_vectors)]:
    missing = [w for w in furniture_queries if w not in kv]
    print(f"{name:14} knows {len(furniture_queries) - len(missing):2} of {len(furniture_queries)}   missing: {missing}")
```


**Сақталған нәтиже:**

```text
GloVe          knows 12 of 12   missing: []
Yelp Word2Vec  knows  8 of 12   missing: ['armchair', 'recliner', 'bookshelf', 'headboard']
```



GloVe тексерілген он екі жиһаз сөзінің бәрін қамтиды. Yelp моделінде төртеуі жоқ: `armchair`, `recliner`, `bookshelf` және `headboard`. Мейрамхана пікірлері жиһаз туралы сирек айтады, ал векторлық модель сөздіктен тыс сөзді кеңейте алмайды.

Сондықтан мысал осы каталогқа GloVe таңдайды, бірақ қатысты сөздер мен қарама-қарсылықтар нашар кеңейту бере алатынын естен шығармайды.

Лекция осы GloVe моделінде қазақ сөздері жоқ дейді. Қазақша жаттығуға сол оқыту барысымен қазақ мәтінінде векторларды үйретуді ұсынады.
