### Алдын ала оқытылған модельді қолданамыз

Мұнда үйретілген модель тек мейрамхана пікірлерін оқыды. Миллиардтаған сөзде оқыту көбірек есептеу ресурсын қажет етеді. **Алдын ала оқытылған модель** — басқа топ үйретіп, бөліскен дайын модель.

Дереккөз **GloVe** (Stanford, 2014) қолданады: Wikipedia мен жаңалықтардан алты миллиард сөз, 400,000 сөзден тұратын сөздік және әр векторға 100 мән. GloVe Word2Vec-тен басқаша оқытылады, бірақ векторларын сол іздеу мен ұқсастық функцияларымен қолдануға болады.

Дереккөз 128 MB модельді және шамамен 30 секундтық жүктеуді сипаттайды. Келесі код жарияланған файлдарды жүктеп, бірнеше сөзді қарайды.



```python
base = "https://huggingface.co/fse/glove-wiki-gigaword-100/resolve/main/"
for name in ["glove-wiki-gigaword-100.model", "glove-wiki-gigaword-100.model.vectors.npy"]:
    if not os.path.exists(name):
        urllib.request.urlretrieve(base + name, name)

glove = KeyedVectors.load("glove-wiki-gigaword-100.model")
print(f"{len(glove):,} words, {glove.vector_size} numbers each")

for word in ["sofa", "almaty", "apple", "python"]:
    print(f"{word:7} -> {', '.join(w for w, _ in glove.most_similar(word, topn=8))}")
```


**Сақталған нәтиже:**

```text
400,000 words, 100 numbers each
sofa    -> couches, sofas, recliner, cushions, upholstered, couch, mattress, pillows
almaty  -> ashgabat, ulan, bator, ashkhabad, kazakhstan, dushanbe, kazakstan, kazakh
apple   -> microsoft, ibm, intel, software, dell, pc, macintosh, iphone
python  -> monty, php, perl, cleese, flipper, ruby, spamalot, javascript
```



GloVe ішінде `sofa` көршілеріне `couches`, `sofas` және `couch` кіреді; бұлар іздеу міндетіне пайдалы.

`apple` және `python` мысалдары шектеуді көрсетеді. `apple` жемістен гөрі компьютер компанияларына жақын. `python` бағдарламалау тілдері мен Monty Python-ға жақын. Әр сөзде **бір вектор** бар, сондықтан әртүрлі қолданыстары араласады, ал жиі қолданыстар көбірек ықпал етеді.
