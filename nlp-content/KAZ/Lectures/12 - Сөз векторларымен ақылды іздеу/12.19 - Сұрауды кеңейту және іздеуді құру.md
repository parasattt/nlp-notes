### Тауарды іздемес бұрын сұрауды кеңейтеміз

**Сұрауды кеңейту** іздеудің алдында сұрауға жақын сөздерді қосады. Мысал көршіні косинустық ұқсастығы кемінде **0.65** болғанда ғана қабылдайды. Бұл шекара — **шек (threshold)**.

Қайта қолданылатын `SynonymSearch` класы бірнеше таңдауды анық көрсетеді:

- Модельді бір рет жүктеп, класқа беру; әр сұрауда қайта жүктемеу.
- Сөз белгісіз болса, оны кеңейтпей іздеу.
- Ұпайы шектен өтсе де, қажетсіз көршіні қоспау үшін **алып тастау тізімін** қолдану.
- Кеңейту нәтижесін есте сақтау үшін **кэш** қолдану. `most_similar` 400,000 вектормен салыстырады, сондықтан қайталанған сөз бұрынғы жауапты қолдануы керек.
- Класс құрылғанда тауар атауларын бір рет сөздерге бөлу.

Төменде толық іске асыру мен сақталған іздеу нәтижелері берілген.



`expand` алдымен кэшті тексеріп, бастапқы сөзді қалдырады, кейін `topn=20` үміткерінің ішінен рұқсат етілген көршілерді қосады. `search` кеңейтулерді біріктіріп, конструкторда дайындалған тауар сөздері жиындарымен қиылысуын тексереді.

```python
class SynonymSearch:
    def __init__(self, vectors, catalogue, threshold=0.65, topn=20, block=()):
        self.vectors = vectors
        self.catalogue = catalogue
        self.threshold = threshold
        self.topn = topn
        self.block = set(block)
        self.product_words = [set(words_of(p)) for p in catalogue]   # cut each product name once
        self.cache = {}

    def expand(self, word):
        if word in self.cache:                       # answered before: reuse
            return self.cache[word]
        terms = [word]
        if word in self.vectors:                     # unknown word: no expansion
            terms += [w for w, s in self.vectors.most_similar(word, topn=self.topn)
                      if s >= self.threshold and w not in self.block]
        self.cache[word] = terms
        return terms

    def search(self, query):
        terms = {t for w in words_of(query) for t in self.expand(w)}
        return [p for p, words in zip(self.catalogue, self.product_words) if words & terms]

search = SynonymSearch(glove, catalogue)
print("terms for 'sofa':", search.expand("sofa"))
print()
for query in ["sofa", "desk", "sofaaa"]:
    print(f"{query!r:9} -> {search.search(query)}")
print()
print("nearest to 'desk':", [(w, round(s, 2)) for w, s in glove.most_similar("desk", topn=3)])
```
