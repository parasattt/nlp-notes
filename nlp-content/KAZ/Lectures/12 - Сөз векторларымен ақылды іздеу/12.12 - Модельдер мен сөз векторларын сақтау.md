### Бір рет оқытып, кейін іздеу үшін жүктейміз

Оқыту уақыт алады, ал іздеу сұрауына жылдам жауап керек. Әр сұрауда қайта оқытпай, үйретілген нысандарды файлға сақтап, сервис іске қосылғанда жүктеңіз.

`w2v.wv` тек сөз векторларын — шағын модельдегі $v$ орталық векторларын — қамтиды. Осы іздеу мысалына сол жеткілікті.



Бірінші сақтау толық, әрі қарай оқытуға болатын модельді қалдырады. Екіншісі тек сөз векторларын сақтайды. `size_mb` ортақ префиксі бар барлық файлды санайды, өйткені gensim үлкен массивтерді қосымша файлдарға сақтауы мүмкін.

```python
w2v.save("yelp_w2v.model")                  # everything, so training can continue later
w2v.wv.save("yelp_vectors.kv")              # only the word vectors

def size_mb(prefix):
    # gensim may write big arrays to extra files with the same name prefix
    return sum(os.path.getsize(f) for f in os.listdir(".") if f.startswith(prefix)) / 1e6

print(f"full model  : {size_mb('yelp_w2v.model'):.1f} MB")
print(f"vectors only: {size_mb('yelp_vectors.kv'):.1f} MB")

from gensim.models import KeyedVectors
yelp_vectors = KeyedVectors.load("yelp_vectors.kv")
print(f"loaded {len(yelp_vectors):,} word vectors")
```


**Сақталған нәтиже:**

```text
full model  : 16.8 MB
vectors only: 8.7 MB
loaded 20,184 word vectors
```



Тек векторлары бар сақталған файлдар толық модельден шамамен екі есе кіші. Толық модельде $u$ көрші векторлары да бар: олар оқытуды жалғастыруға қажет, бірақ бұл іздеуге қажет емес.
