### Сөз векторларымен арифметика

Вектор айырмасы қатынастарды көрсете алады. Мысалда `man` сөзінен `woman` сөзіне ауысу `king` сөзінен `queen` сөзіне ауысуға ұқсайды:

$$v_{\text{king}} - v_{\text{man}} + v_{\text{woman}} \approx v_{\text{queen}}$$

Мұнда $v_{\text{word}}$ — сол сөздің векторы. `king` векторынан бастап, `man` векторын азайтыңыз, `woman` векторын қосыңыз, кейін жақын сөздік сөзін табыңыз. Бұл — **сөздік аналогия**.

Gensim ішіндегі `most_similar(positive=[...], negative=[...])` шақыруы қосу мен азайтуды орындайды. Төмендегі көмекші функция $b-a+c$ маңынан іздеп, «a-ның b-ға қатынасы c-ның неге қатынасына ұқсайды?» деп сұрайды.



Әр аналогияда `positive=[b, c]` екі векторды қосады, `negative=[a]` бір векторды азайтады. `topn=1` жалғыз ең жақын жауапты қайтарады.

```python
def analogy(a, b, c, kv=glove):
    # a is to b as c is to ?   ->   b - a + c
    return kv.most_similar(positive=[b, c], negative=[a], topn=1)[0][0]

print("man : king    = woman :", analogy("man", "king", "woman"))
print("walk : walked = swim  :", analogy("walk", "walked", "swim"))
print("france : paris = kazakhstan :", analogy("france", "paris", "kazakhstan"))
print("man : doctor  = woman :", analogy("man", "doctor", "woman"))
```


**Сақталған нәтиже:**

```text
man : king    = woman : queen
walk : walked = swim  : swam
france : paris = kazakhstan : almaty
man : doctor  = woman : nurse
```



Алғашқы екі сақталған жауап — `queen` және `swam` — мысал сұраған қатынастарға сәйкес.
