### Алдымен деректерді қарап шығыңыз

Нәтиже есептемей тұрып жаңа деректерді шолыңыз. Басын, соңын, өлшемін, баған атауларын, типтерді және жетіспейтін мәндерді тексеру үшін `head()`, `tail()`, `shape` және `info()` құралдарынан бастаңыз.



```python
df.head(3)        # first 3 rows. df.head() defaults to 5.
```


**Сақталған нәтиже:**

```text
   review_id product  rating                                                    review  verified
0          1  laptop       5  Excellent laptop, fast and quiet. Battery lasts all day.      True
1          2  laptop       1     Screen died after three weeks. Support was unhelpful.      True
2          3   phone       4               Good phone for the price, camera is decent.     False
```



```python
df.tail(2)        # last rows - useful for spotting junk at the end of files
```


**Сақталған нәтиже:**

```text
    review_id product  rating                                                 review  verified
10         11   phone       3         It is fine. Nothing special, nothing terrible.      True
11         12  tablet       5  Fantastic build quality and the display is beautiful.      True
```



```python
df.shape          # (rows, columns)
```


**Сақталған нәтиже:**

```text
(12, 5)
```



```python
df.info()         # column names, types, and how many non-missing values each has
```


**Сақталған нәтиже:**

```text
<class 'pandas.DataFrame'>
RangeIndex: 12 entries, 0 to 11
Data columns (total 5 columns):
 #   Column     Non-Null Count  Dtype
---  ------     --------------  -----
 0   review_id  12 non-null     int64
 1   product    12 non-null     str  
 2   rating     12 non-null     int64
 3   review     12 non-null     str  
 4   verified   12 non-null     bool 
dtypes: bool(1), int64(2), str(2)
memory usage: 528.0 bytes
```



`info()` әсіресе пайдалы: ол әр бағанның **dtype**, яғни дерек типін және жетіспейтін емес мәндер санын көрсетеді. Күтпеген типтер pandas ішінде көп түсініксіз мәселе туғызады.

Бастапқы түсіндірмеде `review` және `product` типі `object` деп көрсетілетіні айтылған. Бұл бұрынғы pandas орталарында мәтін үшін жиі қолданылған белгі. **Алайда осы notebook сақталған нәтижесі екі бағанға да `str` көрсетеді**, әрі pandas нұсқасы `3.0.5` деп сақталған. Түсіндірмедегі dtype атауын күтпей, нақты сақталған нәтижені оқыңыз. Бұл мысалда екі баған да мәтіннен тұрады.



```python
df.describe()     # summary statistics for the numeric columns only
```


**Сақталған нәтиже:**

```text
       review_id     rating
count  12.000000  12.000000
mean    6.500000   3.333333
std     3.605551   1.556998
min     1.000000   1.000000
25%     3.750000   2.000000
50%     6.500000   3.500000
75%     9.250000   5.000000
max    12.000000   5.000000
```



```python
df.columns        # the column names
```


**Сақталған нәтиже:**

```text
Index(['review_id', 'product', 'rating', 'review', 'verified'], dtype='str')
```

Сақталған шолу нәтижелері 12 жол мен 5 бағанды және бастапқы бағандарда жетіспейтін мән жоқ екенін көрсетеді. `head(3)` алғашқы үш жолды, `tail(2)` соңғы екеуін береді. `describe()` сандық бағандардың статистикасын шығарады: мысалы, орташа баға шамамен **3.33**, ал бағалар 1-ден 5-ке дейін. `columns` бес бағанның атауын тізеді.
