### Жетіспейтін деректер

Нақты деректерде жетіспейтін мәндер болады. Pandas оларды `NaN` не басқа маркерлермен көрсете алады. Оларды кейінгі есептерге не модельге байқамай өткізе бермей, қалай өңдеуді шешу керек.



```python
import numpy as np

df2 = df.copy()
df2.loc[2, "review"] = None
df2.loc[5, "rating"] = np.nan
df2[["review_id", "review", "rating"]].head(7)
```


**Сақталған нәтиже:**

```text
   review_id                                                    review  rating
0          1  Excellent laptop, fast and quiet. Battery lasts all day.     5.0
1          2     Screen died after three weeks. Support was unhelpful.     1.0
2          3                                                       NaN     4.0
3          4            Battery drains far too quickly, disappointing.     2.0
4          5         Perfect for reading and taking notes. Very light.     5.0
5          6                Does the job but the keyboard feels cheap.     NaN
6          7    Best phone I have owned. Fast, great screen, worth it.     5.0
```

`df.copy()` жетіспейтін деректер тәжірибесіне бөлек кесте жасайды. `.loc[2, "review"] = None` бір пікір мәнін, ал `.loc[5, "rating"] = np.nan` бір жолдағы бағалау мәнін бос етеді. Сақталған кестеде бұл орындар `NaN` деп көрсетіледі; осы көшірмеде бағалар бөлшек сандар түрінде беріледі.



```python
df2.isna().sum()          # count missing values per column
```


**Сақталған нәтиже:**

```text
review_id      0
product        0
rating         1
review         1
verified       0
char_count     0
word_count     0
is_positive    0
excited        0
shouty         0
dtype: int64
```



```python
df2.dropna(subset=["review"]).shape    # drop rows with no review text
```


**Сақталған нәтиже:**

```text
(11, 10)
```



```python
df2["review"].fillna("")   # or fill the gap with an empty string
```


**Сақталған нәтиже:**

```text
0     Excellent laptop, fast and quiet. Battery lasts all day.
1        Screen died after three weeks. Support was unhelpful.
2                                                             
3               Battery drains far too quickly, disappointing.
4            Perfect for reading and taking notes. Very light.
5                   Does the job but the keyboard feels cheap.
6       Best phone I have owned. Fast, great screen, worth it.
7                      Stopped charging within a month. Avoid.
8           Nice tablet overall, though the speakers are weak.
9          Overheats under any real load. Not worth the money.
10              It is fine. Nothing special, nothing terrible.
11       Fantastic build quality and the display is beautiful.
Name: review, dtype: str
```

`.isna().sum()` бір пікір мен бір бағалау мәнінің жетіспейтінін көрсетеді. `.dropna(subset=["review"])` пікір мәтіні бар жолдарды қалдырып, **(11, 10)** сақталған пішімін береді. `.fillna("")` жетіспейтін мәні бос жолға ауысқан пікір Series нұсқасын көрсетеді.

Соңғы екі өрнек нәтижені қайтарады, бірақ оны `df2` мәніне кері меншіктемейді. Осы түрлендіруді сақтау үшін қайтарылған нәтижені сақтау керек.



Жою не толтыруды жауап беріп жатқан сұрағыңызға қарай таңдаңыз:

- Жолды **жою** ойдан мәтін қоспайды, бірақ деректі жоғалтады.
- **Толтыру** жолды қалдырады, бірақ бос жол сияқты сіз таңдаған мәнді қояды.

Жетіспейтін мәндерді модельге байқамай жібермеңіз. Олар қате туғызуы немесе нәтижені білдірмей бұрмалауы мүмкін.
