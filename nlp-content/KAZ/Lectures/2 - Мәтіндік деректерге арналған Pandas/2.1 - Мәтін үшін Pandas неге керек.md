### Алдымен pandas шешетін мәселе

Pandas пайдасы түсінікті болуы үшін кәдімгі Python шешімінен бастайық. Төмендегі шағын деректер — сөздіктер тізімі, ал сұрақ: **әр тауардың орташа бағасы қандай?**



```python
reviews = [
    {"id": 1, "text": "Great product, works perfectly", "rating": 5, "product": "laptop"},
    {"id": 2, "text": "Broke after two days", "rating": 1, "product": "laptop"},
    {"id": 3, "text": "Good value for the money", "rating": 4, "product": "phone"},
    {"id": 4, "text": "Terrible, do not buy", "rating": 1, "product": "phone"},
    {"id": 5, "text": "Exactly as described", "rating": 5, "product": "tablet"},
]

# Question: what is the average rating per product?
totals = {}
counts = {}
for r in reviews:
    p = r["product"]
    totals[p] = totals.get(p, 0) + r["rating"]
    counts[p] = counts.get(p, 0) + 1

for p in totals:
    print(p, round(totals[p] / counts[p], 2))
```


**Сақталған нәтиже:**

```text
laptop 3.0
phone 2.5
tablet 5.0
```

Цикл әр пікірдің бағасын сол тауардың жалпы бағасына қосып, пікір санын бірге арттырады. Бөлу сақталған орташа мәндерді береді: **ноутбук үшін 3.0**, **телефон үшін 2.5**, **планшет үшін 5.0**. Мұнда Python негіздеріндегі [[KAZ/Lectures/1 - Мәтінмен жұмыс істеуге арналған Python негіздері/1.11 - Сөздіктер|сөздікпен санау үлгісі]] қолданылады.



Кәдімгі Python шешімі екі сөздік сақтайды: бірінде бағалар қосындысы, екіншісінде сандар бар, кейін қосындыларды сандарға бөледі. Осындай шағын сұрақтың өзі бірнеше жолды және қателесудің бірнеше мүмкіндігін қажет етеді.

Келесі ұяшық сол сұрақты pandas арқылы шешеді.



```python
import pandas as pd

df = pd.DataFrame(reviews)
df.groupby("product")["rating"].mean()
```


**Сақталған нәтиже:**

```text
product
laptop    3.0
phone     2.5
tablet    5.0
Name: rating, dtype: float64
```

`pd.DataFrame(reviews)` жазбалар тізімін кестеге айналдырады. `groupby("product")` жолдарды тауар бойынша бөледі, `["rating"]` олардың бағаларын таңдайды, ал `.mean()` әр топтың орташа мәнін табады. Сақталған нәтижелер қолмен жазылған нұсқамен сәйкес келеді.



Деректер DataFrame ішінде болса, `df.groupby("product")["rating"].mean()` сұраққа бір жолмен жауап береді. Сұрақтар күрделенген сайын артықшылығы арта түседі.
