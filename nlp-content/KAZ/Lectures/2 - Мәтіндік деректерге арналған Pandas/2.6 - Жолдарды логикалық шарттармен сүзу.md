### Жолдарды сүзу

Сүзу шартқа сәйкес жолдарды қалдырады. Алдымен `True` және `False` мәндерінің бағанын құрыңыз, содан кейін `True` жолдарын қалдыру үшін оны `df[...]` ішінде қолданыңыз.



```python
# A comparison on a column gives a column of True/False
df["rating"] >= 4
```


**Сақталған нәтиже:**

```text
0      True
1     False
2      True
3     False
4      True
5     False
6      True
7     False
8      True
9     False
10    False
11     True
Name: rating, dtype: bool
```



```python
# Feed that back into the DataFrame to keep only the True rows
good = df[df["rating"] >= 4]
good
```


**Сақталған нәтиже:**

```text
    review_id product  rating                                                    review  verified
0           1  laptop       5  Excellent laptop, fast and quiet. Battery lasts all day.      True
2           3   phone       4               Good phone for the price, camera is decent.     False
4           5  tablet       5         Perfect for reading and taking notes. Very light.      True
6           7   phone       5    Best phone I have owned. Fast, great screen, worth it.      True
8           9  tablet       4        Nice tablet overall, though the speakers are weak.     False
11         12  tablet       5     Fantastic build quality and the display is beautiful.      True
```



```python
# Combine conditions with & (and) and | (or).
# Each condition MUST be wrapped in its own parentheses.
df[(df["rating"] >= 4) & (df["product"] == "phone")]
```


**Сақталған нәтиже:**

```text
   review_id product  rating                                                  review  verified
2          3   phone       4             Good phone for the price, camera is decent.     False
6          7   phone       5  Best phone I have owned. Fast, great screen, worth it.      True
```

`df["rating"] >= 4` **логикалық маска** жасайды: әр жолға бір шешім. `df[mask]` сәйкес жолдарды қалдырады; сақталған деректерде осы баға шегіне алты пікір сәйкес келеді. Оны `product == "phone"` шартымен біріктірсеңіз, телефон туралы екі жоғары бағалы пікір қалады.



Баған шарттарын біріктіргенде екі ереже маңызды:

- «Және» үшін `&`, «немесе» үшін `|` қолданыңыз. Python ішіндегі `and` және `or` жеке логикалық мәндерді біріктіреді, ал мұнда тұтас бағандардың шарттарын біріктіру керек.
- **Әр шартты жақшаға алыңыз**. `&` сияқты операторлардың басымдығы `==` операторынан жоғары, сондықтан жақшалар болмаса, Python өрнекті басқаша түсініп, түсініксіз қате беруі мүмкін.
