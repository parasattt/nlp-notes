```python
# When there is no built-in method, .apply() runs your own function on every row
def has_exclamation(text):
    return "!" in text

df["excited"] = df["review"].apply(has_exclamation)

# Same thing written inline with a lambda
df["shouty"] = df["review"].apply(lambda t: sum(1 for c in t if c.isupper()) > 3)

df[["review", "excited", "shouty"]]
```

`has_exclamation()` кемінде бір `!` бар-жоғын тексереді. Lambda бас әріптерді санап, олардың саны үштен көп пе деп тексереді. `.apply()` осы ережелерді әр пікірге қолданады. Бұл деректердегі `excited` және `shouty` барлық сақталған мәндері — `False`.



`.apply()` бағанның әр мәніне өз функцияңызды іске қосады. Сәйкес дайын операция болмағанда оны қолданыңыз. Notebook мүмкіндігінше дайын `.str` әдістерін ұсынады, себебі `.apply()` баяуырақ болуы мүмкін; дегенмен дұрыс жұмыс жылдамдықтан маңызды.
