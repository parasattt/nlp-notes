### Файлдарды оқу және жазу

Іс жүзінде деректер Python сөздігі ретінде емес, **CSV файлы** түрінде жиі келеді. Келесі ұяшықтар кестені сақтайды, файлдың бастапқы түрін қарап, қайта жүктейді.



```python
df.to_csv("reviews.csv", index=False)
print("saved")
```


**Сақталған нәтиже:**

```text
saved
```

`to_csv()` қазіргі кестені, соның ішінде есептелген белгі бағандарын жазады. `!head -3 reviews.csv` — тақырып пен алғашқы екі дерек жолын көрсететін shell командасы. Бірінші пікір тырнақшаға алынған, себебі мәтініндегі үтір баған бөлгіші болып қабылданбауы керек.



`index=False` pandas жол индексін CSV ішіне қосымша баған етіп жазбауын қамтамасыз етеді. Индексті қателесіп сақтап, қайта оқығанда кәдімгі дерек деп қабылдасаңыз, `Unnamed: 0` сияқты артық баған пайда болуы мүмкін.

`pd.read_csv("reviews.csv")` сақталған файлды `loaded` ішіне жүктейді. Алғашқы үш жол бастапқы бағандардың, қосылған санақтардың және логикалық белгілердің CSV ішіне жазылғанын көрсетеді.



`read_csv()` көптеген параметрді қолдайды. Дереккөз мына пайдалы параметрлерді бөледі:

```python
pd.read_csv("file.csv",
            encoding="utf-8",   # or "latin-1", "cp1251" for some older files
            sep=",",            # "\t" for TSV files
            nrows=1000)         # read only the first N rows - do this first on a big file
```

- `encoding` pandas файл байттарын таңбаларға қалай айналдыру керегін айтады.
- `sep` бөлгішті көрсетеді; TSV файлдары табуляцияны қолданады.
- `nrows` үлкен файлды жүктемей тұрып, оның шағын бастапқы бөлігін қарауға мүмкіндік береді.
