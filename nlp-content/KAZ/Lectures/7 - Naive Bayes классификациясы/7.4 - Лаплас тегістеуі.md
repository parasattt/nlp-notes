## Тікелей көбейтудің екі мәселесі

Қолмен жазылған классификатор негізгі ойды көрсетеді. Бірақ бұл тікелей нұсқаны сенімсіз ететін екі мәселе бар: нөлдік сөз ықтималдығы барлық дәлелді жоя алады, ал ұзын көбейтінді компьютерде сақтауға тым кіші болуы мүмкін.



### Нөлдік ықтималдық басқа сөздердің әсерін жояды



```python
classify_by_hand("free money tomorrow")
```


**Сақталған нәтиже:**

```text
message   : free money tomorrow
spam score: 0.0000000000
ham score : 0.0000000000
verdict   : ham

```



Екі ұпай да нөл болғандықтан, шыққан `ham` шешімінің пайдасы жоқ. Код `>` шартын қолданады; екі нөл тең болғанда `else` тармағын таңдайды.

`tomorrow` оқыту спамында кездеспеген, сондықтан $P(\text{tomorrow} \mid \text{spam}) = 0$. Осы нөлге көбейту `free` және `money` берген дәлелді жояды. Ham үшін де бұл сөздердің ықтималдығы нөл, сондықтан оның ұпайы да нөл болады.

Шектеулі оқыту жиыны әр сөзді әр класта көрсете алмайды. Мұндай жағдай жиі болады. Сондықтан «осы класта байқалмаған» мен «осы класта болуы мүмкін емес» ұғымдарын ажырату қажет.



## Лаплас бойынша тегістеу

**Лаплас бойынша тегістеу**, яғни аддитивті тегістеу, сөздіктегі әр сөздің кездесу санына шағын қосымша қосады. Notebook ішіндегі `alpha=1` кезінде әр сөз әр класта тағы бір рет кездескендей есептейміз:

$$P(w \mid c) = \frac{\text{count}(w, c) + \alpha}{\text{total words in } c + \alpha \times |V|}$$

- `w` — сөз, ал `c` — класс, мысалы spam.
- `count(w, c)` — сол сөздің осы класта кездесу саны.
- `alpha` — сөздіктегі әр сөз санына қосылатын шама.
- `|V|` — ортақ сөздіктегі әртүрлі сөздер саны.
- Бөлімге `alpha × |V|` қосылады, өйткені сөздіктегі әр сөз үшін бір рет `alpha` қостық. Осылай жеке сандар мен жалпы сан бір-біріне сәйкес қалады.

Мұнда сөздікте 26 сөз бар. Spam үшін бөлім `18 + 1 × 26 = 44` болады. Енді `free` ықтималдығы `(3 + 1) / 44 = 4/44`, `money` ықтималдығы `3/44`, ал спамда кездеспеген `tomorrow` ықтималдығы нөлдің орнына `1/44` болады. Оның болмауы spam ықтималдығын азайтады, бірақ spam класын мүмкін емес етпейді.

Келесі код ортақ сөздік құрып, сол көбейтуге негізделген классификаторда тегістелген ықтималдықты қолданады.



```python
vocabulary = set(spam_words) | set(ham_words)
V = len(vocabulary)
ALPHA = 1.0

def p_smoothed(word, counts, total):
    return (counts[word] + ALPHA) / (total + ALPHA * V)

def classify_smoothed(message, verbose=True):
    words = message.split()
    score_spam, score_ham = p_spam, p_ham
    for w in words:
        score_spam *= p_smoothed(w, spam_counts, len(spam_words))
        score_ham  *= p_smoothed(w, ham_counts,  len(ham_words))
    verdict = "spam" if score_spam > score_ham else "ham"
    if verbose:
        print(f"{message}")
        print(f"  spam: {score_spam:.12f}   ham: {score_ham:.12f}   -> {verdict}")
    return verdict
print("vocabulary size:", V)
print()
classify_smoothed("free money tomorrow")
classify_smoothed("send the report tomorrow")
```


**Сақталған нәтиже:**

```text
vocabulary size: 26

free money tomorrow
  spam: 0.000070435763   ham: 0.000015410537   -> spam
send the report tomorrow
  spam: 0.000000133401   ham: 0.000006030210   -> ham
```


**Сақталған нәтиже:**

```text
'ham'
```



Сақталған нәтиже енді `free money tomorrow` хабарламасын spam деп белгілейді. Оның spam ұпайы `0.5 × (4/44) × (3/44) × (1/44) = 0.000070435763`. Ham есебі `20 + 26 = 46` бөлімін пайдаланып, `0.000015410537` береді, сондықтан spam жеңеді. `send the report tomorrow` үшін әлі де ham жеңеді.

Мұнда `tomorrow` ортақ сөздікте бар, бірақ spam класында кездеспеген. Тегістеу осы нөлдік санның дәлелді әлсіретуіне мүмкіндік береді, алайда бүкіл көбейтіндіні жоймайды.
