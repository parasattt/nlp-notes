## Көпшілік классқа негізделген бастапқы болжаммен салыстырамыз

Нақты поштада spam мен ham саны тең болуы міндетті емес. Кіріс хабарламаларының тек 10%-ы спам делік. Келесі мысал 2 spam және 18 ham арқылы accuracy кіші кластағы толық сәтсіздікті қалай жасыратынын көрсетеді.



```python
imbalanced_texts = spam_samples[:2] + ham_samples + ham_samples[:3]
imbalanced_labels = ["spam"] * 2 + ["ham"] * (len(ham_samples) + 3)

print("class balance:", Counter(imbalanced_labels))

class AlwaysHam:
    def predict(self, texts):
        return ["ham"] * len(texts)

lazy = AlwaysHam()
lazy_pred = lazy.predict(imbalanced_texts)

print()
print("accuracy of a model that just says 'ham' every time:",
      round(accuracy_score(imbalanced_labels, lazy_pred), 3))
```


**Сақталған нәтиже:**

```text
class balance: Counter({'ham': 18, 'spam': 2})

accuracy of a model that just says 'ham' every time: 0.9
```



`AlwaysHam` бірде-бір спамды ұстамайды, бірақ accuracy мәні `18 / 20 = 0.9`. Жалғыз ережесі — әр хабарлама үшін `ham` қайтару.

Бұл деректерде accuracy 90% деудің өзі аз ақпарат береді. Бастапқы салыстыру деңгейі жорамалданған 50% емес, **ең жиі кластың үлесі**, яғни 90%. Пайдалы модельді осы деңгеймен де, маңызды қателермен де бағалау керек.



```python
print(classification_report(imbalanced_labels, lazy_pred, zero_division=0))
```


**Сақталған нәтиже:**

```text
              precision    recall  f1-score   support

         ham       0.90      1.00      0.95        18
        spam       0.00      0.00      0.00         2

    accuracy                           0.90        20
   macro avg       0.45      0.50      0.47        20
weighted avg       0.81      0.90      0.85        20

```



Класс есебі сәтсіздікті көрсетеді: spam recall мәні **0.00**, өйткені екі спам хабарламасының ешқайсысы ұсталмаған. Сақталған есепте spam precision және F1 де нөл. Жалпы accuracy-ге ғана сүйенбей, әр класты тексеріңіз.
