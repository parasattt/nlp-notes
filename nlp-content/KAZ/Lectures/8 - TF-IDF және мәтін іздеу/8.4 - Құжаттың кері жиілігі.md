## Құжат жиілігін кері құжат жиілігіне айналдырамыз

`the` барлық 3 құжатта, `battery` 2 құжатта, ал сөздіктің қалған сөздері 1 құжатта кездеседі. Азырақ құжатта бар сөз бір құжатты басқасынан ажыратуға пайдалырақ.

**Құжаттың кері жиілігі**, немесе IDF, осындай сирек сөздерге үлкенірек салмақ береді:

$$\text{idf}(w) = \log \frac{N}{\text{df}(w)}$$

- `w` — салмағын тапқымыз келетін сөз.
- $N$ — барлық құжаттар саны.
- `df(w)` — осы сөз бар құжаттар саны.
- Сөз сиреген сайын `N / df(w)` артады.
- Логарифм қатынас шамасын кішірейтеді, бірақ сирек сөздердің салмағын жиі сөздерден жоғары сақтайды.

### Логарифм не үшін қажет?

Келесі кесте 1,000 пікірі бар дүкенді елестетеді. Бірнеше құжат жиілігі үшін бастапқы қатынас пен оның натурал логарифмін салыстырыңыз.



```python
N_shop = 1000
table = pd.DataFrame({"df": [1, 10, 100, 500, 1000]})
table["N / df"] = N_shop / table["df"]
table["log(N / df)"] = np.log(table["N / df"]).round(2)
print(table.to_string(index=False))
```


**Сақталған нәтиже:**

```text
  df  N / df  log(N / df)
   1  1000.0         6.91
  10   100.0         4.61
 100    10.0         2.30
 500     2.0         0.69
1000     1.0         0.00
```



1,000 пікірдің біреуіндегі сөз үшін `N / df = 1000`, он пікірдегі сөз үшін `N / df = 100` болады. Қатынас **10-ға 1**. Бастапқы абзацта «100 есе сирек» және «салмағы 100 есе үлкен» делінген, бірақ өз кестесі он есе айырманы көрсетеді.

Логарифмсіз бір рет кездескен сөз не `batery` сияқты қате жазу өте үлкен сиректік салмағын алар еді. Логарифм ретті сақтап, арақашықтықты азайтады: `1000` шамамен `6.9` болады, `100` шамамен `4.6` болады.

IDF-ті күтпегендікті өлшеу деп елестетіңіз. `the` сөзін көру қай пікірді оқып тұрғаныңыз туралы аз ақпарат береді. `cracked` сияқты ерекше сөз әлдеқайда көп айтады. Сақталған график құжат жиілігі өскен сайын IDF төмендейтінін көрсетеді.



График құжат жиілігін логарифмдік осьте көрсетіп, сирек және жиі сөздерді бірге көруге мүмкіндік береді. Белгілер қате жазуды, `cracked`, `is` және `the` сөздерін мысал жиіліктеріне орналастырады.

```python
df_range = np.arange(1, N_shop + 1)

plt.figure(figsize=(6, 3.2))
plt.plot(df_range, np.log(N_shop / df_range))
for d, label in [(1, "a typo"), (10, "'cracked'"), (500, "'is'"), (1000, "'the'")]:
    plt.scatter(d, np.log(N_shop / d), zorder=3)
    plt.annotate(label, (d, np.log(N_shop / d)), textcoords="offset points", xytext=(6, 6))
plt.xscale("log")
plt.ylim(-0.5, 8)
plt.xlabel("document frequency (log scale)")
plt.ylabel("idf")
plt.title("IDF falls as a word gets more common (N = 1000)")
plt.tight_layout()
plt.show()
```

Сол оқу формуласын үш құжаттық корпусқа қолданайық. Келесі нәтиже әр сөздің IDF мәнін кішіден үлкенге қарай көрсетеді.

```python
idf_naive = np.log(N / df)

print(pd.Series(idf_naive, index=vocab).round(3).sort_values())
```
