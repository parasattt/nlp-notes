## Қайта қолданылатын алдын ала өңдеу тізбегі



Бұл функция алдын ала өңдеу таңдауларын параметрлер арқылы ашық көрсетеді. Үш шақыру тек stop сөздерді өңдеуді өзгертеді және алынған көріністің есепке сай болуы керегін көрсетеді.

```python
def preprocess(text, lowercase=True, remove_stop=True, keep_negations=True,
               min_length=2, language="english"):
    """Turn raw text into tokens, with the choices made explicit."""
    if lowercase:
        text = text.lower()

    tokens = word_tokenize(text)
    tokens = [t for t in tokens if t.isalpha()]

    if remove_stop:
        stops = set(stopwords.words(language))
        if keep_negations:
            stops = stops - NEGATIONS
        tokens = [t for t in tokens if t not in stops]

    tokens = [t for t in tokens if len(t) >= min_length]
    return tokens


sample = "I did NOT like the battery life, but the screen is absolutely beautiful!!"

print("default        :", preprocess(sample))
print("keep stop words:", preprocess(sample, remove_stop=False))
print("drop negations :", preprocess(sample, keep_negations=False))
```


**Сақталған нәтиже:**

```text
default        : ['not', 'like', 'battery', 'life', 'screen', 'absolutely', 'beautiful']
keep stop words: ['did', 'not', 'like', 'the', 'battery', 'life', 'but', 'the', 'screen', 'is', 'absolutely', 'beautiful']
drop negations : ['like', 'battery', 'life', 'screen', 'absolutely', 'beautiful']
```



Таңдаулар әртүрлі болғандықтан, бір сөйлемнен үш токен тізімі шығады. `lowercase` үлкен-кіші әріпті өзгертуді; `remove_stop` stop сөз сүзгісін; `keep_negations` тізімдегі терістеулерді қорғауды басқарады; `min_length` қысқа токендерді жояды; `language` NLTK stop сөздер тізімін таңдайды. `isalpha()` тек әріптерден тұратын токендерді қалдырады.

Әдепкі нұсқа `not` сөзін сақтайды, ал `keep_negations=False` оны жояды. `remove_stop=False` баптауы stop сөздерді сақтайды, бірақ әдепкі ең аз ұзындық бір әріптік `I` токенін бәрібір алып тастайды. Әр баптау әртүрлі есепке жарауы мүмкін. Таңдаулардың көрініп тұруы тізбекті тексеру мен қатесін түзетуді жеңілдетеді.
