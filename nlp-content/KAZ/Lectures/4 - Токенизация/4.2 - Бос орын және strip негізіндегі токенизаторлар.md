## Бос орын таңбалары бойынша бөлу

`.split()` жолды бос орын таңбалары бойынша бөледі. Бұл таза сөйлемге жақсы келеді. Негізгі жол операциялары [[KAZ/Lectures/1 - Мәтінмен жұмыс істеуге арналған Python негіздері/1.9 - Мәтінді бөлу және біріктіру|Python негіздері лекциясында]] түсіндіріледі.



```python
text = "Natural language processing is useful"
print(text.split())
```


**Сақталған нәтиже:**

```text
['Natural', 'language', 'processing', 'is', 'useful']
```



Енді шынайырақ жолды көріңіз.



```python
messy = "Dr. Smith didn't pay $19.99 for the U.S.A. trip... Wasn't that great?! :) #nlp @ai_lab"

print(messy.split())
```


**Сақталған нәтиже:**

```text
['Dr.', 'Smith', "didn't", 'pay', '$19.99', 'for', 'the', 'U.S.A.', 'trip...', "Wasn't", 'that', 'great?!', ':)', '#nlp', '@ai_lab']
```



Нәтижеде бірнеше мәселе бар:

- `great?!` пен `trip...` ішінде тыныс белгілері әлі жабысып тұр. Олар `great` пен `trip` токендерінен бөлек болады.
- `didn't` бір токен болуы керек пе, әлде екеу ме? Мұны есеп анықтайды.
- `:)` тұтас қалды. Бұл пайдалы, өйткені смайлик эмоциялық реңкті жеткізеді.

Жабысып қалған тыныс белгілері сөз санақтарын байқатпай жаңылыстыруы мүмкін.



```python
reviews = "great! great. great great?! GREAT"
print(Counter(reviews.split()))
```


**Сақталған нәтиже:**

```text
Counter({'great!': 1, 'great.': 1, 'great': 1, 'great?!': 1, 'GREAT': 1})
```



Бір сөз бес рет аталған, бірақ санағыш әрқайсысы 1 рет кездескен бес бөлек жолды көрсетеді.



## Екінші әрекет: тыныс белгілерін шеттерінен алу



`tokenize_v2` бос орын таңбалары бойынша бөледі, әр токеннің шетінен тізімдегі таңбаларды жояды, бос емес нәтижелерді кіші әріпке айналдырады және ештеңе қалмаған токендерді тастайды. Токеннің ішіндегі тыныс белгілерін жоймайды.

```python
def tokenize_v2(text):
    tokens = []
    for word in text.split():
        word = word.strip('.,!?;:"()[]{}-\'')
        if word:
            tokens.append(word.lower())
    return tokens

print(tokenize_v2(reviews))
print()
print(tokenize_v2(messy))
```


**Сақталған нәтиже:**

```text
['great', 'great', 'great', 'great', 'great']

['dr', 'smith', "didn't", 'pay', '$19.99', 'for', 'the', 'u.s.a', 'trip', "wasn't", 'that', 'great', '#nlp', '@ai_lab']
```



Енді `great` сөзінің бес нұсқасы да бірдей, бірақ өзгеріс басқа мәселелер туғызады:

- `:)` толық жоғалады. Ол тек тыныс белгілерінен тұрғандықтан, тазалаудан кейін бос жол қалады.
- `u.s.a.` соңғы нүктесінен айырылады. Енді `u.s.a.` түрінде жазылған басқа токенге сәйкес келмейді.

Бір мысалды түзететін ереже екіншісін бұзуы мүмкін. Деректерге лайық жасалған токенизатордан бастаған дұрысырақ.
