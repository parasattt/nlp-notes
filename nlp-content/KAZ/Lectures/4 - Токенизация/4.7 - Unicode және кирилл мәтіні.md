## Ағылшын тілінен басқа мәтін



Қазақша және орысша мысал жолдар келесі салыстыруларға бірге сақталады. Бірінші regex тек латын ASCII әріптерін қолданады.

```python
kk = "Мен дүкеннен екі жаңа кітап сатып алдым. Достарыма бердім! Олар қуанды."
ru = "Мы купили два новых ноутбука в магазине. Они работали отлично!"

print("ascii pattern [a-zA-Z]+ on Kazakh:", re.findall(r"[a-zA-Z]+", kk))
```


**Сақталған нәтиже:**

```text
ascii pattern [a-zA-Z]+ on Kazakh: []
```



ASCII өрнегі осы қазақша мәтінге қате не ескерту шығармай, бос тізім қайтарады. Оны қолданатын өңдеу тізбегі қазақша құжаттардан еш токен алмай-ақ жалғаса беруі мүмкін.

`\w+` Unicode сөз таңбаларын таниды және осы мысалдарда екі әліпбиді де өңдейді. Бұл [[KAZ/Lectures/3 - Мәтінді талдау және Regex/3.4 - Unicode таңбаларын қолдайтын токендер|Unicode қолдайтын regex токендерінде]] түсіндірілген айырмашылықтың өзі.



Unicode қолдайтын regex-ті екі тілге де қолданып, нақты шыққан токендерді салыстырыңыз.

```python
print("KK:", re.findall(r"\w+", kk))
print()
print("RU:", re.findall(r"\w+", ru))
```


**Сақталған нәтиже:**

```text
KK: ['Мен', 'дүкеннен', 'екі', 'жаңа', 'кітап', 'сатып', 'алдым', 'Достарыма', 'бердім', 'Олар', 'қуанды']

RU: ['Мы', 'купили', 'два', 'новых', 'ноутбука', 'в', 'магазине', 'Они', 'работали', 'отлично']
```



Үлкен-кіші әріпті өзгерту кириллицада да, соның ішінде бастапқы жолдағы қазақ тіліне тән әріптерде де жұмыс істейді.

```python
# Lowercasing works on Cyrillic, including Kazakh-specific letters.
print("ӘЛЕМ САЛЕМ Ұлы Қазақстан".lower())
```


**Сақталған нәтиже:**

```text
әлем салем ұлы қазақстан
```
