## NLTK токенизаторлары

`nltk` — бірнеше токенизаторы бар, көптен қолданылып келе жатқан NLP кітапханасы. Notebook оның Colab-та дайын бар екенін айтады; басқа ортада орнату командасы — `pip install nltk`.



Дайындық сөйлем токенизаторының `punkt` және `punkt_tab` ресурстарын және stop сөздер тізімдерін жүктейді. Бастапқы комментарий қайта іске қосқанда бар ресурстар өткізілетінін түсіндіреді; сақталған нұсқа — NLTK 3.9.2.

```python
import nltk

# Safe to re-run, it skips anything already present.
nltk.download("punkt", quiet=True)
nltk.download("punkt_tab", quiet=True)
nltk.download("stopwords", quiet=True)

print("nltk", nltk.__version__)
```


**Сақталған нәтиже:**

```text
nltk 3.9.2
```



Бұл салыстыру бір `messy` жолын қолмен жазылған токенизаторға және үш NLTK нұсқасына береді. Әрқайсысы қандай бірліктерді сақтайтынын не бөлетінін қараңыз.

```python
from nltk.tokenize import word_tokenize, wordpunct_tokenize, TweetTokenizer

print("ours    :", tokenize_v2(messy))
print()
print("wordpunct:", wordpunct_tokenize(messy))
print()
print("nltk     :", word_tokenize(messy))
print()
print("tweet    :", TweetTokenizer().tokenize(messy))
```


**Сақталған нәтиже:**

```text
ours    : ['dr', 'smith', "didn't", 'pay', '$19.99', 'for', 'the', 'u.s.a', 'trip', "wasn't", 'that', 'great', '#nlp', '@ai_lab']

wordpunct: ['Dr', '.', 'Smith', 'didn', "'", 't', 'pay', '$', '19', '.', '99', 'for', 'the', 'U', '.', 'S', '.', 'A', '.', 'trip', '...', 'Wasn', "'", 't', 'that', 'great', '?!', ':)', '#', 'nlp', '@', 'ai_lab']

nltk     : ['Dr.', 'Smith', 'did', "n't", 'pay', '$', '19.99', 'for', 'the', 'U.S.A.', 'trip', '...', 'Was', "n't", 'that', 'great', '?', '!', ':', ')', '#', 'nlp', '@', 'ai_lab']

tweet    : ['Dr', '.', 'Smith', "didn't", 'pay', '$', '19.99', 'for', 'the', 'U', '.', 'S', '.', 'A', '.', 'trip', '...', "Wasn't", 'that', 'great', '?', '!', ':)', '#nlp', '@ai_lab']
```



Төрт токен тізімін мұқият салыстырыңыз:

- **`wordpunct_tokenize`** сөздер мен тыныс белгілерін бөлек топтарға бөледі. Нәтижесі болжамды, бірақ `didn't` жолын `didn` + `'` + `t` етіп, ал `19.99` жолын `19` + `.` + `99` етіп бөледі.
- **`word_tokenize`** — лекцияның жалпы бастапқы таңдауы. Мұнда `Dr.`, `U.S.A.` және `19.99` тұтас сақталады. `didn't` жолын `did` + `n't` етіп бөліп, терістеуді көрінетін күйде қалдырады. Бірақ `:)` бөліктерге бөлінеді.
- **`TweetTokenizer`** әлеуметтік желілерге арналған. Осы төрт мысал ішінде тек ол `:)`, `#nlp` және `@ai_lab` бірліктерін тұтас сақтайды. Ол `Dr.` пен `U.S.A.` бірліктерін де бөледі.

Барлық кіріске бірдей ең жақсы токенизатор жоқ. Деректер мен есепке сай келетінін таңдаңыз.
