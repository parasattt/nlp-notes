## Орысша мәтін токенизаторы

Лекция `razdel` құралын шағын әрі жылдам орысша токенизатор ретінде ұсынады. Мұндағы қазақша мысалдарда да ол жеткілікті жақсы жұмыс істейді, өйткені тыныс белгі ережелері ұқсас. Бұл — лекция мысалдары туралы тұжырым, барлық қазақша мәтінге берілген кепілдік емес.



Бастапқы орнату командасы `razdel` дайындайды; осы конвертация кезінде орнату жасалмайды.

```python
!pip install razdel --quiet
print("done")
```



`sentenize` сөйлем аралықтарын, ал `tokenize` токен аралықтарын қайтарады; `.text` әр аралықтың мәтінін оқиды. Тыныс белгілері жеке токендер ретінде көрініп қалады.

```python
from razdel import tokenize as rz_tokenize, sentenize as rz_sentenize

print("RU sentences:", [s.text for s in rz_sentenize(ru)])
print("RU tokens   :", [t.text for t in rz_tokenize(ru)])
print()
print("KK sentences:", [s.text for s in rz_sentenize(kk)])
print("KK tokens   :", [t.text for t in rz_tokenize(kk)])
```


**Сақталған нәтиже:**

```text
RU sentences: ['Мы купили два новых ноутбука в магазине.', 'Они работали отлично!']
RU tokens   : ['Мы', 'купили', 'два', 'новых', 'ноутбука', 'в', 'магазине', '.', 'Они', 'работали', 'отлично', '!']

KK sentences: ['Мен дүкеннен екі жаңа кітап сатып алдым.', 'Достарыма бердім!', 'Олар қуанды.']
KK tokens   : ['Мен', 'дүкеннен', 'екі', 'жаңа', 'кітап', 'сатып', 'алдым', '.', 'Достарыма', 'бердім', '!', 'Олар', 'қуанды', '.']
```



Сақталған нәтиже осы үш қазақша сөйлемді дұрыс бөледі. Бірақ бұл әлі тек **мәтінді бөлу**. `кітап` пен `кітаптарымызда` бір негізден шыққанын тану — [[KAZ/Lectures/5 - Стемминг және лемматизация/5.13 - Қазақ тіліндегі агглютинация|стемминг пен лемматизацияда]] қаралатын басқа есеп.
