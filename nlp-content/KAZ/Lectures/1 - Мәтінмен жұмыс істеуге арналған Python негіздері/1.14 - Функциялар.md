### Функциялар

**Функция** қайта қолданылатын код бөлігіне атау береді. Бір нұсқауларды көшіре бермей, оны әртүрлі кірістермен қайта шақыруға болады.



```python
def clean_text(text):
    """Lowercase the text and strip surrounding whitespace."""
    # Hello
    return text.strip().lower()



print(clean_text("   HELLO World   "))
print(clean_text("  Another EXAMPLE "))
```


**Сақталған нәтиже:**

```text
hello world
another example
```



Функция анықтамасын былай оқыңыз:

- `def` функция анықтамасын бастайды.
- `clean_text` — оның атауы.
- `text` — **параметр**, яғни шақырушы беретін кіріс мәні.
- Шегіністі нұсқаулар **денені** құрайды.
- `return` нәтижені шақырушыға қайтарады. Мән қайтармаған функция `None` қайтарады.
- Үш тырнақшадағы жол — **docstring**, құжаттама жолы. Notebook ішіндегі `clean_text?` анықтама командасы оны көрсете алады.

Бірнеше бірдей жолды қайта-қайта көшіріп жүрсеңіз, оларды функцияға біріктіруді ойлаңыз.



```python
def count_words(text):
    return len(text.split())

def average_word_length(text):
    words = text.split()
    if len(words) == 0:          # guard against dividing by zero
        return 0
    total = sum(len(w) for w in words)
    return total / len(words)


sample = "Natural language processing is mostly data cleaning"
print(count_words(sample))
print(round(average_word_length(sample), 1))
```


**Сақталған нәтиже:**

```text
7
6.4
```

`count_words()` бос орынмен бөлінген бөліктерді санайды. `average_word_length()` мәтінді бөледі, нөлге бөлмеу үшін бос тізімде `0` қайтарады, таңба ұзындықтарын қосады да, сөз санына бөледі. Сақталған мысалда **7 сөз** бар, олардың дөңгелектелген орташа ұзындығы — **6.4**.



```python
# Default values for parameters
def preview(text, n=30, p = 10):
    if len(text) <= n or not len(text) > n+p:
        return text
    return text[:n+p] + "..."


long_text = "Python is a programming language that is widely used in data science and NLP"
print(preview(long_text))
print(preview(long_text, 50, 50))
print(preview(long_text, n=10, p=5))
```


**Сақталған нәтиже:**

```text
Python is a programming language that is...
Python is a programming language that is widely used in data science and NLP
Python is a pro...
```

`n=30` және `p=10` — параметрлердің әдепкі мәндері. Осы функция қысқарту ұзындығы ретінде тек `n` емес, **`n + p` қолданады**. Мәтін осы шекке сыйса, бастапқы мәтінді қалдырады; әйтпесе `text[:n+p]` алып, `"..."` қосады.

Алғашқы шақыру 40 таңбалық шекті қолданады. Екіншісі `50, 50` беріп, шекті 100-ге жеткізеді, сондықтан сақталған нәтиже — толық мәтін. Атаулы аргументтері бар шақыру `10 + 5 = 15` қолданып, сақталған `Python is a pro...` үзіндісін береді.
