#### Индекстер және тілімдер

Жолдағы орындар **0** санынан басталады. Индекс бір таңбаны таңдайды. `[start:end]` тілімі `start` орнындағы таңбаны қосады да, `end` орнына **жетпей** тоқтайды.

Бастапқыда осы шекара ережесінен қателесу оңай. `word[0:4]` ішінде 0, 1, 2 және 3 орындары бар, ал 4-орын кірмейді.



```python
word = "language"
#       01234567

print(word[0])     # first character
print(word[3])     # fourth character
print(word[-1])    # last character
print(word[-2])    # second to last
```


**Сақталған нәтиже:**

```text
l
g
e
g
```



```python
print(word[0:4])   # characters 0,1,2,3 -> 'lang'
print(word[:4])    # same thing, start is optional
print(word[4:])    # from 4 to the end
print(word[::-1])  # reversed
```


**Сақталған нәтиже:**

```text
lang
lang
uage
egaugnal
```

Теріс индекстер соңынан кері санайды: `-1` — соңғы таңба. Тілімнің басын не соңын көрсетпеу жолдың сәйкес шетіне дейін алуды білдіреді. `[::-1]` ішіндегі `-1` қадамы жолды кері оқиды.
