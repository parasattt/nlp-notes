```python
review = "The service was slow but the food was excellent"

print(review.startswith("The"))
print(review.endswith("."))
print("food" in review)            # substring test - very common
print(review.count("was"))
print(review.find("food"))         # position, or -1 if not found
```


**Сақталған нәтиже:**

```text
True
False
True
2
29
```

`startswith()` және `endswith()` жолдың басы мен соңын тексереді. `in` ішкі жолды кез келген жерден іздейді. `count("was")` екі кездесуді табады, ал `find("food")` оның алғашқы таңбасының `29` орнын береді; табылмаса, `-1` қайтарар еді.



`in` операторы бір жолдың екіншісінің ішінде бар-жоғын тексереді. Бұл қарапайым **кілт сөз іздеуін** береді.
