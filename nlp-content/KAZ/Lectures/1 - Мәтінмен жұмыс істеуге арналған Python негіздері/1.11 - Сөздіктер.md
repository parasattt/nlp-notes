### Сөздіктер

**Сөздік** **кілттерді** **мәндермен** байланыстырады. Мәтіндегі жиі қолданысы — сөздерді санау: кілт — сөз, ал мән — оның кездесу саны.



```python
counts = {"the": 12, "cat": 3, "sat": 1}

print(counts["the"])
print(len(counts))

counts["mat"] = 5          # add a new key
counts["the"] = 13         # change an existing one
print(counts)
```


**Сақталған нәтиже:**

```text
12
3
{'the': 13, 'cat': 3, 'sat': 1, 'mat': 5}
```

`counts["the"]` кілт бойынша мәнді табады. `len(counts)` мәндерді қоспай, кілттерді санайды. Жаңа кілтке меншіктеу оны қосады, ал бар кілтке меншіктеу бұрынғы мәнін ауыстырады.



```python
# Asking for a missing key is an error.
print(counts["dog"])
```


**Notebook ішінде сақталған қате:**

```text
---------------------------------------------------------------------------
NameError                                 Traceback (most recent call last)
/tmp/ipykernel_4071/2830354060.py in <cell line: 0>()
      1 # Asking for a missing key is an error.
----> 2 print(counts["dog"])

NameError: name 'counts' is not defined
```

**Сақталған нәтижедегі сәйкессіздік:** сабақ жоқ кілт қатесін көрсетуді көздейді. Егер `counts` жоғарыда анықталғандай бар болса, `counts["dog"]` сұрауы `KeyError` қатесін берер еді. Бірақ сақталған traceback `NameError: name 'counts' is not defined` дейді: бұл сақталған қате шыққан сеанста `counts` болмағанын білдіреді. Бастапқы код пен нақты сақталған қате бірге берілген.



```python
# .get() is the safe version: returns a default instead of crashing.
print(counts.get("dog"))         # None
print(counts.get("dog", 0))      # 0  <- this is the useful one for counting
print("dog" in counts)           # False
```


**Сақталған нәтиже:**

```text
None
0
False
```



```python
# Looping over a dictionary
for word, n in counts.items():
    print(f"{word:>5} : {n}")
```


**Сақталған нәтиже:**

```text
  the : 13
  cat : 3
  sat : 1
  mat : 5
```

Кілт жоқ болса, `.get("dog")` `None` қайтарады, ал `.get("dog", 0)` әдепкі мән ретінде нөл береді. `"dog" in counts` кілттерді тексереді. `.items()` циклге `(key, value)` жұптарын береді, ал `:>5` сөзді ені бес таңбалық өрістің оң жағына туралайды.
