#### f-жолдар: мәндерді мәтінге кірістіру

Жолдың ашылатын тырнақшасының алдына `f` қойыңыз. Ішіндегі `{variable}` мәнді кірістіреді; фигуралы жақшаларда `name.upper()` немесе `len(name)` сияқты өрнектер де болуы мүмкін.

`:.1f` пішімі санды ондық нүктеден кейін бір таңбамен көрсетеді.



```python
name = "Aisha"
score = 87.6531

print(f"{name} scored {score} points.")
print(f"{name} scored {score:.1f} points.")   # .1f = one decimal place
print(f"{name.upper()} — {len(name)} letters")# any expression works inside braces
```


**Сақталған нәтиже:**

```text
Aisha scored 87.6531 points.
Aisha scored 87.7 points.
AISHA — 5 letters
```
