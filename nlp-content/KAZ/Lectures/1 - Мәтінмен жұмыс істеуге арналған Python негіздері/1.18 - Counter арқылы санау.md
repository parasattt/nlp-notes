```python
# Python has a built-in counter that does all of the above in one line.
from collections import Counter

counter = Counter(cleaned)
print(counter.most_common(5))
```


**Сақталған нәтиже:**

```text
[('the', 6), ('cat', 3), ('mat', 3), ('warm', 2), ('sat', 1)]
```

`Counter(cleaned)` тазаланған токендерден сөз санақтарын жасайды. `.most_common(5)` ең жиі бес `(word, count)` жұбын қайтарады. Сақталған нәтиже `('the', 6)` мәнінен басталады, одан кейін әрқайсысы үш рет кездескен `cat` және `mat` келеді.



Python басынан-ақ `Counter` арқылы санай алар еді. Бірақ алдымен қолмен құру бұл қысқа тәсілдің не істейтінін көрсетіп, кейін күтпеген нәтижелерді түсінуге көмектеседі.
