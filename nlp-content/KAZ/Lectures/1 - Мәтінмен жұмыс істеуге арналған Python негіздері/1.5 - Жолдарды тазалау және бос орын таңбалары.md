#### Іс жүзінде қолданылатын жол әдістері

Python ішінде жол әдістері көп. Келесі мысалдар мәтінді тазалау мен тексеруде жиі қолданылатын әдістерді таныстырады.



```python
messy = "   The Movie Was GREAT!!!   "

print(repr(messy.strip()))          # remove whitespace at both ends
print(messy.strip().lower())        # chain them together
print(messy.replace("GREAT", "good"))
print(messy.strip().split("Was"))        # split on whitespace into a list
```


**Сақталған нәтиже:**

```text
'The Movie Was GREAT!!!'
the movie was great!!!
   The Movie Was good!!!   
['The Movie ', ' GREAT!!!']
```

`strip()` шеттердегі бос орын таңбаларын алып тастайды, `lower()` регистрді өзгертеді, ал `replace("GREAT", "good")` дәл көрсетілген ішкі жолды ауыстырады. `.strip().lower()` тізбегі операцияларды кезекпен орындайды.

**Дереккөздегі ерекшелік:** соңғы код `.split("Was")` қолданады, сондықтан тура `Was` сөзі бойынша бөліп, `['The Movie ', ' GREAT!!!']` береді. Бастапқы түсініктеме «бос орындар бойынша бөлу» дейді; бұл сипаттама осындағы сақталған кодқа емес, аргументсіз `.split()` шақыруына сәйкес келеді. Бастапқы код та, түсініктеме де сақталған.



`repr()` жолды тырнақшалары мен escape-таңбалары көрінетіндей көрсетеді. Бұл бос орындарды тексеруге әсіресе пайдалы: соңындағы артық бос орын әдеттегі нәтижеде байқалмауы мүмкін, бірақ салыстыруды бәрібір өзгертеді.



```python
a = "cat "
b = "cat"
print(a == b)          # False - and you cannot see why from the printout
print(repr(a), repr(b))# now you can
print(a.strip() == b)  # True
```


**Сақталған нәтиже:**

```text
False
'cat ' 'cat'
True
```
