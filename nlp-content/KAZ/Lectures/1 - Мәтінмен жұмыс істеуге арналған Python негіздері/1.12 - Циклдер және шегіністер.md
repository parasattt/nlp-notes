### Циклдер

`for` циклі жинақтың әр элементі үшін денесін бір рет орындайды. Келесі мысалдар сөздер туралы ақпарат шығарады, сүзілген тізім құрады және элементтің орнын мәнімен бірге алу үшін `enumerate()` қолданады.



```python
words = ["cat", "elephant", "dog", "hippopotamus"]

for word in words:
    print(word, "has", len(word), "letters")
```


**Сақталған нәтиже:**

```text
cat has 3 letters
elephant has 8 letters
dog has 3 letters
hippopotamus has 12 letters
```



```python
# Building a new list as you go
long_words = []

for word in words:
    if len(word) > 3:
        long_words.append(word)

print(long_words)
```


**Сақталған нәтиже:**

```text
['elephant', 'hippopotamus']
```



```python
# enumerate() gives you the position as well as the item
for i, word in enumerate(words):
    print(i, word)
```


**Сақталған нәтиже:**

```text
0 cat
1 elephant
2 dog
3 hippopotamus
```

Кәдімгі цикл сөздерді ретімен қарайды. Екінші мысал бос тізімнен бастап, үш таңбадан ұзын сөздерді қосады. `enumerate(words)` сөздерді нөлден басталатын орындарымен бірге береді.



#### Шегініс — синтаксистің бөлігі

Python қай нұсқаулар циклдің не басқа блоктың ішінде екенін көрсету үшін **шегіністі** қолданады. Әдетте төрт бос орын алынады. Жабылатын фигуралы жақша не `end` кілт сөзі жоқ.

Келесі ұяшықта шегіністі `print()` әр сөз үшін орындалады. Соңғы шегініссіз `print()` циклден кейін бір рет қана орындалады.



```python
for word in ["a", "b", "c"]:
    print("inside the loop:", word)
print("outside the loop, runs once")
```


**Сақталған нәтиже:**

```text
inside the loop: a
inside the loop: b
inside the loop: c
outside the loop, runs once
```
