# Step 3: count
counts = {}
for w in cleaned:
    counts[w] = counts.get(w, 0) + 1

**Сақталған нәтиже:**

```text
{'the': 6, 'cat': 3, 'sat': 1, 'on': 1, 'mat': 3, 'was': 1, 'warm': 2, 'liked': 1, 'and': 1, 'slept': 1}
```



Маңызды санау үлгісі — `counts.get(w, 0) + 1`. Әр `w` сөзі үшін ағымдағы санын алыңыз; бұрын кездеспесе, нөл қолданыңыз; содан кейін бірді қосып, нәтижені сақтаңыз.



```python
# Step 4: sort by count, most frequent first
ranked = sorted(counts.items(), key=lambda pair: pair[1], reverse=True)

for word, n in ranked:
    print(f"{word:>6} : {n}")
```


**Сақталған нәтиже:**

```text
   the : 6
   cat : 3
   mat : 3
  warm : 2
   sat : 1
    on : 1
   was : 1
 liked : 1
   and : 1
 slept : 1
```



`lambda pair: pair[1]` — шағын атаусыз функция. Сөздіктің әр элементі — `(word, count)` жұбы, ал `pair[1]` оның санын таңдайды. Осы мән бойынша `reverse=True` арқылы сұрыптау ең жиі сөздерді алдына қояды.

Ең жиі сөздер — *the*, *cat* және *mat*. Мұнда *cat* пен *mat* мәтіннің не туралы екенін түсінуге көмектеседі, ал *the* тақырып туралы аз ақпарат береді. *the*, *a*, *is* және *and* сияқты жиі сөздер **стоп-сөздер** деп аталады.
