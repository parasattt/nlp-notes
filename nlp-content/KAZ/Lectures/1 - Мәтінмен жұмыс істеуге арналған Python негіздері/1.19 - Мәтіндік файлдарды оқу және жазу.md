### Мәтінді файлдан оқу

Бұл курста деректер ұяшықтарға терілген жолдардан ғана емес, файлдардан да келеді. Келесі ұяшықтар notebook таза машинада жұмыс істеуі үшін алдымен мысал файл жасайды, кейін бүкіл файлды және оның жолдарын оқуды көрсетеді.



```python
# First create a file to read, so this notebook works from a clean machine.
sample_text = """Product arrived on time and works perfectly.
Terrible quality, broke after two days.
Good value for the price, would buy again.
The packaging was damaged but the item was fine.
Absolutely useless, do not waste your money.
"""

with open("reviews.txt", "w", encoding="utf-8") as f:
    f.write(sample_text)

print("File created.")
```


**Сақталған нәтиже:**

```text
File created.
```



```python
# Read the whole file as one string
with open("reviews.txt", "r", encoding="utf-8") as f:
    content = f.read()

print(content)
```


**Сақталған нәтиже:**

```text
Product arrived on time and works perfectly.
Terrible quality, broke after two days.
Good value for the price, would buy again.
The packaging was damaged but the item was fine.
Absolutely useless, do not waste your money.
```



```python
# Read it as a list of lines - usually what you want
with open("reviews.txt", "r", encoding="utf-8") as f:
    lines = f.read().splitlines()

for i, line in enumerate(lines, start=1):
    print(f"{i}. ({len(line.split())} words) {line}")
```


**Сақталған нәтиже:**

```text
1. (7 words) Product arrived on time and works perfectly.
2. (6 words) Terrible quality, broke after two days.
3. (8 words) Good value for the price, would buy again.
4. (9 words) The packaging was damaged but the item was fine.
5. (7 words) Absolutely useless, do not waste your money.
```

`read()` бүкіл файлды қамтитын бір жолды жүктейді. `read().splitlines()` пікір жолдарының тізімін жасайды. `enumerate(lines, start=1)` көрсету үшін оларды 1-ден нөмірлейді, ал `len(line.split())` әр жолдағы бос орынмен бөлінген сөздерді санайды. Сақталған жол ұзындықтары — 7, 6, 8, 9 және 7 сөз.



Файлмен жұмыс істеу үшін `with open(...) as f:` қолданыңыз. Блок аяқталғанда, оның ішінде қате болса да, Python файлды жабады.

Әр файлда тек `"\n"` қолданылады деп есептемей, жолдарды `splitlines()` арқылы бөліңіз. Windows жол соңы `"\r\n"` түрінде болады; `splitlines()` оны әр жолға артық `"\r"` жабыстырмай өңдейді.
