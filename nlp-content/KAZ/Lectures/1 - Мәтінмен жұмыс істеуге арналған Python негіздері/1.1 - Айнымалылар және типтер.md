Бұл лекция бәрін басынан бастайды және Python тәжірибесін талап етпейді.

Мысалдардың көбі **мәтінмен** жұмыс істейді. Курс бойы сөйлемдер, пікірлер, мақалалар және хабарламалармен жұмыс істейсіз, сондықтан бұл мысалдар деректеріңіздің қандай болатынын таныстырады.

Notebook ұяшықтарды іске қосып, не болатынын көру үшін мысалдарды өзгертуді ұсынады. Кодты оқу пайдалы, бірақ оны сынап, қателерді түсіну — үйренудің маңызды бөлігі. Жазбаларда сақталған мысалдар мен нәтижелер қайта орындалмай берілген.



### Айнымалылар

**Айнымалы** — мәнге сілтейтін атау. Атауға мән меншіктеу үшін `=` қолданыңыз.



```python
course = "Natural Language Processing"
year = 2026
passing_grade = 50.0
is_fun = True

print(course)
print(year)
```


**Сақталған нәтиже:**

```text
Natural Language Processing
2026
```

Меншіктеулер жолды, бүтін санды, бөлшек санды және логикалық мәнді сақтайды. Ұяшық тек `course` және `year` шығарады; қалған мәндер notebook ортақ сеансында қолжетімді болып қалады.



Python әр мәннің **типін** автоматты түрде анықтайды: бұл айнымалыларды жасағанда типін жарияламайсыз. Дегенмен тип маңызды. Операция күткендей жұмыс істемесе, оны `type()` арқылы тексеріңіз.



```python
print(type(course))       # str   - text
print(type(year))         # int   - whole number
print(type(passing_grade))# float - number with a decimal point
print(type(is_fun))       # bool  - True or False
```


**Сақталған нәтиже:**

```text
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```



Атау таңдауда мына ережелер мен әдеттерді ұстаныңыз:

- Атауларда әріптер, сандар және `_` болуы мүмкін, бірақ атау саннан басталмайды.
- `WordCount` түріндегі атаудың немесе `wc` сияқты түсініксіз қысқартудың орнына `word_count` секілді астын сызу таңбасымен бөлінген кіші әріпті сөздерді таңдаңыз.
- Регистр маңызды: `Text` пен `text` — екі түрлі айнымалы.
- Түсінікті атау кейде түсініктемеден де көп ақпарат береді.

Келесі мысалдар мән типінің неге маңызды екенін көрсетеді.
