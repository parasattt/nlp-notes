### Шарттар

Әрекеттердің бірін таңдау үшін `if`, `elif` және `else` қолданыңыз. Әр шарт жолы қос нүктемен аяқталады, ал шегініс денесін көрсетеді. Python тармақтарды ретімен тексеріп, бірінші сәйкесін орындайды; `else` қалған жағдайды өңдейді.



```python
review = "The film was boring and far too long"
list_of_good_review_words = ["good", "amaing"]
list_of_bad_review_words = ["trash", "bad"]

if "excellent" in review or "great" in review:
    sentiment = "positive"
elif "boring" in review or "bad" in review:
    sentiment = "negative"
else:
    sentiment = "unclear"

print(sentiment)
```


**Сақталған нәтиже:**

```text
negative
```

Мысал `negative` таңдайды, себебі пікірде `"boring"` бар. Шарттың үстіндегі екі тізім, соның ішінде `"amaing"` жазылуы, дереккөзден сақталған; шешім қабылдағанда код бұл тізімдердің ешқайсысын қолданбайды.



Бұл — **кілт сөздерге негізделген тоналдық классификаторы**: таңдалған сөздер арқылы мәтінге оң, теріс не түсініксіз белгі береді. Алғашқы тоналдық жүйелері осындай жалпы тәсілді қолданған.

Бұл ережені оңай жаңылыстыруға болады. `"The film was not boring"` ішінде әлі де `"boring"` бар, сондықтан код оны теріс деп белгілер еді. Ол терістеуді түсінбейді. [[KAZ/Lectures/2 - Мәтіндік деректерге арналған Pandas/2.17 - Тоналдық ұпайлары және бастапқы әдісті бағалау|Көлемдірек бастапқы тоналдық әдісіне]] және кейін үйретілетін классификаторларға өткенде осы шектеуді есте сақтаңыз.



```python
# Comparison operators
print(5 > 3)
print(5 == 5)      # == compares, = assigns. Mixing these up is a classic error.
print(5 != 3)
print("a" < "b")   # strings compare alphabetically (by character code)

# Combining conditions
n = 7
print(n > 5 and n < 10)
print(n < 5 or n > 6)
print(not (n == 7))
```


**Сақталған нәтиже:**

```text
True
True
True
True
True
True
False
```

`==` мәндерді салыстырады, ал `=` мән меншіктейді. `!=` «тең емес» дегенді білдіреді. `and`, `or` және `not` жеке логикалық шарттарды біріктіреді не кері аударады. Жолдарды салыстыру таңба кодтарының ретін қолданады.
