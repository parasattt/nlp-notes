#### Бөлу және біріктіру: үнемі қажет екі операция

`split()` жолды бөліктер тізіміне айналдырады. Бөлгіш аргументі болмаса, бос орын таңбалары бойынша бөледі. `join()` тізімдегі жолдарды `.join()` алдындағы бөлгішпен бір жолға біріктіреді.

Мәтін өңдеудің жиі қолданылатын реті: мәтінді бөлу, бөліктерін өңдеу, қайта біріктіру. Осы бастапқы тәсілдің шектеулері [[KAZ/Lectures/3 - Мәтінді талдау және Regex/3.2 - Жол әдістерімен токенизация|жол әдістерімен токенизация]] тақырыбында берілген.



```python
sentence = "natural language processing is useful"

tokens = sentence.split()
print(tokens)

back_together = " ".join(tokens)
print(back_together)

with_dashes = "-".join(tokens)
print(with_dashes)
```


**Сақталған нәтиже:**

```text
['natural', 'language', 'processing', 'is', 'useful']
natural language processing is useful
natural-language-processing-is-useful
```



```python
# split() takes an argument if you do not want to split on spaces.
csv_line = "Aisha,Almaty,87"
print(csv_line.split(","))

path = "data/raw/reviews.txt"
print(path.split("/"))
```


**Сақталған нәтиже:**

```text
['Aisha', 'Almaty', '87']
['data', 'raw', 'reviews.txt']
```

Аргументсіз `split()` сөздерді бос орындармен бөледі. `","` берілсе, үтірмен бөлінген өрістерді, `"/"` берілсе, жолдың құрамдас бөліктерін бөледі. `.join()` алдындағы жол — бөлгіш, сондықтан `" ".join(tokens)` бос орындарды қайтарады, ал `"-".join(tokens)` дефистер кірістіреді.
