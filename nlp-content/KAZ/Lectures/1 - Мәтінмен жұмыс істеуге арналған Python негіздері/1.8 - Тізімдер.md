### Тізімдер

**Тізім** — реттелген жинақ. Мәтінді өңдеуде сөз тізімдері үнемі қолданылады. Жолдар секілді тізімдер де нөлден басталатын орындарды, соңынан саналатын теріс орындарды және тілімдерді қолдайды.



```python
words = ["the", "quick", "brown", "fox"]

print(words)
print(len(words))
print(words[0])
print(words[-1])
print(words[1:3])
```


**Сақталған нәтиже:**

```text
['the', 'quick', 'brown', 'fox']
4
the
fox
['quick', 'brown']
```



```python
words.append("jumps")       # add to the end
print(words)

words.insert(0, "and")      # add at a position
print(words)

words.remove("and")         # remove by value
print(words)

last = words.pop()          # remove and return the last item
print(last, "|", words)
```


**Сақталған нәтиже:**

```text
['the', 'quick', 'brown', 'fox', 'jumps']
```


**Notebook ішінде сақталған қате:**


Бұл операциялар тізімнің өзін өзгертеді: `append()` соңына қосады, `insert(index, value)` көрсетілген орынға кірістіреді, `remove(value)` сәйкес мәнді жояды, ал `pop()` әдетте соңғы элементті жойып, оны қайтарады.

**Сақталған нәтижедегі сәйкессіздік:** қазіргі дереккөзде `words.insert(0, "and")` бар, бірақ сақталған traceback бұрынғы `words.insert("and")` шақыруын көрсетеді. Ол шақыруда міндетті орын аргументі жетіспеген, сондықтан `TypeError: insert expected 2 arguments, got 1` қатесі шыққан. Тек алғашқы тізім мен осы қате сақталған. Кейінгі жолдардың сәтті нәтижелері ойдан қосылмайды.
